常见问题排错

[!abstract] 高频故障速查
按”现象 → 可能原因 → 排查命令 → 解法”组织，覆盖认证、权限、推送、合并、性能五大类。

1. 认证类

现象 排查 解法
SSH Permission denied ssh -v -p 29418 user@host gerrit version 公钥未注册/用户名错/私钥路径
HTTP 登录跳转死循环 看 nginx X-Forwarded-* 头 补齐头并改 proxy-http://
无法成为任意账号 auth 类型是 HTTP 换 DEVELOPMENT_BECOME_ANY_ACCOUNT（测试）或 SSO

2. 权限类

现象 排查 解法
push 被拒 not permitted 检查 refs/for/* 权限 给组加 Push 权限（05-权限与组）
无法 Submit 缺 Submit 权限或 -2 未清 检查标签与 Submit 规则
CI 回写被拒 检查 Verified 权限 jenkins 账号加 Verified
匿名能看到私有仓库 All-Projects 的 Anonymous Read 收紧全局 Read

3. 推送与 Change 类

现象 排查 解法
每次 push 生成新 Change 缺 Change-Id 安装 commit-msg hook / 开启 require-change-id
missing Change-Id 报错 hook 未生效 git commit --amend 补上
合入后历史是乱序 merge submit-type 配置 改 FAST_FORWARD_ONLY（要线性）
push 超时 大仓库首次 服务端 git gc、HTTP 隧道或分批

4. 同步/复制类

现象 解法
复制卡队列 目标 SSH 不通 / 公钥失效 / 磁盘满
副本滞后 调大线程池、缩短 replicationDelay
对账不一致 手动 replication start --wait <project>

5. 性能类

现象 解法
搜索慢 gerrit flush-caches --cache change / 重建索引
diff 加载慢 调大 cache.diff 内存；索引换到 SSD
内存飙高 调 container.javaOptions -Xmx，观察 GC
推送巨慢 仓库 git gc；关闭无关 hook

6. 日志位置

[!tip] 万能排查顺序

  1. error_log 最新条目；
  2. 复现并打开浏览器开发者工具看 API 状态码；
  3. 权限页核对 ACL；
  4. 查官方文档/社区（gerrit-review.googlesource.com）。

[!warning] 注意
涉及配置修改（gerrit.config）需重启；权限（Access 页）在线生效；索引重建要停写或接受短暂不可用。
