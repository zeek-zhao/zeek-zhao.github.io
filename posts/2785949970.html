数据库基础与 SQL 入门

[!info] 本页概览
本文讲解数据库核心概念：关系型数据库、SQL 分类（DDL/DML/DQL/DCL）、SQL 基本语法（SELECT/INSERT/UPDATE/DELETE）、数据类型与常用函数，配可运行示例。

核心概念

  • 数据库（DB）：按数据结构组织、存储和管理数据的仓库。
  • 数据库管理系统（DBMS）：管理数据库的软件，如 MySQL、PostgreSQL、Oracle。
  • 关系型数据库（RDBMS）：以二维表（行+列）存储数据，用 SQL 操作。
  • 表（Table）：行（记录）+ 列（字段）；主键唯一标识一行。
  • SQL：结构化查询语言，分为 DDL（定义）、DML（操作）、DQL（查询）、DCL（控制）。

SQL 分类

类别 作用 代表命令
DDL 定义库表结构 CREATE、ALTER、DROP
DML 操作数据 INSERT、UPDATE、DELETE
DQL 查询数据 SELECT
DCL 权限控制 GRANT、REVOKE

金额一律用 DECIMAL，禁止用 FLOAT/DOUBLE（浮点精度丢失）。

常见坑

  1. 字符集不一致导致乱码：库/表/连接统一 utf8mb4。
  2. NULL 参与运算结果 NULL：用 IFNULL(col, 0) 或 COALESCE。
  3. SELECT * 滥用：按需取列，减少 IO 与网络传输。
  4. 隐式类型转换：WHERE phone = 13800138000 会使索引失效，用字符串。
  5. 保留字不加反引号：如 order、group，用 ` 包裹。

最佳实践

  • 表名/字段名统一小写下划线风格（snake_case）。
  • 必须有主键；业务字段加 NOT NULL + 默认值。
  • 每张表建议含 created_at / updated_at。
  • 先设计表结构再写代码，字段变更成本高。
