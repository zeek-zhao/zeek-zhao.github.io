20-数据库访问

发表于2026-10-25|groovy
|浏览量:

[!info] 本节目标
Groovy 简化 JDBC 访问，学习数据库操作与查询 DSL。

1. JDBC 基础

Groovy 使用 java.sql 驱动连接数据库，Sql 类封装连接与查询。加载驱动、建立连接、执行 SQL 与 Java 流程一致但代码更短。

Sql.withInstance 管理连接生命周期，自动关闭资源。

2. Sql 查询

Sql 的 rows 方法执行查询返回行列表，eachRow 逐行处理。查询结果行为 Map 或对象，列名直接访问。

参数化查询用问号占位符或命名参数，避免 SQL 注入，是数据库访问的铁律。

3. 增删改操作

executeInsert 返回生成的主键，executeUpdate 执行更新删除，execute 执行任意 SQL。批量操作用 withBatch 提升性能。

事务管理通过 withTransaction 包裹，保证一致性。

4. 存储过程与函数

Sql 支持调用存储过程与函数，通过 CallableStatement 传参与取返回。复杂业务逻辑封装在数据库时配合使用。

存储过程返回结果集与输出参数的处理要仔细验证。

5. 与 ORM 集成

Grails 的 GORM 提供对象关系映射，支持动态查找、关联与事务。数据库访问在框架场景下优先使用 ORM。

纯脚本或轻量场景直接用 Sql 类即可，避免引入过重依赖。

6. 数据库实践

连接串与凭据通过配置或环境变量注入，禁止硬编码；查询结果注意列名大小写；大批量数据用流式处理避免内存溢出。

为每个数据源建立测试用例，验证连接、查询与事务行为。

7. 数据库访问实战

报表统计查询用 Sql 的 eachRow 流式处理大量行，聚合结果在内存中二次加工，避免一次性加载全部数据。

批量导入用 withBatch 提交批次，配合事务控制，导入中途失败可整体回滚，数据一致性有保障。

连接池管理连接生命周期，数据库参数（超时、重试）统一配置；生产环境开启慢查询日志定位性能瓶颈。
