tf 坐标变换

[!info] 本节目标
理解 tf/tf2 坐标树模型，掌握静态与动态坐标变换的发布、监听与常见 API。

1. 什么是 tf

机器人各部件（底盘、激光、相机、机械臂末端）都有独立坐标系。tf（transform library）负责维护这些坐标系之间的变换关系，让任何坐标可以在任意坐标系间转换。

[!note] tf 与 tf2
tf 是 ROS1 早期实现，tf2 是新一代（Noetic 默认 tf2）。API 基本兼容，新代码一律用 tf2。

2. 坐标树概念

  • frame：坐标系，如 base_link、laser。
  • transform：两坐标系间的平移+旋转（TFMessage）。
  • 树结构：每个 frame 有唯一父 frame，形成无环树。
  • 时间戳：变换带时间，用于历史查询与预测。

[!warning] 必须有树根
坐标变换必须构成树，不能有环。最顶层通常为 map 或 odom。

3. 常用工具命令

[!tip] rviz 查看
rviz 中可勾选 TF 显示整棵坐标树，直观确认变换是否正常（见 14-rviz可视化）。

8. 常用转换 API

API 作用
buffer.lookupTransform(target, source, time) 查询变换
buffer.transform(point, target_frame) 变换坐标点
buffer.canTransform(target, source, time) 判断是否可用
tf2_ros.TransformBroadcaster 广播变换
tf2_ros.StaticTransformBroadcaster 广播静态变换

9. 常见问题排查

症状 原因
“Lookup would require extrapolation into the past” 时间戳未来/过去超出缓存，用 latest common time
“Frame X does not exist” 该 frame 未发布（缺 static_transform_publisher 或 URDF）
TF 树断裂 某些 link 缺变换
坐标跳动 时间不同步（检查 use_sim_time 与 bag 回放时钟）

[!danger] 时间同步
仿真或 bag 回放时，务必设置 use_sim_time=true 并让各节点使用仿真时钟，否则 tf 与数据时间错乱（见 34-常见问题排查）。
