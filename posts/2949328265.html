05-Recipe（BB文件）语法

发表于2026-10-24|yocto
|浏览量:

[!info] 本节目标
掌握编写 Recipe 的必备语法与常用变量，能够创建自己的软件配方。

1. Recipe 是什么

Recipe（.bb 文件）描述如何获取、编译、安装一个软件组件，包括版本、源码地址、依赖、构建步骤与打包信息，是 Yocto 最基本的单元。

2. 必需变量

变量 作用
SUMMARY 简短描述
DESCRIPTION 详细描述
LICENSE 许可证
SRC_URI 源码来源
SRCREV 源码版本（git 时）
S 源码目录
DEPENDS 构建依赖

3. 完整示例

4. 变量展开

BitBake 支持立即展开（=）、延迟展开（:=）、追加（+=）与覆盖（_append/_prepend/_remove）。理解变量展开时机是编写可靠配方的基础。

5. 类与继承

配方可通过 inherit 继承通用类，如 autotools、cmake、meson、pkgconfig 等，大幅简化构建步骤。

6. 调试配方

使用 bitbake -e 查看展开后的完整环境，使用 -c devshell 进入手动调试环境，结合 log.do_compile 等日志定位问题。

7. 常用变量补充

除基础变量外，常用变量还包括：PV 与 PR 定义版本与修订；PACKAGES 定义包拆分；FILES 定义每个包包含的文件；RDEPENDS 定义运行时依赖；EXTRA_OECMAKE 等传递构建系统参数；PACKAGECONFIG 提供特性开关。正确使用这些变量可精细控制配方行为。查阅 Reference Manual 变量章节可获得完整说明。

8. 版本与覆盖语法

现代 BitBake 推荐使用覆盖语法如 VAR:append、VAR:prepend、VAR:remove，替代旧式 _append/_prepend/_remove 写法。覆盖语法在变量展开时应用，语义更清晰且不易出错。配方版本控制采用 PV 与下游 bbappend 配合，为产品定制保留扩展入口，详见 bbappend 与补丁篇。

9. 配方编写练习

编写配方建议循序渐进：先创建简单 hello 程序配方，验证 fetch 与 compile 流程；再增加 install 与打包配置；随后引入依赖、补丁与打包拆分。每步通过 bitbake 构建验证，使用 devtool 辅助调试。练习中体会变量展开与任务顺序，积累配方编写经验，再逐步扩展至复杂软件集成场景。

10. 本节小结

Recipe 语法是 Yocto 定制的基础。结合后续 Layer 机制与 bbappend 篇学习，可构建完整的配方定制能力。
补充：变量展开与覆盖语法需在真实构建中验证效果，建议结合示例配方练习，逐步形成编写规范。
