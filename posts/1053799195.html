qt 90-资料索引指南

发表于2026-10-24|qt
|浏览量:

[!info] 本节目标
汇总 Qt 官方文档、课程、论坛与社区高质量资料，为学习与开发提供导航。

1. 官方文档中心

doc.qt.io 是 Qt 最权威的信息源，包含 API 参考、教程、概览与迁移指南。查类与函数直接搜索文档中心，Qt Creator 中按 F1 可即时查阅离线文档。文档随版本更新，优先以官方域名为准。

2. 官方学习平台

Qt Academy 是官方免费在线学习平台，提供可视化交互课程，覆盖设计、开发与测试方向。课程按难度分级并给出评分，完成推荐路径课程可获结业证书。适合系统学习与快速上手。

3. 官方社区与代码

Qt Forum 是官方讨论板，获取专家指导与问题解答。Qt Wiki 由社区维护，包含贡献指南与技术文章。code.qt.io 与 code.woboq.org 提供源码在线查看，深入原理必读。

4. 中文社区

QTCN 开发网是国内最早最活跃的 Qt 中文社区，版块覆盖基础、嵌入式、QML 与发布，答疑氛围好。Qter 开源社区提供图文原创教程与开源作品，适合零基础入门。CSDN Qt 论坛与知乎专栏汇聚海量经验文章。

5. 高质量博客

豆子空间《Qt 学习之路》系列是经典入门教程，一去二三里与 feiyangqingyun 提供大量实战示例，QtDebug 电子书式教程系统完整。博主文章质量参差，结合官方文档交叉验证。

6. 推荐书籍

入门可选《Qt Creator 快速入门》与《Qt 5.9 C++ 开发指南》，经典进阶读《C++ GUI Qt 4 编程》与《Qt 高级编程》，QML 方向首选《Qt Quick 核心编程》。免费在线书 QmlBook 含中文版，GitHub 可获取。

7. 扩展资源

QCustomPlot 与 QWT 提供图表控件，Awesome-Qt 汇总开源资源，Inqlude 收录 Qt 库档案。视频教程 B 站与 Udemy 提供可视化学习，开源项目源码是工程化实践范本。国内镜像加速安装包下载。

8. 使用建议

查 API 与语法优先官方文档，系统学习用 Academy 课程，疑难问题结合 Forum 与中文社区，验证信息以 .qt.io 域名为准。建立遇到问题先查文档再搜社区的习惯，实践项目巩固所学。
