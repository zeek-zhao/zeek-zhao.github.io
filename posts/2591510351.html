Shell 资料索引指南

[!important] 使用说明
本指南整理 Shell 脚本学习所需的官方文档、经典书籍、在线教程、GitHub 仓库与中文资源，按”入门→进阶→精通”组织，配合本目录 22 篇教程使用。

一、官方文档（权威首选）

资源 地址 说明
GNU Bash 官方手册 https://www.gnu.org/software/bash/manual/ Bash 权威参考（含 Parameter Expansion 全章）
Bash Reference Manual (中文) https://www.gnu.org/software/bash/manual/bash.html 英文原版
POSIX Shell 标准 https://pubs.opengroup.org/onlinepubs/9699919799/ 可移植脚本规范
Linux man 手册 man bash、man grep 等 本地速查

二、经典书籍

书名 作者 定位
《Linux命令行与Shell脚本编程大全》 Richard Blum 入门经典
《Shell脚本学习指南》 Arnold Robbins 系统全面
《Unix Shell Programming》 Kochan & Wood 经典教材
Bash Cookbook O’Reilly 实战配方
《ABS Guide》 Mendel Cooper 进阶参考

三、免费在线教程

资源 地址 特点

Bash Hackers Wiki https://wiki.bash-hackers.org/ 深入语法
ShellCheck https://www.shellcheck.net/ 在线静态检查（必备）
ExplainShell https://explainshell.com/ 解释复杂命令
Devhints Bash https://devhints.io/bash 速查表

仓库 地址 简介

项目 地址/命令 用途

六、中文教程

资源 地址 说明
阮一峰 Bash 教程 https://www.ruanyifeng.com/blog/2017/07/bash-guide.html 中文入门精品
鸟哥的 Linux 私房菜 https://linux.vbird.org/ 经典中文 Linux 教程
菜鸟教程 Shell https://www.runoob.com/linux/linux-shell.html 语法速查
廖雪峰 Shell 教程 https://liaoxuefeng.com/books/shell/ 简明入门
B 站 Linux 运维教程 搜索”Shell 脚本 从入门到精通” 视频教学

七、学习路线建议

  1. 入门：阮一峰 Bash 教程 + 本目录 01-05；会写简单脚本。
  2. 核心：BashGuide + 06-12；掌握函数、数组、文本处理、调试。
  3. 实战：13-22 项目练习；用 ShellCheck 检查每个脚本。
  4. 精通：阅读 GNU Bash Manual 的 Parameter Expansion 与内部命令章节；研究 pure-bash-bible 技巧。
  5. 工具链：jq/yq 处理数据，flock 防并发，systemd 管理服务。

[!tip] 核心理念
Shell 的价值在”组合与自动化”。先精通常用命令（grep/sed/awk/find），再学脚本组织，最后落到真实运维场景（部署、监控、备份、CI）。
