文件与 JSON

[!info] 本页概览
数据处理离不开文件读写与 JSON 编解码。本文讲解 os 文件操作、io.Reader/Writer 抽象、bufio 缓冲、encoding/json 的序列化反序列化与 CSV 处理。

核心概念

Go 的 IO 抽象基于 io.Reader（读）与 io.Writer（写）接口：一切可读可写对象（文件、网络连接、缓冲区）都实现这两个接口。JSON 通过结构体 tag 与反射完成映射。

常见坑

  1. os.ReadFile 读超大文件：一次性载入内存，大文件必须流式读（bufio.Scanner / io.Copy）。
  2. JSON 数字精度：float64 处理大整数/金额会精度丢失，用 json.Number 或字符串字段。
  3. JSON 字段名大小写：未加 tag 时默认用字段名（首字母大写），与约定不符。统一用 json:"xxx"。
  4. 忽略 Close 错误：defer f.Close() 丢弃错误可接受，但写入后必须检查 Flush/Sync 错误。
  5. Unmarshal 到 nil map/slice：反序列化空 JSON 时目标可能为 nil，先初始化再使用。
  6. 写入路径不存在：os.WriteFile 不自动建目录，需先 os.MkdirAll。

最佳实践

  • 文件路径用 filepath.Join 组合，避免分隔符平台差异。
  • JSON 解析前先 json.Valid 校验，或直接处理错误。
  • 大 JSON 用 json.Decoder 流式解析；大文件用 bufio。
  • 配置/交换数据优先 JSON；记录型数据用 CSV；复杂关系用数据库（见 database 目录）。
  • 用 io.Copy 高效复制文件，而不是手动循环读写。
