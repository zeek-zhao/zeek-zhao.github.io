资料索引指南

[!info] 本页概览
本文汇总 database 专题的学习资料与工具资源，按分类给出官方文档、教程与工具链接，供持续学习与查漏补缺。

官方文档

  • MySQL 官方文档：https://dev.mysql.com/doc/ —— 含参考手册、版本发布说明，是查语法与参数的权威来源。
  • PostgreSQL 中文文档：https://www.postgresql.org/docs/zh/ —— 官方维护的中文版手册，覆盖 SQL、管理、高级特性。
  • Redis 中文文档：https://redis.io/docs/zh/ —— 命令参考、持久化、集群与模块说明。
  • MongoDB 中文手册：https://docs.mongoing.com/ —— 社区维护的中文文档站，覆盖 CRUD、索引、聚合框架。
  • MongoDB 官方文档：https://www.mongodb.com/docs/ —— 英文权威文档。

进阶与架构资料

  • TiDB 文档：https://docs.pingcap.com/zh/ —— NewSQL 架构、部署运维、最佳实践。
  • Milvus 向量数据库：https://milvus.io/docs/zh/ —— 向量检索原理、部署、RAG 案例。
  • MySQL 高可用方案：MHA（https://github.com/yoshinorim/mha4mysql-manager）、Orchestrator（https://github.com/openark/orchestrator）。

工具与监控

  • Percona Toolkit：https://www.percona.com/software/percona-toolkit —— pt-query-digest、pt-table-checksum 等运维利器。
  • ProxySQL：https://proxysql.com/ —— 读写分离与查询路由中间件。
  • mysqld_exporter：https://github.com/prometheus/mysqld_exporter —— Prometheus 的 MySQL 指标采集器。
  • Grafana Dashboards：https://grafana.com/grafana/dashboards/ —— 社区现成 MySQL 监控面板。

学习路径建议

  1. 基础篇精读 01-数据库基础与SQL入门 至 07-SQL 优化，掌握 SQL 与索引。
  2. 工程篇学习 08-备份恢复、13-Redis 持久化与集群、18-读写分离与高可用。
  3. 运维篇按 19-运维监控 与 20-数据库安全与权限 搭建生产体系。
  4. 架构篇参考 21-分布式数据库与新技术，再按需深入 TiDB / 向量库。

[!note] 使用提示

  • 所有链接以官方文档为准，第三方教程注意版本差异。
  • 更新知识时用「资料索引」回查，避免记忆过时语法。
