dnsmasq 资料索引指南

[!info] 本节目标
汇总 dnsmasq 学习与运维的权威资料：官方文档、协议标准、社区资源与工具链。

官方资料

来源 地址 说明
dnsmasq 官网 https://thekelleys.org.uk/dnsmasq/doc.html 官方文档与 FAQ
dnsmasq man page https://thekelleys.org.uk/dnsmasq/docs/dnsmasq-man.html 全部参数参考
dnsmasq CHANGELOG https://thekelleys.org.uk/dnsmasq/CHANGELOG 版本变更
dnsmasq-dhcp man 同上站内 dhcp 文档 DHCP/TFTP 专项

协议与标准

  • RFC 1034/1035：DNS 基础协议
  • RFC 2131/2132：DHCP 与选项
  • RFC 2782：SRV 记录
  • RFC 4033-4035：DNSSEC 体系
  • RFC 6840：DNSSEC 校验澄清
  • RFC 1918：私有地址段（bogus-priv 依据）

社区与博客

  • GitHub：imp/dnsmasq 官方镜像仓库、jpillora/dnsmasq Web UI 镜像
  • OpenWrt 官方 Wiki：https://openwrt.org/docs/guide-user/base-system/dhcp_configuration
  • 知乎/CSDN：搜”dnsmasq 内网 DNS””dnsmasq 去广告”
  • 51CTO：dnsmasq 生产实践系列

工具链

  • dig / nslookup：标准查询工具（bind-utils/dnsutils）
  • dnsperf：DNS 压测工具
  • tcpdump / Wireshark：抓包分析
  • dnsproxy / odoh-client：DoH/DoT 转换
  • keepalived：VIP 高可用

典型参考配置

  • 官方示例：/usr/share/doc/dnsmasq/examples/dnsmasq.conf.example
  • OpenWrt 生成配置：/tmp/etc/dnsmasq.conf.cfg01411c
  • Docker 镜像：jpillora/dnsmasq（带 Web 管理界面）
