健康检查

[!info] 本节目标
掌握 homepage 的服务健康检查机制，让导航页成为内网服务的”状态面板”。

健康检查方式

homepage 支持多种探针：

方式 配置 说明
ping ping: nas.lan TCP 可达性探测
HTTP 通过 widget 的 url HTTP 状态码/内容检查
Docker docker.yaml 容器运行状态
专用 widget 各服务类型 深度状态（如 Grafana）

TCP ping 配置

探测成功显示绿色状态点，失败显示红色并附错误信息。

HTTP 健康检查

服务带 widget 时可配置 HTTP 探测：

不同服务类型的 widget 返回各自的指标（版本、告警数、用户数等）。

Docker 服务状态

挂载 docker.sock 后可展示容器状态：

页面显示容器运行状态与资源占用。

状态徽章与展示

  • 绿色：正常
  • 红色：异常/离线
  • 黄色：未知/受限
  • 卡片显示错误摘要，鼠标悬停查看详情

健康检查最佳实践

  • 关键服务全部配置 ping 或 widget
  • 内网服务用主机名而非公网地址探测
  • widget 密码用环境变量注入
  • 定期检查探针是否仍有效（地址变更）

常见问题

问题 处理
状态一直红色 用 curl 验证 widget url 与认证
ping 不通但可访问 防火墙禁 ICMP/端口、主机名解析
widget 报错 检查 API 路径与版本兼容
状态未知 确认探针配置字段拼写

[!tip] 价值
健康检查是 homepage 的核心亮点：导航页兼具监控面板能力，故障第一时间可见。
