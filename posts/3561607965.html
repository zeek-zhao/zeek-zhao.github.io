34-常见问题排查

常见问题排查

[!info] 本节目标
掌握 ROS1 高频问题的定位思路与常用诊断命令，快速解决编译、通信、TF、启动类故障。

1. 排查方法论

[!tip] 日志先行
先看 rosnode info、rostopic hz、rosrun rqt_console，多数问题不需要读源码即可定位。

2. 编译类问题

报错 原因/解决
Could not find package 未 source 或未安装依赖
fatal error: xxx.h: No such file CMake 缺 find_package 或头文件路径
catkin_make 一半失败 内存不足、删除 build 重来
Python.h: No such file 缺 python3-dev
链接错误 缺库 sudo apt install libxxx-dev

[!warning] 依赖安装
出现 ModuleNotFoundError / command not found 时先安装依赖再重试，不要反复改代码。

3. 通信类问题

现象 原因/解决
话题无数据 发布者未运行/remap 错/类型错
频率为 0 节点崩溃、数据源异常
跨机收不到 ROS_IP/ROS_MASTER_URI 错（见 28-多机器人协同）
QoS/缓冲满 queue_size 过小或消费者太慢

[!tip] 幽灵话题
rostopic list 出现但无数据的”僵尸话题”多来自已退出的发布者残留或 remap 残留，重启节点清理。

4. TF 类问题

报错 原因
Lookup would require extrapolation 时间不同步/未 set use_sim_time
No transform from ... to ... 节点未启动/TF 未发布
Transform cache memory 时间跳变/多次重新发布
TF 树断开 robot_state_publisher 配置错

[!warning] 时间戳
所有消息 header.stamp 必须与 TF 发布时间一致；仿真用 use_sim_time，真机用系统时间（见 33-仿真场景搭建）。

5. 启动（launch）类问题

报错 原因/解决
RLException: file does not exist launch 路径/$(find) 包名错
no such file or directory 资源文件路径用相对路径导致
参数未生效 <arg>/<param> 未正确传递
节点秒退 依赖服务未起，先启动依赖

[!tip] 分段启动
大 launch 拆成多个小 launch 分别启动，出错时能快速定位是哪个节点。

6. 运行时崩溃类

现象 原因/解决
节点频繁重启 段错误/空指针，看日志堆栈
内存暴涨 消息积压/循环发布
CPU 100% 忙等/无效循环/降频
随机崩溃 线程安全/时间戳极端值

[!danger] 空指针/段错误
C++ 节点崩溃常见于空消息、未判空；修复后务必在 rqt_console 确认无异常再上线。

7. 性能类问题

优化 说明
降频 高频传感器降频
压缩 图像 compressed（见 25-视觉处理）
精简 只跑必要节点（见 35-性能优化）
异步 回调不要做重计算，放线程池

8. 排查工具箱

工具 用途
rqt_graph 节点/话题关系
rqt_console 日志过滤
rosbag 录制回放复现
rostopic/rosnode/rosservice 通信诊断（见 05-命令行工具）
tf view_frames TF 树
rqt_reconfigure 动态调参

[!note] 延伸
系统化调试日志方法见 18-日志与调试；性能深入优化见 35-性能优化。
