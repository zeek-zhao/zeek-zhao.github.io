📑一句话

安装前提¶

Hexo 依赖两个基础工具，安装前请先确认：

  • Node.js（建议 LTS 版本）：Hexo 与全部插件都运行在 Node.js 之上。
  • Git：用于版本管理，也是 Git 部署方式的基础。

Windows 用户直接从官网下载安装包；Linux/macOS 用户可使用包管理器。以 Ubuntu 为例，建议通过 NodeSource 安装较新版本：
