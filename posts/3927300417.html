参数机制

[!info] 本节目标
掌握 ROS2 参数机制：声明、读写、动态修改、回调与参数文件持久化。

1. 参数概念

参数（Parameter）是节点内的键值配置项。每个节点维护自己的参数表，可被 ros2 param 命令或其他节点动态读取/写入。

参数类型 说明
bool 布尔
int / double 整数/浮点
string 字符串
array 上述类型的数组

[!note] 参数 vs ROS1
ROS1 有全局参数服务器，ROS2 参数归属于节点，不再有独立参数服务器。

2. Python 声明与读写

[!warning] 未声明读取
读取未声明参数会抛 ParameterNotDeclaredException；一律先 declare_parameter 再读取。

3. 参数动态回调

[!tip] 回调用途
动态修改参数时实时调整控制速率、话题频率等，无需重启节点。

[!note] 延伸
参数在 launch 中的完整用法见 19-launch系统；动态调参与控制相关可结合 33-实时性与QoS策略。

8. 参数管理最佳实践

参数应集中声明并在代码中给出合理默认值，运行时通过 ros2 param set 或动态调参工具调整，避免硬编码魔法数字。不同运行环境的差异（如传感器话题名、机器人尺寸）应全部参数化，配置文件随 launch 加载。注意参数是节点私有数据，跨节点共享数据仍应使用话题或服务。生产环境建议将参数文件纳入版本管理，并记录每次调参前后的效果对比，便于复现与回滚。

[!note] 建议
动态调参配合可视化工具可显著提升调试效率；节点参数与配置管理在生产部署中的用法见 38-产品化与部署实践。
