多分支流水线

[!abstract] 是什么
Multibranch Pipeline 自动扫描 Git 仓库的分支/标签/PR，每个分支生成独立 Job，跑各自分支的 Jenkinsfile。

创建多分支任务

  1. New Item → Multibranch Pipeline；
  2. 配置 Branch Sources：
  1. Discover branches：All branches（或排除 dev/* 等）；
  2. 保存后自动扫描并建出各分支 Job。

[!note] 核心收益
新分支推代码 → 自动出现对应构建；分支删除 → 构建记录清理。每个分支独立、互不干扰。

分支命名策略

[!tip] 常用环境变量
env.BRANCH_NAME 分支名；env.CHANGE_ID PR 号；env.CHANGE_TARGET PR 目标分支。

与 Gerrit 的差异

场景 Multibranch Gerrit Trigger
GitHub/GitLab PR 原生支持 需额外配置
Gerrit Change 不直接适用 专用触发器
分支多自动建 是 按需

[!warning] 注意
仓库扫描频率默认 1 分钟；扫描太频繁会耗资源，生产调大 Periodic folder triggering interval。
