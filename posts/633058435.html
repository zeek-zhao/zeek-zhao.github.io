C/C++ 资料索引指南

[!important] 使用说明
本指南整理 C/C++ 学习所需的官方文档、经典书籍、在线教程、GitHub 仓库与中文资源，按”入门→进阶→精通”路径组织，供配合本目录 22 篇教程使用。

一、官方文档（权威首选）

资源 地址 说明
cppreference（英文） https://en.cppreference.com/ C/C++ 标准库与语言特性最权威参考
cppreference（中文） https://zh.cppreference.com/ 官方翻译，中文学习者首选
ISO C++ 官网 https://isocpp.org/ 标准委员会新闻、FAQ、推荐书目
C++ 标准草案 https://eel.is/c++draft/ 实时跟进 WG21 标准草案

二、经典书籍

书名 作者 定位
《C Programming Language》（K&R） Kernighan & Ritchie C 语言鼻祖教材，薄而精
《C Primer Plus》 Stephen Prata 现代 C 入门友好教材
《C++ Primer》（第 5 版） Lippman 等 公认 C++ 入门圣经，覆盖 C++11
《Effective C++》/《More Effective C++》 Scott Meyers 55 条最佳实践
《The C++ Programming Language》 Bjarne Stroustrup C++ 之父手册型著作
《C++ Templates》 Vandevoorde 等 模板深度专著
《C++ Concurrency in Action》 Anthony Williams 并发编程权威

五、中文教程

B 站 / 中国大学 MOOC 搜索”C++ 哈工大/浙大” 高校公开课

六、学习路线建议

  1. 入门：选《C++ Primer》或 Learn C++，配合 cppreference 查词、菜鸟教程补语法。
  2. 巩固：TheAlgorithms、30-seconds-of-cpp 读代码，Exercism 做练习。
  3. 进阶：读《Effective C++》、现代 C++ 教程，掌握智能指针、移动语义、模板、并发。
  4. 精通：啃《C++ Templates》《C++ Concurrency in Action》，跟进标准草案，参与开源项目。
  5. 工具链：gcc/clang + CMake + gdb + ASan 是标准开发配置。

[!tip] 核心理念
官方文档（cppreference）是地基，经典书籍是骨架，GitHub 与教程是血肉。三者结合，由浅入深，方能从入门走向精通。
