常见坑

  1. Agent 端口未放行：9001 需从 Server 可达。
  2. TLS 配置错误：Agent 与 Server 证书不匹配。
  3. 环境离线：网络/Agent 容器停止，先检查。
  4. 权限未配：新环境默认所有用户可见，按组授权。
  5. 删除环境误删容器：移除环境不删除容器，但不可再管理。

最佳实践

  • 环境分组 + 标签标准化，与权限模型对齐。
  • Agent 模式适合内网多节点，Edge 适合边缘。
  • 生产环境独立分组并最小授权。
