进阶实践与排错

[!abstract] 本节目标
掌握生产级实践与常见故障排查思路。

生产实践清单

  • 镜像：优先官方镜像、固定版本标签、用多阶段构建（见 04-Dockerfile与镜像构建）；
  • 安全：容器以非 root 运行，避免明文密钥进镜像；
  • 资源限制：docker run -m 512m --cpus 1 限制内存与 CPU；
  • 健康检查：--health-cmd "curl -f http://localhost:3000/health"。

日志与监控

常见故障排查

现象 排查思路
容器启动即退出 docker logs 看报错；检查 CMD 是否前台运行
端口无法访问 -p 是否映射；docker port web 确认
拉取镜像超时 配置镜像加速器后重启 Docker
磁盘占满 docker system df、docker system prune 清理
容器间不通 确认同一自定义网络，用容器名访问

[!tip] 万能三步

  1. docker logs 看日志；2) docker exec 进容器手动验证；3) 用 docker inspect 查看配置细节。

[!warning] 清理需谨慎
docker system prune -a 会删除所有未使用镜像与容器，确认后再执行。
