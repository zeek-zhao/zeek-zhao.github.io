常用传感器驱动

[!info] 本节目标
掌握激光雷达、相机、IMU 等常见传感器在 ROS1 中的驱动安装、数据话题与配置校准。

1. 传感器接入通用流程

[!note] 关键点
驱动输出必须使用标准消息类型（sensor_msgs）并正确发布 TF，下游算法才能直接复用。

2. 激光雷达（2D LiDAR）

常见型号：RPLIDAR、Sick、Hokuyo、思岚 A1/A2、镭神等。

数据话题：

[!warning] frame_id
激光 frame（如 laser）必须与底盘 frame（base_link）建立 TF（static_transform_publisher 或 URDF），否则下游算法无法使用。

[!tip] 串口权限
USB 串口设备报 permission denied 时：sudo usermod -aG dialout $USER 后重新登录。

3. 相机（USB 相机）

常用参数：

话题 类型
/image_raw sensor_msgs/Image
/camera_info sensor_msgs/CameraInfo（内参）
/image_raw/compressed sensor_msgs/CompressedImage

[!warning] 带宽
1080p 30fps 原始图像带宽极大，远程/网络环境用 compressed 或降低分辨率（见 25-视觉处理）。

4. 深度相机

常见：RealSense、Kinect、奥比中光。

5. IMU

常见：MPU6050、BMI088、Xsens、轮趣等。

IMU 数据话题：

[!tip] IMU 标定
使用前建议标定零偏（静止采集均值），否则积分漂移明显。工具：imu_calib 或 imu_tools。

6. GPS

[!note] GPS 与 TF
GPS 经纬度需先转换到本地笛卡尔坐标（如 UTM）才能与 odom/map 对齐，常用 robot_localization 包融合。

7. 里程计（轮式编码器）

来源：底盘驱动节点发布，或差速模型从轮速推算（见 20-机器人运动学基础）。

8. 驱动配置检查清单

检查项 命令/方法
设备是否识别 ls /dev/ttyUSB* / lsusb
串口权限 加入 dialout 组
话题是否发布 rostopic list / hz
数据范围 rostopic echo /scan -n1
TF 是否完整 view_frames / tf2_echo
时间戳 与主时钟对齐

9. 传感器融合方向

[!note] 延伸
传感器数据在 rviz 的显示见 14-rviz可视化；仿真中传感器模拟见 15-Gazebo仿真。
