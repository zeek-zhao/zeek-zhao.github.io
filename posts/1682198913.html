磁盘管理

[!abstract] 用途
磁盘管理（Disk Management / diskmgmt.msc）用于查看物理磁盘、创建/删除分区、格式化卷、更改盘符、扩展卷、初始化新硬盘等，是存储管理的基础工具。

1. 打开方式

2. 核心概念

  • 磁盘：物理硬盘（Disk 0、Disk 1…）；
  • 分区：磁盘上的逻辑划分；
  • 卷/盘符：格式化后的分区以 C:、D: 等访问；
  • GPT / MBR：分区表格式（GPT 现代推荐，支持大容量、UEFI）；
  • 动态磁盘/基本磁盘：基本磁盘是默认。

3. 常用操作

4. 命令行与 PowerShell

[!warning] 危险操作
clean / 删除卷 / 格式化会永久丢失数据。执行前确认磁盘编号与盘符，重要数据先备份。

5. 常见场景

6. 注意事项

  • 系统盘（C:）不要随意压缩/删除分区；
  • NTFS 适合 Windows 主盘；移动盘可用 exFAT（跨平台）；
  • 磁盘管理无法缩小系统保留分区/超出相邻空间时需第三方工具；
  • 定期查看磁盘健康（SMART）：Get-PhysicalDisk | Select MediaType, HealthStatus。
