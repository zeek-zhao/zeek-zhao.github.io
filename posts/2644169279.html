面向对象基础

[!info] 本页概览
本文讲解 Java 面向对象核心：类与对象、构造器、封装（访问修饰符）、继承、多态（重写/重载）、static/final、this/super，配可运行示例与实战陷阱。

核心概念

  • 类：对象的模板（属性 + 行为）；对象：类的实例（new）。
  • 四大特性：封装、继承、多态、抽象。
  • 构造器：创建对象时初始化；可重载；无参构造器默认存在（除非定义了有参构造）。
  • 访问修饰符：public（任意）、protected（包内+子类）、default（包内）、private（类内）。

类与对象

封装

[!note] 封装价值
通过方法控制数据变更，可加入校验/日志/同步，隐藏内部实现。

继承

多态

  • 编译时多态：方法重载（overload），同名不同参。
  • 运行时多态：方法重写（override），父类引用指向子类对象。
  • instanceof 判断实际类型。

static 与 final

常见坑

  1. 构造器与无参默认值：定义了有参构造后，无参构造消失，new Xxx() 报错。
  2. 重写限制：子类重写方法访问级别不能低于父类；不能重写 static 方法（可隐藏）。
  3. super() 必须在构造器第一行：否则编译错误。
  4. final 类不可继承：如 String；final 方法不可重写。
  5. this 与 static 冲突：static 方法中不能使用 this。
  6. 构造器链：子类构造隐式调用父类无参构造，父类没有无参构造需显式 super(参数)。

最佳实践

  • 属性一律 private，通过 getter/setter 或业务方法访问（封装）。
  • 继承层次不超过 3 层，优先组合（has-a）而非继承（is-a）。
  • 用 @Override 注解标记重写方法，防止签名笔误。
  • 类职责单一（SRP），一个类只做一件事。
  • 用 record（Java 16+）定义简单不可变数据载体，减少样板代码。
