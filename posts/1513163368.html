DHCP 服务配置

[!info] 本篇目标
掌握 dnsmasq DHCP 配置：地址池、固定租约、option 下发、主机名自动解析与双栈支持。

1. 最小 DHCP 配置

[!warning] 端口要求
DHCP 服务监听 UDP 67，客户端广播到 255.255.255.255:67。dnsmasq 需监听对应接口且防火墙放行 67/udp，否则客户端拿不到地址。

2. option 下发

通过 dhcp-option 给客户端下发网络参数：

[!tip] option 编号
除名称外可用编号：option:router 即 option:3，dns-server 即 option:6。同一 option 可重复写多次下发多个值。

3. 固定租约（按 MAC 绑定）

[!warning] MAC 大写/小写
MAC 地址大小写不敏感，冒号或短横线分隔均可；某些设备（手机）使用随机 MAC，固定绑定需关闭 MAC 随机化或按 client-id 绑定。

4. 租约文件与管理

5. 主机名自动解析（DNS+DHCP 联动）

dnsmasq 的招牌功能：DHCP 分配后自动把 主机名 -> IP 写入内部 DNS，局域网内直接用主机名访问设备。

[!note] 自动解析依赖
动态设备能否解析取决于客户端是否上报主机名。Windows/macOS 一般会上报；部分 IoT 设备不上报则无法自动解析。

6. IPv6 / 双栈

[!danger] IPv6 谨慎
双栈配置容易踩坑（RA 与 DHCPv6 分工、前缀委派）。无 IPv6 需求的网络不要开启，避免客户端拿到不可达地址。

7. 常见模式

[!tip] 与 DNS 联动总结
DHCP option 下发 dns-server 指向 dnsmasq 自身 + 开启租约主机名解析，即可实现”自动分配 + 自动域名”的完整内网体验（见 06-hosts与域名解析）。
