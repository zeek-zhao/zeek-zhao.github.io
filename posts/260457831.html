04-开发环境搭建（Docker）

发表于2026-10-25|apollo
|浏览量:

[!info] 本节目标
使用官方 Docker 镜像搭建 Apollo 开发环境，掌握容器启动、环境初始化与验证方法。本篇承接 03-自动驾驶技术基础，是动手实践的第一步。

1. 硬件要求

项 最低配置 推荐配置
CPU Intel Core i7-6700K 及以上 Intel Xeon W-2133 及以上
内存 32GB 64GB
硬盘 500GB SSD 1TB SSD（预留 50GB+ 给镜像与缓存）
显卡 NVIDIA GTX 1080 RTX 2080 Ti / Tesla T4 及以上

车载平台推荐工业级 PC + NVIDIA AGX Xavier/Orin。

[!note] 2026 年更新
Apollo 系统支持 Ubuntu 18.04/20.04/22.04、CUDA 11.8；9.0 起支持 AMD ROCm 5.1 与 ARM Orin 平台。10.0 起支持物理机直接安装（不再强制依赖 Docker），但 Docker 方式仍是可复现性最好的开发环境，本篇以 Docker 为主线。

2. 软件环境准备

2.1 安装 Docker 与 NVIDIA 组件

2.2 获取 Apollo 源码

[!warning] 版本匹配
GitHub tag 止于 apollo-v9.0.0，10.0/11.0 经 Apollo 开放平台发布、落在 master 分支。源码版本必须与 Docker 镜像版本一致，否则编译与运行易出错，建议 pin commit。版本演进详见 02-版本发展与架构演进。

3. 启动开发容器

Apollo 提供 dev 与 runtime 两类镜像，开发阶段使用 dev 镜像：

dev_start.sh 会自动拉取与源码版本对应的镜像并挂载源码目录。脚本中可调整容器的内存与 CPU 参数；常见可选参数包括挂载额外数据目录、指定镜像 tag 等。

容器内外的工作方式：源码目录以挂载方式共享，容器内修改即宿主机可见；容器只提供统一的编译运行环境，可随时销毁重建而不损失源码——这也是推荐 Docker 方式的核心原因。

5. 磁盘与镜像管理

  • 查看镜像/容器：docker images、docker ps
  • 清理无用镜像与缓存：docker system prune
  • 配置镜像加速：在 /etc/docker/daemon.json 中设置 registry-mirrors 后重启 docker 服务
  • 清理后重建容器：dev_start.sh 会按需重新拉取镜像，无需手工干预

Apollo 镜像与构建缓存占用大量磁盘空间，建议预留 50GB 以上：官方镜像本体体积较大，加上 Bazel 缓存与构建产物，磁盘不足是新手最常遇到的环境问题。若主机显卡驱动较新而容器内内核模块不匹配，可能出现 GPU 不可用，应查阅官方文档确认驱动版本要求。

6. 网络与代理配置

开发常需访问 GitHub 与 Docker Hub，网络不稳定时建议配置代理。容器内需同步设置 http_proxy 与 https_proxy 环境变量；Docker 构建期的代理需单独配置。镜像拉取失败可切换镜像源，源码下载失败可使用镜像仓库。排查顺序：先确认 DNS 与连通性，再检查代理与防火墙。

7. 关于车载传感器配置的说明

本篇面向开发环境搭建，不需要真实车辆与传感器。若目标是将 Apollo 部署到实车，还需要配置传感器系统（激光雷达、相机、毫米波雷达、RTK/IMU、CAN 卡）并完成驱动接入与标定，这属于后期专题内容。开发阶段的仿真测试（Sim Control、record 回放）无需任何硬件即可覆盖绝大多数学习场景。

8. 常见问题排查

问题 解决方法
权限不足 将用户加入 docker 组：sudo usermod -aG docker $USER
端口冲突 修改 dev_start.sh 中的端口映射
挂载目录失败 确认源码目录路径与权限正确
GPU 不可用 检查主机驱动版本与 nvidia-docker2 安装
容器内命令不可用 先执行 source /apollo/scripts/apollo_base.sh
磁盘空间不足 docker system prune 清理旧镜像
镜像拉取超时 配置 registry-mirrors 或使用代理

[!tip] 学习提示
环境搭建是一次性成本，但版本匹配与网络问题占了新手报错的绝大多数。遇到报错先做三件事：确认源码与镜像版本一致、确认 GPU 驱动可用、确认网络代理生效，大部分问题会随之消失。环境就绪后，进入 05-源码编译与部署 编译第一个目标。若后续升级 Apollo 版本，本篇的验证清单应全部重跑一遍。
