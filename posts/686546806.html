selinux 90-资料索引指南

发表于2026-10-24|selinux
|浏览量:

[!info] 本节目标
汇总 SELinux 学习与实践所需的官方与社区权威资料。

1. NSA 官方资料

NSA 是 SELinux 的最初设计与开发机构，其发布的技术文档具有最高权威性。官方主页提供白皮书、FAQ、配置示例与策略开发指南，是理解设计初衷的最佳起点。白皮书系统阐述类型强制 TE、基于角色的访问控制 RBAC 与多级安全 MLS 的设计理念，适合入门阶段通读。

2. Red Hat 官方文档

Red Hat 是 SELinux 在企业级 Linux 中的主要实现与维护方，文档最为系统且贴近实际应用。安全加固指南中的 Using SELinux 章节覆盖启用禁用、模式切换、布尔值与文件上下文管理；SELinux 用户与管理员指南覆盖策略管理、审计日志分析、audit2why 与 audit2allow 使用以及定制化策略模块编写，是企业环境的首要参考。

3. 项目站点与 Wiki

SELinux 项目 Wiki 是社区维护的官方项目站点，包含策略语言规范与内核接口说明。Fedora 用户指南面向社区发行版提供实践教程且更新频繁，适合跟踪新特性。项目站点的 Getting Started 内容适合从零理解 DAC 与 MAC 的区别。

4. 权威书籍与参考手册

《SELinux by Example》是经典参考书籍，深入讲解策略编写与实战案例，适合系统化学习策略语言。《SELinux System Administration》从系统管理员视角覆盖审计、策略调试与容器场景，是实操手册优选。两本书结合官方文档可构建完整知识体系。

5. 社区与排障资源

Red Hat 知识库 KCS 提供大量针对特定问题的排错与最佳实践文章，适合遇到具体问题查阅。各大发行版论坛、Stack Overflow 与邮件列表积累丰富实战案例，搜索特定 avc denied 报错往往能快速定位相似问题与解法。

6. 学习路径建议

入门阶段阅读 NSA 白皮书与官方入门文档理解模型；进阶阶段学习 Red Hat 用户指南与书籍掌握工具链；实战阶段结合本书案例与 KCS 文章解决真实问题；持续跟踪 Fedora 与项目 Wiki 更新保持知识新鲜。
