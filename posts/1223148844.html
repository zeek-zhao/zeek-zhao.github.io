常见坑

  1. Edge 离线：Server 8000 不可达/防火墙拦截。
  2. 轮询延迟：操作后状态更新慢，耐心等待/手动刷新。
  3. 密钥泄露：Edge Key 泄露可被接管，及时轮换。
  4. privileged 风险：挂载 / 与 privileged 慎用，最小化。
  5. 多节点漂移：Agent 容器被误删，重新部署。

最佳实践

  • 边缘环境统一用 Edge Agent 接入。
  • Server 与 Edge 通信走 HTTPS。
  • 定期检查 Edge 在线状态与密钥。
  • 配合 03-环境管理、09-用户与团队权限。
