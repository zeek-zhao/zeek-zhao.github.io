组件高级模式

[!info] 本页概览
本文讲解 Vue 高级组件模式：动态组件、异步组件与 Suspense、递归组件、函数式组件（透传）、Provide 响应式、组件复用设计，构建复杂组件体系。

核心概念

  • 动态组件：<component :is="..."> 按需渲染不同组件。
  • 异步组件：defineAsyncComponent 懒加载，配合 Suspense。
  • 递归组件：组件自己调用自己（树形菜单、评论树）。
  • 组件扩展：attrs 透传、$slots、provide/inject。

组件复用设计

常见坑

  1. 动态组件不 keep-alive 状态丢失：切换后组件销毁重建；用 KeepAlive 缓存。
  2. 异步组件重复加载：defineAsyncComponent 内部缓存，无需手动防抖。
  3. 递归组件无限递归：无终止条件（children 空判断缺失）导致栈溢出。
  4. Suspense 未捕获异步错误：需 error 组件/onErrorCaptured 处理。
  5. attrs 覆盖冲突：inheritAttrs: false 时手动 v-bind 顺序影响优先级。
  6. 组件循环引用（父子互相 import）：异步组件或延迟 import 打破循环。

最佳实践

  • 大型/低频组件（富文本、图表、地图）用 defineAsyncComponent 分包。
  • 树/列表递归组件抽公共组件，children 结构统一。
  • 通用组件（弹窗、抽屉、表格）封装成”受控 + 事件”模式，接口稳定。
  • 用 provide/inject 传递跨层共享（主题、表单上下文），避免 prop 地狱。
  • 组件间通过插槽解耦：骨架由父组件决定，细节由子组件封装。
