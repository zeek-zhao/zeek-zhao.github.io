homepage 配置文件详解

发表于2026-10-22|homepage
|浏览量:

配置文件详解

[!info] 本节目标
掌握 homepage 各配置文件的职责与语法，能看懂并编写基础配置。

配置文件总览

homepage 使用多个 YAML 文件分离配置：

每个文件均可通过环境变量覆盖关键项（便于容器化）。

settings.yaml 详解

关键字段：

字段 作用
title 页面标题
language 界面语言
theme 主题（dark/light/custom）
layout 各组布局与列数
proxy 健康检查/抓取代理

services.yaml 详解

  • 分组名（如”我的服务”）作为一级标题
  • 每个条目至少需要 名称 与 href
  • icon 支持图标名或自定义 URL

bookmarks.yaml 详解

书签可嵌套多级，适合整理文档与资源。

环境变量覆盖

容器场景可用环境变量覆盖敏感配置（如 API Key）：

配置中引用：${HOMEPAGE_VAR_WEATHER_KEY}。

配置校验

  • homepage 启动时会检查 YAML 语法，错误会输出到日志
  • 修改配置后无需重启：页面自动热加载（部分组件需刷新）

快速入门最小配置

[!tip] 经验
配置遵循”小步迭代”：先写 2-3 个服务验证显示，再逐步添加图标、健康检查和组件，避免一次写大配置难排错。
