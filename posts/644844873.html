Elasticsearch 核心概念与安装

[!abstract] 一句话
Elasticsearch 是分布式、RESTful 的全文检索引擎，基于 Lucene，擅长海量日志与文档的实时检索与分析。

核心概念

概念 类比 说明
集群 Cluster 数据库实例组 多个节点组成的整体
节点 Node 一台服务器 承载数据与查询
索引 Index 数据库/表 同类文档的集合
类型 Type（已废弃） 表 7.x 起单索引单类型
文档 Document 行 一条 JSON 数据
分片 Shard 分表 索引按主分片拆分存储
副本 Replica 备份 分片的高可用副本
倒排索引 词典索引 词 → 文档ID 的映射，检索核心
