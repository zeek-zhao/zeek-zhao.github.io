16-生产运维与监控

📅 2026-10-24· 更新于 2026-10-24 ✍ zeek.zhao #工具#gerrit

生产运维与监控

📑收官篇
把 Gerrit 当生产系统运维：指标、日志、容量、演练，保证研发主链路稳定。

1. 关键指标¶

指标 来源 关注点
Open Changes 数量 REST /changes/?q=status:open 评审积压
平均评审等待时长 事件流统计 效率
队列/线程池 show-caches、JMX 容量
JVM 堆/GC JMX → Grafana 内存
磁盘占用 du -sh $GERRIT_SITE 增长
复制队列 replication status 容灾

2. Prometheus 集成¶

安装 metrics-reporter-prometheus 插件，暴露 /metrics：

Grafana 面板关注：内存、线程池、队列、GC 耗时。

3. 日志规范¶

日志 用途
error_log 主排错入口
sshd_log SSH 连接/认证
httpd_log HTTP 请求/性能
replication_log 复制任务

4. 容量规划¶

监控触发扩容的信号：CPU>70% 持续、GC 长暂停、diff 加载 >3s、推送排队。

5. 高可用演练清单¶

  • 每日备份成功 + 每月恢复演练（11-备份与升级）；
  • 每季度容灾切换演练（主→副本）；
  • 每半年升级演练（测试环境先行）；
  • 关键账号（管理员）异地可用（SSO + 多公钥）。

6. 运维自动化建议¶

🔥与 Jenkins 联动
Gerrit 健康检查可挂到 Jenkins 定时任务；GC/索引重建选择低峰（如凌晨）执行并观察 error_log。
⚠️收官提醒
评审系统是研发主干道的红绿灯：先监控再优化、先演练再扩容、先备份再升级。稳定压倒一切。
