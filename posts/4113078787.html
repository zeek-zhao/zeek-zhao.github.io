[!warning] 危险命令

  • git push --force 会覆盖远程，用 --force-with-lease
  • git reset --hard 丢弃工作区，先确认或 stash
  • rebase 共享分支会改写共享历史，禁止

常见坑

  1. rebase 共享分支：他人 pull 时历史混乱。
  2. 冲突解决只取一边：丢失逻辑，需理解合并。
  3. rebase 中断后新提交：混乱，先 abort 或完成当前。
  4. 强制推送覆盖他人：用 –force-with-lease 防呆。
  5. 丢失提交不会找：reflog 保留 90 天，快速救援。

最佳实践

  • 个人分支尽情 rebase，共享分支只用 merge。
  • 冲突解决保持”最小惊讶”：理解双方意图。
