基础语法与数据类型

[!info] 本页概览
任何程序都由变量、字面量、表达式与语句组成。本文讲解 C/C++ 的基本数据类型、变量声明、字面量与类型转换，是后续所有内容的地基。

核心概念

变量是内存中命名的存储单元，声明时需指定类型。类型决定占用字节数与可表示范围。

基本数据类型

类型 大小（常见平台） 范围示例
char 1 字节 -128 ~ 127 或 0 ~ 255
short 2 字节 -32768 ~ 32767
int 4 字节 -2^31 ~ 2^31-1
long long 8 字节 -2^63 ~ 2^63-1
float 4 字节 约 7 位有效数字
double 8 字节 约 15 位有效数字
bool（C++） 1 字节 true / false

[!warning] 大小不固定
标准只保证 sizeof(char)==1 且 short <= int <= long，不同平台可能不同。需要精确大小时用 <stdint.h> 中的 int32_t、uint64_t 等定宽类型。

变量声明与初始化

类型转换

  • 隐式转换：编译器自动进行，如 int 转 double 会丢失精度吗？不会（扩大），但 double 转 int 会截断小数部分。
  • 显式转换：C 风格 (int)x；C++ 推荐 static_cast<int>(x)。

常见坑

  1. 整数除法：7 / 2 结果是 3 而不是 3.5，因为两个操作数都是整数。
  2. char 的符号性不确定：不同平台 char 可能是 signed 或 unsigned，涉及比较时小心。
  3. 浮点比较：0.1 + 0.2 != 0.3，浮点数是二进制近似，比较应使用误差范围。
  4. 未初始化变量：局部变量默认值是垃圾值，使用前必须赋值（C++ 列表初始化可避免）。

最佳实践

  • 优先使用定宽类型（int32_t 等）编写跨平台代码。
  • C++ 中尽量使用 {} 初始化，借助编译器发现窄化问题。
  • 用 const 修饰不会改变的变量：const int MAX = 100;。
