ROS2 安装与环境配置

[!info] 本节目标
在 Ubuntu 上完成 ROS2 二进制或源码安装，正确配置环境变量并验证安装成功。

1. 安装方式对比

方式 适用 优点 缺点
二进制（deb） 大多数用户 快、稳定、易卸载 版本受限
源码编译 定制/嵌入 可裁剪、跟进最新 耗时、依赖多
Docker 测试/CI 隔离、可复用 性能开销

[!tip] 推荐
学习与开发优先二进制安装；生产或需要裁剪时用源码；CI 用 Docker（见 31-ROS2与Docker）。

2. 环境准备

3. 二进制安装（Humble 示例）

[!warning] 版本对应
Jazzy 使用 ros-jazzy-desktop，Humble 使用 ros-humble-desktop，安装包名与发行版严格对应，勿混用。

4. 环境变量配置

[!tip] 环境变量说明
ROS_DISTRO 发行版、ROS_DOMAIN_ID 多机网络隔离编号、RMW_IMPLEMENTATION 指定 DDS 实现、ROS_LOCALHOST_ONLY 仅本机通信。

5. 验证安装

[!note] 终端示例
ros2 run demo_nodes_cpp talker 与 ros2 topic echo /chatter 需要在不同终端运行；也可以把前者放后台。

6. 源码编译安装（可选）

[!warning] 源码注意
源码编译内存建议 8GB+，磁盘 20GB+；失败时按 CMake 报错逐个安装缺失依赖，不要盲目重编。

7. 常见安装问题

问题 排查
apt 找不到包 检查 sources.list 与发行版代号
版本冲突 卸载旧 ROS2，确保只装一个发行版
setup.bash 不存在 安装未完成或路径错误
rmw 启动失败 换 Cyclone DDS：export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp
防火墙阻断发现 同网段、关闭防火墙或配置 DDS 端口

[!note] 延伸
安装完成后建议完成 03-核心概念 与 05-命令行工具；Docker 安装见 31-ROS2与Docker；问题排查见 36-常见问题排查。

8. 安装验证清单

安装完成后建议按顺序验证：环境变量是否生效（查看发行版版本）、ros2 命令行是否可用、ros2 node list 是否正常返回（初始为空属正常）、运行官方小乌龟示例能否正常通信。验证通过再进入工作空间构建，可避免把环境问题误判为代码问题。若在多台机器协作，还需统一各机发行版、DDS 实现与 ROS_DOMAIN_ID，保证后续章节的多机示例可复现。

[!note] 建议
将环境配置写成一个初始化脚本放入家目录，每次开新终端执行一次，可显著减少环境类报错；具体排障见 36-常见问题排查。
