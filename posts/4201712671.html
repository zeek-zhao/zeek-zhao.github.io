常见坑

  1. alias 只在构建时生效：编辑器（VSCode）需 jsconfig/tsconfig paths 配合。
  2. proxy 只影响 dev：生产环境由 Nginx 反代；勿以为 dev proxy 会打包进产物。
  3. manualChunks 过度拆分：太多小块反而增加请求数；按需拆。
  4. 环境变量缓存：修改 .env 需重启 dev server。
  5. node_modules 大：用 npm ci 锁定版本，CI 中缓存依赖。
  6. 构建产物路径：base: '/app/' 子路径部署需配置 base。

最佳实践

  • 新项目直接 Vite + <script setup> + TS（见 19-TypeScript集成）。
  • lint/format 进 pre-commit（husky）与 CI，保持代码一致。
  • 环境变量按模式分层，敏感信息不进仓库。
  • 关注构建报告：vite build --report 或 visualizer 插件优化体积。
  • 依赖更新用 renovate/dependabot 定期升级，控制风险。
