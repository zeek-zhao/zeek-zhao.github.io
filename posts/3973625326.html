Jira MCP 连接与使用配置指南

ℹ️文档用途
本文档介绍如何在本地环境中连接并配置 Jira MCP（Model Context Protocol）服务，涵盖方案选型、依赖安装、MCP 配置、凭据获取、连接验证与常用工具使用。

1. 方案选型：官方 Rovo MCP vs 社区版 mcp-atlassian¶

维度 官方 Atlassian Rovo MCP 社区版 mcp-atlassian
适用场景 仅 Jira Cloud 自托管 Jira Server / Data Center
端点 https://mcp.atlassian.com/v2/mcp 本地 stdio 进程（无远程端点）
认证方式 OAuth 2.1 环境变量（Personal Access Token / API Token）
安装方式 远程 MCP（remote / streamablehttp） pip install mcp-atlassian
自有站点支持 ❌ 不适用 ✅ 适用
⚠️关键结论
官方 Rovo MCP 仅支持 Jira Cloud（xxx.atlassian.net），不适用于自托管站点。若你的 Jira 为 Server / Data Center 部署（如 https://issues.rollingwireless.com），必须使用社区版 mcp-atlassian。

2. 安装依赖¶

社区版 mcp-atlassian 通过 pip 安装，需要 Python 3.11（与本机 Marvis 内置 Python 3.11.8 一致）。

🔥环境要求
  • Python 版本：3.11（推荐使用 Marvis 内置的 Python 解释器）
  • 安装后可通过 python -c "from mcp_atlassian import main; main()" 验证包可用

3.1 关键字段说明¶

字段 说明
name 服务名称，建议使用 jira
type **必须为 stdio**。缺少该字段会导致服务卡在 initializing / streamablehttp 状态，工具数为 0
command 本机 Marvis 内置 Python 绝对路径
args ["-c", "from mcp_atlassian import main; main()"] 作为 stdio 入口。注意：**不要依赖 uvx**（本机缺失时无法启动）
env.JIRA_URL 自托管 Jira 站点根地址
env.JIRA_PERSONAL_TOKEN Jira 个人访问令牌（PAT），占位符必须替换为真实凭据
⚠️私有 config 不接受占位符
私有（private）MCP 配置在安装校验阶段不接受 ${...} 形式的占位符，必须填写真实凭据才能通过校验。

4. 凭据获取：创建 Personal Access Token（PAT）¶

自托管 Jira（Server / Data Center）使用 PAT 认证，获取步骤如下：

  1. 登录 Jira 站点 https://issues.rollingwireless.com/；
  2. 点击右上角个人头像 → 选择 Profile（个人设置）；
  3. 进入 Personal Access Tokens 页面；
  4. 点击 Create token（创建令牌）；
  5. 填写令牌名称（如 mcp-jira），可设置过期时间与权限范围；
  6. 创建完成后立即复制保存令牌（仅展示一次，关闭后不可再次查看）；
  7. 将令牌填入 MCP 配置的 JIRA_PERSONAL_TOKEN 环境变量。
📝令牌权限建议
建议按需最小授权：只读查询可仅授予 read 权限；需要操作工单（创建 / 流转 / 评论）时再授予对应写权限。

5.1 MCP 列表状态检查¶

  • 服务名：jira
  • 状态：authenticated（已认证）
  • 工具数量：63 个（mcp-atlassian 提供的全部 Jira 工具）
✅安装成功标志
状态为 authenticated 且工具数大于 0（本机实测为 63 个），说明服务已正常连接。

6. 常用工具¶

mcp-atlassian 提供 63 个 Jira 相关工具，常用工具如下：

工具名 用途 典型参数
jira_search JQL 查询工单 jql 查询语句
