Dockerfile构建应用镜像之Vue

前端的容器化比 Java 简单：拿 nginx 做基础镜像，把打包好的 dist/ 拷进静态目录，再用自己的 nginx 配置覆盖默认配置就行。这里真正要留意的是 nginx 的 try_files，它决定了 Vue 的 history 路由刷新会不会 404。

环境准备：Dockerfile、忽略文件与 nginx 配置¶

先把三份文件准备好。COPY dist/ 的目标目录必须是 nginx 的默认站点根目录，而自定义 nginx.conf 负责把前端路由回退到 index.html。

.dockerignore 用来告诉 Docker 哪些文件不用发进构建上下文。把 node_modules 排掉能明显加快构建速度——我见过不写这个文件、每次构建都把整个依赖目录传上去的情况。

nginx.conf 里关键是 location / 下的 try_files $uri $uri/ /index.html;，这一行就是 history 路由刷新的保障：

构建时记住：COPY 的是上下文里的文件¶

Dockerfile 里写 COPY dist/ ...，拷贝的其实不是本机当前目录下的 dist 内容，而是 Docker 引擎展开后的构建上下文里的文件。所以 -f 指向的 Dockerfile 路径和最后的上下文路径要配合好。

运行并进容器核对静态文件¶

带 --restart=always 启动，再进容器看 /usr/share/nginx/html 下 dist 的内容是否到位。
