Go 资料索引指南

[!important] 使用说明
本指南整理 Go 学习所需官方文档、经典书籍、在线教程、GitHub 仓库与中文资源，按”入门→进阶→精通”组织，配合本目录 22 篇教程使用。

一、官方文档（权威首选）

资源 地址 说明
Go 官网 https://go.dev/ 下载、文档、博客入口
Go 官方文档 https://go.dev/doc/ 入门指南、FAQ
Go 标准库文档 https://pkg.go.dev/std 标准库权威 API 参考
Effective Go https://go.dev/doc/effective_go 官方风格与最佳实践

Go 语言规范 https://go.dev/ref/spec 语法与语义权威规范

二、经典书籍

书名 作者 定位
《The Go Programming Language》 Donovan & Kernighan 公认 Go 入门圣经
《Go 语言程序设计》（中文版） 同上 中文翻译版
《Go 语言实战》 William Kennedy 等 面向实战的进阶书
《Concurrency in Go》 Katherine Cox-Buday 并发编程权威
《100 Go Mistakes》 Teiva Harsanyi 常见错误与陷阱（推荐）
《Go 语言学习笔记》 雨痕 深入源码与运行时（中文）

资源 地址 特点

六、中文教程

资源 地址 说明
Go 语言中文网 https://studygolang.com/ 社区、文档、招聘
李文周博客 https://www.liwenzhou.com/ Go 实战教程（很受欢迎）
菜鸟教程 Go https://www.runoob.com/go/ 语法速查
极客兔兔 https://geektutu.com/ Go 教程与实战
B 站搜索”Go 入门/进阶” — 大量免费视频课程

七、学习路线建议

  1. 入门：Go Tour + Go by Example 快速上手，读《The Go Programming Language》前 8 章。
  2. 巩固：李文周/极客兔兔实战教程做小项目；掌握并发、接口、错误处理。
  3. 进阶：《100 Go Mistakes》避坑、《Concurrency in Go》深入并发、uber-go/guide 学规范。
  4. 精通：读 Go 官方博客与源码、Go 101，参与开源（awesome-go 挑一个项目贡献）。
  5. 工具链：go fmt/vet + golangci-lint + pprof + go test -race 是标配。

[!tip] 核心理念
Go 强调”少即是多”与约定大于配置。跟随官方风格，多读标准库与开源代码，边做边学，从入门走向精通。
