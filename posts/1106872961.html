rviz2 可视化

[!info] 本节目标
掌握 rviz2 的显示类型、话题订阅、TF 树显示与配置保存，高效可视化调试。

1. rviz2 简介

rviz2 是 ROS2 的 3D 可视化工具，用于显示机器人模型、传感器数据、TF 树、路径等。

[!note] 界面
左侧 Display 面板管理显示项，中央 3D 视图，顶部工具栏切换视角/测量。

2. 常用 Display 类型

Display 用途
RobotModel 显示 URDF 模型
LaserScan 2D 激光点云
PointCloud2 3D 点云
TF 坐标系与箭头
Image 图像话题（相机）
Path 路径
Marker 标记（文本/箭头/立方体）
Map 栅格地图

3. 添加与配置 Display

  1. 点击 Add → 选择 Display 类型
  2. 设置 Topic（如 /scan）
  3. 设置 Fixed Frame（如 map 或 odom）
  4. 调节 Size/Color/Decay Time

[!warning] Fixed Frame
若显示空或抖动，先检查 Fixed Frame 是否在 TF 树中存在（见 15-tf2坐标变换）。

4. TF 显示

[!tip] TF 调试
TF Display 红色为断链、绿色为正常，可快速定位变换缺失（配合 tf2_monitor）。

5. Marker 可视化（Python）

[!tip] Marker 类型
ARROW / CUBE / SPHERE / CYLINDER / TEXT_VIEW_FACING / POINTS / LINE_LIST 等；scale 控制大小，color.a 控制透明度。

rviz 配置建议放包内 config/ 目录，launch 用 FindPackageShare 定位。

7. 图像显示

[!note] 图像传输
图像话题可配合 image_transport 压缩（见 26-视觉处理），rviz 支持 compressed 话题。

8. 常见问题

问题 排查
空白视图 Fixed Frame 不对、话题未匹配
模型不显示 RobotModel 的 Description Topic 未设置
数据不更新 QoS 不匹配（BEST_EFFORT vs RELIABLE）
卡顿 点云降采样、Decay Time 调小

[!note] 延伸
模型显示结合 16-URDF与xacro建模；导航可视化见 22-导航2框架；点云与视觉见 26-视觉处理。

8. rviz2 配置管理

rviz2 的配置可保存为 rviz 文件，纳入 launch 与版本管理，保证团队视觉环境一致。调试新话题时用 Add 面板添加对应 Display 并设置正确的 topic 与 frame_id；颜色与命名规范便于多人协作。发布 TF 前先确认 frame_id 存在，否则可视化为空。rviz2 还支持测量工具、交互式标记与插件扩展，可结合 rosbridge 做远程可视化。定期整理配置，删除不再使用的 Display，避免界面混乱。

[!note] 建议
rviz2 是 ROS2 最重要的可视化与调试工具，从建图、定位到导航全程伴随；导航综合可视化见 39-实战：自动驾驶小车。
