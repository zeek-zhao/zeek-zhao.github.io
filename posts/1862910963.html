Obsidian简介与安装

[!abstract] 一句话
Obsidian 是一款”本地优先”的 Markdown 知识库软件：数据永远是属于你的纯文本文件，而双向链接、图谱与插件生态则把它变成一台思考机器。

Obsidian 是什么

认知科学家史蒂芬·平克说过：”写作之难，在于将网状的思想，通过树状的句法，用线性的文字展开。”传统的文件夹笔记是树状甚至线性的，而人的思考是网状的。Obsidian 的价值正在于此：它把每篇笔记当作一张卡片，通过链接把卡片织成网络，这就是经典的卡片盒笔记法（Zettelkasten）在数字时代的落地。

与 Notion、语雀这类云端笔记相比，Obsidian 有三个根本差异。第一是本地优先：所有笔记都是存储在本地文件夹里的 .md 纯文本文件，不依赖任何服务器，软件停更了你的数据也还在；第二是可组合：它像 Chrome 和 VS Code 一样，开箱即用，又能通过插件无限扩展；第三是快：因为文件完全本地化，切换笔记几乎没有加载延迟，上下文切换极其流畅。

[!note] 2026 更新
截至 2026 年，Obsidian 桌面版已更新至 1.13.7（2026-08-12 发布），移动端为 1.13.8，Catalyst 早期访问版本为 1.14。自 2025-02-20 起，Obsidian 对个人使用（含商用）完全免费；软件基于 Electron 构建，同一套代码覆盖 Windows / macOS / Linux 桌面端与 iOS / Android 移动端。

创建 Vault（知识库）

Obsidian 的单位不是”单篇笔记”，而是 Vault（仓库）——一个普通的文件夹，Obsidian 只是在它上面叠加了链接、索引与配置。首次启动会让你创建或打开一个仓库，共有三种方式：

  1. Create new vault：新建一个空白文件夹作为仓库；
  2. Open folder as vault：把已有文件夹（比如你积累多年的 Markdown 笔记）直接打开为仓库，这是最常用的迁移方式；
  3. Open folder from Obsidian Sync：从官方同步服务拉取远程仓库。

首次配置建议

打开设置（左下角齿轮，或 Ctrl+, / Cmd+,），建议先完成这几项：

  • 编辑器 → 严格换行：建议关闭，保持 Markdown 换行兼容性；
  • 文件与链接 → 新建笔记位置：选”当前文件夹”或指定的收件箱目录；
  • 文件与链接 → 附件默认存放位置：指定统一的 attachments/ 目录，避免图片散落各处；
  • 外观：按喜好选择浅色/深色主题，调整字号与行宽；
  • 核心插件：按需开关，新手保留默认即可（详见 08-插件生态总览）。

核心界面速览

  • 左侧边栏：文件列表、快速切换、搜索、书签；
  • 右侧边栏：反向链接、出链、大纲、标签面板；
  • 编辑区：支持编辑视图与阅读视图，实时预览模式让 Markdown 语法即打即渲染。

先记住四个快捷键就能顺畅上手：Ctrl+P 命令面板（一切功能的入口）、Ctrl+O 快速切换文件、Ctrl+N 新建笔记、Ctrl+E 切换编辑/阅读。

常见坑

[!warning] 新手避坑清单

  1. 移动 Vault 前先退出 Obsidian：直接在资源管理器里搬动正在使用的仓库，可能导致配置与缓存损坏；
  2. 多端同步用冲突解决机制：用网盘裸同步实时编辑的文件容易产生冲突副本，优先用 Obsidian Sync 或 Git（见 17-同步发布与分享）；
  3. 附件不放任自流：第一天就设好附件目录，省去日后清理（见 20-维护与清理）；
  4. 不要一上来装一堆插件：先熟悉核心功能，再按需扩展；
  5. 本地也要备份：本地优先意味着没有”云端自动兜底”，用 Git 或网盘做定期备份。

下一步

安装完成后，建议先花十分钟理解 Obsidian 的最小知识单元——笔记与链接，见 02-核心概念-笔记与链接；组织仓库的整体思路可提前浏览 03-笔记组织与文件夹。
