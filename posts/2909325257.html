apt 与 dpkg

[!abstract] 用途
apt 是 Ubuntu 的软件包管理前端（Advanced Package Tool），负责从仓库下载、安装、升级、卸载软件；dpkg 是底层 .deb 包管理器。两者构成 Ubuntu 软件安装的核心链路，几乎所有软件安装都依赖它们。

1. 安装与更新仓库

[!note] 源配置
Ubuntu 24.04 默认使用 /etc/apt/sources.list.d/ubuntu.sources（deb822 格式）。换源（如阿里云/清华）可大幅提升国内下载速度。

6. 注意事项

  • 升级前先 apt update，否则源索引陈旧；
  • 不要混合使用多个发行版源（Debian 源装到 Ubuntu 极易损坏系统）；
  • apt remove 与 purge 区别在于配置文件是否保留；
  • 卸载系统自带包前确认依赖（apt depends 查询）；
  • 出现”broken packages”先 sudo apt -f install 修复，不要强行删除。
