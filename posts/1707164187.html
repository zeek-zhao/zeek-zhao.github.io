ufw

[!abstract] 用途
ufw（Uncomplicated Firewall）是 iptables 的前端封装，用简单命令管理入站/出站规则，Ubuntu 默认推荐使用，适合个人服务器快速加固。

1. 启用与状态

[!warning] 启用前注意
启用 ufw 前务必先放行 ssh（否则可能把自己锁在服务器外）：
sudo ufw allow OpenSSH 或 sudo ufw allow 22/tcp

4. 应用配置文件

5. 日志与排错

6. 注意事项

  • 先放行 ssh 再 enable，是避免失联的第一原则；
  • 云服务器注意：云厂商安全组与 ufw 是两层，都要放行；
  • ufw reset 会删除全部规则回到禁用状态，生产慎用；
  • 修改规则立即生效，无需 reload；
  • 复杂 NAT/端口转发需直接用 iptables/nftables（22-磁盘与日志排错工具集），ufw 力有不逮。
