资料索引指南

ℹ️本篇目标
汇总 GitLab 学习与运维的核心资料源：官方文档、工具链、社区资源与故障排查入口，作为本套教程的扩展目录。

1. 官方文档¶

资源 地址 用途
GitLab Docs https://docs.gitlab.com 全量官方文档（安装/管理/使用/API）
Installation https://docs.gitlab.com/ee/install/ 各种安装方式
Administration https://docs.gitlab.com/ee/administration/ 运维管理手册
CI/CD https://docs.gitlab.com/ee/ci/ Pipeline 与 Runner
API https://docs.gitlab.com/ee/api/ REST API 参考
Upgrade Path https://docs.gitlab.com/update/upgrade_paths/ 升级路径查询
Reference Architectures https://docs.gitlab.com/ee/administration/reference_architectures/ 大规模参考架构
🔥以官方为准
本套教程的示例基于常见稳定版本，实际操作以你部署版本的官方文档为准；版本升级前务必核对 Upgrade Guide。

2. 工具链¶

工具 用途
glab GitLab 官方 CLI：MR/Issue/Pipeline 命令行操作
gitlab-runner Runner 代理程序
gitlab-backup / gitlab-rake 备份与维护任务
gitlab-ctl Omnibus 运维控制台
terraform-provider-gitlab GitLab 资源 IaC 管理
gitlab-ci-local 本地模拟运行 CI Job，调试 .gitlab-ci.yml

4. 社区与案例¶

  • GitLab Forum / Community：官方社区问答，适合疑难杂症。
  • GitLab Blog：发布公告、最佳实践、版本特性。
  • YouTube / 公开课程：GitLab Learn、官方 Webinar 录播。
  • 开源镜像与中文社区：GitLab China（www.gitlab.cn）提供中文文档与镜像加速。
📝版本差异提醒
各版本 UI 位置与关键字可能有差异（如 only/except 与 rules、gitlab-rake 与 gitlab-backup），查阅文档时先确认版本号。
