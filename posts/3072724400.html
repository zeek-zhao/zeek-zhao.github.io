常用工具与运维

[!info] 本节目标
掌握 LDAP 日常运维工具链：命令行客户端、图形工具、备份恢复与监控告警，形成可落地的运维清单。

命令行客户端

常用调试参数：-d 1 输出协议级日志，-v 输出详细模式，-LLL 精简输出。

图形工具

  • Apache Directory Studio：最流行的 LDAP 浏览器，支持条目编辑、schema 浏览、LDIF 模板
  • phpLDAPadmin：Web 管理界面，适合非技术人员做用户维护
  • LDAP Admin / JXplorer：轻量桌面工具

监控与告警

生产环境建议监控以下指标：

指标 命令/方法 阈值
服务存活 systemctl status slapd / 端口探测 中断即告警
复制延迟 对比 entryCSN > 5 分钟告警
连接数 slapd -d stats 或 SSF 统计 容量规划
认证失败率 日志统计 invalid credentials 突增告警

可用 Prometheus + ldap_exporter 或 Zabbix 自定义脚本采集。

日常巡检清单

  1. 每周备份并验证可恢复性
  2. 检查日志中的异常 bind（暴力破解）
  3. 校验磁盘空间与日志轮转
  4. 确认 TLS 证书有效期
  5. 定期测试复制链路

[!tip] 小技巧
批量导入前先用 ldapadd -c（continue on error）跳过坏条目；生产变更统一走 LDIF 文件评审，避免直接手工改。
