其他语言格式化：Rust / Swift / SQL

[!info] 本页概览
本文讲解 Rust（rustfmt）、Swift（swift-format）、SQL（sqlfluff/pg_format）、Shell（shfmt）等语言的格式化工具与配置示例，形成完整格式化工具图谱。

Rust：rustfmt

[!note] 官方标准
rustfmt 是 Rust 官方格式化工具，配合 rust-analyzer 保存即格式化。

Swift：swift-format

SQL：sqlfluff / pg_format

Shell：shfmt

其他常用工具一览

语言 工具 命令 备注
Kotlin ktlint ktlintFormat 官方风格
Dart/Flutter dart format dart format . 官方工具
Ruby rubocop -A rubocop -A 兼顾 lint
PHP php-cs-fixer php-cs-fixer fix 可配置
Lua stylua stylua –check . Rust 实现
Scala scalafmt scalafmt 配置驱动

常见坑

  1. 各工具配置语法不同：rustfmt.toml、.swift-format、.sqlfluff 语法各异，别混用。
  2. SQL 方言差异：sqlfluff 必须选 dialect（postgres/mysql/bigquery…）。
  3. shell 脚本格式与 lint 分离：shfmt 管格式，shellcheck 管质量，两者都跑。
  4. 版本锁定：固定工具版本，CI 与本地一致。
  5. 生成代码：代码生成产物加 ignore 或统一重新格式化。

最佳实践

  • 每种语言选择官方/社区公认工具，团队统一配置入库。
  • CI 全量 format check；IDE 保存即格式化。
  • 所有工具的 –check/–diff 模式供 CI 使用。
