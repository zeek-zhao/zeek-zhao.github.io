13-URDF机器人建模

URDF（Unified Robot Description Format）是 ROS 的机器人描述格式，用 XML 描述机器人的连杆（link）、关节（joint）、几何形状、惯性、视觉与碰撞属性。

URDF 机器人建模

ℹ️本节目标
掌握 URDF 的 link、joint、visual、collision 等核心语法，能创建可显示、可仿真的机器人模型并自动生成 TF。

1. 什么是 URDF¶

URDF（Unified Robot Description Format）是 ROS 的机器人描述格式，用 XML 描述机器人的连杆（link）、关节（joint）、几何形状、惯性、视觉与碰撞属性。

2. 基本结构¶

3. link 元素¶

属性 说明 示例
visual 显示几何 便于 rviz 观察
collision 碰撞几何 物理仿真用，可简化
inertial 惯性参数 质量+惯性张量，Gazebo 必需
material 材质颜色 visual 显示颜色

常用几何：box、cylinder、sphere、mesh（STL/DAE）。

⚠️mesh 路径
网格文件用 package:// 形式引用，不要用绝对路径；文件须在包内 meshes/ 目录。

4. joint 元素¶

关节类型：

类型 说明
fixed 固定（无运动）
revolute 旋转关节（绕轴）
prismatic 平移关节
continuous 连续旋转（轮子）
floating 六自由度浮动
🔥origin 方向
<origin> 的 xyz 是 child 相对 parent 的平移，rpy 是旋转（roll/pitch/yaw），方向错误会导致模型错位。
