界面美化与主题

[!abstract] 一句话
从 Minimal 主题到中文排版补丁，七个插件分层组合：主题定基调、Style Settings 出细节、Hider 做减法、图标与背景做加法，最终拼出一个既好看又好用的 Obsidian。

主题基调：Minimal 全家桶

Minimal 是 Obsidian 社区最受欢迎的主题之一，以简约排版和高可定制性著称。安装路径：设置 →「外观」→「主题」→「管理」→ 搜索”Minimal”→「使用」。要解锁全部能力，务必同时安装社区插件 Minimal Theme Settings。

主题内置十余套配色方案（Atom、Ayu、Catppuccin、Everforest、Gruvbox、Nord、Solarized 等），可为浅色/深色模式分别指定；布局方面可调内容宽度、行线长度、导航栏宽度；排版方面可分设界面字体、正文、标题、代码四类字体。特色功能包括：

  • 焦点模式：编辑时自动淡化非活动段落（快捷键 Cmd/Ctrl+Alt+F）
  • 无边框模式：现代极简观感
  • 预设风格：Default、Minimal、Notion、Things 等一键应用
  • 堆叠标签页：横向堆叠窗格优化多文档工作流

Minimal 的配置存在 .obsidian/plugins/minimal-theme-settings/data.json，同步 .obsidian 目录即可跨设备保持一致。

可视化调参：Style Settings

Style Settings 是主题与用户之间的桥梁——它把 CSS 变量暴露成图形化控件，让你不写代码就能调整颜色、字体、间距、圆角、透明度。它与 Minimal 集成最深，也支持 Things、Primary、Sanctum、AnuPpuccin 等主题。

调好的整套样式可保存为预设（Preset）随时切换，也可导出 JSON 在设备间分享。用 YAML 的 cssclass 属性还能为特定笔记应用专属样式。

[!note] 2026 更新
Obsidian 1.13 将基础配色迁移到 OKLCH 色彩空间，色彩插值与主题适配更统一——主题作者在同一套变量上做出的浅色/深色过渡更平滑，用户在选择强调色时可获得更一致的视觉预期。

视觉减法：Hider 与组件精简

Hider 专注于隐藏界面元素：应用标题栏、状态栏、滚动条、行号、内联标题、YAML 前置元数据、指令符号等。组合隐藏侧边栏、状态栏和标题栏即可进入沉浸式写作环境；为”切换状态栏””切换专注模式”等命令绑定快捷键，可随时唤回元素。它与 Minimal 的样式调整互补——Minimal 管”长什么样”，Hider 管”显不显示”。配合 CSS 片段还能做悬停渐显等精细效果。

视觉加法：Icon Folder 与 Dynamic Background

Icon Folder 为文件浏览器添加图标：右键文件或文件夹选择”Icon Folder: 设置图标”，支持 Emoji、Font Awesome、RemixIcon、Material 等图标库，还能配置自动规则（如路径含 /Projects/ 自动挂图标）与继承机制。典型用法是给 PARA 四类目录（项目📊、领域🧠、资源📁、存档🗄️）设定语义图标。注意大型库中图标过多会拖慢文件浏览器，建议启用图标缓存并控制规则数量。

Dynamic Background 提供动态背景：纯色、渐变、图像、粒子动画、视频五类背景，支持按时间（日/夜循环）、系统状态（电池、全屏）、笔记路径或标签等条件自动切换。写作时用低干扰的柔和蓝色渐变，休息时段切换舒缓背景——背景成为工作状态的视觉提示。务必开启”内容保护”确保文字对比度，移动端切到轻量级背景。

[!warning]
复杂动画与视频背景会显著增加 GPU 负载，老旧设备或移动端建议只保留纯色/渐变，或设定”安静时段”自动暂停动态效果。

中文体验：CM-CHS-Patch

CM-CHS-Patch（CodeMirror Chinese Patch）专为中文编辑体验而生，启用即生效：修复输入法候选框跟随光标、优化中英混排标点、自动在中英文与数字间添加空格、智能配对中文引号。它默认保护代码块与公式不被改动，支持简繁体，还可以在设置里选择直角引号「」或弯引号””。对中文用户来说，这是美化套件里唯一”装了就不想卸”的基础设施。

推荐组合

层级 插件 职责
主题 Minimal 基调与布局
调参 Style Settings + Minimal Settings 图形化微调与预设
减法 Hider 隐藏干扰元素
加法 Icon Folder / Dynamic Background 图标与氛围
本地化 CM-CHS-Patch 中文排版修复

美化过程建议”渐进式调整”：先定主题与配色，再逐项微调，每步在测试库验证，避免一次性堆叠导致样式冲突难以定位。
