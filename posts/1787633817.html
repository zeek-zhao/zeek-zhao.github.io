维护与清理

[!abstract] 一句话
知识库和房间一样需要定期打扫：格式靠 Linter 统一、结构靠 Janitor 体检、附件靠 Oz 清理、孤岛靠 Find Unlinked Files 收编、标签靠 Tag Wrangler 归拢、臃肿靠 Note Refactor 拆分。

格式规范：Linter

Linter 自动执行 Markdown 格式化：标题层级统一、段落空行规范、列表缩进校正、表格对齐、YAML 排序与自动生成（创建/修改日期）。核心命令四个：Lint 当前文件、Lint 选定区域、Lint 所有文件、粘贴并格式化。

用注释标记保护特定区域：

自定义正则表达式可处理特殊规范（如统一产品名大小写）。建议按阶段分配规则强度：写作期最小干预、编辑期启用结构规则、发布期跑完整规则集。

全库体检：Janitor

Janitor 是知识库的”全科医生”，一键扫描并生成健康报告，覆盖六类问题：

  1. 断开的链接：可创建缺失文件、更新链接或转为纯文本
  2. 孤立笔记：创建索引页、打标签（如 #需分类）或归档
  3. 空笔记：批量清理
  4. 重复文件：按相似度合并或保留最新版
  5. 未使用标签：合并到其他标签或移除
  6. 前置元数据不一致：统一日期格式与标签写法

高级设置里可自定义健康评分权重（断链 10 分、孤立 5 分……）并启用每周/每月自动维护计划。

[!warning]
任何大规模修复前必须先备份库或确认 Git 快照（见 23-性能优化与版本管理）。Janitor 支持修复前自动触发备份，务必开启；先跑”报告模式”看清单，再分批确认修复，不要一次全修。

附件治理三件套

Oz Clear Unused Images 专扫未被任何笔记引用的图片：点击 Ribbon 图标扫描 → 预览（含缩略图、大小、修改日期）→ 勾选移除。配置”包含目录/排除目录”提高精度，启用备份选项（默认移入 .trash）。边缘情况注意：CSS 背景图、非标准引用语法可能被误判，高级模式支持自定义正则识别。

Find Unlinked Files 找的是”未被链接的笔记”——没有任何传入链接的孤立内容。它支持按创建日期排序找出被遗忘的早期笔记，提供基于内容相似度的链接建议，可批量移动、打标签或导出清单，还能配合 Dataview 建立未链接文件的动态追踪面板。

Local Images Plus 管图片生命周期：粘贴/拖放自动存图并按规则命名（{{date}}、{{notename}}、时间戳）、一键把网络图片本地化并替换链接、批量压缩转格式（WebP 优先）、识别孤立图片与损坏链接。Image Auto Upload 则走另一条路线——通过 PicGo-Core 把图片上传到 GitHub、七牛等图床，粘贴时自动替换为在线 URL，适合博客发布场景；敏感内容务必用私有图床并保留本地副本。

[!tip]
本地优先选 Local Images Plus（配合 Oz 定期清理孤儿图）；要发布到公网选 Image Auto Upload；两者职责不同，通常二选一避免互相干扰。

结构重构四工具

Bulk Rename 批量重命名：正则替换（查找：^(\d{4})-(\d{2})-(\d{2}) → 替换：$3-$2-$1）、动态变量（{{date:YYYY-MM-DD}}、{{counter:000}}、{{yaml:category}} 从元数据取名）、预览确认后应用，自动更新内部链接。适合统一日期格式、给项目文件加代号、课程笔记序列化。

Note Refactor 拆分臃肿笔记：选中内容”提取为新笔记”（原处留下链接），或按 H1/H2 标题把大文档一键拆成目录页 + 多个子笔记。这是原子化笔记（Zettelkasten）的核心工具——读书笔记里的概念段落随时可提为独立卡片。

Tag Wrangler 标签治理：右键标签即可重命名（全库更新）、合并、删除；支持斜杠嵌套标签（#工作/开发）的树形管理与路径重组；正则重命名可批量规范化变体标签（项目\s*-?\s*(\w+) → 项目/$1）。建议嵌套不超过 3-4 层，每个标签关联 5-50 篇笔记为佳。

Novel Word Count 补上”量化”一环：多维度字数统计（可排除代码块/YAML/引用）、word-goal: 2500 前置元数据设定目标、{{progress}} 进度条嵌入笔记，适合写作项目追踪。

Shell Commands 是高级用户的瑞士军刀：从 Obsidian 内执行系统命令，变量 {{vault_path}}、{{file_path}}、{{selection}} 注入上下文，可用于批量转换附件、定时备份等自动化任务。注意安全级别设置——不要执行来路不明的命令，移动端支持有限。

维护节奏建议

频率 动作
每周 Linter 清洗新增笔记、快速断链检查
每月 Oz 扫描孤儿图、Find Unlinked Files 收编孤岛
每季 Janitor 全面体检、Tag Wrangler 标签审计、Note Refactor 拆分长文
每年 重命名规范复审、库结构评估（是否拆库）
