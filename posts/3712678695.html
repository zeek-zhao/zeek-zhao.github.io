python3 与 pip

[!abstract] 用途
Python 3 是 Ubuntu 默认脚本与开发语言，pip 管理第三方包；venv 提供隔离环境。用于自动化脚本、数据处理、Web 开发与系统管理辅助。

1. 安装与版本

[!note] 系统 Python
不要删除/替换系统自带 python3（系统工具依赖）；自定义版本用 apt 安装或 pyenv。

2. venv 虚拟环境（强烈推荐）

[!warning] 环境隔离
直接在系统环境 pip install 会污染系统包，升级时可能破坏依赖。项目一律用 venv。

7. 注意事项

  • 项目依赖用 venv + requirements.txt / pyproject.toml 管理；
  • 生产脚本尽量用绝对路径调用 venv python，避免 PATH 污染；
  • pip install 提示 externally-managed-environment（PEP 668）时用 venv 或 --break-system-packages（慎用）；
  • 不要用 root 装全局 Python 包到系统目录；
  • 版本冲突排查：pip check、逐层 venv 隔离。
