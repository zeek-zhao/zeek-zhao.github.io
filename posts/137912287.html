数组与字符串

[!info] 本页概览
数组是连续内存中的同类型元素集合；字符串在 C 中是以 \0 结尾的 char 数组，在 C++ 中由 std::string 管理。本文讲解声明、遍历、二维数组、C 字符串函数与 C++ string。

核心概念

数组名在表达式中退化为指向首元素的指针。数组大小必须在声明时确定（C 的变长数组 VLA 仅在 C99 可选支持），C++ 推荐 std::array / std::vector。

常见坑

  1. 数组越界不报错：C/C++ 不做边界检查，越界是未定义行为，可能覆盖其他变量导致诡异 bug。
  2. strcpy 缓冲区溢出：目标数组容量不足时覆盖相邻内存，是经典安全漏洞（CWE-120）。用 strncpy 并确保 \0，或 C++ 用 std::string。
  3. 字符串字面量只读：char *p = "abc"; p[0] = 'x'; 是未定义行为，字面量可能位于只读区段。应写 char p[] = "abc";。
  4. sizeof 用在传参后的数组上：函数参数中的数组退化为指针，sizeof 得到 8 而不是数组大小。
  5. std::string 与 C 字符串混用：s.c_str() 返回的指针在字符串被修改后失效，不要长期保存。

最佳实践

  • C++ 中优先 std::string / std::vector，避免手动管理内存与越界。
  • 固定大小且不变化的数组用 std::array；需要动态增长用 std::vector。
  • C 中拷贝字符串时始终明确目标容量，snprintf 比 strcpy 更安全。
