Docker 认证私有仓库的密码安全问题

Docker 默认把 docker login 的凭证以 base64 形式写进 ~/.docker/config.json，这等于把明文密码留在了磁盘上。要堵住这个口子，就得用 Docker 提供的 credentials store，把用户凭证交给外部凭证存储来保管。我自己判断这是私有仓库接入前必须先做的一步，否则后面所有推送拉取都建立在裸奔的凭证上。

参考文档：https://docs.docker.com/engine/reference/commandline/login/#credentials-store

目前支持如下几种：

  • D-Bus Secret Service
  • Apple macOS keychain
  • Microsoft Windows Credential Manager
  • pass
