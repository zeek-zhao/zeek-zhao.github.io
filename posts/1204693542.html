WindTerm 用户指南

WindTerm 是一款高性能、跨平台的终端工具，支持 SSH、SFTP、Telnet、Serial 和本地 Shell。我把它当主力 SSH 客户端用，主要看中低延迟、多协议一体和分屏；下面按”装好 → 连上 → 用顺 → 排查”的顺序整理。

装的是绿色包，先把安全与保活设置好¶

  • 高性能低延迟终端引擎
  • 多协议一体化支持
  • 现代化 UI 与分屏功能
  • 强大的文件管理能力
  • 高度可定制的配置选项

下载与安装¶

  1. 从官方网站或GitHub下载
  2. 解压到任意位置（绿色软件，无需安装）
  3. 直接运行可执行文件

基础配置¶

主密码设置

  1. 首选项 → 安全
  2. 设置主密码保护会话信息

关闭自动锁屏

  1. 首选项 → 安全
  2. 取消”自动锁定”或将超时设为 0

会话保活配置

  1. SSH 会话属性 → 高级
  2. 启用”保持活动”选项（推荐 60 秒间隔）

界面分四块，会话和标签管理是上手第一关¶

界面概览¶

WindTerm 界面主要分为以下几部分：

  • 会话面板（左侧）：管理和组织连接
  • 终端区域（中央）：显示终端内容
  • 标签页栏（顶部）：管理多个会话标签
  • 状态栏（底部）：显示会话状态和系统信息

创建 SSH 连接¶

  1. 点击左侧”+”按钮或按 Ctrl+Shift+N
  2. 选择 SSH 协议并填写信息：
    • 名称：便于识别的会话名称
    • 主机：服务器地址/IP
    • 端口：SSH端口（默认22）
    • 用户名：登录用户
  3. 选择认证方式：
    • 密码认证
    • 公钥认证（可导入现有密钥或生成新密钥）
    • 密码+公钥（双因素认证）

会话管理¶

组织会话

  • 分组：右键创建文件夹，拖放会话归类
  • 快速过滤：使用会话面板顶部的搜索框

标签操作

  • 新建标签：Ctrl+T
  • 关闭标签：Ctrl+W
  • 切换标签：Ctrl+Tab 或点击标签
  • 重命名标签：中键点击标签或右键菜单

分屏功能

  • 水平分屏：Ctrl+Shift+E
  • 垂直分屏：Ctrl+Shift+O
  • 在分屏中打开会话：拖放会话到分屏区域
  • 关闭分屏：Ctrl+Shift+W 或右键菜单

SFTP 文件传输¶

  1. 在 SSH 会话中点击 SFTP 图标或按 Ctrl+Alt+F
  2. 双窗格界面管理本地/远程文件
  3. 拖放即可上传/下载文件
  4. 右键菜单提供更多文件操作选项

跳板机、隧道和批量输入适合运维场景¶

跳板机和隧道¶

跳板机配置

  1. SSH 会话属性 → 高级
  2. 在”跳转主机”配置中间服务器

SSH 隧道

  1. SSH 会话属性 → 隧道
  2. 添加本地/远程转发规则
  3. 指定源端口、目标主机和目标端口

批量操作¶

  1. 打开多个会话标签或分屏
  2. 按 Ctrl+Shift+I 启用批量输入模式
  3. 输入将同时发送到所有活动会话

命令别名与宏¶

  1. 首选项 → 命令
  2. 添加新别名并指定目标命令和参数
  3. 设置可选的快捷键

终端录制¶

  1. 右键点击会话
  2. 选择”开始记录日志”
  3. 选择保存位置和格式
  4. 完成后选择”停止记录日志”

配置都在 .wind 目录，改 JSON 前先备份¶

配置文件位置¶

  • Windows: C:\Users\<用户名>\.wind
  • macOS: /Users/<用户名>/.wind
  • Linux: /home/<用户名>/.wind

主配置文件：.wind/global/wind.config（JSON 格式）

出问题先分连接、显示、性能三类看¶

连接问题¶

问题 解决方案
无法连接 检查网络、地址端口、防火墙
认证失败 验证凭据、检查密钥权限(600)
连接断开 配置保活、检查网络稳定性
连接缓慢 尝试禁用DNS反向解析、启用压缩

显示问题¶

问题 解决方案
中文乱码 使用支持中文字体、设置 UTF-8 编码
颜色异常 调整终端颜色方案、检查 TERM 变量
界面模糊 调整DPI设置、更新图形驱动

性能问题¶

  • 终端响应缓慢：减小历史缓冲区大小、禁用不必要的视觉效果
  • 文件传输慢：调整缓冲区大小、启用压缩、增加并行传输数
  • 高CPU使用率：检查是否有大量输出、减少开启的会话数、关闭日志记录
