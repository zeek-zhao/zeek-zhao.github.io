动态配置场景¶

  • 自动化平台：通过 API 动态增删站点
  • 服务发现：外部程序实时调整上游
  • 多租户：按租户动态生成路由

与 Caddyfile 混用¶

日常静态配置用 Caddyfile；需要动态时用 JSON + API。二者选一，避免双写冲突。

常见问题¶

问题 处理
API 无响应 确认 admin 接口开启与地址
JSON 加载失败 先 caddy validate --config x.json
修改不生效 检查 PATCH 路径正确
安全问题 admin off 或绑定本机
🔥建议
90% 场景 Caddyfile 足够；只有需要程序化控制时才启用 JSON/API 模式，降低运维复杂度。
