数组与关联数组

[!info] 本页概览
本文讲解 Bash 数组（索引数组）与关联数组（字典）：定义、增删改查、遍历、切片、合并与排序，为脚本提供结构化数据能力。

核心概念

  • 索引数组：arr=(a b c)，下标从 0 开始。
  • 关联数组：declare -A map，键值对结构（类似字典）。
  • 元素引用：${arr[0]}；全部元素：${arr[@]}；下标列表：${!arr[@]}。
  • 数组长度：${#arr[@]}。

常见坑

  1. ${arr} 只取第 0 个元素：要全部用 ${arr[@]}。
  2. **"${arr[@]}" 与 "${arr[*]}"**：前者每个元素独立引号（安全），后者合成一个字符串。
  3. **关联数组必须 declare -A**：否则当普通数组，键被当数字下标。
  4. readarray 处理空行：-t 去掉换行但保留空字符串元素。
  5. 命令替换换行拆词：含空格文件名拆分，用 readarray -t / while IFS= read -r。
  6. bash 版本兼容：关联数组需 bash 4+；macOS 默认 3.2 需自行安装 bash。

最佳实践

  • 遍历全部元素统一 "${arr[@]}" 带引号。
  • 关联数组适合配置/映射场景（状态码文本、扩展名类型）。
  • 数组元素含特殊字符（空格、通配符）时用 readarray 构建。
  • 深处理数据优先 awk/python，Shell 数组适合作轻量集合。
  • 函数间传递数组用 ${arr[@]} 展开，或 local -n ref（bash 4.3+ 引用）。
