服务管理

ℹ️本节目标
掌握 homepage 服务条目的完整配置：名称、图标、链接、标签、描述与状态展示。

服务条目基础¶

字段 说明
名称 显示名称（必填）
href 跳转链接（必填）
icon 图标（官方图标名或 URL）
description 说明文字
tags 标签（可用于筛选）
ping TCP 探测主机
server 关联服务器（状态用）
widget 组件配置（状态卡片）

批量添加技巧¶

  • 服务数量多时可从已有导航页导出 URL 批量整理
  • 定期清理已下线服务，保持页面整洁
  • 关键服务加上 ping 探针，异常一目了然

常见问题¶

问题 处理
图标不显示 检查图标名拼写或改用 URL
状态一直红色 检查 ping/widget 配置与网络
点击无反应 确认 href 完整（含协议头）

服务命名统一规范（如”环境-系统”），标签统一词表，方便长期维护与检索。
