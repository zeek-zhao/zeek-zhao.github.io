基础语法与数据类型

[!info] 本页概览
Go 是静态类型语言，语法简洁。本文讲解变量声明、常量、基本类型（int/float/string/bool）、类型转换与零值机制，这是后续一切代码的基础。

核心概念

Go 的关键特性：零值（声明后自动初始化为默认值）、短变量声明（:=）、强类型（不同类型不能隐式转换）、错误处理显式化（多返回值）。

零值

未初始化的变量自动取零值：0、0.0、""、false、nil（指针/接口/切片等）。这避免了 C 中”未初始化垃圾值”的坑，也让结构体默认可用。

常见坑

  1. 声明未使用：Go 编译报错 “declared and not used”，变量声明必须使用（用 _ 占位忽略）。
  2. 短声明不能用于已声明变量：x := 1; x := 2 报错，需 x = 2。
  3. string 与 []byte 转换有开销：频繁转换会分配内存，热路径避免。
  4. int 与 int64 不能直接运算：var x int64 = 1; x + 1 中 1 是 int 常量可隐式转换，但 int64(i) + j（j 为 int）报错。
  5. iota 在括号内递增：换行才递增，同一行重复引用相同值。

最佳实践

  • 尽量用短声明 := 保持简洁；包级变量用 var 并注释用途。
  • 命名用驼峰：maxRetries、ParseConfig；首字母大写表示导出。
  • 数值运算注意溢出；uint 负数运算会绕回大数。
  • 用 const 定义魔术数字与枚举语义，配合 iota。
