代码推送到 Git → Jenkins 自动构建。核心两步：源码管理（拉代码）+ Webhook 触发（实时通知）。

[!note] 深/浅克隆
大仓库用浅克隆提速：git depth: 1, url: ...；需要完整历史做版本计算时再用全量。

2. Git 平台生成 Token

以 GitHub 为例：Settings → Developer settings → Personal access tokens，勾选 repo 权限，作为 Jenkins 凭据（06-凭据管理）。

3. Webhook 配置（GitHub）

Jenkins 侧：Job 配置 → Build Triggers → 勾选 GitHub hook trigger for GITScm polling。

[!warning] 注意
Webhook 需要 Jenkins 可被 Git 平台反向访问（公网/内网可达）；无法回访时退而用 Poll SCM。

4. GitLab Webhook

Jenkins 安装 gitlab-plugin，勾选 GitLab trigger 并粘贴 Token。
