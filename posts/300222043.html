安全加固

[!info] 本节目标
建立 Caddy 安全基线：响应头、TLS 策略、认证、防扫描与访问收敛。

安全响应头

全站统一安全头，防 XSS/点击劫持/信息泄露。

TLS 策略

  • 禁用 TLS 1.0/1.1
  • 优先 ECDHE 与 AEAD 套件
  • 自动 OCSP stapling 默认开启

基本认证保护

密码哈希生成：

访问收敛

管理/内部接口限制内网网段访问。

防扫描与限流

控制单 IP 请求频率，降低暴力扫描影响。

隐藏敏感信息

  • 关闭 server 版本泄露（默认不暴露）
  • 错误页不返回堆栈（默认安全）
  • 日志避免记录敏感 query 参数

安全基线清单

项 基线
响应头 全站安全头
TLS 1.2+，强套件
认证 管理页面强制认证
网络 管理/内网接口 IP 收敛
限流 全局频率限制
更新 版本定期升级

[!warning] 提醒
安全是层层叠加：反代只是第一层，后端服务自身的认证与最小权限仍需落实。
