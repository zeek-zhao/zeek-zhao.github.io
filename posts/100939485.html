基础语法与第一个脚本

[!info] 本页概览
本文讲解 Shell 脚本的基础：shebang、echo/printf 输出、注释、变量定义与读取、执行方式与退出码，并完成第一个可运行脚本。

核心概念

  • shebang：#!/usr/bin/env bash 声明解释器。
  • 执行方式：bash script.sh 或 chmod +x && ./script.sh。
  • 退出码：0 成功，非 0 失败；$? 获取上一条命令退出码。
  • 脚本逐行执行，命令本质是”外部程序调用 + 组合”。

执行脚本的三种方式

方式 说明
bash script.sh 子 shell 运行，不影响当前环境
./script.sh 需可执行权限 + shebang
source script.sh / . script.sh 当前 shell 运行，变量保留

常见坑

  1. 等号空格：name = "Tom" 会被解析成命令 name + 参数，报错。
  2. 变量引用不加引号：含空格的值被拆分（见 14-安全与健壮性），统一 "$var"。
  3. **$name 与 ${name}**：字符串拼接用 ${name}suffix 形式。
  4. CRLF 换行：Windows 编辑器写脚本会报 $'\r': command not found，用 sed -i 's/\r$//' script.sh 或编辑器换 LF。
  5. 默认 bash 版本：macOS 自带 bash 3.2 语法受限，开发环境装 bash 5+ 或用 zsh。
  6. 忘记 chmod：./script.sh 报 Permission denied，先 chmod +x。

最佳实践

  • 统一 #!/usr/bin/env bash（可移植）。
  • 脚本开头加注释：用途、作者、依赖、用法。
  • 变量全大写常量、小写局部；引用一律 "$var"。
  • 每条命令判断退出码或使用 set -e（见 14-安全与健壮性）。
  • 先写小脚本验证逻辑，再扩展；用 bash -n script.sh 做语法检查。
