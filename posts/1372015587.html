18-文件IO

发表于2026-10-25|groovy
|浏览量:

[!info] 本节目标
Groovy 的 IO 封装简洁强大，学习文件操作与进程交互。

1. 文件读取

File 的 text 属性一行读取全部内容，eachLine 逐行处理大文件，readLines 返回行列表。文本编码通过参数指定。

读取二进制用 bytes 属性与 InputStream，GDK 的 withStream 模式自动管理资源。

2. 文件写入

write 覆盖写入、append 追加、withWriter 带编码写入。新文件自动创建，目录不存在时需手动创建。

临时文件用 createTempFile，输出流用 withOutputStream 确保关闭。

3. 目录操作

listFiles 列出目录内容，eachFile 与 eachFileRecurse 遍历文件，mkdirs 创建多级目录。文件名过滤用正则或扩展名判断。

目录遍历常用于批量处理：重命名、统计、清理、归档等场景。

4. 资源管理

GDK 的 with 系列方法（withReader、withWriter、withInputStream）自动关闭资源，无需显式 try-finally。

这种资源管理风格让 IO 代码更安全简洁，是 Groovy 脚本与工具类的常见写法。

5. 外部进程

execute 方法启动外部命令，返回 Process 对象，读取输出流与错误流。process 方式可以管道输入输出，实现命令编排。

执行外部命令要注意超时、编码与退出码检查，Windows 下命令格式与 Unix 有差异。

6. IO 实践与注意

大文件处理避免一次性读入内存，用流式与逐行处理；敏感文件权限注意；路径拼接用 File 而非字符串拼接。

IO 错误处理统一捕获 IOException 并记录上下文信息，便于排查。

7. IO 综合示例

批量重命名工具：遍历目录、正则匹配旧名、构造新名并移动文件，整个过程用 GDK 方法十几行完成，且带校验与日志。

日志轮转场景中，按日期归档旧日志、压缩历史文件、清理过期文件，脚本化实现并纳入计划任务定期执行。

读取配置文件后动态加载资源、解析并缓存，配合文件监听实现热更新，减少服务重启成本。
