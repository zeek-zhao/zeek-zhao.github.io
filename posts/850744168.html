12-集合与遍历

发表于2026-10-25|groovy
|浏览量:

[!info] 本节目标
集合操作是 Groovy 日常编码的核心，学习丰富的高阶操作。

1. 集合字面量

Groovy 用方括号创建 List、花括号创建 Map，字面量语法让集合定义极简。Range 用两个点表示区间，可以表达数值与日期范围。

Set 通过 as Set 转换或显式构造，元素唯一性自动维护。集合字面量生成 Java 标准接口实例。

2. List 操作

List 支持索引访问、追加、插入、删除、排序等操作，GDK 提供大量便捷方法：sort、reverse、unique、flatten、intersect、disjoint 等。

范围切片 list[start..end] 截取子列表，负索引从尾部计数，操作灵活。

3. Map 操作

Map 支持点号属性访问与方括号键访问，遍历用 each、collect、findAll。Map 可以按 key 排序、分组、转换值。

Map 的默认值为 null，使用带默认值的 getOrDefault 或 Elivs 运算符提供兜底。

4. 遍历与高阶函数

each 遍历、collect 映射、findAll 过滤、find 查找、any/all 判断、groupBy 分组、inject 归约是集合处理的核心工具箱。链式调用表达数据管道。

例如日志分析、报表聚合、批量转换等场景，高阶函数替代循环让代码声明式化。

5. Set 与 Range

Set 提供成员判断、并集、交集、差集等运算，适合去重与集合关系判断。Range 支持包含判断、遍历与转列表，表达区间语义。

Range 与数值运算结合实现分页、采样、循环计数等场景。

6. 集合性能与注意

大集合操作注意复杂度：频繁插入头部用 LinkedList 语义，查找用 Map 索引。动态集合元素类型多样，转型时注意运行时类型。

集合共享时注意可变性，需要只读视图时用 asImmutable 或 asSynchronized。

7. 集合综合应用

数据报表场景中，先用 groupBy 按维度分组，再用 collect 与 sum 聚合指标，最后 sort 排序输出，一条管道完成全部分析。

两个列表的并集、交集与差集用 plus、intersect 与 minus 表达，集合关系判断不再需要手写循环，代码意图一目了然。

遍历大集合时优先流式处理，避免把全部数据载入内存；需要惰性求值可以用迭代器配合 takeWhile 等操作。

Map 的 collectEntries 可以把列表转换为键值映射，配合关联查询与数据索引构建，效率远高于逐项查找。
