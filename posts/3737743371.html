-add / -edit / -delete 写（上传/删除）
nx-repository-admin-<格式>-<仓库>-* 仓库管理
nx-cleanup-* 清理策略管理
nx-apikey-* API Key
nx-roles-* / nx-users-* 用户管理

4. 匿名访问策略

⚙ → Security → Anonymous：

场景 建议
内网可信 匿名开（拉取免登录），只读
公网暴露 匿名关，全部认证
合规严格 匿名关 + 审计

[!warning] 注意
匿名开启 = 仓库 URL 无需凭证可读；禁止给匿名任何写权限。
