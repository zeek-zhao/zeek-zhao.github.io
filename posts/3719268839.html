Python 从入门到精通 · 学习路线总览

[!important] 本套教程说明
本目录包含 22 篇 Python 教程，覆盖环境搭建、基础语法、数据结构、函数与作用域、面向对象、模块与包、文件与异常、迭代器生成器、装饰器、标准库、正则、网络请求、数据可视化、Web 框架、测试、打包发布与性能优化等主题，每篇含真实可运行代码与常见坑。

学习路线（四阶段）

阶段一：入门（01-04）

搭建 Python 环境与虚拟环境、掌握基础语法、控制流、核心数据结构。

阶段二：核心（05-10）

函数与作用域、面向对象、模块与包、文件与异常、迭代器生成器、装饰器。

阶段三：应用（11-16）

常用标准库、正则、网络请求、数据可视化、Web 框架、测试。

阶段四：进阶（17-22）

打包发布、性能优化、类型注解与异步、并发编程、工程规范、综合实战。
