ROS 生态常用库

[!info] 本节目标
盘点 ROS1 生态中的常用工具包、可视化组件与第三方库，了解何时选用什么。

1. 核心基础库

包 用途
roscpp / rospy C++/Python 客户端（见 10-roscpp编程、11-rospy编程）
std_msgs / common_msgs 标准消息（geometry_msgs、nav_msgs 等）
tf2 / tf2_ros 坐标变换（见 12-tf坐标变换）
actionlib 动作通信（见 08-动作通信actionlib）
pluginlib 插件机制（见 37-插件机制与自定义工具）

2. 导航与定位库

包 用途
move_base / nav_core 导航框架（见 21-导航框架move_base）
gmapping / cartographer SLAM 建图（见 22-建图）
amcl 蒙特卡洛定位（见 24-AMCL定位）
teb_local_planner / dwa 局部规划（见 23-路径规划与避障）
map_server 地图服务

3. 可视化与调试库

包 用途
rviz 3D 可视化（见 14-rviz可视化）
rqt_* 图形化工具（rqt_graph/rqt_console/rqt_plot）
rosbag / rostopic 录制回放、诊断（见 05-命令行工具）
tf2_tools TF 调试（view_frames）
plotjuggler 数据曲线分析

[!tip] plotjuggler
PlotJuggler 比 rqt_plot 强大，支持多文件、自定义表达式，适合离线分析里程计/速度曲线。

4. 传感器与驱动库

包 用途
laser_filters 激光滤波
image_transport 图像压缩传输（见 25-视觉处理）
pcl_ros 点云处理
camera_calibration 相机标定
usb_cam / realsense 相机驱动（见 19-常用传感器驱动）

5. 机械臂与仿真库

包 用途
MoveIt 运动规划（见 27-MoveIt机械臂控制）
gazebo_ros Gazebo 仿真（见 15-Gazebo仿真）
ros_control 控制器框架（joint_state_controller 等）
urdf / xacro 模型描述（见 13-URDF机器人建模）

6. 机器人应用框架

包 用途
robot_state_publisher 发布 URDF joint→TF
roslaunch / rosparam 启动与参数（见 16-launch启动文件）
rosbridge_suite Web 交互（见 29-rosbridge与Web端）
rosserial MCU 通信（见 31-ROS与嵌入式平台）
smach 状态机（任务编排）

[!note] smach 状态机
SMACH 用状态机编排复杂任务流程（导航→抓取→放置），适合产品化业务逻辑（见 40-实战：机械臂抓取）。

7. 第三方库与工具

类别 代表
视觉 OpenCV（见 25-视觉处理）、YOLO/darknet_ros
路径 OMPL（MoveIt 底层规划库）
建图 Cartographer、RTAB-Map
工具 rviz2 数据转换、rviz 插件
语言 ROS Java / ROS#（C#）等异构客户端

[!tip] 选库原则
优先选活跃维护、社区大、有文档的库；先跑官方 demo 再集成，避免”冷门库踩坑”。

8. 环境与工具链

工具 说明
rosdep 依赖管理
catkin_make / catkin build 构建（见 04-工作空间与catkin构建）
Docker 环境容器化（见 30-ROS与Docker）
git 版本管理

9. 常见问题

问题 建议
不知道用哪个包 查 wiki.ros.org 分类 + 社区口碑
包不兼容 查版本/维护状态，优先用活跃库
缺少文档 看 GitHub README + ros wiki 页面
生态重复 用同体系包（避免混用冲突插件）

[!note] 延伸
各专题已分散在对应章节；90-资料索引指南汇总官方文档与社区资源，见 90-资料索引指南。
