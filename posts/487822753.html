11-安全权限管理

Manage Jenkins → Security → Authentication：
📅 2026-10-24· 更新于 2026-10-24 ✍ zeek.zhao #工具#jenkins

安全权限管理

📑核心目标
谁能用 Jenkins？谁能看什么 Job？谁能构建/配置？权限矩阵 + 角色策略落地最小权限。

开启安全¶

Manage Jenkins → Security → Authentication：

权限矩阵（Matrix-based）¶

为每个用户/组勾选权限：

权限 含义
Overall/Read 能登录、看系统
Overall/Administer 管理员全部权限
Job/Read 查看 Job 与构建
Job/Build 触发构建
Job/Configure 修改 Job 配置
Job/Delete 删除 Job
Credentials/Manage 管理凭据

Role-based Authorization Strategy¶

大型团队用 Role Strategy 插件：

  1. 安装 role-strategy 插件；
  2. 定义全局角色（Global）：admin、developer、viewer；
  3. 定义项目角色（Project）：按 Job 名模式 demo-*、release-* 授权；
  4. 用户/组绑定角色。
📝按 Job 名前缀隔离
用 Folder + 项目角色，把不同团队的 Job 分到各自目录（如 /dev、/prod），互不可见。

用户管理¶

Manage Jenkins → Users：创建/禁用/删除用户；密码策略（长度/复杂度）。

🔥推荐集成
企业环境对接 LDAP / SSO（OIDC/SAML）：Manage Jenkins → Security Realm 切换，实现统一账号。

审计与安全加固¶

  • 审计日志：安装 Audit Log 插件，记录敏感操作（配置、权限变更）；
  • 安全公告：关注 jenkins.io/security，及时升级；
  • CSRF 防护：默认开启；API Token 代替密码调用 API；
  • Agent 信任：只加可信节点，JNLP 端口谨慎暴露公网；
  • 凭据安全见 06-凭据管理。
⚠️红线
  • 禁止把 Jenkins 8080 裸奔公网；
  • 禁止全员管理员；
  • 离职即停用账号，撤销其 Job 权限与凭据。
