devops-cgit-gitweb-开发指南

1. 简介

Git 是目前最流行的分布式版本控制系统，但其命令行界面对非技术用户并不友好。为了提供更直观的 Web 浏览体验，cgit 和 gitweb 应运而生。它们是两种常用的 Git 仓库 Web 前端，允许用户通过浏览器查看和搜索 Git 仓库的内容，包括提交历史、分支和标签等。

1.1 什么是 cgit

cgit 是一个轻量级、高性能的 Git 仓库 Web 前端，由 C 语言编写，专注于速度和简洁。它由 Lars Hjemli 开发，后来由 Jason A. Donenfeld 维护。cgit 使用 libgit2 作为底层库来处理 Git 仓库数据。

1.2 什么是 gitweb

gitweb 是 Git 官方提供的 Web 界面，使用 Perl 编写，是最早的 Git Web 前端之一。它通过 CGI 或 FastCGI 与 Web 服务器集成，提供了丰富的功能和良好的兼容性。

2.4.1 常见问题与解决方案

问题 可能原因 解决方案
仓库不显示 路径错误 检查 scan-path 或 repo.path 配置
仓库列表为空 权限问题 确保 Web 服务器用户对仓库有读权限
克隆按钮不工作 URL 配置错误 检查 clone-url 设置
性能缓慢 缓存配置不当 增加 cache-size 和适当的 TTL
README 不显示 过滤器配置错误 检查 about-filter 和 readme 设置

2.4.2 性能优化技巧

  1. 使用内存缓存：增大 cache-size 参数
  2. 代码高亮优化：使用高效的代码高亮过滤器
  3. 减少不必要功能：禁用不需要的功能，如 enable-commit-graph=0
  4. 添加反向代理：在前端使用 Nginx 或 Varnish 缓存
  5. 合理的 TTL 设置：根据仓库更新频率调整 TTL

8.2 常见问题及解决方案

问题 原因 解决方案
页面显示”500 Internal Server Error” CGI 配置错误 检查 Web 服务器错误日志，确保 CGI/FastCGI 配置正确
仓库列表为空 路径配置或权限错误 检查仓库路径配置和 Web 服务器用户权限
页面加载缓慢 缓存配置或大仓库问题 优化缓存配置，对大仓库执行 git gc
代码高亮不工作 过滤器配置错误 确认过滤器路径正确，依赖已安装
仓库描述不显示 描述文件权限或格式问题 检查描述文件权限和格式，确保 Web 服务器可读
“git clone” 按钮不工作 URL 配置错误 检查 clone-url 或 $git_base_url 配置
样式错乱 CSS 文件加载问题 检查浏览器控制台错误，确认 CSS 路径正确
