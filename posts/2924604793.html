[!info] 资料导航
本指南汇总 RT-Thread 官方文档、开源仓库、社区论坛、开发工具与推荐书籍，供系统学习与查阅参考，链接以官网实时内容为准。

一、官方文档中心

  • RT-Thread 文档中心：https://www.rt-thread.org/document/site/ 提供编程指南、应用笔记、版本说明与入门教程。
  • 文档中心镜像：https://www.rt-thread.io/document/site/ 英文文档门户，覆盖 Studio 与版本说明。
  • 在线 API 参考：https://www.rt-thread.org/document/api/index.html 查询内核与组件接口。
  • 快速上手教程：https://www.rt-thread.org/document/site/tutorial/quick-start/introduction/introduction/
  • Nano 版介绍：https://www.rt-thread.org/document/site/tutorial/nano/an0038-nano-introduction/
  • 视频中心：https://www.rt-thread.org/page/video.html 官方视频课程与演示。

二、开源仓库

  • 主仓库（内核与组件）：https://github.com/RT-Thread/rt-thread ，Gitee 镜像 https://gitee.com/rtthread/rt-thread
  • Nano 极简内核：https://github.com/RT-Thread/rtthread-nano
  • 软件包索引：https://github.com/RT-Thread/packages ，软件包独立仓库 https://github.com/RT-Thread-packages
  • Env 工具：https://github.com/RT-Thread/env
  • 英文手册：https://github.com/RT-Thread/rtthread-manual-doc
  • 编码规范：https://github.com/RT-Thread/rtthread-specification

三、社区与生态

  • 官方社区论坛：https://club.rt-thread.io/ 技术交流与问答。
  • 问答社区：https://www.rt-thread.org/qa/ 问题检索与提问。
  • 软件包中心：https://packages.rt-thread.org/ 检索与浏览软件包。
  • 大学计划：https://www.rt-thread.org/university.html 课程与教材资源。
  • 官网：https://www.rt-thread.org/ 获取下载与新闻动态。

四、开发工具

  • RT-Thread Studio 主页：https://www.rt-thread.org/studio.html 下载 IDE 与查看文档。
  • Studio 用户手册：https://www.rt-thread.io/document/site/rtthread-studio/um/studio-user-manual/
  • Env 工具说明：随文档中心与仓库提供，支持 menuconfig 配置与软件包管理。
  • 无硬件入门：QEMU 模拟运行 qemu-vexpress-a9 BSP，Windows 与 Ubuntu 均可体验。

五、推荐书籍

  • 《嵌入式实时操作系统：RT-Thread 设计与实现》，邱祎、熊谱翔、朱天龙 著，系统介绍内核架构与实现。
  • 野火《RT-Thread 内核实现与应用开发实战指南》，基于 STM32，由浅入深配合代码示例。
  • 《嵌入式实时操作系统——基于 RT-Thread 的 EAI & IoT 系统开发》，王易怀等 著，面向 AIoT 应用。
  • 《嵌入式实时系统 RT-Thread 应用与开发》，孙冬梅、石南 著，基于国产龙芯处理器。
  • 野火 i.MX RT1052 开源教程：https://github.com/Embedfire-rtthread/ebf_rtthread_tutorial_rt1052 及在线文档 https://doc.embedfire.com/rtos/rtthread/i.mx_rt1052/zh/latest/

六、学习路径建议

先读编程指南掌握内核概念，再通过 Studio 或 QEMU 搭建工程实践，随后深入驱动框架与组件。查阅书籍理解实现原理，结合社区问答与软件包示例解决具体问题。最后通过实战项目串联全流程知识，形成完整技能体系。

七、使用说明

各资料链接对应官方或社区维护页面，使用时注意版本匹配。文档中心开放编辑，可参与贡献。开源协议自 3.1.1 起为 Apache License 2.0，商用友好，具体以官方说明为准。
