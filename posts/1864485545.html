PowerToys

[!abstract] 用途
PowerToys 是微软官方开源效率工具集，提供窗口布局、快速启动、颜色拾取、文本提取、批量重命名、快捷键增强等能力，可显著提升 Windows 使用效率。

1. 安装

2. 核心模块

模块 功能
FancyZones 自定义窗口布局（拖拽分区）
PowerToys Run 快速启动器（Alt+Space）
Always On Top 窗口置顶（Win+Ctrl+T）
颜色选择器 屏幕取色（Win+Shift+C）
文本提取器 屏幕 OCR 复制文本（Win+Shift+T）
批量重命名 PowerRename 正则批量改名
快捷方式增强 快捷键冲突提示
主机编辑器 管理 hosts 文件
文件解锁 检查文件占用（PowerToys File Locksmith）
无鼠标模式 键盘控制鼠标（Win+Ctrl+Shift+M）

4. 命令行

5. 注意事项

  • 部分模块依赖特定 Windows 版本，升级 PowerToys 前查看发行说明；
  • FancyZones 布局建议保存为模板，多显示器需分别设置；
  • 文本提取器对复杂表格/低分辨率识别效果有限；
  • PowerRename 支持正则但误操作会批量改名，建议先”重命名预览”。
