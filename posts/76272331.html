ROS1 安装与环境配置

[!info] 本节目标
在 Ubuntu 20.04 上完成 ROS1 Noetic 的安装、环境变量配置与安装验证，跑通第一个 ROS 程序。

1. 环境准备

  • 系统：Ubuntu 20.04（Noetic 官方支持版本），建议 64 位。
  • 磁盘：预留 10 GB 以上。
  • 网络：可访问 Ubuntu 软件源。

[!warning] 版本匹配
ROS1 发行版与 Ubuntu 版本严格绑定。Noetic 必须配 Ubuntu 20.04；Melodic 配 18.04；Kinetic 配 16.04。混用会导致依赖崩溃。

2. 安装 Noetic（Desktop-Full）

[!tip] 网络问题
若 raw.githubusercontent.com 访问不畅，可用镜像源或提前下载 ros.asc 后本地导入。rosdep update 失败多与网络有关，可配置代理后重试。

3. 安装依赖构建工具

4. 验证安装

[!note] 小海龟测试
能看到小海龟窗口且方向键可控制，说明 ROS Master、节点通信与工具链全部正常。

5. 环境变量说明

ROS 常用环境变量：

[!warning] 多机环境
多机通信时每台机器的 ROS_MASTER_URI 必须指向运行 roscore 的主机，且各机 ROS_IP 设为可互相访问的地址，详见 28-多机器人协同。

6. 工作空间准备（下一节铺垫）

[!tip] 何时 source
每个新终端都要 source /opt/ros/noetic/setup.bash（已写 bashrc 则自动）。工作空间创建后还要 source 其 devel/setup.bash，否则自定义包找不到。

7. 常见安装问题

问题 原因与解决
找不到 ros-noetic-desktop-full 软件源未配置或未 update
roscore 启动失败 端口 11311 被占用：pkill -f rosmaster 后重试
命令找不到 rosrun 未 source 环境：source /opt/ros/noetic/setup.bash
rosdep init 报错 网络或已初始化：可忽略已有提示直接 rosdep update

[!danger] 不要 sudo source
不要用 sudo source，环境变量只对当前用户 shell 生效；也不要在 sudo 命令里依赖 ROS 环境（sudo 会清空环境变量）。
