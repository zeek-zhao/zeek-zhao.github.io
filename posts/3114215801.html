Docker 导入导出镜像

想把一台机器上做好的镜像挪到另一台，又不走仓库，docker save 加 docker load 就是最稳的路子。我更愿意用这种”离线搬砖”的方式处理内网环境，省得为了传个镜像还得先搭私有仓库。

准备一个改过内容的 nginx 镜像¶

先拉 nginx、跑起来、进容器把首页改掉，再 commit 成自己的镜像。这里 -a/-c/-m/-p 四个 commit 参数的含义我一并写在注释里，免得下次还得翻文档。

导入镜像前记得先清掉旧容器和旧镜像¶

导入前得把同名的旧容器、旧镜像删干净，否则容易撞名。我的习惯是先 docker rm -f 再 docker rmi，确认无残留后再 load。
