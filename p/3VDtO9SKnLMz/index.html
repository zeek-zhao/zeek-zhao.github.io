iot-物联网资源导航

文章摘要

物联网(Internet of Things, IoT)技术正迅速改变着我们的生活和工作方式。本文收集整理了全面的物联网资源，涵盖开发平台、硬件厂商、开源项目、学习资源、社区论坛、标准协议、云服务和开发工具等多个方面，旨在为物联网开发者和研究者提供便捷的参考导航，助力物联网项目开发和学习。

1. IoT开发平台

1.1 综合型物联网平台

  • AWS IoT - 亚马逊提供的全面物联网平台，包含设备管理、安全、数据分析等服务
  • Microsoft Azure IoT - 微软的物联网平台，提供设备连接、监控和管理功能
  • Google Cloud IoT - 谷歌云物联网平台，用于设备连接和数据管理
  • IBM Watson IoT Platform - IBM提供的企业级物联网平台
  • Alibaba Cloud IoT Platform - 阿里云物联网平台，提供完整的物联网解决方案
  • Huawei IoT Platform - 华为云物联网平台，专为企业和开发者设计
  • ThingsBoard - 开源物联网平台，可进行设备管理、数据收集、处理和可视化

1.2 开源IoT平台

  • Eclipse IoT - Eclipse基金会的物联网项目集合，包括多个开源实现
  • KubeEdge - 基于Kubernetes的开源系统，用于边缘计算场景
  • EdgeX Foundry - Linux基金会的边缘计算开源平台
  • Mainflux - 工业级物联网消息和设备管理平台
  • DeviceHive - 开源M2M通信框架
  • Kaa IoT Platform - 多功能开源物联网平台
  • Thinger.io - 用于原型设计和产品开发的开源IoT平台

2. IoT硬件和厂商

2.1 主流开发板和模块

  • Arduino - 广受欢迎的开源电子平台，拥有各种IoT开发板
  • Raspberry Pi - 功能强大的单板计算机，常用于物联网原型设计
  • ESP8266/ESP32 - 乐鑫科技的低成本WiFi和蓝牙SoC，物联网项目常用
  • STM32 - ST Microelectronics的ARM Cortex-M系列微控制器
  • Nordic nRF52 - 专注于低功耗蓝牙设备的SoC
  • Particle - IoT开发平台及相关开发板
  • BeagleBone - 适用于IoT项目的单板计算机
  • RockPi - 高性能物联网和AI开发板

2.2 IoT硬件厂商

  • Texas Instruments (TI) - 提供各种传感器和微控制器
  • Microchip - MCU、模拟和传感器产品制造商
  • NXP Semiconductors - 提供广泛的IoT处理器和解决方案
  • Silicon Labs - 连接型MCU和无线SoC供应商
  • Bosch IoT Sensors - 提供高质量环境和运动传感器
  • Sierra Wireless - 蜂窝IoT模块和网关供应商
  • Digi International - 网络产品和IoT解决方案供应商
  • Seeed Studio - 创客和IoT开发者硬件平台

3. IoT开源项目

3.1 设备管理与通信

  • Home Assistant - 开源家庭自动化平台，支持大量设备
  • openHAB - 厂商和技术无关的家庭自动化中心
  • Node-RED - 用于连接IoT设备的可视化编程工具
  • MQTT - 物联网消息协议和实现
  • Mosquitto - 轻量级MQTT代理
  • Eclipse Paho - MQTT和MQTT-SN客户端库
  • Blynk - 快速建立物联网移动应用平台
  • EMQ X - 高性能的开源MQTT broker，可扩展至百万级连接
  • HiveMQ - 企业级MQTT平台，提供高可靠性和扩展性
  • Eclipse Mosquitto - 轻量级开源MQTT broker实现

3.2 物联网操作系统

  • RIOT - 用于物联网的友好型操作系统
  • Zephyr - 可扩展的实时操作系统
  • Contiki-NG - 开源物联网操作系统
  • FreeRTOS - 实时操作系统，支持多种微控制器
  • Mbed OS - ARM针对物联网设计的开源操作系统
  • Apache Mynewt - 适用于约束环境的模块化操作系统
  • Embedded Linux - 适用于资源丰富IoT设备的Linux系统

3.3 数据分析与存储

  • InfluxDB - 用于时间序列数据的数据库，适合IoT应用
  • OpenTSDB - 可扩展的时间序列数据库
  • TimescaleDB - 基于PostgreSQL构建的时间序列数据库
  • Grafana - 数据可视化和监控工具
  • Apache Spark - 大规模数据处理引擎，适用于IoT数据分析
  • ELK Stack - Elasticsearch, Logstash, Kibana，适合IoT数据分析
  • Prometheus - 监控系统和时间序列数据库
