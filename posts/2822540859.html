docker

[!abstract] 用途
Docker 将应用及其依赖打包为镜像、以容器运行，实现环境一致与快速部署，是现代应用发布与测试环境搭建的主流方案。

8. 注意事项

  • 容器是无状态的：容器删除后数据丢失，重要数据用卷持久化；
  • 镜像仓库凭据/敏感变量用 docker secret 或环境文件，不要写进镜像；
  • docker system prune -a 会删除未使用镜像，注意确认；
  • 生产环境建议学习 Docker Compose / Kubernetes，参考工具目录相关文档；
  • 镜像不断更新，定期 docker pull 更新并重建容器。
