[!tip] 字段与处理

  • 增加自定义字段用 fields + fields_under_root: true；
  • 过滤敏感字段：processors: [ - drop_fields: { fields: ["password"] } ]；
  • state 目录保存读取进度（类似 sincedb），重启不重复采集。
