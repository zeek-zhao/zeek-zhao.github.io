AI与自动化前沿

接着上一篇 23-性能优化与版本管理 把库整理利索，就可以谈点更“野心”的事了：让知识库自己开口说话。AI 正在把 Obsidian 从“记录工具”升级为“思考伙伴”——Smart Connections 负责把语义相近的笔记拉到一起，Text Generator 则像坐在编辑器里的副驾驶。

AI 插件就三类，前提是密钥与数据边界¶

Obsidian 的 AI 生态大致分三类：

  1. 语义检索类：以 Smart Connections 为代表，用向量嵌入理解笔记含义，发现关键词搜索找不到的关联
  2. 文本生成类：以 Text Generator、Copilot 类插件为代表，接入大模型做续写、总结、翻译、问答
  3. 辅助采集类：官方 Web Clipper 等，把外部内容结构化收入库中

三类共同的前提是 API 密钥管理与数据边界——这决定了 AI 化的可持续性。我一般按语义检索、文本生成、采集的顺序上，先把密钥管好再谈别的。

📝2026 更新
1.11 引入了 Keychain 安全存储，插件密钥（OpenAI/Anthropic 等 API Key）可交由系统钥匙串保管，不再明文躺在配置文件里，AI 插件的安全性迈出一大步。官方 Web Clipper 自 2024 年发布后在 2024-2026 间快速进化，先后加入模板逻辑（抓取内容按模板落库）与 Reader 视图（去广告正文提取），已成为知识采集的官方级入口。

语义检索让笔记自己开口说话¶

Smart Connections 通过向量嵌入为全库建立语义索引，超越关键词匹配——搜索“提高工作效率”也能找到只谈“时间管理”和“任务优先级”的笔记。

配置：设置 → Smart Connections → 输入 API 密钥（OpenAI 或自托管模型），选择嵌入模型（如 text-embedding-ada-002），设定索引范围（全库/特定文件夹/按标签筛选）与索引粒度（整文件/按段落）。

核心用法：

  • 连接面板：打开笔记时侧边栏自动按相似度列出语义相关笔记
  • 语义搜索：用自然语言提问，返回概念相近的笔记
  • 块级连接：选中段落右键“查找相关内容”，细粒度发现相似观点
  • 智能聊天：向知识库提问，回答引用相关笔记作为依据，支持多轮追问

成本与性能：启用缓存减少重复 API 请求；大型库（数千笔记）使用选择性索引策略、排除无关文件夹、设置最小文本长度；索引安排在低峰时段批量执行。本地模型可让敏感内容不出设备。我的习惯是把索引丢到低峰批量跑，涉及敏感内容的库干脆用本地模型。

🔥
把 Smart Connections 与维护工作流结合：它的连接分析能识别孤立内容和高度相似笔记，正好作为 20-维护与清理 中“收编孤岛、合并重复”的输入信号。

把大模型塞进编辑器，模板是灵魂¶

Text Generator 直接在编辑器内调用 GPT-4、Claude、Llama 等模型。

配置：安装后在设置中选提供商（OpenAI/Anthropic/Cohere/Azure/本地桥接），填入 API 密钥并测试连接；按需调整 Temperature（0-2，越低越确定、越高越有创造性）、Max Tokens 与 System Message。

三种基础触发：选中文本按 Alt+G 续写或改写；命令面板执行预设命令（继续写作/解释所选/总结/翻译/修改风格）；工具栏按钮调用模板。

模板系统是灵魂——模板可引用 {{selection}}、{{context}} 变量：

进阶能力：AI 块（%%ai prompt: ... %% 代码块执行后原地更新内容）、批处理模式（对文件夹/标签批量应用模板）、与 Templater/QuickAdd/Dataview 集成（例如 Dataview 查询结果交给 AI 生成周报摘要）。

成本控制：开启 Token 计数器、设置日/月上限、按任务选模型（总结用小模型、创作用大模型）、启用响应缓存。

AI 化之前先过一遍数据边界清单¶

AI 化最大的风险是数据外流，落地前过一遍清单：

  1. 密钥安全：使用 1.11+ 的 Keychain 存储，或环境变量；定期轮换密钥；配置文件不入 Git
  2. 内容边界：为敏感笔记启用隐私模式（如 %%private%% 标记内容发送前被过滤）；配置不向 API 发送的文件夹
  3. 本地优先选项：本地部署模型（Ollama 等桥接）可让数据完全不出设备
  4. 备份照旧：AI 生成的改动同样需要版本兜底，别因自动化丢了 23-性能优化与版本管理 的纪律

小步试点，人工把关署名¶

  • 语义层成为标配：从关键词到向量的迁移不可逆，早建索引早受益
  • 自动化链路成型：Web Clipper 采集 → AI 总结入库 → Smart Connections 语义关联 → Dataview 面板呈现，四段式流水线已可全链路跑通
  • 混合编辑原则：AI 负责初稿、扩展、格式化；人工负责判断、取舍与署名——内容质量最终由人把关
  • 小步快跑：先在一个文件夹内试点 AI 流程，验证成本与质量后再推广到全库

AI 插件迭代极快，保持插件更新、关注官方论坛的 AI 讨论区，是让这套前沿能力持续保鲜的最简单办法。我会先在一个文件夹里试两周，算清 token 成本和回答质量，再决定要不要推到全库。
