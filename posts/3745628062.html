Vue 从入门到精通 · 学习路线总览

[!important] 本套教程说明
本目录包含 22 篇 Vue 教程（以 Vue 3 + Composition API 为主线），覆盖环境搭建、模板语法、组件体系、路由、状态管理 Pinia、组合式 API、表单、动画、工程化、测试、部署与性能优化，每篇含真实可运行代码与常见坑。

学习路线（四阶段）

阶段一：入门（01-06）

环境搭建、模板语法、组件基础、组件通信、生命周期、计算属性与侦听器。

阶段二：核心（07-12）

路由基础与进阶、状态管理 Pinia、组合式 API、指令与插槽、表单处理。

阶段三：进阶（13-18）

动画过渡、组件高级模式、工程化与构建、测试、部署、组合式 API 进阶。

阶段四：精通（19-22）

TypeScript 集成、性能优化、工程实践与项目架构、综合实战项目。
