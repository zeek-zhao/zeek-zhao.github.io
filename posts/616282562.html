rosbridge 与 Web 端

[!info] 本节目标
掌握 rosbridge 架构、启动配置与通过 Web 端订阅/发布 ROS 话题的方法。

1. 什么是 rosbridge

rosbridge_suite 将 ROS 话题/服务/动作转换为 JSON 协议（WebSocket），让浏览器、App、非 ROS 程序无需 ROS 环境即可与机器人交互。

组件 作用
rosbridge_server WebSocket 服务端（ROS 侧）
rosbridge_library JSON→ROS 协议转换
rosapi 提供话题列表/服务等查询 API

2. 安装与启动

[!tip] 前端库
浏览器端使用 roslibjs 连接；仪表盘常用 roswww 提供静态页面。

3. JSON 协议示例

3.1 订阅话题

3.2 发布话题

3.3 调用服务

4. Web 页面示例（roslibjs）

[!warning] 浏览器安全
Web 端默认可发布任意话题（如 /cmd_vel），对外部署时务必加鉴权（Token/网关/防火墙），见 36-产品化实践。

5. Web 可视化（Ros3D / rviz web）

工具 说明
Ros3DJS Web 端 3D 场景显示 TF/点云/地图
Webviz（ROSBAG） 回放可视化
自绘 Canvas 简单 2D 仪表盘

[!tip] 远程遥控
经典应用：手机浏览器打开页面 → 显示相机画面（video）+ 虚拟摇杆 → 发布 /cmd_vel 遥控小车。

6. 视频流到 Web

[!note] 视频方案对比
mjpeg_server 简单但仅单话题；web_video_server 支持多话题、压缩参数调整，推荐。

7. 非浏览器客户端

[!tip] 多端接入
rosbridge 让 Android/iOS/微信小程序/Unity 等均可接入，是 28-多机器人协同 之外最灵活的异构通信方案。

8. 安全与性能

关注点 建议
访问控制 Token/反向代理/内网隔离
带宽 图像压缩（compressed/低分辨率）
频率 高频话题降频转发
TLS 公网部署用 wss

9. 常见问题

问题 原因/解决
WebSocket 连不上 端口未开/防火墙/IP 错误
收不到话题 type 名错/权限/未订阅
JSON 格式错 缺 op/字段拼写
图像卡顿 带宽不足，压缩图像

[!note] 延伸
跨平台通信与 Docker 部署结合见 30-ROS与Docker；产品化安全实践见 36-产品化实践。
