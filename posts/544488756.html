综合实战项目：待办事项 REST API

[!info] 本页概览
综合运用本套教程知识：模块管理、结构体、接口、错误处理、JSON、Web 编程、测试，实现一个带内存存储与并发安全的 RESTful 待办事项 API，并配套单元测试与 Docker 部署。

需求设计

功能：

  1. GET /todos：列出全部待办
  2. POST /todos：新增待办（标题必填）
  3. GET /todos/{id}：查询单个
  4. PUT /todos/{id}：更新完成状态
  5. DELETE /todos/{id}：删除

技术设计：

  • 内存存储 + sync.RWMutex 保证并发安全（20-并发模式与sync包）
  • 标准库 net/http 路由（Go 1.22 方法模式，12-Web编程）
  • 表驱动测试 + httptest（13-测试）

复盘要点

  1. 并发安全：Store 用 RWMutex，列表读锁、写操作写锁；go test -race 验证。
  2. 错误处理：ErrNotFound 哨兵 + errors.Is，handler 映射 404。
  3. 可扩展：把 Store 抽成接口（Repository）即可替换为数据库实现（参考 07-接口）。
  4. 加分项：加 context 超时、优雅停机、结构化日志、Docker 部署（16-部署）、数据库持久化。
