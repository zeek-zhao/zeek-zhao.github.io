控制流

[!info] 本页概览
本文讲解 Python 的条件、循环与推导式：if/elif/else、for/while、range、enumerate、break/continue/else，以及极具 Python 风格的列表推导式与生成器表达式。

核心概念

Python 控制流简洁：for 遍历可迭代对象（不需要下标），if 支持链式判断，推导式用一行表达式生成集合，是 Python 代码优雅的核心。

常见坑

  1. 在循环里修改正在遍历的列表：删除元素会跳过/错位，先复制 for x in list(original): 或收集后统一处理。
  2. range 与列表混淆：range 是惰性对象，list(range(3)) 才是列表。
  3. and/or 短路返回值：a or b 返回参与计算的值（而非布尔），如 x = name or "default" 是常用技巧，但要清楚语义。
  4. 浮点作为循环步长：while x < 1.0: x += 0.1 可能多走一次（精度），用整数计数。
  5. **忘写 :**：if x > 0: 漏冒号是最高频语法错误。
  6. 推导式过度嵌套：超过两层读起来痛苦，拆成普通循环。

最佳实践

  • 优先 for ... in 遍历，不写 C 风格下标循环。
  • 用 enumerate 取索引，用 zip 并行遍历。
  • 简单筛选用推导式，复杂逻辑写普通循环加注释。
  • 无限循环用 while True + 明确的 break 条件。
  • 判断”是否所有/任意元素满足”用 all()/any()。
