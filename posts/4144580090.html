安全加固

[!info] 本节目标
建立 OpenGrok 生产安全基线：网络隔离、认证授权、加密传输与依赖更新。

网络隔离

  • OpenGrok 仅在内网/VPN 可达，禁止公网直连
  • 管理接口（/api）限 IP 白名单
  • 反向代理层加 WAF 规则（如有必要）

认证与授权

  • 启用 LDAP/SSO 统一认证，禁止匿名访问
  • 项目级 ACL 按组收敛（见 08-权限与认证）
  • 敏感项目（合规/涉密）单独实例隔离

传输加密

  • 全链路 HTTPS：客户端 -> Nginx -> OpenGrok（内部 http 即可）
  • 证书统一管理，定期轮换
  • 如需 LDAPS 接入，配置 TLS 1.2+

系统与依赖

  • OpenGrok 镜像/版本定期更新，跟踪 CVE
  • Java 运行环境及时打补丁
  • 容器以非 root 运行：

数据保护

  • 源码目录权限最小化：查询进程仅需读权限
  • 日志脱敏：避免记录查询关键词（合规敏感）
  • 备份加密存储

审计与监控

项 方式
访问日志 Nginx access log + 集中日志
登录失败 认证网关侧记录
异常查询 敏感关键词规则告警
配置变更 版本库 diff 审计

安全基线速查

维度 基线
网络 内网 + 管理接口白名单
认证 统一 SSO/LDAP，禁匿名
授权 项目级 ACL
传输 HTTPS
运行 非 root + 只读
更新 镜像定期升级
审计 访问日志留存 180 天

[!tip] 建议
将安全基线纳入部署模板（docker-compose + Nginx 配置模板），新环境一键套用，避免手工遗漏。
