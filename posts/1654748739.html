Windows 必备软件指南

这份清单是我给自己攒机器时的安装顺序：先解决搜索、压缩、截图这些高频动作，再装开发和远程工具，美化和娱乐放最后。优先选官方渠道下载，省掉捆绑软件的麻烦。

系统工具类先把搜索、压缩、窗口管理搞定¶

1. Snipaste¶

  • 简介：轻量级但功能强大的截图工具，支持贴图功能
  • 亮点：截图后可将图片悬浮在屏幕上，便于对比和参考
  • 适用场景：需要频繁截图、对比图片内容的工作场景

2. PowerToys¶

  • 简介：微软官方开发的系统增强工具集
  • 亮点：包含窗口管理、批量重命名、颜色选择器等多种实用工具
  • 安装方式：Microsoft Store 或 GitHub 下载

3. Everything¶

  • 简介：极速文件搜索工具
  • 亮点：秒级搜索电脑中的任何文件
  • 适用场景：需要快速定位文件的场合

4. 7-Zip / WinRAR¶

  • 简介：高效的文件压缩与解压缩工具
  • 亮点：支持多种压缩格式，7-Zip开源免费，WinRAR功能更全面
  • 适用场景：处理压缩文件、减小文件传输体积

5. FreeFileSync¶

  • 简介：开源文件同步工具
  • 亮点：支持实时同步、批量比较和同步文件夹
  • 适用场景：数据备份、跨设备同步文件

6. Q-Dir¶

  • 简介：四窗口文件管理器
  • 亮点：最多可同时显示4个文件夹视图，支持多标签
  • 适用场景：文件整理、跨目录文件操作

7. DeskPins¶

  • 简介：窗口置顶工具
  • 亮点：可将任何窗口固定在最前面，轻量级
  • 适用场景：需要同时查看多个窗口时，保持重要窗口始终可见

8. Bandizip¶

  • 简介：高速压缩文件管理器
  • 亮点：快速、轻量、界面美观，支持多种压缩格式
  • 适用场景：日常文件压缩解压，查看压缩包内容

9. One Commander¶

  • 简介：现代化设计的文件管理器
  • 亮点：双栏布局、标签页支持、快速预览、自定义主题
  • 适用场景：需要更强大文件管理体验的用户，替代Windows资源管理器

10. X-Mouse Button Control¶

  • 简介：鼠标按键自定义和增强工具
  • 亮点：可针对不同应用设置鼠标按键功能，支持手势和滚轮调整
  • 适用场景：需要提高鼠标使用效率，特别是多按键鼠标用户

11. QuickLook¶

  • 简介：类似macOS的空格键快速预览功能
  • 亮点：选中文件按空格即可快速预览内容，无需打开文件
  • 适用场景：快速浏览文件内容，提高文件管理效率

12. WizTree¶

  • 简介：超快的磁盘空间分析工具
  • 亮点：比同类工具速度更快，直观显示占用空间最大的文件和文件夹
  • 适用场景：清理磁盘空间，查找大文件

13. Rufus¶

  • 简介：USB启动盘制作工具
  • 亮点：小巧、快速、功能全面，支持多种系统ISO
  • 适用场景：制作系统安装U盘，修复系统

14. Autoruns¶

  • 简介：微软Sysinternals套件的启动项管理工具
  • 亮点：详细显示所有系统启动项，可禁用不需要的项目
  • 适用场景：系统优化，排查启动问题，提升开机速度

15. SpaceSniffer¶

  • 简介：视觉化磁盘空间分析工具
  • 亮点：通过方块大小直观显示文件和文件夹占用空间，交互式界面
  • 适用场景：磁盘清理，查找大文件，空间使用分析

开发场景按编辑器、版本控制、终端、对比工具四件套配¶

1. Visual Studio Code¶

  • 简介：轻量级但功能丰富的代码编辑器
  • 亮点：丰富的插件生态系统，支持几乎所有编程语言
  • 适用人群：开发人员、文本编辑爱好者

2. Git¶

  • 简介：分布式版本控制系统
  • 亮点：高效管理代码历史记录
  • 配套工具：GitHub Desktop, GitKraken 等图形界面客户端

3. Windows Terminal¶

  • 简介：现代化的终端应用程序
  • 亮点：支持多标签、分屏、自定义主题
  • 安装方式：Microsoft Store

4. Beyond Compare 3¶

  • 简介：专业的文件和文件夹比较工具
  • 亮点：支持文本、二进制、图像等多种比较模式
  • 适用场景：代码合并、文件同步、数据验证

5. WindTerm¶

  • 简介：专业的跨平台SSH/SFTP/Shell终端
  • 亮点：支持多会话管理、分屏、自定义主题，性能优秀
  • 适用场景：服务器管理、开发调试

6. Apifox¶

  • 简介：API设计、开发、测试一体化工具
  • 亮点：集合Postman+Swagger+Mock+JMeter功能
  • 适用场景：API接口调试、文档管理、自动化测试

7. DBeaver¶

  • 简介：通用数据库管理工具
  • 亮点：支持几乎所有主流数据库，跨平台，开源免费
  • 适用场景：数据库管理、SQL开发、数据分析

8. draw.io¶

  • 简介：免费开源的图表绘制工具
  • 亮点：支持流程图、UML、网络图等多种图表类型，可在线使用或本地安装
  • 适用场景：软件设计、流程图制作、系统架构图绘制

笔记和剪贴板决定日常顺不顺手¶

1. Notion¶

  • 简介：集笔记、知识库、项目管理于一体的协作平台
  • 亮点：高度可定制，支持多种内容块
  • 适用场景：个人笔记整理、团队协作

2. Microsoft 365¶

  • 简介：Office 全家桶订阅服务
  • 亮点：Word, Excel, PowerPoint 等经典办公软件
  • 适用人群：学生、上班族、各类办公需求

3. Ditto¶

  • 简介：剪贴板管理工具
  • 亮点：保存多条复制历史，随时调用
  • 适用场景：需要在多个内容之间频繁切换复制粘贴的工作

4. Xmind¶

  • 简介：专业思维导图和头脑风暴工具
  • 亮点：直观的界面，多种导图样式，支持导出多种格式
  • 适用场景：项目规划、知识整理、创意发想

5. Obsidian¶

  • 简介：基于本地Markdown文件的知识库工具
  • 亮点：强大的双向链接功能，插件生态丰富
  • 适用场景：个人知识管理、笔记整理、学习研究

播放器按格式需求选，截图录屏交给 ShareX¶

1. VLC¶

  • 简介：开源多媒体播放器
  • 亮点：支持几乎所有音视频格式，无需额外编解码器
  • 适用场景：视频播放、简单的媒体转换

2. PotPlayer¶

  • 简介：强大的多媒体播放器
  • 亮点：高度可定制界面，丰富的功能设置
  • 适用人群：影音爱好者

3. ShareX¶

  • 简介：功能全面的截图、录屏工具
  • 亮点：支持多种截图方式、屏幕录制、上传分享
  • 适用场景：内容创作、教程制作

密码管理和系统防护别等出事才装¶

1. Bitwarden¶

  • 简介：开源密码管理器
  • 亮点：跨平台同步，安全存储密码
  • 适用场景：管理众多网站账户和密码

2. Windows Defender¶

  • 简介：Windows 内置安全软件
  • 亮点：无需额外安装，持续更新，性能影响小
  • 使用提示：确保定期更新，开启实时保护

1. CCleaner¶

  • 简介：系统清理和优化工具
  • 亮点：清理垃圾文件，修复注册表问题
  • 使用提示：使用免费版即可满足基本需求

2. Process Explorer¶

  • 简介：高级任务管理器
  • 亮点：详细显示进程信息，便于排查问题
  • 适用人群：系统管理员、进阶用户

通讯、阅读、下载与远程，按使用频率取舍¶

1. 微信 for Windows¶

  • 简介：微信的 Windows 客户端
  • 亮点：与手机微信保持同步
  • 适用场景：个人社交、工作沟通

2. Telegram¶

  • 简介：注重隐私和安全的即时通讯工具
  • 亮点：快速、安全、支持大型群组
  • 适用场景：国际交流、隐私通讯需求

1. Calibre¶

  • 简介：电子书管理工具
  • 亮点：支持多种电子书格式转换，设备同步
  • 适用人群：电子书爱好者

2. Anki¶

  • 简介：智能记忆卡片软件
  • 亮点：利用间隔重复算法提高学习效率
  • 适用场景：语言学习、备考记忆

1. Internet Download Manager¶

  • 简介：高速下载管理器
  • 亮点：多线程下载、自动分类、浏览器集成
  • 适用场景：大文件下载、断点续传、批量下载

2. AnyDesk¶

  • 简介：远程桌面控制软件
  • 亮点：高速连接、低延迟、跨平台支持
  • 适用场景：远程办公、技术支持、远程协作

3. Clash for Windows¶

  • 简介：基于Clash的代理软件
  • 亮点：规则分流、多协议支持、GUI界面
  • 适用场景：网络访问、科学上网

4. NoMachine¶

  • 简介：高性能远程桌面连接工具
  • 亮点：低延迟、高质量屏幕共享，支持文件传输和音频转发
  • 适用场景：远程办公、跨平台远程访问、远程技术支持

浏览器与输入法直接决定手感¶

1. Google Chrome¶

  • 简介：谷歌开发的网络浏览器
  • 亮点：快速、稳定、丰富的扩展生态
  • 适用场景：网页浏览、Web应用开发测试

2. Mozilla Firefox¶

  • 简介：自由开源的网络浏览器
  • 亮点：注重隐私保护，可高度定制
  • 适用场景：日常浏览、注重隐私的用户

1. 搜狗输入法¶

  • 简介：流行的中文输入法
  • 亮点：智能联想，词库丰富，皮肤定制
  • 适用场景：日常中文输入，特殊符号输入

2. 微软拼音¶

  • 简介：Windows系统内置的中文输入法
  • 亮点：系统集成度高，无需额外安装，简洁无广告
  • 适用场景：注重隐私和系统原生体验的用户

3. Rime 小狼毫¶

  • 简介：开源、可高度定制的输入法框架
  • 亮点：完全本地化，无云输入，高度可定制化
  • 适用场景：注重隐私，有特殊输入需求的专业用户

娱乐和小工具按需补，不必一次装满¶

1. Steam¶

  • 简介：全球最大的游戏发行平台
  • 亮点：海量游戏库，经常有折扣活动，社区功能丰富
  • 适用人群：各类游戏爱好者

2. Epic Games Launcher¶

  • 简介：Epic公司的游戏平台
  • 亮点：每周免费游戏，独占游戏内容
  • 适用场景：游戏玩家，特别是喜欢收集免费游戏的用户

3. Spotify¶

  • 简介：流行的音乐流媒体服务
  • 亮点：海量音乐库，个性化推荐，播放列表功能
  • 适用场景：音乐爱好者，日常听歌，发现新音乐

4. Xbox Game Pass¶

  • 简介：微软的游戏订阅服务
  • 亮点：低月费畅玩上百款游戏，包括新发行大作
  • 适用人群：喜欢尝试各种游戏而不想单独购买的玩家

5. 哔哩哔哩¶

  • 简介：bilibili视频平台的桌面应用
  • 亮点：支持离线缓存，弹幕互动，全屏播放体验更佳
  • 适用场景：二次元爱好者，视频内容创作者与观众

1. 迅捷PDF转换器¶

  • 简介：在线PDF格式转换工具
  • 亮点：支持PDF与Word、Excel、图片等格式互转，无需安装
  • 适用场景：文档格式转换，快速编辑PDF内容

2. Flameshot¶

  • 简介：功能丰富的开源截图工具
  • 亮点：内置标注工具，支持快速上传分享
  • 适用场景：需要对截图进行复杂编辑和标注的场合

3. f.lux¶

  • 简介：自动调节屏幕色温的工具
  • 亮点：根据时间自动调整屏幕色温，减少蓝光
  • 适用场景：长时间使用电脑，保护眼睛，改善睡眠质量

4. EarTrumpet¶

  • 简介：Windows增强版音量控制工具
  • 亮点：可精细控制每个应用的音量，界面现代
  • 适用场景：需要单独调节不同应用音量的用户

5. TranslucentTB¶

  • 简介：Windows任务栏美化工具
  • 亮点：让任务栏变透明或模糊，提升视觉体验
  • 适用场景：桌面美化，视觉定制

想找更多替代软件时从这些入口进¶

  • Awesome Windows - GitHub 上的 Windows 软件精选列表
  • AlternativeTo - 寻找软件替代品的网站
  • Microsoft Store - Windows 官方应用商店

我的判断是：Everything、7-Zip、PowerToys 这三件先装，后面再有针对性地加；装软件时优先走官方渠道，避免捆绑安装不需要的程序。
