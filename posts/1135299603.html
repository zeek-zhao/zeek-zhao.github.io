Ubuntu 22.04 常用软件安装指南

这份清单覆盖 Ubuntu 22.04 LTS (Jammy Jellyfish) 上开发、办公、多媒体、网络、虚拟化等常用软件的安装与配置。我判断最值得先做的是系统更新加基础工具（curl、wget、git 等），再根据实际需要选 APT、Snap 或 Flatpak——APT 稳定、Snap 隔离但略慢、Flatpak 跨发行版通用，混用没问题但要清楚各自边界。

软件推荐¶

  • 浏览器: Firefox, Chrome, Brave
  • 文本编辑器: VSCode, Sublime Text, Vim, Neovim
  • 终端: GNOME Terminal, Terminator, Alacritty
  • 开发工具: GitKraken, Postman, DBeaver
  • 笔记工具: Obsidian, Joplin, Notion (Web)
  • 效率工具: Ulauncher, Albert
  • 远程桌面: Remmina
  • 安全工具: KeePassXC, Bitwarden
  • 云存储: Dropbox, Nextcloud

最后¶

这些工具覆盖 Ubuntu 22.04 上的大部分常用场景，装完之后记得定期用 sudo apt update && sudo apt upgrade 保持系统更新，及时拿到功能更新和安全补丁。
