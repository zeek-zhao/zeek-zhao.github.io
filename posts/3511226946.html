Docker Compose 入门学习

我用 Compose 的原因很直接：多容器项目靠 docker run 一条条敲，网络、依赖、卷全要手工维护，容易漏也难复现。这篇把从安装验证到 WordPress、微服务编排的每一步和命令都收齐，照着做就能把一套服务一键拉起。

Compose 用一份编排文件管住一组关联服务¶

学习前提¶

  • 已安装 Docker Engine。
  • 具备基础 Linux 命令能力。

三个核心概念¶

  • 服务（service）：应用中的一个运行单元，例如 web、redis、mysql。
  • 项目（project）：一组通过 Compose 编排的关联服务。
  • 编排文件（docker-compose.yml）：描述服务、网络、卷、环境变量等。

Docker 小结¶

  • Docker镜像 -> 通过 run 命令启动镜像
  • Dockerfile 构建镜像（服务打包）
  • docker-compose 启动项目（编排、多个微服务/ 环境）
  • Docker 网络

常用命令速查¶

端口冲突、服务互联与启动顺序是最常见的三类问题¶

  • 端口冲突：检查 5000/6379 是否被占用。
  • 服务无法互联：确认服务名作为主机名使用，例如 redis。
  • 启动顺序问题：使用 depends_on，并在应用里增加重试逻辑。
