资料索引指南（Confluence）

上一页讲完性能与安全（15-性能与安全加固），这份索引把所有常用入口收在一处。我查 Confluence 问题基本固定走「官方文档 → Atlassian 社区 → Marketplace → 视频教程」这条线，下面按官方、社区、插件、运维、周边分类列出来，遇到具体场景直接对号入座。

官方文档是第一手答案¶

我一般先翻官方文档，只有文档没写透的场景才去社区翻帖，这样能省掉大量试错。

资源 地址 说明
Atlassian 官网 https://www.atlassian.com/software/confluence 产品介绍与试用
官方文档 https://confluence.atlassian.com/doc/ Confluence 文档中心
帮助中心 https://support.atlassian.com/confluence-cloud/ 云版帮助
Server 文档 https://confluence.atlassian.com/doc/confluence-server-documentation-1012129952.html 自托管文档
开发者文档 https://developer.atlassian.com/cloud/confluence/ REST API 与开发
迁移指南 https://www.atlassian.com/software/confluence/migration-assistant Server→Cloud

社区资源用来补文档没写透的部分¶

社区：

  • Atlassian 社区：https://community.atlassian.com/

  • Bilibili Confluence 教程视频

认证：

  • Atlassian University：https://university.atlassian.com/
  • ACP 认证（管理员/开发者）

常用插件去 Marketplace 按宏名找¶

官方插件（Marketplace）：

  • Jira 宏：https://marketplace.atlassian.com/
  • Office Connector（Server）
  • 页面属性/属性报告（内置）

常用第三方：

  • Gliffy（流程图）
  • Draw.io Diagrams
  • Whiteboards（白板，新版）

检索方式：Marketplace 搜索”confluence macro”。

运维资源按兼容性矩阵和安全公告查¶

生态集成围绕 Jira 与文档规范展开¶

生态集成：

  • Jira：需求/任务联动（见 13）
  • Bitbucket：代码文档关联
  • Opsgenie/Statuspage：告警知识库
  • Nginx/Portainer：部署运维（见本工具目录其他套件）

文档规范：

  • Markdown 语法：CommonMark
  • JQL：Jira 查询语言官方文档
