筛选器与 JQL

[!abstract] 查询的艺术
JQL（Jira Query Language）像 SQL 一样查询问题；保存为筛选器后可分享、嵌入看板/仪表盘。

1. 创建筛选器

Issues → Search for issues，输入 JQL 并保存：

2. JQL 基础语法

运算符 用法
= / != 相等/不等
> / < 日期、数字
~ 包含文本（如 summary ~ “登录”）
IN 值列表（priority IN (High, Blocker)）
IS 空值（duedate IS EMPTY）
AND / OR / NOT 逻辑组合
ORDER BY 排序（ORDER BY created DESC）

4. 函数（Functions）

函数 含义
currentUser() 当前用户
startOfWeek()/endOfWeek() 周边界
startOfDay()/endOfDay() 日边界
membersOf("组名") 组内成员
issueHistory() 近期浏览
now() 当前时间

示例：

5. 保存筛选器与分享

分享后其他人可在 Filters → 收藏/搜索 中使用；Dashboard 与 Board 可直接引用（08-仪表盘与报表）。

6. 高级技巧

  • 嵌套/括号：project = PAY AND (priority = High OR labels = urgent)
  • 负向：assignee is not EMPTY
  • 按历史字段：status changed to Done after "2026-10-01"
  • 按团队估算：project = PAY ORDER BY storyPoints DESC

[!warning] 注意

  • JQL 不区分大小写（值可以用引号包裹含空格）；
  • 查询量太大（万级）会慢，用项目/日期收窄（13-性能优化）；
  • 分享筛选器=共享查询逻辑，改名/删除会影响引用方。
