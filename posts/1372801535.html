Kibana 可视化与仪表盘

📑是什么
Kibana 是 ELK 的可视化门户：检索数据（Discover）、制作图表（Visualize）、组装仪表盘（Dashboard）。

🔥KQL 要点
字段名: 值；and / or / not 组合；>= <= 数值比较；* 通配（如 host: web-*）。

创建数据视图（Index Pattern）¶

Stack Management → Data Views → Create data view：

常用可视化类型¶

类型 适用
Lens（推荐） 拖拽式通用图表
TSVB / 时间序列 时间曲线
Pie / Donut 占比
Data table 明细表格
Maps IP 地理分布
Discover 表格 原始日志

制作仪表盘流程¶

  1. Create dashboard → 添加面板；
  2. 用 Lens 拖入：X 轴 @timestamp（date_histogram）、Y 轴 count 或 Average of request_time；
  3. 加过滤（如只显示 app: nginx）；
  4. 保存并分享（embed 链接或导出 PDF/CSV）。
