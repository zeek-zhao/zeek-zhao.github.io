2026-07-15工具集总览 本知识库收集整理了各类实用工具和软件，目的是提高效率、解决技术问题、优化工作流程。工具按功能和平台两个维度分类，方便快速查找和使用。 2026-07-14Docker 是什么 先抓住三个对象——镜像、容器、仓库，Docker 就没那么抽象了。镜像是运行环境模板，容器是镜像运行后的实例，仓库是镜像存储与分发的位置。 2026-07-13Docker 安装与卸载 优先使用 Docker CLI 插件（docker compose），其次再考虑 docker-compose。 2026-07-12Docker 运行 Nginx 用 Docker 拉取 Nginx 镜像并通过端口映射运行可访问的容器 2026-07-11Docker 运行 Java 项目 同一个 jar 包有四种跑法：原生 jar、Java 镜像环境、可远程调试、从镜像仓库拉取。我的判断是，本地开发优先用远程调试方式定位问题，上线则走镜像仓库方式，把配置通过环境变量注入，别把 profile 写死在命令里。 2026-07-10Docker 常用命令 这份速查覆盖基本、开发、容器信息、运维和镜像构建五类高频命令。我的判断是，日常最容易出事的是删除操作——务必按“停容器→删容器→删镜像”的顺序来，批量清理前先用查询命令确认目标，别直接全量执行。 2026-07-09Docker 认证私有仓库的密码安全问题 用 pass 外部凭证存储保护 Docker 仓库登录凭证：从 GPG 密钥、docker-credential-pass 到 config.json 的完整配置与验证。 2026-07-08Docker 基于容器创建一个新的镜像 用 docker commit 把改过内容的容器提交成新镜像并推送：参数说明与 centos、redis、jenkins 三个完整示例。 2026-07-07Docker 导入导出镜像 把改过的容器 commit 成镜像后用 docker save 导出、docker load 导入的完整流程，含 nginx 首页修改示例。 2026-07-06Docker 镜像推送 把本地镜像推到仓库其实是四步走：登录、拉取、改名、推送。我判断 docker tag 这步最容易被忽略——不改名直接 push，镜像会默认推到 Docker Hub 官方库，而不是你的私服，所以仓库地址一定要写全。
