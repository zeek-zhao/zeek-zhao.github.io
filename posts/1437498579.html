[!info] 资料导航
本指南汇总 FreeRTOS 官方文档、书籍、AWS 集成、中文教程、调试工具与社区资源，按学习路径分层整理，供检索与深入研读。

一、官方文档

FreeRTOS 官方知识库由 AWS 维护，提供英文与简体中文界面。

  • 文档总览（英文）：https://freertos.org/Documentation/00-Overview
  • 文档总览（中文）：https://www.freertos.org/zh-cn-cmn-s/Documentation/00-Overview
  • 快速入门指南：https://www.freertos.org/zh-cn-cmn-s/Documentation/01-FreeRTOS-quick-start/01-Beginners-guide/02-Quick-start-guide
  • 官方文档覆盖内核概念、API 参考、编码规范、库说明与版本路线图，是权威依据。

二、权威书籍

  • Mastering the FreeRTOS Real Time Kernel（作者 Richard Barry）：https://freertos.org/Documentation/02-Kernel/07-Books-and-manual/01-RTOS_book
  • GitHub Releases 下载（含 PDF 与示例源码）：https://github.com/FreeRTOS/FreeRTOS-Kernel-Book/releases
  • 最新 V1.1.0 PDF：https://github.com/FreeRTOS/FreeRTOS-Kernel-Book/releases/download/V1.1.0/Mastering-the-FreeRTOS-Real-Time-Kernel.v1.1.0.pdf
  • 该书为官方实操教程，从入门到源码剖析循序渐进，配套示例代码。

三、AWS FreeRTOS

  • AWS FreeRTOS 资源中心：https://aws.amazon.com/freertos/resources/
  • 用户指南（英文）：https://docs.aws.amazon.com/freertos/latest/userguide/
  • 入门指南：https://www.aws.amazon.com/freertos/getting-started/
  • 集成 AWS IoT 连接、安全与 OTA 更新，提供 Windows 模拟器便于无硬件上手。

四、中文教程与学习资源

  • 百问网 FreeRTOS 视频教程汇总：https://rtos.100ask.net/docs/all_video_tutorials
  • CHSGY/FreeRTOS 中英双语学习仓库：https://github.com/Despacito0o/FreeRTOS
  • 成功大学 FreeRTOS Wiki：http://wiki.csie.ncku.edu.tw/embedded/freertos
  • 中文书籍推荐：野火《FreeRTOS 内核实现与应用开发实战指南：基于 STM32》、许颖劲《FreeRTOS 源码详解与应用开发（第 2 版）》、基于 STM32Cube 与 Tracealyzer 的应用开发（第 2 版）。
  • B 站配套视频：野火 FreeRTOS 实战、正点原子 RTOS 入门、刘火良内核实战。

五、调试与跟踪工具

  • Percepio Tracealyzer：https://percepio.com/tracealyzer/
  • FreeRTOS 官方 Tracealyzer 介绍页：https://www.freertos.org/Documentation/03-Libraries/02-FreeRTOS-plus/05-FreeRTOS_plus_Trace/00-FreeRTOS_Plus_Trace
  • Tracealyzer 提供 30 余种交互式视图，基于内核 trace hooks 无需修改源码，支持流式与快照模式，兼容主流工具链与开发板。
  • SEGGER SystemView 与 FreeRTOS 插件：https://www.segger.com/products/development-tools/systemview/

六、社区与源码

  • FreeRTOS 社区论坛：https://forums.freertos.org/
  • GitHub 主仓库：https://github.com/FreeRTOS/FreeRTOS
  • 官方贡献指南：https://www.freertos.org/Documentation/01-FreeRTOS-quick-start/01-Beginners-guide/06-Join-the-FreeRTOS-community
  • 社区提供内核讨论、库支持、网络研讨会与商业支持渠道。

七、学习路径建议

入门阶段研读官方快速入门与 Mastering 书籍前几章，配合开发板搭建环境；进阶阶段深入 API 参考与源码分析，结合 Tracealyzer 观察调度行为；高级阶段研究 AWS 集成、网络栈与安全特性，参与社区讨论解决实际问题。

八、工具链与集成环境

主流 IDE 与工具链对 FreeRTOS 提供原生或插件支持，提升开发调试效率。STM32CubeIDE、IAR、Keil、VS Code 与 ESP-IDF 均有成熟集成方案，提供任务视图、栈统计与内核对象监控。官方与厂商示例工程覆盖主流评估板，可快速起步验证配置。建议优先使用官方与厂商维护的集成环境，减少自定义配置成本，并定期升级工具链获取内核调试增强功能。
