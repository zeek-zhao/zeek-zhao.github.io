31-角色与用户管理

发表于2026-10-24|selinux
|浏览量:

[!info] 本节目标
掌握 SELinux 用户、角色与登录映射的配置方法。

1. SELinux 用户体系

SELinux 用户是策略层的身份抽象，如 root、user_u、staff_u。登录用户通过映射绑定 SELinux 用户，决定其初始域与可用角色，是权限边界的基础。

2. 默认映射

系统默认将普通登录用户映射到 unconfined_u 或 user_u，root 映射到 root。映射决定用户进程域：user_u 受限、unconfined_u 非受限，安全差异显著。

3. 角色与域

角色（role）关联域集合，如 staff_r 含 sysadm_t 与 staff_t，通过角色切换实现提权。角色机制实现职责分离，管理员与普通用户使用不同角色域。

4. 配置命令

semanage login -a/-m/-d 管理登录映射，semanage user -a/-m 管理用户定义，semanage login -l 查看映射。修改后新登录生效，现有会话不受影响。

5. 场景实践

安全环境将普通用户映射 user_u，运维用户映射 staff_u 并授予 sudo 提权路径；禁用 unconfined 登录；root 登录限制与审计强化。

6. 注意事项

映射错误导致用户无法登录或权限不足，修改前备份映射并预留恢复通道；结合 PAM 与 sudo 策略协同，避免单点失效。

7. 角色转换实践

staff 用户通过 newrole 切换到 sysadm 角色执行管理任务，转换需输入认证且受策略约束。角色转换实现最小特权与职责分离，日常操作保持低权限域。配置转换路径时确保策略允许对应域权限，测试覆盖登录、转换、退出全流程。审计日志记录转换行为，支撑安全审查。

8. 用户映射审计

定期审计登录映射与用户角色，清理不再使用账户。root 直接登录与 sudo 提权路径分别管控，降低风险。映射变更走审批并记录，异常登录及时处置。审计报告支撑合规与安全改进。

9. 权限收敛策略

按职责最小化分配角色与域，收敛 root 使用。周期性复查权限清单，移除过期授权。权限收敛降低内部威胁与误操作风险，是安全运营的持续任务。
