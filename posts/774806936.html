Harbor私服部署

Harbor 是用来存储和分发 Docker 镜像的企业级 Registry 服务器。我这里的部署基于 docker 和 docker-compose，装好之后走一遍推送/拉取流程，私服就算通了。文中的安装路径、域名和密码按自己的环境替换即可。

本次环境版本：

  1. Docker version 20.10.8, build 3967b7d
  2. docker-compose version 1.29.2, build 5becea4c

下载离线包并按模板改好配置再安装¶

整套安装就是「下载 → 解压 → 拷贝配置模板 → 改配置 → 执行 install.sh」。注意 harbor.yml 由 harbor.yml.tmpl 拷来，别直接改模板。

下面是我用的 harbor.yml 配置 demo，按自己的情况改即可。hostname 不要用 localhost 或 127.0.0.1，因为 Harbor 需要被外部客户端访问。

登录 Harbor 要先把 HTTP 私服加进信任列表¶

docker login 走 IP 认证会报错，因为 Docker 默认要求 HTTPS。我倾向于配 hosts 解析用域名登录，比改 daemon.json 更省事；两种办法都列在下面。

报错时截图如下：

⚠️未转换的 Obsidian 嵌入: 73b95277b9b86b76c7d84246fac8d2f9_MD5.png

可参考官方文档： https://goharbor.io/docs/2.3.0/install-config/run-installer-script/#connect-http

办法一：在 /etc/docker/daemon.json 里加 insecure-registries，然后重载并重启 Docker。

办法二：改 hosts 解析。我本地实测改完 hosts 立即生效，再登录 Harbor 就通了。

⚠️未转换的 Obsidian 嵌入: d6e9d0b30cc4056b83b20bb53cc22834_MD5.png

再次登录，成功：

安装报 ssl_cert 未设置时，注释掉 https 配置¶

如果安装阶段报 The protocol is https but attribute ssl_cert is not set，说明 https 配置没给证书却又被启用了。把 harbor.yml 里的 https 相关段落注释掉即可。
