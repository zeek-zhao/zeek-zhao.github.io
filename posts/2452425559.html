15-常见问题排错

curl -s $AUTH "$BASE/service/rest/v1/repositories/maven/proxy/maven-central"
📅 2026-10-24· 更新于 2026-10-24 ✍ zeek.zhao #工具#nexus3

常见问题排错

📑高频故障速查
按”现象 → 排查 → 解法”组织：认证、上传下载、代理缓存、磁盘与迁移。

1. 认证与权限¶

现象 排查 解法
401 Unauthorized 用户名/token 错误 用户 → API Key 重新生成
403 Forbidden 角色权限不足 检查仓库权限（09-权限与匿名访问）
匿名访问被拒 匿名策略关闭 安全基线评估后开启或配置认证
发布被拒 deployer 角色缺 add/edit 授予仓库写权限

2. 上传问题¶

现象 排查 解法
400 Bad Request 版本已存在/策略冲突 release 库禁覆盖：升版本或改策略
413 Request Entity Too Large nginx 限制 client_max_body_size 调大
上传卡死 磁盘 IO/内存 看 nexus.log；扩容/低峰重试
ASSET_CREATE_FAILED Blob 配额满 清理 + Compact（10-Cleanup与任务调度）

3. 拉取问题¶

现象 排查 解法
404 Not Found group 成员缺失/顺序 检查 group 成员与顺序
拉不到最新版本 proxy 缓存过期 仓库 → Expire cache
proxy 仓库红色 外部源不可达 检查远程 URL / 网络 / auto block 解除
慢 磁盘/网络 见 14-性能调优

4. 代理仓库故障¶

状态 处理
blocked 外部源持续失败，修复网络后 Unblock
unavailable 远程不可达，检查 URL/DNS/防火墙
available 正常

5. 存储与磁盘¶

现象 处理
Blob 满/只读 清理策略 + Compact；扩容/迁移（08-Blob Store与存储）
磁盘空间急剧下降 查 nexus.log 大任务；Compact 后验证
组件显示但资产 404 Blob 与索引不一致：Rebuild browse；检查恢复错位

6. 迁移/升级问题¶

现象 处理
升级后无法启动 检查版本差异；恢复旧版备份；看 nexus.log 栈
OrientDB→H2 迁移失败 官方升级工具/支持；备份保留
仓库列表空白 配置库损坏：从备份恢复

7. 日志定位¶

🔥万能流程
备份在手 → 测试复现 → 查日志 → 官方文档/工单。生产改动前先备份（12-备份恢复）。
⚠️红线
不要手动删除 Blob 目录文件”腾空间”（索引/一致性损坏）；走 Cleanup + Compact。
