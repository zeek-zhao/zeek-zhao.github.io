16-XML与JSON处理

发表于2026-10-24|qt
|浏览量:

[!info] 本节目标
掌握 Qt 对 XML 与 JSON 数据的解析与生成。

1. 数据格式概述

XML 与 JSON 是交换数据的两种主流格式。XML 结构严谨支持复杂嵌套与命名空间，常用于配置文件与文档交换；JSON 轻量直观广泛用于网络接口与日志。按场景选择格式，必要时双格式支持。

2. JSON 解析与生成

QJsonDocument 解析与序列化 JSON，QJsonObject 与 QJsonArray 描述结构，QJsonValue 承载数据。从字节流构造文档后逐层取值，生成时构建对象树再序列化。错误处理覆盖非法输入与类型不符。

3. XML 解析方式

Qt 提供 DOM 与流式两种解析方式。QDomDocument 构建完整内存树，适合随机访问与修改；QXmlStreamReader 逐事件解析，内存占用低适合大文件。QXmlStreamWriter 流式写出，性能好结构清晰。

4. 数据映射与转换

结构化数据与 C++ 对象间转换是常见需求，手动映射直观可控，自动序列化框架提升效率。QJson 与 QVariant 配合实现通用数据容器。版本字段保障数据演进兼容，未知字段策略明确。

5. 性能对比

JSON 解析速度通常优于 DOM XML，内存占用更低；流式 XML 适合超大文件。高频解析场景缓存结果避免重复解析。数据规模与访问模式决定解析策略选择。

6. 安全与健壮性

解析外部数据需处理异常输入，设置大小限制防止资源耗尽。XML 实体扩展攻击需防护，禁用外部实体解析。JSON 深度限制避免栈溢出，严格校验数据格式与取值范围。

7. 应用实践

配置文件、协议报文与导出数据是主要场景。统一序列化封装层屏蔽格式差异，接口参数使用 QVariantMap 提高通用性。单元测试覆盖序列化往返，详见测试篇。

本节小结

JSON 与 XML 各有适用场景：JSON 轻量直观适合接口与配置，XML 结构严谨适合文档交换。Qt 提供 DOM 与流式两种 XML 解析方式，按数据规模与访问模式选择。解析外部数据时务必处理异常输入、限制资源消耗并防范实体扩展攻击，序列化层统一封装可屏蔽格式差异，保证数据演进兼容。
