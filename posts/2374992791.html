三、书籍与电子书

  • 《Zephyr RTOS Embedded C Programming: Using Embedded RTOS POSIX API》：Andrew Eliasz 著，Apress/Springer 2024，约 677 页。覆盖 Cortex-M、多任务与线程、消息队列/管道/邮箱、文件系统、BLE、以太网/Wi-Fi/TCP-IP、Devicetree、Renode 仿真等。SpringerLink、VitalSource、O’Reilly 有电子版。
  • 《Zephyr RTOS Cookbook》：Roy Jamil 与 Ayoub Bourjilat 著，Packt 2026 年 6 月出版，约 226 页。以菜谱形式讲解 west 工作区、Kconfig、Devicetree、GPIO/I2C/ADC/Logging/Shell、User Mode 安全与驱动模型，附 DRM-free PDF 与代码包，Zephyr 创始人之一 Anas Nashif 作序。
  • 《Zephyr RTOS for Embedded Developers: Theory, Tools, and Projects》：Norms Albert 著，2025 年 12 月出版，约 434 页。覆盖多板配置、外设管理、多线程、功耗优化、固件安全、云连接 IoT、蓝牙与 MQTT。

五、教程与课程

  • 官方 Getting Started Guide：docs.zephyrproject.org 入门路径。
  • Adafruit《Blinking an LED with the Zephyr RTOS》：面向初学者的安装、west、构建与点亮 LED 教程。
  • Bluetooth SIG《Bluetooth LE Developer Study Guide V5.1》：以 Zephyr 为平台的 BLE/GATT/GAP 理论与实践。
  • Nordic Developer Academy – nRF Connect SDK Fundamentals：约 8 小时免费课程，前 4 课（构建系统、Devicetree、GPIO、线程）可迁移至任意 Zephyr 板，被广泛评价为最佳结构化课程。
  • Memfault Practical Zephyr Blog Series：工程实践系列博客，覆盖构建、调试与部署。
  • DigiKey Zephyr Tutorial Series、Golioth Free Zephyr Training、PlatformIO + Zephyr 教程：社区补充学习路径。

六、主题速查

  • 模拟调试：QEMU 调试（ninja debugserver / west build -t debugserver_qemu / gdb target remote localhost:1234）；native_sim 原生调试、valgrind、ASAN，注意无限快时钟模型禁止忙等。
  • 低功耗：CONFIG_PM、CONFIG_PM_DEVICE_RUNTIME、电源策略管理器、tickless idle；调试时临时关闭 PM 或锁定电源状态。
  • 安全：TF-M 可信执行环境、MPU 内存隔离、mbedTLS/TLS/DTLS、PSA Crypto；生产密钥唯一、禁用默认 MCUboot 密钥。
  • OTA：MCUboot + 签名验证 + 双槽位 + 确认回滚；imgtool.py ECDSA-P256/RSA 签名；版本单调性防降级。
  • CMake 模块：3.7 起 EXTRA_ZEPHYR_MODULES 取代 ZEPHYR_EXTRA_MODULES；模块经 zephyr/module.yml 声明 cmake/kconfig/sysbuild/depends，构建系统注入 ZEPHYR_模块名_MODULE_DIR 等变量。
  • 版本与 LTS：Zephyr 3.7.0 为当前 LTS（LTS3，维护至 2029-07）；稳定版支持约 1 年；4.x 为最新主线。

七、学习路径建议

  1. 先掌握 RTOS 基础概念：任务、队列、信号量、互斥量、定时器、优先级反转与死锁。
  2. 按官方文档完成 blinky 与 hello_world 构建，熟悉 west 工作流。
  3. 系统学习构建系统、Devicetree、GPIO 与线程（可借助 Nordic Academy 课程）。
  4. 进阶阅读书籍与实战项目，结合 QEMU/native_sim 动手实验。
  5. 求助路径：先查文档与邮件归档，再到 Discord / 邮件列表提问并附最小可复现信息。
