SSH 配置与账号

[!abstract] 为什么必须配 SSH
Gerrit 的 git 推送与 ssh -p 29418 user@host gerrit ... 管理命令都走 SSH。先用 SSH 建立身份，才能 push refs/for 做评审。

1. 生成并注册密钥

浏览器打开 Settings → SSH Keys，粘贴公钥保存。

[!note] 多用户场景
一个账号可注册多个公钥（笔记本/CI/跳板机）。私钥不要离开个人设备。

5. 账号体系与类型

认证类型 账号来源 适用
HTTP 反向代理 SSO 头 企业统一登录
LDAP AD/LDAP 目录 企业内网
OpenID/OAuth 第三方 公网/开源
DEVELOPMENT_BECOME_ANY_ACCOUNT 自建 测试环境

[!warning] 注意

  • SSH 用户名要与 Gerrit 账号名一致（http.password 只影响 HTTP）；
  • 公司代理环境 SSH 端口 29418 需放通；
  • 修改用户名会导致旧引用不可用，建议账号名稳定（如工号/邮箱前缀）。

6. 排错速查

症状 原因
Permission denied (publickey) 公钥未注册 / 用户名错 / 私钥路径错
Connection refused 29418 sshd 未启用或端口没监听
Host key verification failed 首次连接需确认 host key
command not found 老版本 Gerrit 无对应命令
