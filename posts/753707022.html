GPT常用提示词指南

提示词工程是让 AI 输出稳定可用的关键技能¶

本文介绍了GPT模型的提示词(Prompt)工程技术，包含提示词的基本概念、结构和设计原则，以及各种场景下的实用提示词模板。掌握这些技巧将帮助您更有效地与AI沟通，获得更加精确和有用的回答。

我的判断是：提示词不是越花哨越好，把角色、任务、格式和约束四件事写清楚，输出质量就已经超过大多数”随便问问”。

提示词是你输入给 AI 的指令，质量取决于是否说清意图¶

提示词是用户向AI模型输入的指令或问题，它引导AI生成回答的方向和内容。一个好的提示词能够让AI准确理解用户意图，并生成符合期望的高质量回答。

📝提示词工程
提示词工程(Prompt Engineering)是指设计、优化和精炼提示词的过程，目的是使AI模型能够产生最符合用户期望的输出。

提示词的四个核心要素¶

  • 清晰性：确保您的指令明确、具体且不含糊。AI不能读心，它只能根据您提供的文字来理解任务。
  • 上下文：提供足够的背景信息，帮助AI理解问题所处的环境和前提条件。
  • 具体性：指定输出的格式、长度、风格和预期内容，避免模糊的请求。
  • 示例：在复杂任务中提供示例可以大大提高AI理解任务的能力。

一个完整提示词由角色、任务、格式、示例约束四段组成¶

一个完整的提示词通常包含以下部分：

1. 角色设定¶

通过为AI指定一个特定的角色，可以引导它以特定的专业知识或视角回答问题。

示例：

请以一名经验丰富的数据科学家的身份，解释…
作为一位Python编程专家，请帮我…
你是一位专业的英语教师，请纠正我的语法错误…

2. 任务描述¶

清晰地描述您希望AI完成的任务，包括任务目标和必要的背景信息。

示例：

分析下面这段代码中的性能问题并提出改进建议…
为一个销售健康食品的电商网站撰写一段吸引人的产品描述…

3. 格式要求¶

格式指定示例：

  • 请用表格形式列出结果
  • 请用Markdown格式回答
  • 将答案组织为带编号的步骤
  • 以JSON格式返回数据

4. 示例或约束条件¶

提供示例或设定限制可以进一步引导AI的输出方向。

示例：
回答长度不超过200字
请以5个要点概括主要内容
参照以下例子进行回答：[示例内容]

六类常用模板覆盖内容、技术、学习、代码、数据和排障¶

1. 内容创作类提示词¶

博客文章

请以[角色]的身份，创作一篇关于[主题]的博客文章。文章应当包含以下部分：引言、[3-5个主要部分]、结论。每个部分需要包含具体的例子和数据支持。语调应当是[语调类型]，目标受众是[受众描述]。文章长度约为[字数]字。

社交媒体内容

为[产品/服务/品牌]创作5条[平台名称]帖子，每条不超过[字数]字。内容应强调[卖点/特色]，包含[1-2个]相关话题标签，并加入一个吸引人点击的号召性用语。语调应该是[正式/轻松/幽默]的。

2. 技术文档类提示词¶

请编写一份[技术名称]的技术文档，包括以下部分：

  1. 概述：简要解释该技术的用途和重要性
  2. 安装/配置步骤：提供详细的步骤和代码示例
  3. 核心功能：解释主要功能和API
  4. 常见问题及解决方案：列出使用中可能遇到的问题
  5. 最佳实践：提供优化使用该技术的建议

文档应该适合[初级/中级/高级]开发者阅读，并使用Markdown格式。

3. 学习辅助类提示词¶

🔥学习提示词
我想深入学习[主题]，目前我的知识水平是[初学者/有一定基础/高级]。请为我创建一个10天的学习计划，每天包含：
  1. 学习目标
  2. 需要掌握的核心概念（附简要解释）
  3. 推荐的学习资源（书籍/文章/视频）
  4. 实践练习
  5. 自测问题

学习计划应循序渐进，从基础到高级，每天的学习内容应当建立在前一天的基础上。

5. 数据分析类提示词¶

我有一个关于[主题]的数据集，包含以下字段：

  • [字段1]：[描述]
  • [字段2]：[描述]
    …

我想要:

  1. 进行探索性数据分析，识别关键趋势和模式
  2. 查找[字段X]和[字段Y]之间的相关性
  3. 创建可视化来展示[特定发现]
  4. 基于数据提供关于[商业问题]的建议

请提供分析步骤、Python代码和结果解释。

6. 问题解决类提示词¶

我遇到了以下问题：[详细问题描述]

环境/背景：

  • [系统/软件版本]
  • [相关配置]
  • [已尝试的解决方案]

错误信息：[完整的错误消息]

我的目标是：[期望达到的结果]

请帮我：

  1. 分析可能的原因
  2. 提供解决步骤
  3. 解释为什么会出现这个问题
  4. 提供防止此类问题再次发生的建议

四种高级技巧让输出更可控¶

1. 链式思考提示词¶

请一步步思考以下问题：[复杂问题]

  1. 首先，分析问题的核心是什么
  2. 确定解决这个问题所需的信息和方法
  3. 系统地应用这些方法
  4. 验证结果的合理性
  5. 得出最终结论

请在每一步展示你的推理过程。

3. 角色扮演提示词¶

我希望你扮演[特定角色]的角色。你拥有[相关经验和知识]，对[领域]有深入的理解。
我现在遇到了[问题/情况]，需要你从[角色]的视角提供专业建议或见解。
在回答时，请考虑[特定因素]，并使用[角色]会使用的专业术语和表达方式。

4. 对比分析提示词¶

📝对比分析
请对比分析[概念A]和[概念B]之间的异同点。

分析应包括：

  1. 两者的定义
  2. 核心特点对比
  3. 适用场景比较
  4. 优缺点分析
  5. 具体使用案例

请使用表格形式呈现主要对比点，并在表格后提供详细的文字解释。

2. 内容创作场景¶

SEO文章提示词

请创作一篇针对关键词”[主关键词]”优化的SEO文章，要求：

  1. 包含H1标题，使用主关键词
  2. 至少5个H2小标题，自然融入相关关键词
  3. 文章长度约[字数]字
  4. 加入[数量]个内部链接占位符
  5. 文章开头有吸引人的引言
  6. 文章结尾有明确的号召性用语
  7. 融入[2-3个]相关统计数据或案例
  8. 语调专业但平易近人
  9. 添加FAQ部分，包含5个与主题相关的常见问题

目标受众：[受众描述]

产品描述提示词

请为以下产品编写一段吸引人的产品描述：

产品名称：[名称]
产品类型：[类型]
主要特点：

  • [特点1]
  • [特点2]
  • [特点3]
    目标客户：[客户描述]
    价格区间：[价格]
    独特卖点：[卖点]

产品描述应强调产品的好处而非功能，使用感性的语言吸引目标客户，长度约为[字数]字。

3. 教育学习场景¶

概念解释提示词

请用简单易懂的语言解释[复杂概念]，就像向一个[年龄/知识水平]的人解释一样。

解释中需要：

  1. 使用生活中的类比
  2. 提供具体的例子
  3. 分解为基本原理
  4. 避免使用行业术语，或在使用时提供解释
  5. 如果可能，添加视觉描述或类比

最后，提供1-2个简单的活动或思考习题，帮助加深理解。

学科辅导提示词

我正在学习[学科][具体主题]，目前遇到了以下问题：

[问题描述]

我的理解是：[学生目前的理解]

请帮我：

  1. 判断我的理解是否正确
  2. 解释正确的概念
  3. 提供一步步的解题方法
  4. 给我一些类似的练习题

提示词优化是初始、分析、调整、测试的循环¶

优化提示词是一个迭代过程，可以遵循以下步骤：

  1. 开始使用初始提示词
  2. 分析AI的回答
  3. 调整提示词
  4. 重复测试

提示词优化技巧¶

  • 增加细节：向提示词中添加更多具体的要求和背景信息。
  • 修改结构：改变提示词的组织结构，比如将复杂任务分解为子任务。
  • 调整语气：修改提示词的语气或用词，使指令更加明确或友好。
  • 添加约束：增加输出限制或格式要求，引导AI生成更符合期望的回答。

常见问题与解决方案¶

问题 解决方案
AI回答过于冗长 添加具体的长度限制或要求简洁回答
回答不够具体 提供更详细的问题背景和明确的要求
回答偏离主题 明确指出核心问题，增加关注点提示
回答缺乏创意 鼓励AI思考多个角度或提供创新思路
回答过于技术化 要求使用简单语言或针对特定受众解释

用 AI 时守住伦理底线¶

在使用提示词与AI交流时，请注意以下伦理原则：

⚠️伦理提醒
  • 避免使用提示词诱导AI生成有害、歧视或不当内容
  • 尊重知识产权，不要要求AI复制受版权保护的内容
  • 对AI生成的内容保持批判性思考
  • 不要过度依赖AI进行专业决策
  • 在需要专业建议的情况下，咨询人类专家

好提示词的本质是清晰、具体、有结构且带上下文¶

掌握提示词技巧是有效使用AI工具的关键。通过不断实践和优化提示词，您可以显著提高与AI交互的效率和质量。记住，好的提示词就像与AI的良好对话—清晰、具体、有结构且富有上下文。
