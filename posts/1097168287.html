安全与健壮性

ℹ️本页概览
生产级 Shell 脚本必须安全健壮：引号与字面量、set 严格模式、输入校验、命令注入防护、权限最小化、临时文件安全与错误处理策略。

核心概念¶

  • 引号即安全：未加引号的变量展开是命令注入与单词拆分的源头。
  • 严格模式：set -euo pipefail 快速失败。
  • 输入不可信：用户输入、文件名、网络数据都可能是恶意内容。
  • 临时文件用 mktemp 而非固定路径，防符号链接攻击。

常见坑¶

  1. 未加引号：空格/通配符拆分，导致误删文件或注入。
  2. eval/反引号执行不可信内容：命令注入风险，禁用 eval。
  3. 固定临时文件路径：多进程冲突、符号链接覆盖攻击；用 mktemp。
  4. set -e 与 grep：grep 无匹配返回 1 导致脚本退出；用 || true 或 if grep。
  5. 秘密进命令行：密码、token 出现在 ps、shell history、日志；用环境变量/stdin。
  6. 校验缺失：越界、非法字符、相对路径穿越；全部白名单校验。
  7. sudo 脚本：校验输入后再拼接，避免把参数直接传 sudo sh -c。

最佳实践¶

  • 全部变量加引号："$@"、"$var"；需要拆词才故意不加。
  • 函数入口校验参数；脚本入口校验环境（root、依赖命令）。
  • 删除/覆盖类操作双确认；非交互脚本默认不执行危险动作。
  • 用 mktemp + trap 管理临时资源（见 18-信号处理与trap）。
  • 敏感信息只读一次（环境变量），不落盘、不打日志。
