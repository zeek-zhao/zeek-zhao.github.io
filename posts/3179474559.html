常用工具类与字符串

ℹ️本页概览
本文讲解 String/StringBuilder、包装类、Math、Arrays、Objects、Optional、日期时间 API（java.time），配可运行示例与性能陷阱。

核心概念¶

  • String 不可变：每次拼接产生新对象，大量拼接用 StringBuilder。
  • 字符串常量池：字面量复用，new String() 不进入常量池。
  • 包装类：类型转换、缓存、parse 工具。
  • java.time：LocalDate/LocalTime/LocalDateTime/Instant/DateTimeFormatter。

常见坑¶

  1. 循环内 + 拼接：性能差；用 StringBuilder。
  2. == 比较字符串：new String("a") == "a" 为 false；用 equals。
  3. **"abc".equals(s) 与 s.equals("abc")**：前者空安全，后者可能 NPE。
  4. substring 半开区间：substring(0, 5) 不含第 5 个字符。
  5. 旧 Date/SimpleDateFormat 线程不安全：新代码用 java.time。
  6. StringBuilder 未调 toString 就输出：打印对象地址而非内容。
  7. Math.random() 含 0 不含 1：取 [0, N) 用 (int)(Math.random() * N)。

最佳实践¶

  • 字符串判空用 isBlank()（Java 11+），覆盖空白字符。
  • 拼接大量字符串用 StringBuilder；少量用 + 可读。
  • 金额比较用 BigDecimal（见 07-异常处理 后数值专题可扩展）。
  • 时间计算一律用 java.time，避免 Date 的时区/线程安全问题。
  • 返回可能为 null 的值时用 Optional 表达”可能缺失”语义。
