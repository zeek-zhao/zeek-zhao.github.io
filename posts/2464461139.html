综合实战项目：待办清单命令行工具 + Web API

[!info] 本页概览
综合运用本套教程知识：类型注解、dataclass、文件存储、argparse、测试、打包，实现一个待办清单 CLI 工具，再包装为 FastAPI 接口，形成完整项目闭环。

需求设计

功能：

  1. todo add "写周报"：新增待办
  2. todo list：列出全部
  3. todo done <id>：标记完成
  4. todo delete <id>：删除
  5. 数据持久化到 JSON 文件

技术选型：dataclass + pathlib + argparse + pytest，符合 17-打包发布 的 src 布局。

项目结构

数据层（store.py）

命令行入口（cli.py）

Web 接口（app.py）

测试（tests/test_store.py）

运行与发布

复盘要点

  1. 数据层与入口分离：Store 可独立测试，CLI/API 只是薄壳。
  2. 类型注解贯穿：IDE 与 mypy 友好。
  3. 异常转 HTTP：KeyError → 404，语义清晰。
  4. 加分项：加 --storage 参数、并发线程安全、导出 Markdown、Docker 部署。
