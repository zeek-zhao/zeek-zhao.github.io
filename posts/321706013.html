07-布局管理

Qt 布局系统实战：QHBoxLayout/QVBoxLayout/QGridLayout/QFormLayout 的组合用法、sizePolicy 伸缩策略、QScrollArea 自适应，附可运行 C++ 示例与四条踩坑。

ℹ️本节目标
掌握 Qt 布局系统实现自适应界面。

适用版本：Qt 5.15+ / Qt 6.x（下列示例在 Qt 6.5 + C++17 验证）。Qt 5 与 6 的布局 API 基本一致。

1. 布局概述¶

布局管理器自动计算控件位置与大小，窗口缩放时保持合理排布，是自适应界面的核心。Qt 提供四种基础布局：

布局类 排布方式 典型场景
QHBoxLayout 水平一行 工具栏、按钮组
QVBoxLayout 垂直一列 表单纵向堆叠
QGridLayout 行列网格 计算器、仪表盘
QFormLayout 标签-输入对 设置项、参数录入

组合使用这四种布局，可覆盖绝大多数界面结构。

3. 尺寸策略与伸缩¶

控件尺寸策略（QSizePolicy）控制伸缩行为，addStretch(factor) 的伸缩因子决定剩余空间分配比例。合理设置 setMinimumSize / setMaximumSize 与 sizePolicy 可避免界面变形：

  • 列表与文本区域：设为 Expanding，允许随窗口扩展。
  • 按钮与标签：保持 Fixed 或 Preferred，不要被拉伸变形。
  • 需要等比例分配时，给多个 stretch 设相同因子。

4. 边距与间距¶

三个概念别混淆：

  • 布局边距（setContentsMargins）：布局整体与父窗口的留白。
  • 间距（setSpacing）：控件之间的空隙。
  • 内容边距（QSS padding）：控件内部的内边距。

5. 滚动与自适应¶

长内容区域嵌入 QScrollArea 实现滚动。关键点：给 scroll area 设置一个内部 widget，并让内容布局设置到这个 widget 上，否则不会出现滚动条。

窗口最小尺寸与初始尺寸要合理设置（setMinimumSize），避免启动时布局跳动；高分辨率屏幕注意缩放策略（Qt 6 默认支持高 DPI）。

6. 代码与设计器¶

布局可在 Qt Designer 中可视化编辑（生成 .ui 文件），也可代码动态创建：

  • 设计器：适合静态界面，所见即所得，.ui 经 uic 编译生成的代码与手写等价。
  • 代码：适合动态界面、运行时按数据生成控件的场景。

两者可按场景结合——静态骨架用设计器，动态部分用代码补充。

7. 布局调试与优化¶

布局问题常见表现为控件重叠、拉伸异常、控件”消失”，排查顺序：

  1. 检查 sizePolicy 是否被设成 Ignored 导致控件不显示。
  2. 检查父布局是否缺少 addStretch，导致空间分配异常。
  3. 临时给 widget 设置背景色（setStyleSheet("background: #f00;")）辅助观察边界。
  4. 复杂界面拆成多个子布局再组装，可维护性显著提升。

常见踩坑¶

  1. 忘记 setWidgetResizable：QScrollArea 不加这一行，内容不会随区域缩放，滚动行为异常。
  2. 对有父布局的 widget 再 setLayout：Qt 会警告 “QWidget already has a layout”，应先移除旧布局。
  3. 只设 minimumSize 不设 sizePolicy：拉伸行为不符合预期，两者要配合。
  4. stretch 加错层级：加在子布局还是父布局，效果完全不同，调试时从上往下逐层看。

小结¶

  • 四种基础布局组合嵌套，覆盖绝大多数界面结构。
  • sizePolicy + stretch 控制伸缩，边距间距显式设置保证跨平台一致。
  • 滚动区域记得 setWidgetResizable(true)；复杂界面拆子布局。

版本兼容说明¶

  • Qt 5.15 与 Qt 6.x 的布局 API 基本一致，示例可直接迁移。
  • Qt 6 默认启用高 DPI 缩放，若需兼容 Qt 5 行为需显式设置 QT_SCALE_FACTOR。
