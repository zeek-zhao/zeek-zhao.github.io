Redis 入门与常用命令

[!info] 本页概览
本文讲解 Redis 入门：安装、五大基础数据结构（String/List/Hash/Set/ZSet）、常用命令、过期策略、应用场景与常见坑，配可运行命令。

核心概念

  • Redis：高性能内存键值数据库，单线程事件模型（I/O 多路复用）。
  • 端口：默认 6379。
  • 数据模型：key-value；value 支持多种数据结构。
  • 特点：内存读写极快（10万+ QPS）、原子命令、持久化可选。
  • 用途：缓存、计数器、分布式锁、消息队列、排行榜。

安装与连接

五大基础结构

String（字符串）

List（列表）

Hash（哈希）

Set（集合）

ZSet（有序集合）

过期与删除

[!note] 过期策略
Redis 过期删除 = 惰性删除（访问时判断）+ 定期删除（每秒抽查）。缓存务必设置 TTL 防止内存涨爆。

常用全局命令

应用场景速查

场景 结构 示例
缓存 String 热点数据 SETEX
计数器 String 点赞 INCR
排行榜 ZSet 积分排行
共同好友 Set SINTER
消息队列 List BLPOP
对象存储 Hash 用户信息
分布式锁 String SETNX + 过期

常见坑

  1. KEYS 阻塞：大库用 SCAN。
  2. 大 key：String 超大值/大集合阻塞删除，用 UNLINK/分批删。
  3. 无 TTL 缓存涨爆：内存淘汰策略 maxmemory + allkeys-lru。
  4. 缓存穿透/击穿/雪崩：见 14-Redis 高级特性。
  5. 单线程误区：命令阻塞（KEYS/大 O 命令）拖垮全部请求。
  6. 不设密码：公网 Redis 常被入侵挖矿；requirepass + 防火墙。

最佳实践

  • key 命名规范：业务:对象:id（user:1:name）。
  • 热 key 拆分、大 value 压缩（gzip）或拆 hash。
  • 连接用连接池，避免每请求新建连接。
  • 结合 13-Redis 持久化与集群 配置持久化与高可用。
