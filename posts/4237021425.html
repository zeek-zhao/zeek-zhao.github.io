IO与NIO

[!info] 本页概览
本文讲解 Java IO 体系：File/Path、字节流与字符流、缓冲流、对象序列化、NIO（Channel/Buffer/Selector）、Files 工具类，配可运行示例与性能对比。

核心概念

  • 传统 IO（java.io）：面向流（Stream），阻塞式：InputStream/OutputStream、Reader/Writer。
  • NIO（java.nio）：面向缓冲区与通道，非阻塞：Channel/Buffer/Selector；Path/Files 简化文件操作。
  • 字符流 vs 字节流：文本用 Reader/Writer（处理编码），二进制用 Stream。
  • try-with-resources 自动关闭（见 07-异常处理）。

常见坑

  1. 文件编码混乱：Windows 默认 GBK，跨平台读文件显式指定 UTF-8。
  2. 流未关闭：资源泄漏；用 try-with-resources。
  3. read() 返回值判断：字节流 read() 返回 -1 表示结束；字符流 read() 返回 int（可 -1）。
  4. Reader.readLine 返回 null 判断：null 表示读完，不是空串。
  5. 序列化版本不一致：serialVersionUID 不匹配抛 InvalidClassException。
  6. Files.writeString 覆盖：默认覆盖；追加用 StandardOpenOption.APPEND。
  7. 中文乱码：FileReader 默认平台编码，跨平台用 Files.newBufferedReader(path, UTF_8)。

最佳实践

  • 新代码优先 NIO.2（Path/Files），代码简洁、错误处理清晰。
  • 大文件用缓冲流 + 定长 byte[]，避免一次性读入内存。
  • 文本处理显式指定字符集 UTF-8。
  • 序列化敏感字段加 transient（密码、token 不落盘）。
  • 网络通信/高并发 IO 用 NIO/Netty（见 18-性能调优）。
