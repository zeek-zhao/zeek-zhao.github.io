结构体与方法

[!info] 本页概览
Go 没有类，用结构体（struct）组织数据、方法（method）绑定行为。本文讲解结构体定义、值/指针接收者、嵌入（embedding）与 JSON 标记。

核心概念

结构体是字段的集合；方法是为特定类型定义的函数（接收者 receiver）。值接收者操作副本，指针接收者操作原对象。Go 通过嵌入（匿名字段）实现类似继承的复用。

[!tip] 接收者选择
需要修改接收者、或结构体较大时用指针接收者；否则值接收者。同一类型的方法应统一接收者风格（混用是糟糕实践）。

常见坑

  1. 值接收者方法不会修改原对象：c.Inc() 若定义成值接收者，调用后 value 不变（编译不报错，逻辑错误）。
  2. 复制含 mutex/切片的结构体：结构体值拷贝会把锁复制（危险）、切片共享底层数组，注意语义。
  3. 嵌入字段冲突：外层与嵌入类型同名方法/字段，外层优先；同名嵌入字段需显式指定。
  4. 构造后忘初始化嵌入字段：字面量初始化嵌入字段必须写 Animal: Animal{...}，否则零值。
  5. 方法接收者与接口匹配：值类型实现的方法集与指针类型不同，接口断言容易踩（见 07-接口）。

最佳实践

  • 结构体命名用驼峰；字段注释文档化。
  • 方法接收者统一：修改型用 *T，只读型视大小定。
  • 用构造函数模式：func NewStudent(name string, age int) *Student { ... } 集中校验与初始化。
  • JSON 序列化用 tag 明确字段名，敏感字段用 json:"-" 排除。
  • 面向对象场景优先”组合 + 接口”而非深继承。
