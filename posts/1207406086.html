01-Yocto简介与历史

发表于2026-10-24|yocto
|浏览量:

[!info] 本节目标
理解 Yocto 项目是什么、为什么需要它，以及它的发展脉络。

1. 什么是 Yocto

Yocto Project 是一个开源协作项目，提供构建自定义嵌入式 Linux 系统的工具、模板与方法。它不是单一的发行版，而是一套元数据、工具链与构建框架，帮助开发者为特定硬件定制轻量、可裁剪的 Linux 镜像。

2. 为什么需要 Yocto

嵌入式设备形态多样，处理器架构、外设与功能需求各不相同。通用发行版体积大、灵活性低，难以满足产品化需求。Yocto 提供高度可配置的构建系统，让团队能够从源码构建整个系统，精确控制每一层软件。

3. 核心特性

特性 说明
可定制 通过 Layer 与 Recipe 自由组合软件
可复现 固定版本与哈希，构建结果可复现
架构支持 支持 x86/ARM/RISC-V 等广泛架构
生态丰富 社区维护数千个软件配方
长期稳定 每年两次正式版本发布

4. 版本演进

Yocto 以代号命名版本，每六个到九个月发布一次。常见版本包括 Thud、Warrior、Zeus、Dunfell、Kirkstone、Langdale、Mickledore、Scarthgap 等，其中 Dunfell 与 Kirkstone 为长期支持版本，适合产品化使用。

5. 与 Linux 发行版的关系

Yocto 不是发行版，而是发行版生成工具。Poky 是 Yocto 的参考发行版，其他发行版如 Wind River Linux、Ubuntu Core 等也在一定程度上借鉴或使用 Yocto 技术。

6. 学习价值

掌握 Yocto 意味着掌握嵌入式 Linux 工程化的核心能力：从源码到镜像的完整链路、构建系统原理、层与配方管理。这些能力在产品开发、运维与团队协作中极具价值，也是理解 Buildroot、OpenEmbedded 等生态的基础。

7. 与 OpenEmbedded 的关系

Yocto 项目与 OpenEmbedded 紧密关联：OpenEmbedded 提供构建系统的核心元数据与 BitBake 引擎，Yocto 项目在此基础上提供参考发行版 Poky、测试体系、版本管理与长期支持机制。许多社区配方同时被两者使用。理解这一关系有助于查阅文档与社区资源时快速定位：涉及层与配方细节时查 OpenEmbedded 文档，涉及版本与工具链集成时查 Yocto 文档。

8. 生态中的关键角色

生态中除 Yocto 与 OpenEmbedded 外，还有多个重要角色：各 SoC 厂商维护的 BSP 层、发行版供应商的定制方案、云与 CI 服务商的构建服务。厂商 BSP 层通常随芯片文档与评估板发布，是产品开发的重要基础。选择合适的 BSP 层并保持与 Yocto 版本兼容，是项目启动阶段的重点工作，具体方法见 Layer 机制与 BSP 相关篇目。
