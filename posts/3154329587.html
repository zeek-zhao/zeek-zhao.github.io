TypeScript 集成

[!info] 本页概览
本文讲解 Vue 3 + TypeScript：创建 TS 项目、组件类型定义（defineProps/defineEmits）、接口设计、类型工具（Ref/Computed/MaybeRef）、vue-tsc 类型检查，让代码类型安全。

核心概念

  • Vue 3 对 TS 一等支持，<script setup lang="ts"> 自动类型推导。
  • defineProps/defineEmits 泛型：声明 props/事件类型。
  • 接口（interface）：定义数据结构，贯穿组件与 API。
  • vue-tsc：对 .vue 做类型检查（Vite 不检查类型）。

常见坑

  1. defineProps 泛型与默认值：泛型写法不能直接给默认值；用 withDefaults(defineProps<Props>(), {...})。
  2. reactive 类型推导：reactive<User>({...}) 或 interface + 断言；简单对象可自动推导。
  3. ref 初始 null：ref<User | null>(null)，使用时判空。
  4. import type 隔离：仅类型导入用 import type，避免运行时引入（side-effect）。
  5. vue-tsc 未跑：Vite 构建不做类型检查；build 脚本必须含 vue-tsc。
  6. 第三方库缺类型：npm i -D @types/xxx 或声明 declare module 'xxx'。

最佳实践

  • 数据结构统一用 interface 建模，组件/API/Store 复用。
  • 组合函数显式返回类型，复用处类型推导。
  • any 限制使用，逃逸类型用 unknown + 收窄。
  • 类型检查进 CI（npm run typecheck）。
  • 响应式 API 优先 ref<T> + computed<T>，类型推导更稳。
