指针与内存

[!info] 本页概览
指针是 C/C++ 的灵魂，也是新手最容易踩坑的地方。本文讲解指针的本质、指针运算、指针与数组、引用（C++）、堆栈内存与动态分配。

核心概念

指针保存另一个变量的内存地址。* 用于解引用（访问所指对象），& 用于取地址。指针类型决定解引用时按多少字节、什么类型解释内存。

常见坑

  1. 悬空指针：释放内存后继续使用指针（use-after-free），是安全漏洞主源之一。释放后置 NULL 只能防一层，正确做法是确保所有使用点在释放前。
  2. 野指针：未初始化指针指向随机地址，解引用即崩溃。声明时初始化为 NULL 或直接赋值。
  3. 内存泄漏：malloc/new 后未 free/delete，长时间运行内存耗尽。用 valgrind、ASan 检测。
  4. 指针越界：p[5] 超过数组范围，读取/写入相邻内存，属于未定义行为。
  5. C 中 malloc 返回值强转：在 C++ 中必须强转（(int*)），C 中不必；现代 C++ 根本不用 malloc。
  6. 引用与指针的区别（C++）：引用必须初始化、不能重绑、无 NULL 引用；指针可以 NULL、可以修改指向。

最佳实践

  • 遵守规则：谁分配谁释放，明确所有权归属。
  • 现代 C++ 优先 std::unique_ptr / std::shared_ptr（RAII），避免裸 new/delete。
  • 传参时能用引用就不用指针；必须允许”空”时才用指针。
  • 开启 AddressSanitizer（-fsanitize=address）调试内存问题。
