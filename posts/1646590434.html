[!info] 本页概览
本文讲解 Vue 应用部署：构建产物说明、Nginx 配置（history 回退、缓存、gzip）、Docker 化部署、CD/CI 发布、环境与回滚，把应用安全上线。

核心概念

  • npm run build 产出 dist/ 静态文件，可放任意静态服务器。
  • 单页应用需将未知路由回退到 index.html（history 模式）。
  • 部署要点：缓存策略、gzip/brotli、CDN、HTTPS、Docker。

静态资源 hash 文件名可长缓存；index.html 禁止长缓存（需更新引用）。

CD/CI 发布（GitHub Actions）

回滚策略

  • 保留历史构建：dist-1.0.0 / dist-1.0.1，Nginx root 软链切换。
  • 或镜像 tag 回退：docker run myapp:1.0.0 替换当前容器。
  • 发布前健康检查（curl 首页 200 + 关键 API）。

常见坑

  1. history 模式未配 try_files：直接访问 /about 404；务必回退 index.html。
  2. base 路径错：部署在子路径（/app/）需 vite base: '/app/'，否则资源 404。
  3. index.html 被缓存：用户拿旧资源；配置 no-cache。
  4. Docker 内 API 代理：Nginx 中配置 /api 反代后端，而不是在容器内起 node。
  5. 环境变量泄漏：VITE_ 前缀变量打包进 bundle；敏感配置走运行时/后端。
  6. 静态资源 404：检查 dist 资源路径与部署目录层级（root 指向 dist）。

最佳实践

  • 生产构建启用 sourcemap 开关按需（安全与调试权衡）。
  • 用 CDN 托管 hash 静态资源，回源站做缓存。
  • HTTPS 全站（Let’s Encrypt），HSTS 头。
  • 发布流程：构建 → 冒烟测试（staging）→ 灰度 → 全量 → 监控。
  • 安全头：X-Content-Type-Options、Content-Security-Policy（视项目）。
