git

[!abstract] 用途
git 是分布式版本控制系统，跟踪文件变更、支持分支协作与回滚，是开发与运维（配置即代码、CI/CD）的基础设施。

[!warning] 危险
git reset --hard / git push --force 会覆盖历史，先确认无未提交重要改动，协作仓库谨慎使用。

8. 注意事项

  • 提交信息写清楚变更目的（why），方便回溯；
  • 敏感信息（密码/密钥）不要提交进仓库，即使后来删除也在历史中；
  • 私有密钥用 SSH 方式，公网仓库禁用密码认证；
  • 大文件用 Git LFS 或外部存储，普通 git 不适合；
  • 多设备协作先 git pull 再 git push，避免冲突。
