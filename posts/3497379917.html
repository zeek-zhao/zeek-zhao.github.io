权限与组

[!abstract] 权限模型
Gerrit 权限基于 组 + 引用（refs） 的 ACL：组定义”谁”，ref 定义”哪里”，权限项定义”能做什么”。

1. 组管理

[!note] 系统组
Administrators 全权限；Registered Users 所有已注册用户；Anonymous Users 匿名。权限配置时注意排除匿名。

2. 权限继承链

Projects → web-frontend → Access 可配置继承（Inherit）或覆盖（Override）。

3. 常用权限项

权限 说明 典型授予
Read 可读项目 全员
Push 可推 refs/for 评审 开发组
Create Reference / Push Signed Tag 直接建分支/打标签 维护者
Code-Review 评审打分 评审组
Verified CI 验证标签 CI 账号
Submit 合入变更 维护者/发布组
Owner 管理项目配置 项目 Owner

4. refs 权限配置示例

[!tip] 前缀匹配
refs/heads/release/* 限定发布分支；refs/tags/* 管标签；refs/meta/* 管元数据分支。

5. 标签（Label）体系

Gerrit 内置 Code-Review（-2..+2）与 Verified（-1..+1）：

[!note] Submit 前提
通常规则：至少一个 +2、无 -2、Verified +1。可用 set-project --submit-rule 自定义。

6. 自定义标签

[!warning] 安全建议

  • Anonymous Users 默认 无 Read（私有评审）；
  • Submit 权限只给最小集合；
  • 定期审计组与权限：Projects → 项目 → Access 查看实际生效矩阵。
