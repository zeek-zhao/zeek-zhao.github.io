Skill 索引

一个 skill 一个 md 文件，固定五段：name / version / description / inputs / outputs + 步骤。

skill 职责 触发指令
capture-classify Inbox 清洗、分类打标、去留建议 “清 Inbox”
metadata-fill 补全/校验 frontmatter 必填字段 “补元数据”
quality-gate 发布门禁质检，PASS 才允许发布 “质检”
hexo-convert 发布格式预检（md-format 一票否决项） “准备发布”
digest 周报：产出统计、管线状态、待办 “本周回顾”
publish-flow 发布操作与上线核对（走 rules/07-publish.md 8 步） “发布”

管理规则：

  • skill 只能被 AI.md 路由调用；skill 之间不互相调用。
  • 修改任何 skill 必须升 version 并在 90-OB工程管理/log/ 留痕。
