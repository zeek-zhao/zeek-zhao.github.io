06-GString与字符串

发表于2026-10-25|groovy
|浏览量:

[!info] 本节目标
GString 是 Groovy 字符串处理的核心语法，学习插值、惰性求值与文本操作。

1. 字符串类型

Groovy 字符串分为 Java String 与 GString 两类。单引号创建普通 String，双引号创建 GString（包含插值表达式时）。GString 在需要时转换为 String，与 Java API 无缝兼容。

三引号支持多行字符串，保留换行与缩进；斜杠字符串适合正则；美元斜杠字符串用于复杂模板。

2. 插值语法

GString 插值使用美元符加大括号形式，表达式可以是变量、方法调用或任意 Groovy 表达式。例如输出变量值、输出属性值。

插值是惰性求值的：GString 被使用时才计算表达式值。注意与直接字符串拼接的性能差异，高频路径可用 StringBuilder。

3. 常用字符串方法

GDK 为 String 增加大量便捷方法：tokenize 分词、eachLine 逐行处理、padLeft 对齐、reverse 反转、capitalize 首字母大写等。

字符串比较用等号即可，无需调用 equals 方法；大小写忽略比较用 equalsIgnoreCase 或转换小写对比。

4. 格式化与模板

printf 与 format 支持 Java 格式化语法，百分号占位符常用。模板引擎 SimpleTemplateEngine 用 GString 风格占位符渲染模板，适合代码生成与报告。

数字格式化用 String.format 或 DecimalFormat，日期用 SimpleDateFormat，注意线程安全。

5. 文本处理场景

日志输出、错误消息、SQL 拼接、URL 构造与 JSON 生成都涉及字符串处理。插值让这些场景代码更短，但要注意注入风险，动态内容拼接 SQL 与脚本时要做转义与校验。

大量字符串拼接场景使用 StringBuilder 或 join 方法，避免频繁创建中间字符串。

6. 常见陷阱

GString 的 toString 每次计算，作为 Map 键时要用 String 而非 GString；闭包中修改插值变量要注意求值时机；转义字符输出字面美元符号。

调试字符串问题时，先确认变量实际值，再检查插值语法，避免误以为插值失败。
