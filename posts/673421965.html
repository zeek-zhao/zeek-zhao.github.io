面向对象

[!info] 本页概览
本文讲解 Python 类与对象：属性与方法、__init__、继承与多态、魔术方法、@property、dataclass 与私有约定，掌握 Python 风格的 OOP。

核心概念

  • 类是蓝图，实例是具体对象。
  • 魔术方法（__xxx__）定义语言级行为：构造、比较、打印、运算符。
  • Python 无真正私有成员，用下划线约定访问级别。

常见坑

  1. **忘记 self**：实例方法第一个参数必须是 self（或 cls），漏掉调用时报参数错误。
  2. 类属性与实例属性混淆：给实例赋同名属性会遮蔽类属性。
  3. 可变类属性共享：类列表属性被一个实例修改会影响全部实例。
  4. __init__ 返回 None：构造器不允许返回值，写 return 报错。
  5. 多重继承 MRO 复杂：class C(A, B) 顺序影响方法查找，尽量少用。
  6. 直接用私有约定：_x/__x 是约定而非强约束，跨模块设计 API 时明确文档。

最佳实践

  • 简单数据容器优先 dataclass，不要手写样板。
  • 用 @property 做只读派生属性与访问控制，不裸访问私有字段。
  • 组合优于继承：Has-a 用属性持有对象。
  • 类命名 CamelCase，方法/属性 snake_case。
  • 重写 __eq__ 时同步考虑 __hash__（可变对象不可哈希）。
