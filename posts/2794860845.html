03-任务创建与删除

发表于2026-10-24|FreeRTOS
|浏览量:

[!info] 本节目标
掌握任务创建与删除 API 的正确使用。

1. 任务创建 API

xTaskCreate 创建任务并指定任务函数、栈深度、参数与优先级，成功返回句柄。任务函数是独立执行体，通常包含初始化与无限循环。句柄可用于挂起、恢复、通知与查询等后续操作。

2. 静态与动态创建

动态创建由内核从堆分配 TCB 与栈，静态创建由调用者提供内存缓冲区。静态创建适合资源受限与安全要求高的场景，可编译期确定内存布局。两种方式配置项分别使能，选择依据项目内存策略。

3. 任务参数传递

任务参数通过 void 指针传入，可传递数值、结构体指针或字符串。传递局部变量地址需确保生命周期有效，动态分配对象由任务负责释放。参数封装为结构体可扩展多个字段。

4. 任务删除

任务可自行删除或由其他任务删除，vTaskDelete 释放 TCB 与栈内存。任务删除后资源由空闲任务回收，被删任务不可再被引用。删除前需同步协作对象，避免资源泄漏。

5. 任务句柄与自引用

任务函数内可用 NULL 句柄表示自身，删除或操作自己时传递 NULL。句柄保存供其他任务使用，使用前确认任务仍存活。句柄有效性管理是并发编程常见难点。

6. 任务创建失败处理

创建失败通常因堆内存不足或栈分配失败，检查堆大小配置与任务数量。错误处理应在创建处立即反馈，避免静默失败。调试时打印堆剩余空间定位内存瓶颈。

7. 实践建议

任务命名规范便于调试跟踪，栈深度按调用链估算并留余量。动态创建简化开发，静态创建保障确定性，混合使用按模块评估。创建与删除成对管理，配合看门狗监控任务健康。
