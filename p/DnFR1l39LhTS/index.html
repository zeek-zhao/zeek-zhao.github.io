1. Gitea 简介

Gitea 是一个轻量级、开源的自托管 Git 服务解决方案，使用 Go 语言开发。它旨在提供与 GitHub、GitLab 或 Bitbucket 类似的功能，但具有更低的系统资源需求和更简单的维护方式。

2. 安装与配置

2.1 系统要求

Gitea 的系统资源需求非常低，这使其可以在各种规模的服务器和设备上运行：

  • 最低配置：

    • CPU: 单核
    • RAM: 512MB
    • 存储: 依赖于代码库大小，最低建议 1GB
    • 数据库: SQLite3（内置）或外部数据库

  • 推荐配置（适合中小型团队）：

    • CPU: 双核或更高
    • RAM: 2GB 或更高
    • 存储: SSD，10GB+
    • 数据库: MySQL, PostgreSQL 或 MSSQL

7.2.1 集群配置关键点

  1. 共享存储：所有 Gitea 节点需要访问相同的存储位置

    • 可以使用 NFS, S3 兼容存储或其他分布式文件系统

  2. 数据库配置：使用主从复制或集群数据库

    • MySQL Cluster, PostgreSQL 主从复制等

  3. 会话共享：使用 Redis 或类似解决方案共享会话

    • 防止用户需要在不同节点上重复登录

  4. 负载均衡：使用 Nginx, HAProxy 或云负载均衡器

    • 将请求分配到不同的 Gitea 节点
