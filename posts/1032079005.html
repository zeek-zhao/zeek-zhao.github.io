常见问题排错

[!abstract] 高频故障速查
按”现象 → 原因 → 排查 → 解法”组织，覆盖登录、数据、查询、性能与插件。

1. 登录与访问

现象 排查 解法
登录后 404 Base URL 配置错 ⚙ → General → Base URL 改对外地址
反代后循环重定向 X-Forwarded 头缺失 补 X-Forwarded-Proto 等头（02-安装部署）
忘记管理员密码 内置恢复流程 java -cp ... EditUser 重置或数据库临时改密码哈希
账号被锁 登录失败锁定 ⚙ → System → 登录策略

2. 数据与问题

现象 排查 解法
问题突然看不到 权限/角色变更 检查权限方案（06-权限方案）
字段值没保存 屏幕/字段配置 检查 Screen 是否含该字段
状态点不动 工作流流转限制/条件 检查流转条件与权限
重复/脏数据 导入/自动化规则 清理 + 校验器防重

3. JQL 查询

现象 解法
查询超时 收窄范围（项目+日期），避免 project in (...) 无边界
结果与预期不符 检查字段值拼写/大小写/引号；IS EMPTY 与 = "" 区别
函数报错 确认函数名/权限（如 membersOf() 需浏览用户权限）
慢查询 常用查询转筛选器；重建索引（13-性能优化）

4. 性能与资源

现象 解法
界面卡顿 JVM 堆调优；插件瘦身；重建索引
索引查询慢 Re-index；索引目录换 SSD
后台任务堆积 ⚙ → System → Services 查看调度
数据库慢 独立 DB 主机、ANALYZE、归档旧数据

5. 插件问题

现象 解法
插件加载失败 检查兼容版本 → 更新/禁用该插件
插件功能消失 插件被禁用或升级失败 → 重新启用/重装
卸载后数据残留 插件数据表清理需官方工具，先导出再卸载

6. 日志与支持

[!tip] 万能三件套
备份在手（12-备份与升级）→ 测试环境复现 → 文档查证。生产操作前先备份。

[!warning] 注意
修改生产数据库高风险，非 Atlassian 官方指引不要直接 SQL 改；紧急情况先快照/备份再动手。

[!note] 系列完结
恭喜学完 Jira 17 篇。配套 Jenkins/Gerrit/Nexus3 教程见 工具系列索引。
