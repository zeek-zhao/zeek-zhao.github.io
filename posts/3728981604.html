浏览器必备插件指南

插件能显著改变浏览体验，但装多了反而拖慢浏览器¶

浏览器插件（扩展程序）是提升网络浏览体验的重要工具，能够为浏览器增添各种实用功能。本文整理了各类别的高质量浏览器插件，适用于Chrome、Edge、Firefox等主流浏览器。

📝提示
虽然插件能够提升效率，但安装过多可能导致浏览器性能下降。建议根据个人需求选择性安装。

我的判断是：插件贵精不贵多，按”每天都会用到”这个标准筛一遍，留下的通常不超过十个。

生产力插件解决标签页膨胀和网页内容收藏¶

1. OneTab¶

  • 功能：将所有标签页转换为一个列表，节省内存
  • 适用场景：经常开启多个标签页的用户
  • 下载链接：Chrome商店

2. Notion Web Clipper¶

  • 功能：快速保存网页内容到Notion
  • 适用场景：Notion用户、信息收集者
  • 下载链接：Chrome商店

3. Todoist¶

  • 功能：快速添加任务到Todoist
  • 适用场景：使用Todoist进行任务管理的用户
  • 下载链接：Chrome商店

4. Obsidian Web Clipper¶

  • 功能：快速保存网页内容到Obsidian知识库
  • 适用场景：Obsidian用户、知识管理爱好者
  • 下载链接：Chrome商店

5. Tree Style Tab¶

  • 功能：树状结构管理标签页，提供垂直侧边栏
  • 适用场景：同时打开大量标签页的用户、多任务工作者
  • 下载链接：Firefox附加组件

隐私安全插件从广告、密码和跟踪器三个角度加固¶

1. uBlock Origin¶

  • 功能：高效的广告拦截器
  • 适用场景：所有用户
  • 下载链接：Chrome商店

2. Bitwarden¶

  • 功能：开源密码管理器
  • 适用场景：需要安全管理密码的用户
  • 下载链接：Chrome商店

3. Privacy Badger¶

  • 功能：自动学习并阻止隐形跟踪器
  • 适用场景：注重隐私保护的用户
  • 下载链接：Chrome商店

开发类插件覆盖 JSON 查看、框架调试和自定义脚本¶

1. JSON Formatter¶

  • 功能：美化JSON数据显示
  • 适用场景：开发人员、数据分析师
  • 下载链接：Chrome商店

2. React Developer Tools¶

  • 功能：调试React应用
  • 适用场景：React开发者
  • 下载链接：Chrome商店

3. Vue.js devtools¶

  • 功能：调试Vue.js应用
  • 适用场景：Vue开发者
  • 下载链接：Chrome商店

4. 篡改猴 (Tampermonkey)¶

  • 功能：用户脚本管理器，可运行自定义JavaScript脚本修改网页功能
  • 适用场景：定制网站功能、自动化操作、增强网页体验
  • 下载链接：Chrome商店

    • 功能：解除网站复制限制、文本选择限制、右键菜单限制等
    • 安装链接：Greasy Fork

  4. HTML5视频播放器增强脚本

    • 功能：视频播放加速、音量放大、快捷键控制等
    • 安装链接：Greasy Fork

  5. 豆瓣资源下载大师

    • 功能：为豆瓣电影、图书页面添加下载资源链接
    • 安装链接：Greasy Fork

  6. CSDN增强脚本

    • 功能：自动展开CSDN全文、去除广告、移除登录弹窗、免登录复制代码
    • 安装链接：Greasy Fork
    • 额外功能：支持黑暗模式、屏蔽推荐内容、优化阅读体验

  7. 知乎增强

    • 功能：去除知乎广告、关键词屏蔽、优化界面、去除登录弹窗
    • 安装链接：Greasy Fork
    • 特色：支持去水印保存视频/图片、屏蔽时间线广告、自定义黑名单

  8. 自动展开全文阅读脚本

    • 功能：自动展开各大网站的”阅读全文”、自动关闭登录弹窗
    • 安装链接：Greasy Fork
    • 兼容站点：简书、CSDN、知乎、百家号、腾讯新闻、微信公众号等

  9. 网盘助手增强版

    • 功能：支持多个网盘，提供高速下载链接、去除广告、自动填写提取码
    • 安装链接：Greasy Fork
    • 支持网盘：百度网盘、阿里云盘、天翼云盘、蓝奏云、微云等

  10. GitHub增强

    • 功能：为GitHub添加下载按钮、文件大小显示等功能
    • 安装链接：Greasy Fork

  11. 全网VIP视频解析

    • 功能：一键解析各大视频网站的VIP内容
    • 安装链接：Greasy Fork
🔥提示
使用脚本前请先阅读脚本说明和评论，了解其功能和可能的风险。一些脚本可能会被网站更新所影响而失效，需及时更新或寻找替代品。

阅读学习插件把翻译、语法检查和网页标注带进浏览器¶

1. Grammarly¶

  • 功能：语法检查和写作辅助
  • 适用场景：英文写作、邮件编写
  • 下载链接：Chrome商店

2. 沙拉查词¶

  • 功能：划词翻译、生词本
  • 适用场景：阅读外语网页
  • 下载链接：Chrome商店

3. Hypothesis¶

  • 功能：网页标注、批注
  • 适用场景：研究人员、学生
  • 下载链接：Chrome商店

4. 沉浸式翻译¶

  • 功能：双语对照翻译网页内容和PDF文档，支持多种翻译引擎
  • 适用场景：外语网页阅读、学术文献阅读、跨语言学习
  • 下载链接：官方网站
  • 特色：免费版功能丰富，支持PDF文档翻译，可自定义翻译样式

视觉设计插件主打取色、字体识别和暗色模式¶

1. ColorZilla¶

  • 功能：颜色拾取器
  • 适用场景：设计师、前端开发
  • 下载链接：Chrome商店

2. WhatFont¶

  • 功能：识别网页上使用的字体
  • 适用场景：设计师、前端开发
  • 下载链接：Chrome商店

3. Dark Reader¶

  • 功能：为任意网站启用黑暗模式
  • 适用场景：长时间使用电脑的用户、夜间浏览
  • 下载链接：Chrome商店

社交媒体插件补全平台本身砍掉的小功能¶

1. Hover Zoom+¶

  • 功能：鼠标悬停放大图片
  • 适用场景：浏览图片网站、社交媒体
  • 下载链接：Chrome商店

2. Return YouTube Dislike¶

  • 功能：显示YouTube视频的不喜欢数量
  • 适用场景：YouTube用户
  • 下载链接：Chrome商店

3. 哔哩哔哩助手¶

  • 功能：B站视频下载、去广告等
  • 适用场景：B站用户
  • 下载链接：GitHub

插件要定期清理并限制权限，性能开销主要来自数量和后台运行¶

如何有效管理插件¶

  1. 定期清理：移除不常用的插件
  2. 分组管理：Chrome允许创建不同的配置文件，可以按需启用插件
  3. 快捷键设置：为常用插件设置快捷键
  4. 权限控制：限制插件只在特定网站运行
⚠️安全提示
只从官方商店下载插件，谨慎授予插件权限，特别是”读取和更改网站数据”的权限。

插件性能影响¶

影响因素 说明
插件数量 安装过多插件会增加内存占用
后台运行 部分插件会在后台持续运行，消耗资源
权限范围 权限越广，潜在风险越高

选插件的原则是匹配需求并定期检查必要性¶

选择合适的浏览器插件可以显著提升工作效率和浏览体验。希望本指南能帮助你找到适合自己需求的插件。记住，插件在带来便利的同时也可能带来安全风险，请谨慎使用并定期检查插件的安全性和必要性。
