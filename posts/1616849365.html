02-任务管理与调度

发表于2026-10-24|FreeRTOS
|浏览量:

[!info] 本节目标
理解 FreeRTOS 任务模型与调度器运行机制。

1. 任务与调度器

任务是 FreeRTOS 中独立执行的代码单元，拥有自己的栈与上下文。调度器负责在多个任务间分配 CPU，依据优先级与就绪状态选择下一个运行任务。任务看似并发执行，实际由调度器快速切换实现。

2. 调度原则

FreeRTOS 采用优先级抢占调度：高优先级任务就绪时立即抢占低优先级任务。同优先级任务默认时间片轮转，也可配置为协作式。空闲任务优先级最低，负责回收被删除任务的资源。

3. 任务控制块

每个任务由任务控制块 TCB 描述，包含栈指针、状态、优先级与任务名等信息。TCB 由内核在任务创建时分配，记录任务全部执行上下文，调度切换本质是 TCB 的切换。

4. 上下文切换

上下文切换保存当前任务寄存器现场并恢复目标任务现场，由 PendSV 异常或汇编代码实现，切换开销决定内核实时性。切换点包括任务阻塞、延时节拍与高优先级就绪触发抢占。

5. 调度器生命周期

内核启动前创建任务，vTaskStartScheduler 启动调度器后控制权交由内核。调度器运行期间任务被创建、阻塞与删除，vTaskEndScheduler 一般仅用于部分场景。空闲任务与定时器守护任务由内核自动创建。

6. 任务状态与切换

任务在运行、就绪、阻塞与挂起状态间迁移。运行任务调用阻塞 API 进入阻塞态，延时到期或事件满足后回到就绪态，挂起与恢复由 API 显式控制。状态迁移驱动调度器选择目标任务。

7. 设计要点

任务划分遵循单一职责，控制任务数量与栈大小，避免长时间占用 CPU 导致低优先级饿死。合理分配优先级与阻塞策略，让调度器按预期行为运转，是实时系统设计的基础。
