1. Jira 简介

Jira 是 Atlassian 公司开发的一款专业的项目管理和问题跟踪工具，广泛应用于软件开发、项目管理、需求管理、任务跟踪等领域。Jira 的灵活性和可扩展性使其成为企业级项目管理的首选工具之一。

4.3.2 JQL示例

查询目标 JQL示例
我的待处理任务 assignee = currentUser() AND status = "待办"
高优先级Bug issuetype = Bug AND priority in (Highest, High)
本周创建的问题 created >= startOfWeek() AND created <= endOfWeek()
逾期未完成任务 duedate < now() AND status != Done
特定冲刺任务 sprint in openSprints() AND project = "项目名"
最近更新的问题 updated >= -1d ORDER BY updated DESC
无人分配的问题 assignee is EMPTY AND status != Closed
跨项目关联问题 issueFunction in linkedIssuesOf("project = PRJ")
