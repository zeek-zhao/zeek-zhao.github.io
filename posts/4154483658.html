元数据字段规范

三层模型。字段字典唯一来源是本文件；新字段必须先入字典并写明消费方。

层 字段 说明
核心（全类型必填） title, date, tags 最小集
类型层 素材: source/topic/status · 文章: categories/description/cover · 灵感: topic 见各模板
发布层（仅 40 区成稿） status, published, updated, permalink(可选) Hexo 消费依据

发布层字段字典

字段 取值 消费方
status draft → review → published Dataview + Hexo 过滤
published true / false Hexo 唯一发布开关
date / updated YYYY-MM-DD Hexo 排序 / sitemap
tags / categories 数组 Hexo 归档分类；tags 2~3 个，不得超过 3 个（collect.js 强制拦截）
description ≤120 字 SEO 摘要
cover /assets/ 路径 封面图

规则

  • 字段值只取枚举值；AI 每次写完 frontmatter 自校验。
  • 非法字段 = 体检异常项（见 rules/06-auto-check.md）。
