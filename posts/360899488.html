与IDE集成

ℹ️本节目标
将 OpenGrok 检索能力接入 IDE 与编辑器，让开发者在不离开编码环境的情况下使用代码检索。

集成注意事项¶

  • 统一入口：所有开发者共享同一 OpenGrok 地址，减少本地环境差异
  • 认证环境：浏览器需保持登录态（SSO），IDE 外链复用默认浏览器会话
  • 项目范围：模板中固定 project 参数，避免跨项目噪音

集成方案对比¶

工具 方案 复杂度
JetBrains URL 模板/插件 低
VS Code 任务/扩展 低
Vim 快捷键+browser 极低
CLI curl 脚本 极低
🔥最佳实践
IDE 集成适合”从编码到检索”的短链路；深度代码走读仍推荐浏览器完整交互界面（xref、调用图、历史）。
