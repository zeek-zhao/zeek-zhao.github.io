问题类型与字段

[!abstract] 数据模型设计
问题类型区分”这是什么工作”；字段记录”需要什么信息”；屏幕决定”在哪里录入”。

1. 问题类型

⚙ → Issues → Issue types：

类型 用途
Epic 大需求（跨 Sprint）
Story 用户故事（验收标准驱动）
Task 任务
Bug 缺陷
Sub-task 子任务
自定义 如 Tech Debt、Risk

[!note] 类型方案
问题类型可以按项目配置（Issue Type Scheme）：项目 A 不需要 Epic 就去掉。

2. 自定义字段（Custom Fields）

⚙ → Issues → Custom fields → Add：

常用类型：

类型 场景
文本/多行文本 描述、验收标准
数字 估算、版本号
单选/多选 环境、优先级
日期时间 期望日期
用户 负责人、评审人
URL 关联链接
级联选择 分类级联

[!tip] 字段治理建议

  • 能复用系统字段就不建新字段（Priority、Reporter、Components）；
  • 每加一个字段都要问”谁会用？要不要必填？报表要不要？”；
  • 定期清理废弃自定义字段（删除影响历史数据）。
