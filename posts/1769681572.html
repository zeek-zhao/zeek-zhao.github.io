10-Templater自动化

用 Templater 把 JavaScript 带入模板系统，实现动态日期、条件逻辑、用户交互与外部系统调用，打造全自动笔记生成流水线。
📅 2026-10-25· 更新于 2026-10-25 ✍ zeek.zhao #工具#obsidian

Templater自动化

📑一句话
Templater 是 Obsidian 的自动化模板引擎：在 <% %> 标记中运行 JavaScript，让每次新建笔记都能自动填日期、弹对话框、跑脚本、执行命令，把重复劳动压缩成一次按键。

从内置模板到 Templater¶

Obsidian 自带的模板插件只能插入静态文本和少量日期变量。Templater 则把整个 JavaScript 运行时开放给模板：变量替换无限制、支持条件与循环、能弹出输入框和选择器、能调用 Obsidian 命令甚至执行系统脚本。它和 09-Dataview数据查询、QuickAdd 一起构成 Obsidian 自动化的三驾马车——Dataview 负责查询数据，Templater 负责生成内容，QuickAdd 负责把动作串成流程。

安装与初始设置¶

  1. 设置 →「第三方插件」→「社区插件市场」→ 搜索 “Templater” → 安装并启用
  2. 进入设置 → Templater，完成三项关键配置：
    • 模板文件夹位置：指定存放模板的目录（建议专门建一个 Templates/ 文件夹，并将其从 Dataview 索引中排除）
    • 触发词（Trigger）：设置输入前缀后按 Tab 自动插入模板
    • 新建笔记时自动应用：可指定某些文件夹的新笔记自动套用某模板（Folder Templates），这是日记自动化的基础

三种核心语法¶

Templater 的所有功能围绕三种标记展开：

  • <% %>：执行 JavaScript 代码，不输出结果
  • <%= %>：执行并输出结果
  • <%* %>：多行脚本块，适合写逻辑后再统一输出

tp 对象：内置函数全家桶¶

Templater 的内置函数都挂在 tp 对象下，常用的包括：

  • tp.date：tp.date.now("YYYY-MM-DD") 取当前日期，tp.date.yesterday()、tp.date.lastweek() 取相对日期，是日记与周报模板的主角
  • tp.system：tp.system.prompt("项目名称") 弹出输入框，tp.system.suggester() 弹出选择菜单，tp.system.run("脚本路径") 执行外部脚本
  • tp.file：tp.file.title 取文件名，tp.file.include("模板") 嵌入其他模板，tp.file.cursor(1) 控制插入后光标停留位置
  • tp.frontmatter：读取笔记的 frontmatter 属性，实现”模板读元数据”的联动
  • tp.obsidian：tp.obsidian.executeCommandById("editor:toggle-preview") 直接执行任意 Obsidian 命令

典型应用场景¶

  • 日记模板：自动填日期、星期，配合 14-日记与周期笔记 的 Periodic Notes 使用
  • 会议记录：tp.system.prompt 询问参会人，自动生成议程与行动项清单
  • 文献/书籍笔记：询问书名作者，生成带 rating、progress 字段的读书卡片，供 Dataview 查询
  • 与 Advanced URI 联动：在模板中拼 obsidian://advanced-uri?... 链接，生成可点击的快捷入口
  • 与 QuickAdd 配合：QuickAdd 宏中调用 Templater 模板，实现”一条命令=建文件+填模板+移动位置”的完整流程

故障排除与最佳实践¶

  • 模板无法插入：检查模板文件夹路径是否正确、插件是否启用、触发词是否冲突
  • 变量不生效：核对函数名拼写（tp.date.now 不是 tp.date.today），多行脚本注意 await
  • 想输出 <% %> 字面量：写作教程时会遇到，可拆成 < + % 字符串拼接
  • 管理建议：模板按用途分子文件夹、命名带前缀（如 daily-、meeting-）、为复杂模板加注释；重大修改前先在副本上测试
📝2026 更新
Obsidian 1.9+ 的官方属性（Properties）面板让 frontmatter 编辑体验大幅提升，但动态生成能力仍属 Templater 独有。官方 Bases 与 Templater 结合的新玩法是：用 Templater 批量写入规范属性，再用 Bases 视图展示，几乎可以复刻 Notion 数据库的工作流。

Templater 的真正价值不在于省几次输入，而在于鼓励结构化思考：当你为每类笔记设计模板时，其实是在设计自己的知识生产流程。从简单日期插入起步，逐步引入交互、脚本与插件联动，最终你会得到一套完全贴合个人工作流的自动生成系统。
