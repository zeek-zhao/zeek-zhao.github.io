51-深度学习基础与CNN

融合深度学习基础与 CNN 原理，梳理经典架构演进，并聚焦目标检测、语义分割等自动驾驶感知应用与 2026 年 BEV/端到端趋势。
📅 2026-10-25· 更新于 2026-10-25 ✍ zeek.zhao #系统#apollo
ℹ️本节目标
从零建立深度学习的概念框架：神经网络基本原理、CNN 核心组件、经典架构演进，以及 CNN 在自动驾驶感知系统中的实际应用，并了解 2024-2026 年感知模型的技术走向。训练框架选择见 52-PyTorch与自动驾驶实践 与 53-TensorFlow与Caffe2在自动驾驶中的应用。

1. 深度学习概述¶

1.1 什么是深度学习¶

深度学习是机器学习的一个子领域，使用多层神经网络模拟人脑的信息处理与模式识别能力，通过大量数据自动提取特征并做出决策。它是自动驾驶环境感知、轨迹预测等模块的算法基石。

1.2 发展简史¶

  • 1943 年 McCulloch-Pitts 神经元模型；1958 年感知器
  • 1986 年反向传播算法普及；1989 年早期 CNN；1997 年 LSTM
  • 2012 年 AlexNet 在 ImageNet 突破，引爆深度学习革命
  • 2017 年 Transformer 提出；2018 年后大规模预训练模型兴起
  • 2020 年代：BEV 感知、Occupancy Network、端到端自动驾驶（详见第 7 节）

1.3 神经网络基本原理¶

一个神经元完成”加权求和 + 偏置 + 激活函数”三步：

常用激活函数：

激活函数 公式 特点
Sigmoid 1/(1+e⁻ˣ) 输出 (0,1)，有梯度消失问题
ReLU max(0, x) CNN 默认选择，缓解梯度消失
Leaky ReLU max(0.01x, x) 解决 Dead ReLU
GELU x·Φ(x) Transformer 常用
Softmax eˣⁱ/Σeˣʲ 多分类输出层

损失函数与优化：回归用 MSE，分类用交叉熵；优化器从 SGD（+Momentum）到 Adam/AdamW。训练循环为”前向传播 → 计算损失 → 反向传播 → 参数更新”。

2. CNN 核心组件¶

CNN 通过”局部连接 + 权重共享”高效处理网格结构数据（图像），是自动驾驶感知的基石。

组件 功能 要点
卷积层 特征提取 卷积核尺寸/步长/填充决定输出尺寸；参数共享带来平移不变性
池化层 降维抗噪 最大池化/平均池化，增大感受野、减少过拟合
激活函数 引入非线性 ReLU 系列
全连接层 分类/回归 现代 CNN 趋向用全局平均池化替代，减少参数

📝批归一化（BatchNorm）
对每个 mini-batch 的激活值做归一化再缩放平移，可显著加速训练、允许更大学习率。小批量场景可用 GroupNorm/LayerNorm 替代。

3. 经典架构演进¶

3.1 从 LeNet 到 ResNet¶

架构 年份 关键创新
LeNet-5 1998 首次系统使用卷积+池化组合，手写数字识别
AlexNet 2012 8 层深网、ReLU、Dropout、GPU 训练
VGG 2014 堆叠 3×3 小卷积核替代大核，结构简洁
GoogLeNet 2014 Inception 多尺度并行模块，参数量仅为 AlexNet 1/12
ResNet 2015 残差连接 H(x)=F(x)+x，突破百层深度
MobileNet 2017+ 深度可分离卷积，面向移动/车载端

3.2 残差连接的意义¶

传统网络直接学习 H(x)；ResNet 让网络学习残差 F(x) = H(x) − x。当最优映射接近恒等映射时，”把权重推向 0”比”学一个恒等映射”容易得多，从而解决了深层网络的退化问题。ResNet-50/101 至今仍是自动驾驶感知骨干的常用选择。

3.3 轻量化：面向车载部署¶

  • 深度可分离卷积：逐通道卷积 + 1×1 逐点卷积，参数量约为标准卷积的 1/8~1/9
  • EfficientNet 复合缩放：按 α·β²·γ²≈2 同时缩放深度、宽度、分辨率
  • 模型压缩三板斧：量化（FP32→INT8，体积减 75%）、剪枝、知识蒸馏（大模型教小模型）
🔥为什么车载端偏爱 CNN
CNN 具有平移不变性等归纳偏置，数据效率高、推理延迟确定，在算力受限的车载平台上依然比纯 Transformer 更易部署。与 Transformer 的混合架构（如 Swin、ConvNeXt）是当前主流折中。

4. CNN 在自动驾驶中的应用¶

4.1 目标检测¶

  • 两阶段（Faster R-CNN、Mask R-CNN）：RPN 生成候选框再分类回归，精度高、速度慢
  • 单阶段（YOLO 系列、SSD、FCOS、CenterNet）：直接预测类别与位置，速度快，是车载感知主流
  • 3D 检测：SECOND、CenterPoint 等面向激光雷达点云

4.2 语义分割¶

  • FCN：全卷积化，端到端像素级分类
  • U-Net：编码器-解码器 + 跳跃连接，保留空间细节
  • DeepLab 系列：空洞卷积 + ASPP，多尺度上下文建模

分割结果用于可行驶区域判断、车道线提取等。

4.3 深度估计与多任务网络¶

  • 单目深度估计：MonoDepth/MonoDepth2；立体匹配：PSMNet
  • 多任务共享骨干：一个编码器接检测头、分割头、深度头、车道线头，共享特征大幅降低车载计算量

4.4 与 Apollo 感知的衔接¶

Apollo 感知模块中的 2D 检测器（如 YOLO 系）、车道线网络、红绿灯识别网络均基于 CNN。训练产出模型后经 ONNX/TensorRT 转换部署到车载推理框架，流程见 52-PyTorch与自动驾驶实践；感知数据从哪来、怎么标注，见 55-标注工具与数据闭环；模型上车后如何验证，见 54-自动驾驶测试方法。

5. 训练技巧速查¶

  1. 迁移学习：冻结骨干只训新头，或分层设置学习率（底层 1e-5，新头 1e-2）
  2. 数据增强：随机裁剪/翻转/色彩抖动；自动驾驶场景避免垂直翻转
  3. 类别不平衡：Focal Loss（检测）、Dice Loss（分割）
  4. 学习率调度：余弦退火、OneCycle、ReduceLROnPlateau
  5. 调试利器：TensorBoard 监控曲线，Grad-CAM 可视化模型关注区域

6. 常见挑战¶

挑战 说明 缓解手段
泛化/域偏移 训练域到测试域性能下降 域适应、更大更多样的数据集
可解释性 黑盒决策难以满足安全监管 Grad-CAM、注意力可视化
算力与能耗 车载平台资源受限 量化、剪枝、蒸馏、轻量架构
长尾场景 罕见场景样本稀缺 数据合成、场景挖掘（见 55-标注工具与数据闭环）

7. 2026 年感知技术走向¶

📝2026 年更新
感知模型的主流范式已从”2D 检测 + 后融合”演进为 BEV（鸟瞰图）+ Transformer + Occupancy Network：多摄像头特征统一投影到 BEV 空间，直接输出 3D 障碍物与占用栅格，天然适配端到端下游。同时，端到端自动驾驶（UniAD 为代表，以及 VLA——视觉-语言-动作模型）在 2024-2026 年成为研究热点，感知、预测、规划由一个网络联合完成。Apollo 等工业界系统则普遍采用”BEV 主干 + 分层模块”的折中路线，兼顾性能与可解释性。CNN 并未被淘汰——它仍是 BEV 骨干与车端轻量模型的核心组件。

8. 小结¶

  • 深度学习三要素：数据、模型、算力；CNN 是自动驾驶感知的算法基石
  • 经典架构演进的主线是”更深、更准、更轻”：残差连接解决深度，轻量卷积解决部署
  • 车载感知 = 检测 + 分割 + 深度估计的多任务组合
  • 2026 年趋势：BEV+Transformer+Occupancy 成主流，端到端（UniAD/VLA）快速崛起
