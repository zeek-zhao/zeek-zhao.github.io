数据结构

[!info] 本页概览
Python 内置四种容器：列表 list、元组 tuple、字典 dict、集合 set。本文对比它们的特点与常用操作，覆盖切片、深浅拷贝、常用方法等核心内容。

核心概念

类型 可变 有序 允许重复 典型场景
list 可变 是 是 动态数组、栈、队列
tuple 不可变 是 是 固定记录、字典键、函数多返回值
dict 可变 插入序（3.7+） 键唯一 映射、查找表
set 可变 否 否 去重、集合运算

常见坑

  1. 可变默认参数/可变元素共享：list[0] 嵌套结构赋值时先确认深浅拷贝需求。
  2. dict 键不可变：用列表做键报 TypeError: unhashable type，换元组。
  3. remove 值不存在：报 ValueError，先 in 判断或 try/except。
  4. 遍历字典时修改：for k in d: d.pop(k) 报 RuntimeError，遍历 list(d.keys()) 副本。
  5. [:] 不是深拷贝：只复制外层。深层用 copy.deepcopy。
  6. in 复杂度：x in list 是 O(n)，频繁查找用 set/dict（O(1)）。

最佳实践

  • 固定多值用元组解包，可读性优于下标。
  • 查找类操作用 dict/set，别用 list 线性扫。
  • 从可迭代对象构造容器：list(range(5))、set("abca")、dict(zip(keys, vals))。
  • 统计频率用 collections.Counter，先进先出用 collections.deque。
  • 空容器判断直接用 if items: 而非 if len(items) > 0:。
