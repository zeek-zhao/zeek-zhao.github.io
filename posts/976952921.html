模块与包

ℹ️本页概览
模块（.py 文件）与包（目录）是 Python 组织代码的方式。本文讲解 import 机制、包的 __init__.py、if __name__ == "__main__"、相对导入与 pip 安装本地包。

核心概念¶

  • 模块：一个 .py 文件即一个模块，名字即文件名。
  • 包：含 __init__.py 的目录（Python 3.3+ 也可缺省命名空间包）。
  • import 顺序：标准库 → 第三方 → 本地模块。
  • 每个模块执行一次，缓存于 sys.modules。

直接运行：__name__ == "__main__"；被导入：__name__ == "math_utils"。用这个模式避免导入时执行测试代码。

sys.path 与常见问题¶

常见坑¶

  1. 模块名与标准库冲突：自建 json.py 会遮蔽标准库，import 错乱。
  2. 循环导入：A 导入 B、B 导入 A。把公共依赖下沉到第三个模块，或在函数内导入。
  3. from module import * 滥用：污染命名空间，用 __all__ 明确导出或显式导入。
  4. 相对导入越级：... 超过包顶层报错，包嵌套过深要重构。
  5. import 顺序混乱：PEP8 要求标准库/第三方/本地分组。
  6. 入口运行 vs 模块导入差异：sys.path[0] 不同，确保从项目根运行或安装包。

最佳实践¶

  • 模块单一职责，文件小（几百行内）优于大而全。
  • __init__.py 导出包的公共 API，隐藏内部模块名。
  • 用 __all__ 明确 from pkg import * 的内容。
  • 依赖方向单向：数据层 → 业务层 → 展示层，避免反向。
  • 测试放在独立 tests/ 目录，pip install -e . 后导入被测包。
