11-默认参数与多重赋值

发表于2026-10-25|groovy
|浏览量:

[!info] 本节目标
Groovy 的参数特性让方法调用更灵活，学习默认参数与解构赋值。

1. 默认参数

Groovy 方法参数可以带默认值，调用时省略的参数自动使用默认值。默认参数避免了 Java 中大量重载方法的样板代码。

默认参数按顺序匹配，省略参数只能从尾部开始；需要更灵活的组合时结合命名参数或 Map 参数。

2. 命名参数

Groovy 方法以 Map 作为第一个参数时，调用可以省略方括号直接写键值对，形成命名参数风格。这让方法调用可读性极高。

命名参数适合配置类方法、DSL 方法与构造器初始化，参数含义一目了然。

3. 多重赋值

Groovy 支持多重赋值：一次声明多个变量并从右侧列表取值，如 def (a, b) = [1, 2]。列表元素按位置解构到变量。

多重赋值适合返回值是列表或 Map 的方法，如分割字符串、解析坐标，代码更紧凑。

4. 解构与集合

多重赋值可以从集合与 Map 中解构值，也可以结合 with 方法链式初始化对象。解构时变量数量与集合元素数量不匹配会怎样，取决于赋值语义。

实现解构的类可以定义 iterator 或 getAt 方法，支持自定义类型的多重赋值。

5. 实际应用场景

默认参数常用于配置 API 与可选参数扩展；命名参数用于 DSL 与领域方法；多重赋值用于解析与返回多值。三者组合可以大幅减少样板代码。

例如坐标解析、配置读取、批量初始化场景中，这些特性让代码意图更清晰。

6. 注意事项

默认参数与重载方法并存时要注意调用歧义；命名参数的 Map 参数会影响方法签名匹配；多重赋值要明确变量语义，避免过度使用降低可读性。

团队使用这些特性时统一风格，在可读性与简洁性之间平衡。
