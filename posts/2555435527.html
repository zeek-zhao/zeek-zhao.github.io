Logstash 管道与插件

[!abstract] 是什么
Logstash 是数据采集与加工管道：input（输入） → filter（过滤） → output（输出）。核心价值在解析非结构化日志。

[!note] 管道说明
file 输入持续跟踪日志文件；grok 正则解析成字段；date 把日志时间写回 @timestamp；geoip 解析 IP 归属地；elasticsearch 输出按天建索引。

Grok 常用模式

模式 匹配内容
%{IP:clientip} IP 地址
%{NUMBER:status:int} 数字并转 int
%{HTTPDATE:timestamp} HTTP 日期
%{LOGLEVEL:level} 日志级别
%{DATA:field} 任意内容
%{TIMESTAMP_ISO8601:time} ISO 时间

多管道与条件路由

[!tip] 性能建议

  • 输出端批量压缩：flush_size => 5000、bulk_path => "_bulk"、gzip；
  • 复杂 grok 优先用精确锚定的正则，避免过度贪婪；
  • 吞吐不足时：pipeline.workers 按 CPU 调、多个 pipeline 分离采集与加工。

[!warning] 注意
Logstash 是重量级组件；轻量采集优先用 07-Filebeat，需要复杂加工再引入 Logstash。
