19-搜索与效率工具

Omnisearch、Another Quick Switcher、Better Command Palette、Various Complements、CMDR 等十个效率插件组成的高速检索体系
📅 2026-10-25· 更新于 2026-10-25 ✍ zeek.zhao #工具#obsidian

搜索与效率工具

📑一句话
搜索决定知识库的”可取出性”：Omnisearch 管全文、Another Quick Switcher 管跳转、命令面板增强管操作、补全管输入、Quiet Outline 管结构——十件套让任何笔记都在三秒内触达。

全文检索：Omnisearch¶

Omnisearch 大幅强化默认搜索：智能相关度排序、内容上下文预览、模糊匹配、搜索历史与收藏。启动方式为快捷键 Ctrl/Cmd+O 或命令面板。

核心搜索语法：

  • AND/OR、-排除词、"精确短语"、通配符*
  • 过滤器：tag:、path:、file:、created:、modified:（支持区间 2025-01-01..2025-03-31）
  • 任务检索：task:"待办内容"、task-todo:、task-done:

结果交互很高效：Tab 预览不离开搜索、Shift+Enter 新标签打开、Alt+Enter 侧栏打开。大型库建议在设置中排除大文件夹并定期执行”重建索引”。

📝2026 更新
1.10 起官方搜索结果已可按相关性排序，弥补了与 Omnisearch 的一部分差距；但对于模糊匹配、任务检索和跨字段过滤，Omnisearch 仍更全面，重度检索用户值得保留。

快速跳转：Another Quick Switcher¶

默认快速切换器只搜文件名，Another Quick Switcher 补齐了内容搜索（content:）、标签过滤（tag:#项目）、路径过滤（path:工作/项目）与排除（-关键词），还提供标签导航、反向链接搜索、头部搜索、相关文件搜索和 Grep 全文搜索五个专用命令。常用键位：Enter 打开、Shift+Enter 新标签、Alt+Enter 分屏、Ctrl/Cmd+O 呼出文件操作菜单、Tab 预览。输入不存在的文件名可直接创建新笔记，配合”输入 ' 查最近文件”的习惯，文件跳转基本告别鼠标。

命令中枢：Better Command Palette 与 CMDR¶

两者都是命令面板增强，侧重不同：

Better Command Palette 强化搜索与组织：@插件名 按来源过滤、#分类 过滤类别、settings: 直接搜设置项、/ 激活正则；支持收藏、命令别名、历史智能排序与命令链（一次执行一串命令）。

CMDR 更像命令管理系统：命令别名（new → 创建新笔记）、命令分组（”写作工具””导航命令”）、多步骤宏（创建笔记 → 插入模板 → 插入日期，可设 200-500ms 步间延迟）、命令过滤器（按场景生成精简面板）与键序列（连按 td 打开今日笔记）。它还可以完全接管 Ctrl/Cmd+P。

🔥
不要重复建设：Better Command Palette 负责日常快速搜索执行，CMDR 负责沉淀分组、宏与过滤器这类长期资产。若嫌重，装一个 CMDR 即可覆盖八成需求。

输入加速：Various Complements¶

Various Complements 提供多来源自动补全：当前文件词汇、全库其他笔记、自定义词典（单词|描述 格式）与特殊触发（# 补全标签、[[ 补全链接、@ 补全人名等）。它对专业术语库极其有用——把领域词汇写进 dictionary.md 后，全库术语拼写永远一致。性能上注意控制索引范围与触发字符数（2-3 字符较平衡），大型库设置文件大小上限并优先索引标题与前置元数据。

界面与结构效率件¶

  • Settings Search：在设置面板顶部搜索任意设置项，从”找字体在哪”到”Dataview 刷新”一跳直达。注意它无法搜索未安装插件的市场条目。
  • Plugin Groups：把插件组合成”写作模式””研究模式””轻量模式”一键切换，支持互斥组、条件触发与启动组——既是效率工具也是性能工具（详见 23-性能优化与版本管理）。
  • Quiet Outline：增强版大纲面板，支持正则筛选标题、按层级折叠、专注模式与”复制大纲为 Markdown 列表”，长文档导航利器。
  • Chronology：时间轴可视化插件，用 ```chronology 代码块把带 event_date/event_end 元数据的笔记渲染成交互时间线，支持 group-by 分组、filter 筛选、nested 嵌套，适合项目里程碑与学习路线回顾。

搜索驱动的日常工作流¶

  1. 早间：CMDR 宏”日记初始化”一键打开今日笔记并套模板
  2. 记录：Various Complements 自动补全术语与标签，保持一致性
  3. 检索：Omnisearch 组合过滤器精确定位；Quick Switcher 在笔记间秒切
  4. 整理：Quiet Outline 快速定位章节；Chronology 按月回顾项目进展
  5. 切换场景：Plugin Groups 一键切换插件组合，界面随场景瘦身
⚠️
效率插件的快捷键容易互相冲突（Ctrl+O、Ctrl+P 是重灾区），安装后先到「快捷键」设置里统一排查一遍，再逐步形成肌肉记忆——只绑定真正高频的十个操作。
