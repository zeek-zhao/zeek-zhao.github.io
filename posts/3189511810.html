文件IO

[!info] 本页概览
文件 IO 是程序与磁盘交互的基础。本文讲解 C 的 fopen/fread/fwrite/fprintf 文件操作、文本模式与二进制模式、错误处理，以及 C++ 的 fstream 流式读写。

核心概念

文件 IO 的本质是把内存数据搬运到磁盘（写）或反之（读）。C 标准库提供 FILE* 流接口；C++ 用 ifstream/ofstream 封装流对象。打开模式决定读写方式：r/w/a（读写追加）、+（同时读写）、b（二进制）。

常见坑

  1. 忘记 fclose：句柄泄漏，Windows 下导致文件被占用无法删除。
  2. fgets 的换行处理：读入的行含末尾 \n，拼接字符串时注意去掉。
  3. feof 的误用：feof(fp) 在读取失败之后才为真，不能作为循环前条件。用读取函数的返回值判断（如 fgets != NULL）。
  4. 文本 vs 二进制模式：Windows 下文本模式会把 \n 转成 \r\n，二进制数据必须用 b 模式。
  5. 打开失败不检查：fopen 返回 NULL 后继续使用是崩溃源，必须检查。

最佳实践

  • 用 RAII 管理文件：C++ 中 fstream 析构自动关闭；C 中保证所有 return 路径都执行 fclose。
  • 写重要数据前先备份，写完后 fflush/fclose 确保落盘。
  • 解析文本优先按行读取（getline/fgets）再拆分，避免流提取的空白陷阱。
  • 处理大型文件时逐块读写（如 64KB 缓冲区），不要一次性读入内存。
