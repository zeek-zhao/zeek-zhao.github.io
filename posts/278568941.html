常见坑¶

  1. 版本号与 tag 不一致：CI 校验构建产物版本 = tag。
  2. 轻量 tag 滥用：附注 tag 更可追溯。
  3. 发布失败继续发布：先回滚稳定，再修复。
  4. hotfix 忘记 bump PATCH：每个发布必有唯一版本。
  5. 回滚改写 tag：不可变，重新发新版本。

最佳实践¶

  • SemVer + 附注 tag + tag 驱动 CI。
  • 提交规范支撑自动 changelog（见 09-提交信息规范）。
  • 与 GitFlow 发布流程（03-GitFlow工作流）配合。
