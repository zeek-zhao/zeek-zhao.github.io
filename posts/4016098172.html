03-项目类型与看板-Scrum板

Projects → Create project：
📅 2026-10-24· 更新于 2026-10-24 ✍ zeek.zhao #工具#jira

项目类型与看板 / Scrum 板

📑把问题可视化
项目确定问题集合的边界，看板（Kanban）与 Scrum 板让工作流动可视化。

1. 创建项目¶

Projects → Create project：

项目类型 适用
Scrum 迭代开发（Sprint 驱动）
Kanban 持续流动（无 Sprint）
缺陷管理（Bug tracking） 纯缺陷跟踪
业务项目（Work Mgmt） 非研发团队
📝项目 KEY
生成如 PAY；问题编号 PAY-123。KEY 创建后不可改，命名前想好（团队缩写+域）。

2. 看板（Board）概念¶

  • 列（Columns）：映射工作流状态；
  • 泳道（Swimlanes）：按 Epic/Assignee/查询分组；
  • WIP 限制：限制进行中数量，暴露瓶颈；
  • 快速筛选：列顶部的筛选快捷入口。

3. Scrum 板与 Sprint¶

Scrum 板除列外还有：

元素 作用
Backlog 待办池（Story 排序）
Active Sprint 当前迭代（开始/完成 Sprint）
燃尽图 Sprint 进度曲线（08-仪表盘与报表）
容量（Velocity） 团队历史速率参考

4. 配置看板列¶

Board → Board settings → Columns：

拖拽问题到列 = 触发工作流转（依赖 05-工作流配置 的状态流转规则）。

5. 泳道配置¶

🔥使用建议
  • 小团队建议 3-5 列，列越多越难维护；
  • WIP 限制建议：每个开发 2-3 个进行中任务；
  • Kanban 不要频繁建 Sprint；Scrum 则固定迭代节奏。
