查询 DSL

[!abstract] 是什么
查询 DSL 是 ES 的 JSON 检索语言。核心分层：Query 上下文（算分） 与 Filter 上下文（缓存、不算分）。

基础查询

全文检索：match

[!note] match 语义
对 text 字段分词后检索，默认 OR 关系；"operator": "and" 可要求全部词命中。

精确匹配：term 与 terms

[!tip] filter vs query
精确过滤用 filter（可缓存、不算分）；相关度检索用 query。组合用 bool。

复合查询 bool

子句 语义
must 必须匹配（算分）
must_not 必须不匹配（不算分）
should 加分项，可选择性匹配
filter 必须匹配（不算分，可缓存）

通配符与正则（慎用）

[!warning] 性能警示
wildcard 前缀通配会全表扫描，生产禁止以 * 开头；模糊匹配优先用 ngram 分词或 match_phrase。
