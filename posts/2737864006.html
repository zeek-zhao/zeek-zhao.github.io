路由进阶与导航守卫

[!info] 本页概览
本文深入 vue-router：全局/路由级/组件内守卫、权限控制、路由懒加载、scrollBehavior、动态添加路由（addRoute），构建复杂导航场景。

核心概念

  • 导航守卫：路由跳转过程中的钩子，可拦截/重定向/放行。
  • 守卫类型：全局（beforeEach/afterEach）、路由级（beforeEnter）、组件内（onBeforeRouteLeave/Update）。
  • 常见用途：登录鉴权、页面标题、埋点、权限校验。
  • 守卫解析流程：组件复用判断 → 全局 beforeEach → 路由 beforeEnter → 组件守卫 → 确认 → afterEach。

常见坑

  1. 守卫中死循环：beforeEach 里重定向到自身路径会无限循环；检查目标路径排除。
  2. 异步守卫未 await：beforeEach 中 await 请求/Store 初始化，否则放行过早。
  3. 守卫修改 query 丢失 redirect：重定向到 login 时把 to.fullPath 放 query，登录后回跳。
  4. 组件内守卫用错钩子：Vue 3 组合式用 onBeforeRouteLeave 等，选项式才是 beforeRouteLeave。
  5. addRoute 权限路由刷新丢失：权限路由动态添加后刷新页面需重新注册。
  6. meta 合并：嵌套路由 meta 需要深度合并时手动合并（beforeEach 中 to.matched）。

最佳实践

  • 权限集中管理：meta 声明（requiresAuth/roles），beforeEach 统一判断。
  • 守卫职责单一：鉴权、标题、埋点拆多个函数。
  • 菜单/权限表驱动动态路由（addRoute），后端返回权限配置。
  • 守卫中不写重逻辑，复杂校验放 store/service。
  • 路由懒加载 + 分包命名：() => import(/* webpackChunkName: "admin" */ ...)。
