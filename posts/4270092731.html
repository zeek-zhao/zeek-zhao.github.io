生命周期

[!info] 本页概览
本文讲解 Vue 3 组件生命周期：创建、挂载、更新、卸载各阶段钩子（选项式与组合式对照），以及常见业务场景（请求、事件监听、清理）的落点。

核心概念

  • 生命周期钩子：组件从创建到销毁各阶段自动调用的函数。
  • 组合式 API 钩子：onMounted、onUpdated、onUnmounted 等（on 前缀）。
  • 关键阶段：setup（创建）→ 挂载 → 更新 → 卸载。
  • 异步/缓存组件也有 onActivated/onDeactivated。

常见坑

  1. 在 onMounted 前操作 DOM：ref 模板引用在 setup 同步阶段为 null；等 onMounted。
  2. 忘记清理监听/定时器：组件销毁后回调还在执行，内存泄漏 + 报错；在 onUnmounted 清理。
  3. 异步数据竞态：请求未返回组件已卸载，setData 报错；加取消标志或 AbortController。
  4. onUpdated 中修改数据：容易死循环；只在必要时机写，优先 computed/watch。
  5. keep-alive 组件 onMounted 只执行一次：重复进入用 onActivated 恢复状态。
  6. SSR 中生命周期差异：onMounted 等浏览器钩子在服务端不执行；SSR 相关用 onServerPrefetch。

最佳实践

  • 数据请求放 onMounted；异步结果用取消标志防泄漏。
  • 全局监听（resize、scroll）在 onUnmounted 成对清理。
  • 组合式逻辑抽离时生命周期钩子可共用（多个 setup 内都注册 onMounted）。
  • 表格页刷新数据用 watch（见 06-计算属性与侦听器）或路由参数变化触发。
  • 理解”数据驱动”：不要手动操作 DOM，交给响应式更新。
