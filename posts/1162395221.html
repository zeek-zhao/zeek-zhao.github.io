组件通信

[!info] 本页概览
本文系统讲解 Vue 组件间通信方式：props/emits、v-model、provide/inject、defineExpose、事件总线与状态管理，覆盖父子、兄弟、跨层级场景。

核心概念

  • 单向数据流：props 向下，emits 向上。
  • v-model：modelValue + update:modelValue 的语法糖。
  • provide/inject：跨多层级传递（祖孙），无需逐层 props。
  • Pinia：全局共享状态（见 09-状态管理Pinia）。

场景 推荐方式
父子 props/emits
表单输入 v-model
祖孙多层级 provide/inject
非层级全局共享 Pinia
临时事件 不推荐事件总线（已废弃），用 Pinia 或回调

常见坑

  1. props 修改警告：子组件直接改 props 会被警告；用本地 ref + watch 或 emit。
  2. provide 传递普通值：非响应式；要传 ref 才响应式（如示例）。
  3. inject 未提供：无默认值时报错；加默认值 inject('key', fallback)。
  4. v-model 参数名错：多 v-model 用 v-model:start 对应 props start 与 update:start。
  5. defineExpose 后模板不可见：defineExpose 只暴露给父组件 ref，不改变模板访问。
  6. 事件总线残留监听：组件销毁未移除监听导致泄漏；优先 Pinia。

最佳实践

  • 优先 props/emits 保持显式；层级太深再考虑 provide/inject。
  • 全局共享状态（用户、主题、购物车）统一 Pinia，避免多层 prop drilling。
  • 组件 API 命名一致：modelValue / update:modelValue 约定成俗。
  • 避免”通信魔术”：组件间隐式依赖会降低可维护性。
