Go 的控制流关键字少而强大：if、switch、for、defer。本文讲解各语句的 Go 特色用法：if 初始化子句、switch 无 break、for 的三种形态、defer 的延迟执行机制。

核心概念¶

Go 去掉了 while 与 do-while，统一用 for；if/switch 支持初始化子句（作用域限定在语句内）；defer 让函数退出前执行清理逻辑，是资源管理的重要工具。

defer f(x) 中 x 在 defer 声明时求值，而非函数退出时。需延迟取值可用闭包：defer func() { fmt.Println(x) }()。

常见坑¶

  1. defer 与 return 的执行顺序：return 先给返回值赋值，再执行 defer，再真正返回。defer 中修改局部变量不会影响已计算的返回值（除非用命名返回值）。
  2. **switch 中 fallthrough**：Go 默认不穿透，明确需要时写 fallthrough，但常导致意外，慎用。
  3. for 中闭包捕获循环变量：Go 1.22 前循环变量被闭包共享，for i := range ... 中 go func(){fmt.Println(i)}() 可能输出相同值。1.22+ 每迭代独立变量。
  4. defer 在循环内积累：循环内大量 defer 会延迟到函数结束才执行，占用资源，应在循环体内用局部函数包裹。
  5. 无限 for 无退出条件：忘记 break 导致死循环。

最佳实践¶

  • 用 switch 替代长 if-else 链，可读性更好。
  • 资源（文件、锁、连接）用 defer 关闭，紧跟获取之后写 defer。
  • defer 按逆序执行，依赖关系注意顺序。
  • 循环遍历集合优先 for i, v := range，见 05-数组切片与映射。
