条件与循环

ℹ️本页概览
本文讲解 Shell 的控制流：test 表达式（文件/字符串/数值判断）、if/elif/else、for/while/until 循环与 case 多分支，覆盖脚本逻辑组织的核心。

核心概念¶

  • test 命令：[ ... ] 与 ...（推荐扩展版）做条件判断。
  • 条件命令返回退出码决定 if 分支。
  • for 遍历列表/命令输出；while 条件循环；case 模式匹配多分支。

test 判断¶

常用 test 含义
-eq -ne -gt -lt -ge -le 数值比较
= != / == 字符串等于/不等
-z -n 字符串为空/非空
-f -d -e -x -r -w 文件、目录、存在、可执行、可读、可写
-a -o / `&&

常见坑¶

  1. [ 后必须有空格：[$n -gt 5] 语法错误，[ 是命令需要空格分隔。
  2. `` 与 [ ] 混用：支持 `&& || ==` 与通配符，`[ ]` 需 `-a -o` 与转义；统一用（bash）。
  3. **数值比较用了 >**：[ 10 > 5 ] 是字符串重定向陷阱，数值用 -gt。
  4. 循环内管道产生子 shell：cat file | while ... 中变量修改不保留，用进程替换 < <(...) 或 for。
  5. for f in *.log 无匹配时：通配符不展开会得到字面 *.log，先 shopt -s nullglob 或判断 -f。
  6. "$s" == t* 引号：模式放变量会变字面匹配，需判断可把模式放右侧不加引号。

最佳实践¶

  • 统一使用 `` 与 (( )) 做判断（bash 特性、更安全）。
  • case 分支都写 *) 兜底处理非法输入。
  • 循环尽量少写 C 风格，用 for x in list。
  • 复杂条件拆变量：is_ready=... 提高可读性。
  • 循环内注意子 shell 陷阱：需要保留变量用进程替换或 coproc。
