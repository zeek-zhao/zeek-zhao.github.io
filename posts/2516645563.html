移动端与多设备

[!abstract] 一句话
移动端的定位是”随手捕获 + 随时阅读”，桌面负责深度整理——选对同步方案、设计好轻量工作流，知识库就能随身携带。

移动端安装

[!note] 2026 更新
1.11（2026-01）对移动端做了大版本 UI 刷新：浮动导航栏、全屏模式、锁屏与主屏小组件，并支持用 iOS Keychain 安全存储插件密钥；1.14（EA，2026-07）进一步带来 iOS 快速捕获与 Share Sheet——在任何 App 里分享内容即可直达 Obsidian 收件箱，”随手记”体验大幅提升。同步方面，官方路线图包含移动端后台同步，值得期待。

多设备同步方案对比

方案 费用 特点 风险
Obsidian Sync 付费 官方、端到端加密、体验最好 成本
Git（Obsidian Git 插件） 免费 版本历史 + 同步二合一 需学习 Git
网盘（OneDrive/坚果云） 免费/低价 配置简单 冲突覆盖风险高
Syncthing 免费 点对点自建、无第三方 需自行维护
Remotely Save 免费 多后端（S3/WebDAV/OneDrive 等） 需配置

选择建议：追求无缝选官方 Sync；追求免费可靠选 Git 自动备份 + 移动端按需拉取；自托管党选 Syncthing 或 Remotely Save 的 WebDAV/S3 模式。详细配置见 17-同步发布与分享。

Obsidian Git 移动端配置

  1. 安装社区插件 Obsidian Git
  2. 配置仓库 URL（建议 GitHub/Gitee 私有仓）
  3. 设置自动提交/拉取间隔（如每 5 分钟）
  4. 首次执行克隆或拉取，同步整个 Vault

[!warning]
移动端 Git 认证使用 Personal Access Token，注意最小权限原则，不要把高权限 token 明文留在移动端。

移动工作流设计

移动端场景按”轻”设计：

  1. 随手记录：快速捕获到收件箱笔记 → 回桌面整理。可用 QuickAdd 快速新建，或 1.14 的 Share Sheet 从微信/浏览器直接分享进库
  2. 阅读复习：翻笔记、看图谱、浏览 Daily Note
  3. 任务处理：用 TASK 查询（Dataview/Tasks）在手机上勾选待办
  4. 会议记录：预置模板 + 语音转文字输入

配套技巧：移动端设置”收件箱”快捷笔记入口；用快捷命令减少打字；大纲与图谱视图天然适合触屏浏览。

冲突避免与习惯养成

常见坑

  1. 移动端拉取后本地修改丢失：先 commit 本地再 pull
  2. 附件未同步：确认附件文件夹纳入同步范围
  3. 插件在移动端异常：部分插件（如 Shell Commands）不支持移动端，按需禁用；可参考 19-搜索与效率工具 中 Plugin Groups 建立”移动端轻量组”
  4. 网络差同步失败：手动触发重试并检查日志
  5. 移动端启动慢：为移动设备创建精简插件组合，避免重量级主题（优化细节见 23-性能优化与版本管理）

最佳实践

  • 移动端以”捕获 + 阅读”为主，深度编辑回桌面
  • 双保险：Git 自动备份兜底 + 移动端按需同步
  • 手机端插件数量控制在 10 个以内，功能尽量靠核心插件与模板
  • 定期在桌面端检查同步日志，及早发现冲突文件
