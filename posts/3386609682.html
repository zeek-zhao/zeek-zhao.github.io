常见坑

  1. tar 路径语义：-C dir 指定工作目录，避免绝对路径警告。
  2. find -delete 前必预览：生产环境先 -print。
  3. read 确认输入：[yY] 匹配，默认不删（N）。
  4. mv 覆盖：目标存在会覆盖，批量前加 -n（不覆盖）或确认。
  5. tree 可能不存在：用 find 兜底。
  6. 脚本硬编码路径：所有路径可参数化（$1/${VAR:-default}）。

最佳实践

  • 每个实战脚本遵守：参数校验 → 前置检查 → 预览 → 执行 → 汇报。
  • 危险操作（删除、覆盖、格式化）一律先预览 + 用户确认。
  • 日志输出带时间戳，便于排查。
  • 脚本积累成库（见 20-函数库与模块化），复用公共函数。
  • 用 set -euo pipefail + shellcheck 保证质量。
