系统管理脚本

[!info] 本页概览
本文汇总常见系统管理脚本：进程监控、磁盘告警、定时任务（cron）、服务管理、日志统计、getopts 参数解析，覆盖运维日常。

核心概念

系统管理脚本 = 系统信息采集 + 阈值判断 + 告警/动作 + 定时执行。常用命令：df、free、ps、uptime、cron、systemctl、journalctl。

常见坑

  1. cron 环境差异：cron 无完整 PATH/环境变量，脚本内显式设置 export PATH=/usr/local/bin:/usr/bin:/bin。
  2. df 输出格式化差异：用 awk 'NR==2 {print $5}' 而非 $4（不同系统列序可能不同）。
  3. mail 命令可能不存在：用 || true 或换成日志 + 第三方通知。
  4. pgrep -f 匹配过宽：进程模式太泛会误杀/误启，用精确命令。
  5. cron 输出邮箱轰炸：重定向日志 >> file 2>&1，避免每次执行发邮件。
  6. 时区与日志轮转：cron 按系统时区，logrotate 配好再统计。

最佳实践

  • 系统脚本统一 set -euo pipefail + 日志 + 幂等（可重复执行）。
  • cron 脚本在脚本内设置环境，不依赖交互 shell。
  • 告警分级：日志 → 邮件 → 短信/企业微信（可配置）。
  • 全部脚本放 /opt/scripts/ 并纳入版本管理。
  • 关键脚本加锁防并发：flock（见 21-性能与效率 或单独实现）。
