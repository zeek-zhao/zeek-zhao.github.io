grep

[!abstract] 用途
grep 在文件或输出流中按模式（正则）匹配行，是日志分析、配置检索、命令输出的过滤利器，几乎每个 Linux 脚本都会用到。

3. 常用选项

选项 作用
-i 忽略大小写
-n 显示行号
-v 反向匹配（排除）
-c 统计匹配行数
-l 只列出含匹配的文件
-w 全词匹配
-E 扩展正则（egrep）
-o 只输出匹配部分
-A2 -B2 匹配后/前 2 行上下文
--color 高亮匹配（alias 常用）

7. 注意事项

  • 二进制文件用 grep -a；默认会提示 binary file matches；
  • 日志文件很大时先 tail 再 grep，避免全量扫描；
  • 正则特殊字符（. * [ ]）需转义或使用 -F 固定字符串；
  • grep -v grep 常用于过滤进程查询自身的干扰；
  • 跨目录搜索海量文件用 grep -r 时结合 --include="*.log" 限类型。
