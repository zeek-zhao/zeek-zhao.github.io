17-字符串与正则

发表于2026-10-25|groovy
|浏览量:

[!info] 本节目标
Groovy 正则语法简洁，学习模式定义、匹配与捕获组使用。

1. 正则表达式定义

Groovy 用斜杠字符串定义正则：/\d+/ 免去双重转义。find 方法判断是否匹配，matches 要求完全匹配，等号操作符简化调用。

正则表达式字面量编译为 Pattern 对象，可以结合 Matcher 使用全部 Java 正则 API。

2. 匹配操作

==~ 完全匹配、=~ 部分匹配（返回 Matcher）、Matcher 的 find 与 group 提取匹配片段。循环 find 遍历所有匹配。

匹配结果可以直接用于条件判断与数据提取，如校验手机号、邮箱、提取日志时间戳。

3. 捕获组

括号定义捕获组，group(1)、group(2) 按索引取内容，命名组可用名称访问。捕获组用于结构化提取文本片段。

例如解析键值对、提取 URL 各部分、解析 CSV 字段时，捕获组是主力工具。

4. 替换与分割

replaceFirst 与 replaceAll 支持正则替换，回调形式可以基于捕获内容动态生成替换文本。split 与 tokenize 按正则或分隔符分割字符串。

注意 Java 替换字符串中的美元符与反斜杠转义，Groovy 中同理。

5. 正则性能与陷阱

复杂正则避免灾难性回溯，嵌套量词要谨慎；预编译 Pattern 复用提升性能；匹配失败要区分 find 与 matches 语义。

贪婪与懒惰量词的选择影响匹配结果，先小范围验证再应用到生产。

6. 文本处理综合示例

日志解析：按行提取时间、级别、消息；配置解析：正则提取键值对；清洗：替换空白、去 HTML 标签片段。组合 find 与 collect 批量处理。

正则解决 80% 文本问题，复杂嵌套结构建议使用解析器或 JSON/XML 工具而非硬啃正则。

7. 正则实战案例

日志解析时用捕获组提取时间、级别与消息字段，再转为结构化对象，为监控与告警提供干净的数据源。

敏感信息脱敏（手机号、身份证）用分组替换保留前后缀，一次正则即可完成；注意替换字符串中转义字符的处理。

性能敏感场景预编译 Pattern 并复用，循环内避免重复编译正则；复杂模式先拆解验证再合并，减少调试成本。
