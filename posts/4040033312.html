工作空间与 catkin 构建

[!info] 本节目标
掌握 catkin 工作空间的结构、创建与构建流程，能创建并编译自己的第一个功能包。

1. 什么是 catkin

catkin 是 ROS1 的官方构建系统（基于 CMake 的定制封装），用于组织功能包、生成消息/服务代码、管理依赖并构建可执行文件。

8. 常用构建命令速查

命令 作用
catkin_make 经典构建（全空间）
catkin build catkin_tools 构建
catkin build --pkg my_pkg 仅构建指定包
catkin clean 清理构建产物
rospack find my_pkg 查找包路径
rosdep install my_pkg 安装包依赖

[!note] 检查依赖
新机器上拉取他人工作空间后，先执行 rosdep install --from-paths src --ignore-src -r -y 补齐系统依赖再构建。
