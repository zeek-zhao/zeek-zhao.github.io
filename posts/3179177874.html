指令与插槽

[!info] 本页概览
本文讲解 Vue 自定义指令（v-xxx）与插槽系统：内置指令回顾、自定义指令的钩子与场景（权限、防抖、聚焦）、具名插槽、作用域插槽，实现高复用组件。

核心概念

  • 内置指令：v-model/v-if/v-for/v-bind/v-on/v-show/v-html/v-cloak/v-once/v-memo。
  • 自定义指令：vDirective，用于 DOM 级操作封装（聚焦、滚动、权限、水印）。
  • 插槽：组件内容分发；具名插槽（#name）、作用域插槽（传数据给父）。

常见坑

  1. 指令在组件上失效：自定义指令应用在组件根元素/普通元素；Vue 3 指令可在组件根，但带 props 需注意。
  2. 指令卸载清理：mounted 里加监听，unmounted 必须移除，否则内存泄漏。
  3. 作用域插槽解构默认值：#default="{ row = {} }" 提供默认，防 undefined。
  4. 插槽命名冲突：默认插槽与具名插槽分别使用；空 template 不渲染。
  5. v-slot 只能在 template 上：直接放组件标签上会警告（除非单插槽简写）。
  6. 指令参数响应性：binding.value 在依赖变化时需 updated 钩子重新处理（或使用 ref 在钩子内读取）。

最佳实践

  • 插槽让通用组件（表格、弹窗、列表）内容高度定制。
  • 作用域插槽把”数据下行 + 回调上行”合一，适合表格操作列。
  • 自定义指令只做 DOM 副作用封装，不要放业务状态逻辑。
  • 团队封装基础指令库（v-permission/v-debounce/v-copy），统一维护。
  • 指令卸载必清理监听器与定时器。
