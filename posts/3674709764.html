基础语法与数据类型

[!info] 本页概览
Python 是动态类型、缩进敏感的语言。本文讲解变量、数字、字符串、布尔、类型转换与常用内置函数，建立基础语法的完整认知。

核心概念

  • 动态类型：变量无需声明类型，运行时绑定。
  • 缩进即语法：4 空格缩进划分代码块。
  • 一切皆对象：数字、字符串、函数都是对象。
  • 不可变 vs 可变：数字/字符串/元组不可变，列表/字典/集合可变。

常见坑

  1. 缩进不一致：混合 Tab/空格导致 IndentationError，编辑器统一空格。
  2. 整数与字符串不能隐式相加："1" + 1 报 TypeError，需 int("1") + 1。
  3. 浮点精度：0.1 + 0.2 != 0.3，金额用 decimal.Decimal。
  4. is 与 == 混淆：is 比较对象身份（地址），== 比较值；小整数缓存可能误导，比较值用 ==。
  5. 可变默认值：def f(x=[]) 默认列表跨调用共享，用 None 再初始化。
  6. 中文编码：Python 3 源码默认 UTF-8，读旧文件需指定 encoding。

最佳实践

  • 命名用 snake_case：user_name、get_total()。
  • 常量全大写：MAX_RETRIES = 3。
  • 用 f-string 格式化，不用 % 或 + 拼接。
  • 数字可加下划线分隔：1_000_000。
  • 空值判断用 is None 而非 == None；真值判断直接 if items:。
