Java 环境与构建工具

[!info] 本页概览
本文讲解 Java 开发环境搭建：JDK 安装与版本管理、IDE 选择、JAVA_HOME 与 PATH 配置、javac/java 命令行编译运行、构建工具概览（Maven/Gradle）。

核心概念

  • JDK（Java Development Kit）：开发工具包，含 javac（编译器）、java（运行时）、jps/jstack/jmap 等诊断工具。
  • JRE：运行环境（JDK 内含）；Java 9+ 模块化（JPMS）后按模块分发。
  • LTS 版本：8 / 11 / 17 / 21 为长期支持版，新项目建议 17 或 21。
  • 构建工具：Maven（约定优于配置）、Gradle（灵活高效），解决依赖管理与打包。

[!warning] 类名与文件名
public 类必须与文件名同名（Hello.java 中只能有一个 public class Hello），否则编译报错。

用 Maven 创建项目（推荐）

IDE 选择

  • IntelliJ IDEA：最主流，社区版免费，支持重构、调试、Spring 集成。
  • Eclipse：老牌免费 IDE。
  • VS Code + Java 插件：轻量方案，适合脚本式开发。

常见坑

  1. JAVA_HOME 未生效：setx 后需重开终端；多版本 JDK 用 jenv/sdkman 管理。
  2. javac 与 java 版本不一致：PATH 里多个 JDK 混用导致；检查两个 -version 输出。
  3. 运行时报 NoClassDefFoundError：classpath 未设置或缺失依赖 jar。
  4. 编码乱码：Windows 默认 GBK，源码用 UTF-8；编译加 -encoding UTF-8。
  5. Maven 下载慢：配置阿里云镜像（见 16-Maven与Gradle）。
  6. IDE 与命令行 JDK 不一致：IDE 内 Project SDK 单独设置，需与项目要求匹配。

最佳实践

  • 统一用 LTS 版本（17/21），团队一致避免语法差异。
  • 新项目用 Maven/Gradle 管理依赖，不要裸 javac 大战。
  • 环境配置入文档（README），新成员可快速复现。
  • 用 jenv/sdkman（Linux/macOS）或手动切换（Windows）管理多版本。
  • 定期升级 JDK 补丁版本（安全修复）。
