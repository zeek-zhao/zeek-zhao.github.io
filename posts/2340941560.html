文本处理三剑客：grep / sed / awk

[!info] 本页概览
grep（搜索）、sed（流编辑）、awk（字段处理与编程）是 Linux 文本处理的三大神器，配合正则表达式几乎能处理一切文本任务。

核心概念

工具 定位 典型用法
grep 按模式筛选行 找包含关键词的行
sed 按模式编辑流 替换、删除、插入行
awk 按字段/条件计算 取列、统计、格式化输出

grep：搜索

sed：流编辑

[!warning] sed -i 谨慎
-i 原地覆盖不可逆，先加 .bak 后缀或确认备份。

awk：字段处理

组合实战

常见坑

  1. awk 与 shell 变量：awk 内 $1 是列，shell 变量用 -v v="$var" 传入。
  2. grep -r 搜二进制：加 -I 跳过二进制，避免乱码刷屏。
  3. sed -i 无备份：先测试输出再原地编辑。
  4. 正则流派差异：grep 默认 BRE，+ 需转义 \+；用 -E（ERE）更顺手；grep -P 用 PCRE。
  5. awk 浮点精度：默认双精度，格式化用 printf "%.2f"。
  6. 大文件内存：grep/sed/awk 都是流式（逐行），安全；排序类（sort/uniq）会占内存。

最佳实践

  • 过滤优先 grep，替换优先 sed，统计取列优先 awk。
  • 管道组合遵循”缩小数据面”：先 grep 缩小 → 再 awk 取字段 → 再 sort/uniq。
  • 复杂 awk 程序写成脚本文件 awk -f prog.awk 可维护。
  • 处理 CSV 用 awk 前确认转义（引号内逗号），复杂 CSV 用 python csv。
  • 学一个”万用模式”：awk '{...} END {...}' 做聚合统计。
