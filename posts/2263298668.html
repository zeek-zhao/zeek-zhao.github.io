05-闭包基础

发表于2026-10-25|groovy
|浏览量:

[!info] 本节目标
闭包是 Groovy 的核心特性，理解闭包才能用好 Groovy 的函数式能力。

1. 闭包定义

闭包用花括号定义，可以赋值给变量、作为参数传递、作为返回值返回。最简单的闭包打印文本，无参数，调用时用 call 方法或直接加括号。

闭包是 Groovy 的一等公民，贯穿集合操作、DSL、回调与并发编程，是整个语言的使用基础。

2. 参数与返回值

闭包参数在箭头前声明，如 { x -> x * 2 }。未声明参数时隐式变量 it 代表第一个参数。闭包总有返回值，最后一条表达式的值即返回值。

闭包支持默认参数、变长参数与多参数列表，与方法的参数规则一致。

3. 闭包与集合

闭包最典型的应用是集合操作：each 遍历、collect 映射、findAll 过滤、find 查找、inject 归约。这些方法让数据处理声明式化，替代传统 for 循环。

例如列表 collect 生成新列表，findAll 过滤元素，链式组合表达力极强。

4. 闭包与作用域

闭包可以访问定义处的外层变量，形成闭包环境。闭包内可以修改外层变量，与 Java lambda 的 effectively final 限制不同。

闭包访问的变量是引用绑定，循环中创建闭包要注意共享变量问题，必要时用局部副本。

5. 闭包作为回调

闭包天然适合事件回调、资源管理与模板方法模式。传入闭包即可定制行为，无需定义匿名类或函数式接口。

Java 方法接受函数式接口时，Groovy 闭包会自动适配，与 Java 8 lambda 无缝互操作。

6. 常用闭包技巧

组合闭包用右移或左移操作符；带记忆闭包可以缓存计算结果；闭包可以用 memoize 方法包装，实现简单缓存。

trampoline 支持递归优化，避免深递归栈溢出。掌握这些技巧能让函数式代码更优雅。
