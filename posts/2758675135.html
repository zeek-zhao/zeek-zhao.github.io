综合实战：自动化运维脚本

ℹ️本页概览
综合运用本套全部知识点，实现一个生产级运维脚本：健康检查 + 磁盘监控 + 备份 + 日志清理 + 参数解析 + 安全防护，可直接部署到服务器。

需求设计¶

功能：

  1. -h 参数解析与帮助
  2. 服务健康检查（HTTP）
  3. 磁盘使用率告警
  4. 备份指定目录（tar + 日期）
  5. 清理过期日志（预览 + 确认）
  6. 全部日志输出 + 退出码 + flock 防并发

复盘要点¶

  1. 参数化：所有路径/阈值可通过选项覆盖，默认值安全。
  2. 安全：删除先预览 + 确认；flock 防并发；依赖检查。
  3. 健壮：set -euo pipefail + 统一日志 + 非零退出码。
  4. 可维护：函数拆分 + 公共库复用（20-函数库与模块化）。
  5. 扩展方向：告警发企业微信、配置独立文件、支持多机 SSH 批量、接入 systemd timer。
