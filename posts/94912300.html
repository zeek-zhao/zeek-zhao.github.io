Pipeline 基础语法

[!abstract] 是什么
Pipeline 把 CI/CD 流程写成代码（Jenkinsfile），随仓库版本控制：可审计、可复用、可分支差异化。

两种语法

语法 特点 推荐
声明式 Declarative 结构清晰、门槛低 首选
脚本式 Scripted 灵活、Groovy 自由度大 复杂逻辑

声明式 Pipeline 骨架

常用指令速查

指令 作用
agent 指定执行节点/标签
stages / stage 阶段容器/阶段
steps 阶段内步骤
environment 环境变量
options 超时、重试、丢弃策略
parameters 参数化构建（05-参数化构建与触发器）
post 结果处理（always/success/failure）
when 条件执行（分支判断）

[!tip] 调试技巧

  • Pipeline Syntax 页面（/pipeline-syntax）可可视化生成步骤代码；
  • 本地快速验证 Groovy：jenkinsci/pipeline-examples 仓库有大量范例；
  • 出错看 Blue Ocean 或 Console Output 的红色阶段定位。

[!warning] 注意
Pipeline 脚本写在仓库 Jenkinsfile；每次改脚本需重跑构建验证，没有”编译期”保护。
