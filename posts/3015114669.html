主题推荐与对比

[!abstract] 一句话
选主题先看两点：内容形态是否匹配、社区是否活跃，本文横向对比 2026 年主流 Hexo 主题给出选型结论。

主题在 Hexo 中的角色

主题决定了博客的颜值与一大半交互能力：导航菜单、侧边栏、搜索、评论、暗色模式、文章 TOC 都由主题提供。换主题的成本不低（配置迁移、样式适配），因此值得在起步阶段慎重选择。

第一梯队：Butterfly

推荐指数：★★★★★，目前最适合构建知识库类博客的 Hexo 主题。

  • 精美的卡片式设计，适合知识点展示
  • 完善的多级目录导航、标签与分类页面
  • 支持深色模式和多种主题色，代码块样式美观
  • 标签插件体系丰富（提示框、选项卡、时间轴、图库等）
  • 社区庞大、文档完善、持续活跃维护

[!note] 2026 更新
Butterfly 最新版本为 5.7.0（2026 年 8 月发布），GitHub 8,100+ stars，采用 Apache-2.0 协议，维护非常活跃。注意：其仓库默认分支是 dev，通过 git clone 安装时应使用 git clone -b master 拉取稳定版；npm 安装的版本号与 GitHub release tag 不完全对应，使用前需核对。

由于功能最全、生态最成熟，本套件后续的 06-Butterfly主题全面指南、07-Butterfly自定义侧边栏、08-Butterfly分类与标签系统 都以 Butterfly 为基础展开。

第二梯队：Fluid / NexT / Volantis

Fluid（★★★★☆）：现代简洁风，界面优雅，加载速度快，字体与间距设计合理，阅读体验极佳，配置简单直观，适合以长文字为主的博客。

NexT（★★★★☆）：极简风格的经典老牌主题，专注内容展示，MathJax/KaTeX 数学公式支持出色，SEO 优化成熟，是学术型与技术文档型博客的常青树。

[!note] 2026 更新
NexT 家族累计 star 数约 27k，提供 Muse、Mist、Pisces、Gemini 四种布局，从紧凑单栏到双栏卡片任选，是”审美保守但求稳”用户的可靠选择。

Volantis（★★★★☆）：为内容创作者优化的卡片式主题，小部件系统强大，布局选项丰富，适合构建数字花园（Digital Garden）式的知识网络。

其他值得关注的主题

  • Icarus：基于 Bulma 框架的三栏布局，英文文档质量是所有主题中最好的，适合英文写作者与喜欢清晰结构化配置的人。
  • Matery：卡片杂志风，首页轮播与瀑布流视觉效果出众，适合作品展示与生活方式类博客。
  • Cactus：极简作品集风格，单栏、无干扰，适合追求”内容即一切”的极简主义者。
  • AnZhiYu：Butterfly 的增强 fork，内置 AI 摘要等新潮功能与更活泼的交互设计，适合喜欢尝鲜的用户。

[!tip] 选 fork 主题的代价
fork 主题（如 AnZhiYu）通常更新跟随上游但略有延迟，社区规模小于本体。如果依赖社区问答解决问题，本体主题仍是更稳妥的选择。

选型决策建议

用一个简单的决策树：

  1. 想要功能全、中文资料多、能折腾 → Butterfly
  2. 只想安静写字、偏好简洁 → Fluid 或 NexT
  3. 做作品集/杂志感 → Matery
  4. 学术论文、公式密集 → NexT
  5. 喜欢新功能、不介意风险 → AnZhiYu

Hexo 主题生态与 SSG 趋势

[!note] 2026 更新
从整个静态站点生成器（SSG）格局看，Hugo 以构建速度领先，Astro 凭组件化现代栈快速崛起。Hexo 的核心竞争力不在性能而在于中文社区与主题生态的成熟度——主题数量、文档汉化、问答积累都是其他框架短期难以复制的护城河。

另一个常被忽略的考量是评论系统配套：主流方案 Waline、Twikoo、Giscus、Valine、Artalk 在 Butterfly 与 NexT 中的集成最完善，选主题时不妨顺带确认评论方案的支持情况，详见 15-评论系统与互动。
