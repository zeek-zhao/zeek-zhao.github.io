常见坑

  1. 版本功能误解：CE 无 Kubernetes 高级管理，先确认需求。
  2. 单点管理局限：Portainer 是管理面，业务流量不走它。
  3. 安全默认弱：部署后立即改默认密码（见 14）。
  4. 数据持久化遗漏：Portainer 自身数据也要备份（见 13）。
  5. 与 Docker CLI 混用：UI 与 CLI 可并存，注意操作一致。

最佳实践

  • 先规划环境接入方式（本机/Agent/Edge）。
  • 生产环境启用 HTTPS（见 02）。
  • 权限模型提前设计（见 09）。
