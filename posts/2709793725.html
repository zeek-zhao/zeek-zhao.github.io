运算符与控制流

[!info] 本页概览
本文讲解 Java 运算符（算术、比较、逻辑、位、三元、赋值）与控制流（if/switch/for/while/增强 for/break/continue），含可运行示例与常见陷阱。

核心概念

  • 运算符：按优先级计算表达式，注意结合性与括号。
  • 短路：&& 与 || 短路求值。
  • 控制流：分支（if/switch）、循环（for/while/do-while/增强 for）。
  • Java 14+ 的 switch 表达式更安全优雅。

常见坑

  1. 整数除法截断：10 / 3 == 3；需要小数时用浮点。
  2. 浮点相等判断：0.1 * 3 == 0.3 为 false；用差值范围。
  3. switch 漏 break：传统写法会穿透；用 switch 表达式/箭头避免。
  4. 短路与副作用：a && b++ 在 a 为 false 时 b 不自增。
  5. **比较字符串用 ==**：应为 "abc".equals(s)。
  6. 死循环条件写反：while (i < 0) 直接不进入。

最佳实践

  • 优先 switch 表达式（Java 14+），无穿透风险且更清晰。
  • 循环边界清晰，避免魔法数字；用 list.size() 等真实边界。
  • 位运算用于标志位/权限时命名常量，勿裸数字。
  • 复杂条件抽方法（isEligible(user)），提升可读性。
  • 集合遍历用增强 for 或 Stream（见 14-Lambda与Stream）。
