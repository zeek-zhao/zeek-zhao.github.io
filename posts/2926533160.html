07-操作符重载

发表于2026-10-25|groovy
|浏览量:

[!info] 本节目标
掌握 Groovy 如何将操作符映射为方法调用，并自定义运算行为。

1. 操作符与方法的映射

Groovy 中操作符本质是方法调用：加法映射为 plus 方法，等号比较映射为 equals 或 compareTo 方法，索引映射为 getAt 方法。自定义类实现对应方法即可获得操作符支持。

这种映射机制让 DSL 与领域类型获得自然运算语义，如向量相加、矩阵乘、时间区间判断等。

2. 常用重载操作符

算术操作符映射到 plus、minus、multiply、div、mod、power；比较映射到 compareTo 与 equals；索引映射到 getAt 与 putAt；一元操作符映射到 positive、negative、next、previous。

范围操作符映射到 rangeTo，包含端点的表达式非常直观。

3. 重载实现要点

实现重载方法时注意参数类型匹配，Groovy 按运行时类型选择方法。equals 重载要满足一致性要求，hashCode 同步重写。

返回类型尽量保持运算语义正确，例如 minus 返回同类型对象，避免类型混乱。

4. 操作符在 DSL 中的应用

DSL 中常利用操作符表达领域逻辑：时间表用加法添加任务、权限系统用 in 判断成员、数值区间用范围表达。合理的操作符设计让 DSL 接近自然语言。

注意不要过度重载导致代码难以理解，操作符语义应符合直觉。

5. 与 Java 互操作

Java 类不能直接使用 Groovy 操作符语法，但 Java 代码可以调用对应方法名，如 plus、getAt 等。

Java 集合与 Groovy 互操作时，Groovy 操作符自动适配，如列表索引访问、映射属性访问。

6. 常见陷阱

等号在 Groovy 中是 equals 语义，与 Java 的引用比较不同，移植 Java 代码时要注意。is 方法保留引用比较语义。

操作符优先级与 Java 一致，复杂表达式加括号明确语义；重载方法性能略低于直接方法调用，高频路径注意。

7. 操作符重载综合示例

以一个坐标类为例，重写 plus、minus、multiply 与 equals 后，可以直接用加号、减号、乘号对坐标做运算，代码读起来与数学表达式无异。

索引操作符配合 getAt 与 putAt，可以让自定义容器对象像数组一样按位置读写元素，这是集合类库的常见实现方式。

重载设计时保持对称性：加法可交换、减法与加法互为逆运算、乘法分配律成立，行为符合直觉的运算才能被团队放心使用。
