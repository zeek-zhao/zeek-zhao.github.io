PowerShell

[!abstract] 用途
PowerShell 是 Windows 的现代命令行与脚本环境，基于 .NET，能操作文件、注册表、服务、WMI 等几乎所有系统对象，是运维自动化的核心工具。

1. 安装

  • Windows 10/11 自带 Windows PowerShell 5.1；
  • 推荐安装跨平台新版本 PowerShell 7（pwsh）：

启动：开始菜单搜 PowerShell 或运行 pwsh（7）/ powershell（5.1）。

[!note] 版本区别
Windows PowerShell 5.1 兼容老脚本（只能跑在 Windows）；PowerShell 7 是跨平台的新主版本，建议新脚本用 7。

2. 基础概念

  • Cmdlet：形如 动词-名词 的命令，如 Get-Process、Set-Location；
  • 管道：| 把前一个命令输出传给后一个命令对象；
  • 对象：PowerShell 传的是对象而非文本，可 Select-Object/Where-Object 筛选；
  • 别名：ls/dir 等同 Get-ChildItem，cd 等同 Set-Location。

5. 注意事项

  • 执行策略默认限制运行脚本：Set-ExecutionPolicy RemoteSigned（管理员）后运行 .ps1；
  • 删除/修改系统关键项前确认路径，Remove-Item 无回收站概念；
  • 命令帮助：Get-Help Get-Process -Examples；
  • 敏感信息用 -Credential/安全字符串，避免明文密码。
