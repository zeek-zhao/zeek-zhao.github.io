索引与映射

[!abstract] 是什么
Mapping（映射） 决定文档字段如何被索引与检索：类型、是否分词、是否存储。设计好 Mapping 是查询快而准的前提。

创建索引并定义 Mapping

常用字段类型

类型 用途 说明
text 全文搜索 分词、支持 match 查询
keyword 精确匹配/聚合/排序 不分词，如 status、ip
integer / long / float 数值 范围查询、聚合
date 时间 支持格式化与范围
boolean 布尔 true/false
ip IP 地址 支持 CIDR 范围
object / nested 嵌套结构 注意 nested 才支持数组对象独立查询

[!note] text vs keyword
message 用 text 可搜索”关键词”；level: ERROR 用 keyword 做精确匹配与聚合。一个字段可同时配两种：

分词器

分析器 特点
standard 默认，英文分词
ik_max_word 中文最细粒度分词（需装插件）
ngram / edge_ngram 前缀/子串匹配
keyword 不分词

[!tip] 中文场景
中文日志检索建议安装 IK 分词器：./bin/elasticsearch-plugin install analysis-ik，Mapping 指定 "analyzer": "ik_max_word"。

[!warning] 注意
已创建的字段类型不能直接修改；改类型需重建索引（reindex，见 12-运维与排错）。
