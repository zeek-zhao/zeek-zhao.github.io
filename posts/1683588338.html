Ubuntu 必备软件指南

我把日常装机会用到的软件按用途归在一起，原则是 apt 能装就别折腾编译，图形界面够用就别硬记命令。下面这些不是排行榜，只按我自己的使用频率排了序。

备份与包管理要优先装，别等系统出问题再补¶

1. Timeshift¶

  • 简介：系统备份还原工具
  • 亮点：类似 Windows 的系统还原点，支持定时自动备份
  • 安装方式：sudo apt install timeshift
  • 适用场景：系统配置前备份，防止系统崩溃后无法恢复

2. Synaptic Package Manager¶

  • 简介：图形化软件包管理器
  • 亮点：比软件中心更强大，可进行高级包管理操作
  • 安装方式：sudo apt install synaptic
  • 适用场景：精确管理系统软件包，解决依赖问题

3. Stacer¶

  • 简介：系统优化和监控工具
  • 亮点：清理系统垃圾、启动项管理、服务管理等功能
  • 安装方式：sudo apt install stacer
  • 适用场景：系统维护、优化性能、监控资源使用

4. GNOME Tweaks¶

  • 简介：GNOME 桌面环境高级设置工具
  • 亮点：提供许多默认设置中没有的选项，如图标主题、字体调整等
  • 安装方式：sudo apt install gnome-tweaks
  • 适用场景：个性化桌面环境，调整系统外观

5. Gparted¶

  • 简介：图形化分区编辑器
  • 亮点：可视化管理磁盘分区，支持多种文件系统
  • 安装方式：sudo apt install gparted
  • 适用场景：磁盘分区管理、调整分区大小、格式化

6. BleachBit¶

  • 简介：系统清理工具
  • 亮点：深度清理系统缓存、临时文件、历史记录等
  • 安装方式：sudo apt install bleachbit
  • 适用场景：释放磁盘空间，保护隐私

7. Nemo¶

  • 简介：功能强大的文件管理器
  • 亮点：比默认的 Nautilus 提供更多功能和定制选项
  • 安装方式：sudo apt install nemo
  • 适用场景：高级文件管理，需要更多功能的用户

开发环境一次配齐，编辑器优先选轻量的¶

1. Visual Studio Code¶

  • 简介：轻量级但功能丰富的代码编辑器
  • 亮点：丰富的插件生态系统，支持几乎所有编程语言
  • 安装方式：从官网下载 .deb 包或通过 Snap 安装
  • 适用人群：开发人员、文本编辑爱好者

2. Git¶

  • 简介：分布式版本控制系统
  • 亮点：高效管理代码历史记录
  • 安装方式：sudo apt install git
  • 适用场景：代码版本控制，项目协作

3. Docker¶

  • 简介：容器化平台
  • 亮点：轻量级虚拟化，快速部署应用
  • 安装方式：sudo apt install docker.io
  • 适用场景：应用部署、开发环境一致性、微服务架构

4. Terminator¶

  • 简介：高级终端模拟器
  • 亮点：支持分屏、标签页、自定义布局
  • 安装方式：sudo apt install terminator
  • 适用场景：需要同时管理多个终端会话的开发工作

5. Meld¶

  • 简介：可视化文件对比工具
  • 亮点：直观展示文件差异，支持三向对比
  • 安装方式：sudo apt install meld
  • 适用场景：代码审查、文件合并、配置文件对比

6. Postman¶

  • 简介：API 开发和测试工具
  • 亮点：易于创建和管理 API 请求，自动化测试
  • 安装方式：通过 Snap 安装 sudo snap install postman
  • 适用场景：API 开发、测试、文档管理

7. DBeaver¶

  • 简介：通用数据库管理工具
  • 亮点：支持几乎所有主流数据库，跨平台，开源免费
  • 安装方式：从官网下载或 sudo snap install dbeaver-ce
  • 适用场景：数据库管理、SQL开发、数据分析

8. GitKraken¶

  • 简介：Git 图形界面客户端
  • 亮点：直观的操作界面，简化版本控制
  • 安装方式：通过 Snap 安装 sudo snap install gitkraken
  • 适用场景：Git 可视化管理，团队协作

9. Zsh¶

  • 简介：高级命令行 shell
  • 亮点：比 Bash 提供更多功能，高度可定制，支持插件
  • 安装方式：sudo apt install zsh
  • 适用场景：命令行工作，提高终端工作效率

10. Oh My Zsh¶

  • 简介：Zsh 配置管理框架
  • 亮点：丰富的主题和插件，简化 Zsh 配置
  • 安装方式：sh -c "$(curl -fsSL https://raw.github.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"
  • 适用场景：美化终端，增强 Zsh 功能

11. Tmux¶

  • 简介：终端复用器
  • 亮点：在单一终端窗口中创建多个会话，支持分屏、会话持久化
  • 安装方式：sudo apt install tmux
  • 适用场景：远程服务器工作，需要保持会话的长时间任务

12. Neovim¶

  • 简介：Vim 文本编辑器的现代化分支
  • 亮点：异步执行，丰富的插件，比 Vim 更现代化的代码库
  • 安装方式：sudo apt install neovim
  • 适用场景：终端中的代码编辑，服务器环境开发

13. JetBrains Toolbox¶

  • 简介：JetBrains IDE 管理工具
  • 亮点：管理和更新各种 JetBrains IDE，如 IntelliJ IDEA、PyCharm 等
  • 安装方式：从官网下载 .tar.gz 文件并解压安装
  • 适用场景：使用多个 JetBrains 产品的开发者

14. Yarn¶

  • 简介：JavaScript 包管理器
  • 亮点：比 npm 更快、更可靠的依赖管理
  • 安装方式：npm install -g yarn 或通过官方源
  • 适用场景：JavaScript/Node.js 开发

15. HTTPie¶

  • 简介：命令行 HTTP 客户端
  • 亮点：比 curl 更友好，彩色输出，JSON 支持
  • 安装方式：sudo apt install httpie
  • 适用场景：API 测试，命令行中进行 HTTP 请求

截图、启动器和笔记这类小工具，最能改变日常手感¶

1. Flameshot¶

  • 简介：功能丰富的截图工具
  • 亮点：内置标注工具，支持快速上传
  • 安装方式：sudo apt install flameshot
  • 适用场景：截图并编辑，分享标注图片

2. Ulauncher¶

  • 简介：快速启动器和搜索工具
  • 亮点：类似 macOS 的 Spotlight，提高工作效率
  • 安装方式：从官网安装或 PPA
  • 适用场景：快速启动应用、搜索文件、执行命令

3. Dropbox¶

  • 简介：云存储和文件同步服务
  • 亮点：自动同步文件，跨平台访问
  • 安装方式：从官网下载或 sudo apt install dropbox
  • 适用场景：文件备份、跨设备同步、团队协作

4. Obsidian¶

  • 简介：基于本地Markdown文件的知识库工具
  • 亮点：强大的双向链接功能，插件生态丰富
  • 安装方式：从官网下载 AppImage 或 .deb 包
  • 适用场景：个人知识管理、笔记整理、学习研究

5. CopyQ¶

  • 简介：高级剪贴板管理器
  • 亮点：保存剪贴板历史，支持编辑和搜索
  • 安装方式：sudo apt install copyq
  • 适用场景：需要管理多个剪贴内容的工作

6. KeePassXC¶

  • 简介：密码管理工具
  • 亮点：开源、安全、本地存储密码
  • 安装方式：sudo apt install keepassxc
  • 适用场景：安全存储密码，生成强密码

影音与图像播放编辑，开源方案够用¶

1. VLC¶

  • 简介：多功能媒体播放器
  • 亮点：支持几乎所有格式，功能丰富
  • 安装方式：sudo apt install vlc
  • 适用场景：视频播放、音频播放、流媒体

2. GIMP¶

  • 简介：图像编辑工具
  • 亮点：开源的 Photoshop 替代品，功能强大
  • 安装方式：sudo apt install gimp
  • 适用场景：照片编辑、图像处理、数字绘画

3. Kdenlive¶

  • 简介：非线性视频编辑器
  • 亮点：专业级功能，界面友好
  • 安装方式：sudo apt install kdenlive
  • 适用场景：视频剪辑、后期制作

4. OBS Studio¶

  • 简介：开源录屏和直播软件
  • 亮点：功能强大，可自定义场景
  • 安装方式：sudo apt install obs-studio
  • 适用场景：屏幕录制、游戏直播、在线教学

5. Audacity¶

  • 简介：音频编辑软件
  • 亮点：录制和编辑音频的全套工具
  • 安装方式：sudo apt install audacity
  • 适用场景：音频编辑、录制、混音

6. Inkscape¶

  • 简介：矢量图形编辑器
  • 亮点：SVG 格式支持，专业设计功能
  • 安装方式：sudo apt install inkscape
  • 适用场景：设计徽标、插图、海报等矢量图形

浏览器和远程连接，先解决连通性再谈体验¶

1. Firefox¶

  • 简介：开源网页浏览器
  • 亮点：注重隐私保护，扩展丰富
  • 安装方式：Ubuntu 预装或 sudo apt install firefox
  • 适用场景：日常网页浏览，开发测试

2. Google Chrome¶

  • 简介：谷歌浏览器
  • 亮点：速度快，同步功能强大
  • 安装方式：从官网下载 .deb 包安装
  • 适用场景：网页浏览，Web 开发

3. Remmina¶

  • 简介：远程桌面客户端
  • 亮点：支持多种协议，如 RDP、VNC、SSH
  • 安装方式：sudo apt install remmina
  • 适用场景：远程连接 Windows 或其他系统

4. FileZilla¶

  • 简介：FTP 客户端
  • 亮点：易用的界面，支持多种文件传输协议
  • 安装方式：sudo apt install filezilla
  • 适用场景：文件上传下载，网站管理

5. qBittorrent¶

  • 简介：BitTorrent 客户端
  • 亮点：轻量级，无广告，功能全面
  • 安装方式：sudo apt install qbittorrent
  • 适用场景：下载和分享大文件，开源内容

6. NordVPN¶

  • 简介：VPN 服务客户端
  • 亮点：保护隐私，加密连接
  • 安装方式：从官网下载安装脚本
  • 适用场景：隐私保护，访问地理限制内容

办公套件和文献工具，别被格式兼容绊住¶

1. LibreOffice¶

  • 简介：开源办公套件
  • 亮点：文档处理、电子表格、演示文稿等全套应用
  • 安装方式：Ubuntu 预装或 sudo apt install libreoffice
  • 适用场景：日常办公，文档处理

2. Evolution¶

  • 简介：邮件和日历客户端
  • 亮点：集成邮件、日历、任务和联系人
  • 安装方式：sudo apt install evolution
  • 适用场景：邮件管理，日程安排

3. Zotero¶

  • 简介：文献管理工具
  • 亮点：收集、组织、引用和分享研究资料
  • 安装方式：从官网下载或 sudo snap install zotero-snap
  • 适用场景：学术研究，论文写作

4. Nextcloud Desktop¶

  • 简介：Nextcloud 云存储客户端
  • 亮点：私有云同步，自托管的云存储替代品
  • 安装方式：从官网下载或通过 PPA
  • 适用场景：文件同步，自托管云服务

5. Calibre¶

  • 简介：电子书管理工具
  • 亮点：电子书转换、编辑、阅读，设备同步
  • 安装方式：sudo apt install calibre
  • 适用场景：电子书收藏管理，格式转换

游戏和美化属于可选项，按需挑一两个就够¶

1. Steam¶

  • 简介：游戏平台
  • 亮点：大量 Linux 兼容游戏，Proton 兼容层
  • 安装方式：sudo apt install steam
  • 适用场景：游戏，社区互动

2. Lutris¶

  • 简介：游戏管理平台
  • 亮点：简化 Wine 游戏安装，整合多个游戏平台
  • 安装方式：sudo apt install lutris
  • 适用场景：玩 Windows 游戏，管理游戏库

3. Spotify¶

  • 简介：音乐流媒体服务
  • 亮点：庞大的音乐库，个性化推荐
  • 安装方式：从官网安装或 sudo snap install spotify
  • 适用场景：音乐欣赏，播放列表创建

4. Discord¶

  • 简介：通讯软件
  • 亮点：游戏社区交流，语音聊天
  • 安装方式：从官网下载或 sudo snap install discord
  • 适用场景：游戏社交，团队沟通

5. GNOME Games¶

  • 简介：游戏管理与模拟器前端
  • 亮点：整合多种游戏模拟器，界面统一
  • 安装方式：sudo apt install gnome-games
  • 适用场景：怀旧游戏，模拟器管理

1. Conky¶

  • 简介：系统监视器小部件
  • 亮点：高度可定制的桌面小部件
  • 安装方式：sudo apt install conky
  • 适用场景：系统监控，桌面美化

2. Variety¶

  • 简介：自动壁纸更换器
  • 亮点：支持多个图片源，定时切换
  • 安装方式：sudo apt install variety
  • 适用场景：桌面美化，壁纸管理

3. Plank¶

  • 简介：简约 Dock 栏
  • 亮点：类似 macOS 的底部 Dock
  • 安装方式：sudo apt install plank
  • 适用场景：美化桌面，快速启动常用应用

4. Latte Dock¶

  • 简介：功能丰富的 Dock 栏
  • 亮点：高度可定制，动画流畅
  • 安装方式：sudo apt install latte-dock
  • 适用场景：KDE 桌面环境美化，工作效率提升

5. Albert¶

  • 简介：快速启动器
  • 亮点：类似 Alfred，支持插件扩展
  • 安装方式：从 PPA 安装
  • 适用场景：快速启动程序，提高工作效率

编程语言按项目选，不必全装¶

1. Node.js¶

  • 简介：JavaScript 运行环境
  • 亮点：构建网络应用的平台
  • 安装方式：sudo apt install nodejs npm
  • 适用场景：Web 开发，服务器应用

2. Python¶

  • 简介：编程语言
  • 亮点：易学易用，应用广泛
  • 安装方式：Ubuntu 预装或 sudo apt install python3 python3-pip
  • 适用场景：脚本编写，数据分析，Web 开发

3. Java¶

  • 简介：编程语言和运行环境
  • 亮点：跨平台，广泛应用
  • 安装方式：sudo apt install default-jdk
  • 适用场景：企业应用，跨平台开发

4. Go¶

  • 简介：编程语言
  • 亮点：高效、简单、可靠
  • 安装方式：sudo apt install golang
  • 适用场景：后端服务，系统工具开发

5. Rust¶

  • 简介：系统编程语言
  • 亮点：安全性、并发性和性能
  • 安装方式：通过 rustup 安装
  • 适用场景：系统编程，高性能应用
