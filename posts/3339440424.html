四、面试准备与学习路线¶

资源 地址 说明
JavaGuide 面试题 https://javaguide.cn/ 集合/并发/JVM/分布式八股权威
LeetCode https://leetcode.cn 算法刷题平台
CodeGym https://codegym.cc/zh 游戏化 Java 练习（支持中文）
tutorialspoint 在线编译 https://www.tutorialspoint.com/online_java_compiler.php 在线运行 Java

推荐学习路线（零基础 → 精通）：

  1. 基础（约 45 天）：韩顺平《零基础 30 天学会 Java》（B站）+ 廖雪峰教程 + 《Head First Java》。
  2. Java 8 现代特性：Lambda、Stream、新日期 API，配合《Java 8 实战》。
  3. 巩固基础：数据结构与算法（LeetCode）+ 计算机网络/操作系统。
  4. 进阶企业级：JavaGuide 主线 + advanced-java + Spring Boot/MySQL/Redis/分布式。
