42-实战：搭建Demo自动驾驶演示

发表于2026-10-25|apollo
|浏览量:

[!info] 本节目标
从零完成 Apollo 本地 Demo 自动驾驶演示：搭建 Docker 开发环境、编译源码、启动各核心模块，在 DreamView 中观察感知-规划-控制全链路数据流，并掌握演示过程的排查方法与进阶方向。

1. 实战目标

使用 Apollo 演示地图与仿真/回放数据，启动各模块，在 DreamView 中观察”感知框出现 → 轨迹生成 → 车辆沿轨迹行驶”的自动驾驶全过程。这是理解前述各篇（33-车道级导航与决策、36-高速场景 等）所讲机制的最好入手实验。

2. 准备环境

驱动 NVIDIA Driver 460+ 470+

3. 编译与启动

4. 运行演示

  1. 打开 DreamView：浏览器访问 http://localhost:8888
  2. 选择地图与车辆：左侧下拉选择演示地图（如 San Jose / 国内演示地图）与开发车辆配置
  3. 启动数据回放/仿真：播放预置 demo record，或使用 Sim Control 模式让车辆在仿真中行驶
  4. 设置目的地：在地图上右键选择目的地，触发 Routing
  5. 观察全链路：
观察对象 预期表现
感知框 障碍物（车辆/行人）被检测并跟踪
红绿灯 识别状态显示正确
规划轨迹 从车头延伸的平滑曲线，随环境实时更新
决策标签 跟车/变道/停车等决策文本
车辆位姿 沿轨迹平滑行驶，弯道减速

5. 结果验证清单

检查项 预期

轨迹 生成平滑、无越界、及时响应障碍
车辆 沿轨迹行驶、停车位置准确
DreamView 无报错弹窗，图层渲染正常

6. 常见问题与解决

现象 排查方向
容器启动失败 检查 Docker 与 NVIDIA Docker 安装、查看 docker logs
编译失败 磁盘空间不足 / 依赖缺失，重试 ./apollo.sh build
模块不启动 查看 launch 依赖顺序与模块日志
话题无数据 检查回放文件路径、驱动配置
规划无轨迹 检查地图与车辆配置是否匹配、Routing 是否下发
控制不执行 检查底盘/仿真模式配置

系统性排查方法论见 43-常见问题排查。

7. 进阶扩展方向

演示跑通后，按以下路径深入：

  1. 修改规划参数：调整速度限制、车距参数，观察轨迹与行为变化，体会参数-行为映射
  2. 构造自定义仿真场景：设计行人横穿、前车急刹等场景，验证决策逻辑
  3. 替换感知模型：更换检测模型对比效果，实践模型部署流程
  4. 接入真实传感器数据：录制实车数据后回放调试，体验数据闭环
  5. 开发自己的组件：按 Cyber RT 组件规范写一个简单模块，理解 DAG/launch 机制

[!note] 2026 年更新
演示环境的价值在于理解系统机制。工业界的最新进展（Apollo 10.0 的 ADFM 大模型与火焰图性能工具、11.0 的低速功能车场景）需要更大的数据与算力投入，但在 Demo 环境中依然可以演练其外围工具链——性能分析与数据回放的工作流与本篇一致。
