ssh 与 scp

[!abstract] 用途
ssh 通过加密通道远程登录服务器或执行命令；scp 基于 ssh 在本地与远程间传输文件；配合密钥认证可实现免密自动化。是 Linux 运维的核心入口。

[!note] 权限要求

8. 注意事项

  • 公钥可公开，私钥（id_ed25519）绝不可泄露；
  • 连接陌生主机出现 host key 警告时核对指纹，不要盲目信任；
  • 服务端修改 sshd_config 后先 ssh -t 测试再退出，避免锁死自己；
  • 大文件/大量文件优先 rsync（11-tar 与 zip 与 rsync），scp 适合单文件；
  • 公网服务器务必关闭密码登录，仅用密钥。
