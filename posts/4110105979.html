常见坑¶

  1. formatter 未安装：VS Code 提示”No formatter”，需装对应扩展。
  2. 多 formatter 冲突：同一语言必须唯一 defaultFormatter。
  3. IDE 配置不入库：个人配置覆盖团队配置，格式漂移。
  4. formatOnSave 与大型文件：极慢时改用 format on paste/save 手动。
  5. .editorconfig 与工具冲突：工具配置优先，editorconfig 为基础。

最佳实践¶

  • 把 .vscode/settings.json、.editorconfig 提交仓库，新成员零配置。
  • 配合 pre-commit 和 CI 形成”IDE 保存 + 提交钩子 + CI”三层防线。
