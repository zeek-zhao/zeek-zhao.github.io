变量与参数

[!info] 本页概览
本文详解 Shell 变量的分类（环境/局部/只读）、位置参数（$1/$@/$#）、特殊变量（$?/$$/$0）与参数展开的常用形式，是脚本接收外部输入的基础。

核心概念

  • 环境变量：export 后子进程可见（PATH、HOME）。
  • 局部变量：脚本内定义，子 shell 默认不可见。
  • 位置参数：$0 脚本名、$1-$9 第 N 个参数、$# 参数个数。
  • **$@ / $***：全部参数；”$@” 每个参数独立引号，推荐使用。

常见坑

  1. $@ 不加引号：参数含空格会拆分，统一 "$@"。
  2. $10 误解：第 10 个参数要用 ${10}，$10 是 $1 + 字符串 0。
  3. export 后修改：export 后修改变量值会同步影响子进程环境（按值拷贝，子进程改不影响父）。
  4. $* 与 $@ 区别：未加引号相同；"$*" 合成一个字符串，"$@" 保持独立。
  5. 变量名大小写：Shell 区分大小写，$HOME 与 $home 不同。
  6. 环境变量注入风险：信任输入（如 PATH、LD_PRELOAD 被恶意设置），脚本内设置关键变量时覆盖为受控值。

最佳实践

  • 所有外部输入（位置参数、环境变量）用 ${var:-default} 给默认值并校验。
  • 处理参数用 while [ $# -gt 0 ]; do ...; shift; done 或 getopts（15-系统管理脚本）。
  • 字符串展开统一加引号："$@"、"$var"。
  • 脚本顶部集中定义可配置项，注释说明含义与范围。
  • 敏感信息（密码/token）绝不写入脚本，用环境变量或 vault。
