rviz 可视化

[!info] 本节目标
掌握 rviz 的基本操作、常用 Display 插件（TF、LaserScan、Image、Marker）与配置保存，能用 rviz 诊断机器人状态。

1. rviz 是什么

rviz（ROS Visualization）是 ROS1 的3D 可视化工具，用于显示机器人模型、传感器数据、TF 坐标、路径规划等，是 ROS 开发中最常用的调试界面。

[!note] 与 Gazebo 区别
rviz 只负责”看”（数据可视化），Gazebo 负责”仿真物理世界”（见 15-Gazebo仿真）。

2. 界面布局

常用快捷键：W 平移视角、R 缩放、鼠标右键旋转。

3. 常用 Display 插件

Display 作用 对应话题
RobotModel 显示 URDF 模型 /robot_description
TF 显示坐标轴 /tf
LaserScan 显示激光点云 /scan
PointCloud2 显示点云 /points
Image 显示图像 /image_raw
Camera 相机视图 /image_raw + /camera_info
Marker/MarkerArray 显示标记 /visualization_marker
Path 显示路径 /plan
Odometry 显示里程计 /odom
Grid 网格/代价地图 -

[!tip] 添加显示
点击左下角 Add 按钮，选择 Display 类型与话题；也可以直接输入话题名自动匹配。

4. 显示激光数据

rviz 设置建议：

[!warning] Fixed Frame
Fixed Frame 必须存在且已有 TF 到该 frame，否则显示 “Fixed Frame [xxx] does not exist”。

5. 显示图像

[!tip] Camera 与 Image
Camera 插件需要 image+camera_info（可叠加 3D 数据）；只看图像用 Image 插件即可。

6. 使用 Marker 显示自定义标记

[!note] Marker 类型
支持 ARROW、CUBE、SPHERE、CYLINDER、TEXT_VIEW_FACING 等，常用于可视化导航目标点、障碍物、调试输出。

7. 3D 视图与相机控制

8. 保存与加载配置

[!tip] 配置管理
把常用的 rviz 配置放入包内 rviz/ 目录，团队共享，避免每次重新添加 Display。

9. 常见问题排查

问题 原因/解决
Fixed Frame does not exist TF 未发布或 frame 名拼错
激光无数据 话题未发布、类型不匹配
显示延迟 数据频率高/带宽大，降低更新频率
模型不显示 /robot_description 参数未加载
图像花屏 编码格式问题，选 raw 或压缩话题

[!tip] 高效调试习惯
同时打开 rqt_graph（看通信拓扑）+ rqt_console（看日志）+ rviz（看数据），形成”拓扑-日志-数据”三位一体调试法。

导航中 rviz 显示代价地图、路径、AMCL 粒子见 21-导航框架move_base；传感器数据显示见 19-常用传感器驱动。
