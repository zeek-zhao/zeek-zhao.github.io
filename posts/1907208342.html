函数

[!info] 本页概览
本文讲解 Shell 函数：定义与调用、参数传递（$1/$@/$#）、返回值（$? / echo）、局部变量 local、作用域与常用函数库组织。

核心概念

  • 函数是”命令组”的复用单元，定义后即可像命令一样调用。
  • 参数在函数内仍通过 $1/$2/$@ 获取（覆盖全局位置参数）。
  • return 只能返回 0-255 整数状态码；返回值数据用 echo + 命令替换捕获。
  • local 声明局部变量，避免污染全局。

常见坑

  1. 函数名前不能有空格：greet () { 与 greet(){ 均可，但 greet { 错误。
  2. return 与 echo 混用：return 会立即结束并设置状态码；echo 的数据若在 return 后不会输出。
  3. 局部变量忘加 local：函数内变量默认全局，可能意外覆盖。
  4. 返回值 >255：return 300 会截断，用 echo 返回大数。
  5. 命令替换丢换行：$(...) 会去掉尾部换行；多值用 read + 进程替换。
  6. 递归深度：函数递归过多消耗内存，深递归用迭代。

最佳实践

  • 函数名小写+下划线；加 local 声明所有内部变量。
  • 单一职责：一个函数做一件事，返回明确状态码。
  • 数据返回用 echo，状态用 return，二选一清晰表达。
  • 通用函数独立成库文件，source 复用（见 20-函数库与模块化）。
  • 函数内参数校验：-n "$1" || { echo "缺参"; return 1; }。
