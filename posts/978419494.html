类与对象

[!info] 本页概览
类是 C++ 面向对象编程的核心：封装数据与行为。本文讲解类定义、访问控制、构造函数、析构函数、继承与多态（虚函数）。

核心概念

  • 封装：把数据（成员变量）与操作（成员函数）绑定，用 private 隐藏内部细节。
  • 构造/析构：对象创建时调用构造函数初始化，销毁时调用析构函数释放资源（RAII 基础）。
  • 继承：子类复用父类接口与实现，形成 is-a 关系。
  • 多态：虚函数 + 基类指针/引用，运行时动态分派到正确实现。

特殊成员函数

C++ 自动生成：默认构造、析构、拷贝构造、拷贝赋值、移动构造、移动赋值。有自定义构造函数/析构/资源时，通常需要同时考虑拷贝与移动语义（Rule of Five）。

常见坑

  1. 多态基类析构不是虚函数：delete 基类指针时只调用基类析构，子类资源泄漏。
  2. 构造函数中调用虚函数：构造期间虚函数分派到当前构造阶段类型，而非最终子类。
  3. 切片（slicing）：按值传基类对象会丢失子类部分，多态必须用指针/引用。
  4. 忘记初始化成员：构造列表遗漏成员，成员被默认构造；引用/const 成员必须在初始化列表中初始化。
  5. const 成员函数：不改成员的方法应标 const，否则 const 对象无法调用。

最佳实践

  • 默认 private，对外只暴露必要接口；数据成员尽量 private。
  • 用初始化列表而非构造函数体内赋值。
  • 多态接口基类加虚析构；非多态类不要虚析构（浪费 vtable）。
  • 优先组合而非继承（has-a 优于 is-a），仅在真正的多态场景使用继承。
