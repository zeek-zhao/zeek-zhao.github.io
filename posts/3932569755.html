组件基础

[!info] 本页概览
本文讲解 Vue 组件核心：组件定义与注册、props 传参、emits 事件、组件命名、单文件组件规范，以及组件设计的关注点。

核心概念

  • 组件：可复用的 UI + 逻辑单元，通过 props 接收数据、emits 发出事件。
  • 单文件组件（SFC）：.vue 一个文件封装 template/script/style。
  • 单向数据流：父传子（props），子传父（emit 事件），禁止子组件直接改 props。
  • 组件名推荐 PascalCase；使用 kebab-case 或 PascalCase 均可。

常见坑

  1. props 被直接修改：违反单向数据流；用 emit 或 v-model 更新。
  2. 默认值为对象/数组：必须用工厂函数 default: () => []，共享引用导致互相污染。
  3. 事件命名大小写：模板监听 @my-event，emit 'my-event'；PascalCase 需注意 HTML 大小写不敏感。
  4. 组件名与原生标签冲突：避免 button/input 等；规范前缀（AppButton）。
  5. defineProps 解构：直接解构会失去响应性，用 props.xxx 或 toRefs。
  6. <script setup> 中组件自动注册：import 即可用，无需 components 选项。

最佳实践

  • 组件单一职责：一个组件一个清晰的展示/交互目标。
  • props 用对象式定义，带类型、默认值与校验。
  • 数据流清晰：props 下传、事件上抛、状态管理共享（见 09-状态管理Pinia）。
  • 通用组件（按钮、卡片、弹窗）放 components/ui 目录。
  • 组件 API 稳定：避免频繁改 props 名称，用语义化命名。
