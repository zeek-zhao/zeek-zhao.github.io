winget

[!abstract] 用途
winget（Windows Package Manager）是微软官方命令行包管理器，可从仓库安装、卸载、更新软件，支持批量与静默安装，适合初始化环境与自动化部署。

1. 安装与更新

2. 常用命令

3. 常用参数

参数 作用
-e / --exact 精确匹配 ID
--id / --name 按 ID / 名称安装
-s / --source 指定源（winget / msstore）
--scope user/machine 安装作用域
--silent 静默安装
-h / --silent 同静默
--accept-* 跳过协议提示

4. 批量初始化环境

5. 配置文件（winget configure）

6. 注意事项

  • 部分软件安装器需要管理员权限，建议管理员终端运行；
  • winget upgrade --all 更新前留意软件兼容性，重要软件单独更新；
  • 使用 --source msstore 时部分应用需登录微软账号；
  • 仓库中的版本以发布者维护为准，个别软件可能缺失或滞后。
