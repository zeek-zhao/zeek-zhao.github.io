Docker Swarm集群部署与实战

Docker Compose 负责在单机上创建多个容器，而 Docker Swarm 负责在多台服务器上创建容器集群服务，更适合微服务的部署。我的理解是：Compose 解决「一台机器跑多个容器」，Swarm 解决「多台机器当一个资源池用」，两者不是替代关系。

环境与端口前置条件要先满足¶

准备两台机器，一台作为 manager、一台作为 worker：

机器 说明
192.168.101.90 node1
192.168.101.22 node2

Docker 安装的步骤见 02-Docker安装与卸载.md。

Swarm 通过监听 2375 端口进行通信，远程连接配置见 10-Docker配置远程连接2375端口.md。

集群通信还要求防火墙放开以下端口，或者直接关掉防火墙：

  • TCP端口2377，用于集群管理通信；
  • TCP和UDP端口7946，用于节点之间通信；
  • UDP端口4789，用于覆盖网络。

初始化集群时用 advertise-addr 指定通告地址¶

初始化命令里的 advertise-addr 参数表示其它 swarm 中的 worker 节点使用这个 IP 地址与 manager 联系，命令输出会包含其它节点加入集群的命令。初始化后记得把 manager 和 worker 的 token 都记下来。
