36-常见问题排查

发表于2026-10-24|ros2

常见问题排查

[!info] 本节目标
掌握 ROS2 常见问题诊断方法、常用排查命令与解决套路。

1. 排查思路

工具 用途
ros2 doctor 综合诊断
ros2 node list / info 发现与连接
ros2 topic list / info -v 话题状态
ros2 service list 服务状态
ros2 daemon stop/start 守护进程重置

[!tip] 万能三连
遇到问题先跑：ros2 doctor、ros2 node list、ros2 topic info -v <topic>，多数问题可见端倪。

2. 环境与启动问题

错误 原因 解决
command not found 未 source source /opt/ros/humble/setup.bash
Package ‘x’ not found 未安装 sudo apt install ros-humble-x
resource not found 未 source install source install/setup.bash
daemon 过期 缓存 ros2 daemon stop

[!warning] 多版本共存
多发行版 source 会串；每终端只 source 一个发行版。

3. 发现与通信问题

现象 排查
节点互相看不到 ROS_DOMAIN_ID、网络、防火墙、DDS
话题无数据 QoS 不匹配、发布频率低
收到乱码/类型错 消息类型不匹配
服务超时 服务未启动、跨域

[!tip] QoS 兼容
ros2 topic info -v 明确显示发布/订阅 QoS；Reliability/Durability 不匹配最常见（见 33-实时性与QoS策略）。

4. 编译构建问题

错误 原因 解决
CMake Error 缺依赖 rosdep 安装
fatal error: x.hpp 找不到 头文件/依赖路径 检查 find_package
link error 库缺失 find_package + 链接
colcon 找不到包 未 source install source install/setup.bash
编译超时 资源不足 增量、Release、限任务

[!warning] rosdep
新工作空间首次 rosdep install 很关键；离线环境需本地 rosdep 源。

5. 运行时问题

现象 排查
节点崩溃 日志、core dump、GDB
CPU 100% 死循环、日志爆炸
内存增长 队列积压、泄漏
卡死 死锁、单线程阻塞

[!tip] 回调阻塞
单线程 Executor 里一个耗时回调会拖死所有回调；用回调组/多线程（见 14-执行器与回调组）。

6. 仿真与 TF 问题

现象 排查
TF 不存在 是否发布、frame_id 拼写
坐标跳变 时间戳、TF 树冲突
仿真卡 物理引擎、步长、负载
无 map map_server、yaml 路径

[!warning] frame_id
frame_id 必须精确匹配（大小写/下划线）；tf2_echo 是快速验证手段。

7. 常见问答

[!note] 延伸
系统化日志调试见 20-日志与调试工具；性能问题见 35-性能优化与Benchmark；安全相关见 34-安全与权限。

8. 排障案例复盘

排障能力来自案例沉淀，建议团队建立问题台账：记录现象、环境、根因与解决方案，供新成员检索。典型复盘案例：现象为节点间偶发断连，根因是 QoS 不匹配或网络波动；现象为启动即崩溃，根因多为依赖缺失或环境变量未加载；现象为定位漂移，根因是里程计标定误差。每个案例尽量补一条命令行或检查步骤，形成可执行的知识。遇到未知问题先复现最小场景，再逐步扩大定位范围。

[!note] 建议
排障是开发日常，系统化方法论比零散经验更有效；配合日志与调试工具见 20-日志与调试工具。
