clang-format：C 与 C++ 格式化

[!info] 本页概览
本文讲解 clang-format 的使用：安装、.clang-format 配置、常用风格（LLVM/Google）、常用选项、命令行操作与 IDE 集成，配真实配置示例。

核心概念

  • clang-format：基于 LLVM clang 的 C/C++/Obj-C 格式化工具。
  • 风格预设：LLVM（默认）、Google、Chromium、Mozilla、WebKit。
  • .clang-format：仓库根目录的 YAML 配置文件，团队统一入口。
  • 幂等：格式化结果再次执行不变。

常见坑

  1. 本地与 CI 版本不一致：统一 clang-format 版本（GitHub Action 固定 tag）。
  2. 旧代码全量格式化 diff 巨大：存量代码单独一次”格式化提交”。
  3. 宏与模板格式乱：宏内格式化受限，可用 // clang-format off 局部关闭。
  4. 配置不落库：.clang-format 必须提交进仓库并设为唯一来源。
  5. ColumnLimit 过窄：深层嵌套代码行拆太碎，按团队共识设 100-120。

最佳实践

  • 采用 Google 风格 + 少量团队覆盖项（如 IndentWidth: 4）。
  • CI 中 clang-format –dry-run –Werror 强制检查。
  • 配合 Google C++ Style 规范代码。
