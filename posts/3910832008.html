MySQL 安装与配置

[!info] 本页概览
本文讲解 MySQL 的安装（Windows/Linux/Docker）、初始化与配置文件 my.cnf、服务管理、客户端连接、字符集与基础安全配置，配可运行命令。

核心概念

  • MySQL：最流行的开源关系型数据库，InnoDB 为默认存储引擎。
  • 端口：默认 3306。
  • 配置文件：Linux 为 /etc/my.cnf，Windows 为 my.ini；按 [mysqld]/[client] 分段。
  • root 用户：安装后默认无密码（需初始化），务必尽快设置强密码。

innodb_buffer_pool_size 是 MySQL 性能关键参数，取物理内存 50%-70% 是常见经验值；修改后需重启服务。

安全基础配置

[!warning] root 远程登录
生产环境禁用 root 远程登录；业务使用最小权限账号，仅开放必要主机。

常见坑

  1. 初始化失败：数据目录权限、依赖库缺失（Linux 需 libaio）。
  2. 端口占用：3306 被其他程序占用，netstat -ano 排查。
  3. 忘记密码：mysqld –skip-grant-tables 临时绕过（禁远程）。
  4. 字符集仍是 latin1：只改库不改连接，客户端加 –default-character-set=utf8mb4。
  5. max_connections 过小：连接数打满报 Too many connections。

最佳实践

  • 生产环境关闭 root 远程、限制 bind-address。
  • 配置文件统一管理（ansible/脚本），禁止手工零散改。
  • 定期检查磁盘空间与日志大小（binlog/慢查询）。
  • 结合 03-MySQL 常用操作 开始建库建表实战。
