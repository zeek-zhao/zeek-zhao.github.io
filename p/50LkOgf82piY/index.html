1. SonarQube 简介

SonarQube 是一个开源的代码质量管理平台，旨在通过持续检查代码质量来帮助开发团队编写更优质的代码。它可以自动分析源代码以检测错误、代码气味和安全漏洞，提供可视化的报告，并跟踪质量问题的演变趋势。

1.1 SonarQube 核心功能

1.2 SonarQube 的优势

  1. 全面的代码质量分析：检测各种代码问题，包括代码错误、漏洞、代码气味、重复代码等
  2. 开发过程早期发现问题：在CI/CD流水线早期检测问题，降低修复成本
  3. 多语言支持：支持超过25种编程语言
  4. DevOps集成：与常见CI/CD工具无缝集成
  5. 质量门禁：通过定义质量门禁，确保代码质量满足最低标准
  6. 可视化报告：提供直观的图表和报告，便于团队理解和监控项目质量
  7. 可扩展性：支持插件和自定义规则开发

4.2 质量门禁

质量门禁（Quality Gate）定义了代码必须满足的质量条件集合。如果代码不满足这些条件，可以在CI/CD流水线中阻止部署。

flowchart TD
    A[代码推送] --> B[代码分析]
    B --> C{质量门禁检查}
    C -->|通过| D[继续部署流程]
    C -->|失败| E[阻止部署]
    E --> F[修复问题]
    F --> A

    subgraph 质量门禁条件
    G[代码覆盖率 >= 80%]
    H[重复代码 < 5%]
    I[严重问题 = 0]
    J[技术债务率 < 5%]
    end

    C --- 质量门禁条件

    style C fill:#bbf,stroke:#333,stroke-width:2px

4.2.1 配置质量门禁

  1. 导航至 质量门禁 页面
  2. 创建新的质量门禁或编辑默认的质量门禁
  3. 添加条件，例如：
    • 代码覆盖率必须大于80%
    • 重复代码块必须小于5%
    • 不允许有任何严重漏洞
    • 技术债务比率必须小于5%
  4. 将质量门禁应用于项目

4.2.2 质量门禁条件示例

度量 运算符 值 严重性
新增代码覆盖率 小于 80% ERROR
新增重复行 大于 3% ERROR
可靠性等级 差于 A ERROR
安全等级 差于 A ERROR
可维护性等级 差于 A WARN

6.2 问题浏览与筛选

SonarQube可以检测到不同类型的问题：

  1. Bug：代码中的潜在错误，可能导致程序崩溃或不正确的行为
  2. 漏洞：安全隐患，可能被攻击者利用
  3. 代码气味：维护性问题，使代码难以理解和修改

11.2 SonarQube术语表

术语 描述
质量配置文件 定义代码分析规则集合的配置
质量门禁 决定项目是否通过质量检查的条件集合
问题 代码中检测到的缺陷、漏洞或代码气味
技术债务 反映修复所有代码气味所需的时间
SQALE 软件质量评估和估计方法
覆盖率 代码被测试覆盖的程度
复杂度 衡量代码复杂程度的指标
重复度 代码库中重复代码的比例
热点 需要特别关注的问题集中区域
漏洞 可能导致安全问题的代码
规则 用于分析代码的模式检测器
