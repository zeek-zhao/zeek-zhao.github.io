结构体与联合体

[!info] 本页概览
结构体（struct）把不同类型的数据聚合为一个整体；联合体（union）让多个成员共享同一块内存；枚举（enum）定义命名常量。本文讲解定义、访问、内存布局与常见陷阱。

核心概念

  • struct：成员依次排列（可能有填充字节），每个成员独立占内存。
  • union：所有成员共享起始地址，同一时刻只存一个成员，大小为最大成员的大小。
  • enum：整数常量的集合，底层类型默认 int。

常见坑

  1. 结构体对齐与填充：成员之间可能有 padding，sizeof(struct) 通常大于成员大小之和。跨网络传输或写文件时不要直接 dump 结构体。
  2. union 成员覆盖：写入一个成员后再读另一个成员，除共用内存场景外是未定义行为（C++ 中更严格，读取非活跃成员是 UB）。
  3. 结构体浅拷贝：包含指针成员时，= 复制的是指针值而非指向的数据，两份结构体共享同一块内存，容易双重释放。
  4. typedef 与匿名结构体：typedef struct { ... } Name; 后可直接用 Name 声明变量，但无法再递归引用自己（链表节点需用具名结构体）。

最佳实践

  • 结构体传参时用指针或引用避免整体拷贝开销；只读时加 const。
  • C++ 中 struct 与 class 几乎等价（默认访问权限不同），小聚合对象用 struct。
  • 跨平台序列化结构体时使用 #pragma pack 或逐字段显式编码，避免对齐差异。
  • 枚举加 typedef enum（C）或直接 enum class（C++11），enum class 更强类型、不隐式转 int。
