Tmux 用户指南

Tmux 解决的是远程终端里最现实的问题：SSH 一断，前台跑的任务还在不在。我的判断是，只要是长时间在服务器上工作，先把会话放进 Tmux 再启动任务，比事后补救省心得多；下面把安装、概念、快捷键、配置和排障一次讲清。

Tmux 让一个终端窗口承载多个可持久化的会话¶

Tmux是一个终端复用器（terminal multiplexer），它允许用户在单个终端窗口中同时运行和管理多个终端会话。Tmux最大的优势是可以保持会话连接，即使网络断开或SSH连接中断，会话仍然在服务器上运行。

会话、窗口、窗格是三级组织结构¶

Tmux有三个主要概念：

  • 会话(Session): 一组窗口的集合，通常与一个特定任务关联
  • 窗口(Window): 相当于标签页，可以包含多个窗格
  • 窗格(Pane): 一个窗口内的分割区域，每个窗格运行一个独立的Shell

会话管理命令、前缀键和三类快捷键构成日常操作¶

会话管理¶

命令 描述
tmux new -s session_name 创建新会话并命名
tmux ls 列出所有会话
tmux attach -t session_name 连接到指定会话
tmux kill-session -t session_name 关闭指定会话
tmux rename-session -t old_name new_name 重命名会话
tmux detach 或 前缀键 + d 分离当前会话
tmux switch -t session_name 切换到指定会话

前缀键¶

Tmux的所有快捷键都以前缀键开始，默认是 Ctrl+b。以下快捷键都需要先按前缀键，再按对应的键。

窗口操作¶

快捷键 描述
c 创建新窗口
& 关闭当前窗口
, 重命名当前窗口
p 切换到上一个窗口
n 切换到下一个窗口
0-9 切换到指定编号的窗口
w 列出所有窗口供选择
f 在所有窗口中查找内容
. 修改当前窗口的编号
' 通过编号选择窗口

窗格操作¶

快捷键 描述
% 垂直分割窗格
" 水平分割窗格
x 关闭当前窗格
o 切换到下一个窗格
↑↓←→ 切换到上/下/左/右窗格
Ctrl+↑↓←→ 调整窗格大小
z 最大化/还原当前窗格
{ 将当前窗格向前移动
} 将当前窗格向后移动
! 将当前窗格变成新窗口
q 显示窗格编号
Alt+1,2,3... 切换到对应编号的窗格
space 循环切换窗格布局

复制模式¶

快捷键 描述
[ 进入复制模式
Space 开始选择
Enter 复制选中内容
] 粘贴
q 退出复制模式
/ 在复制模式中搜索
n 移动到下一个搜索结果
N 移动到上一个搜索结果

总结¶

Tmux是一个强大的终端复用工具，掌握它可以显著提高命令行工作效率。通过会话、窗口和窗格的概念，你可以在单个终端窗口中组织和管理多个任务，而不需要打开多个终端。而且即使网络连接中断，你的工作也不会丢失。结合本指南中的配置和插件，你可以打造一个更加高效、美观且功能丰富的终端环境。
