Vim 使用指南

Vim 是 Vi 的改进版，设计理念就是”编辑效率”：靠模式和快捷键组合完成文本操作，而不是靠鼠标。我把最常用的命令按场景收在一起，卡住时先按 ESC 回普通模式，再想下一步。

先分清三种模式，卡住就按 ESC 回普通模式¶

Vim 有三种基本模式，各个模式侧重点不一样：

  1. 普通模式（Normal Mode）：默认模式，用于导航和操作文本（光标移动、复制、粘贴、删除）
  2. 插入模式（Insert Mode）：用于输入文本（编辑文本）
  3. 命令模式（Command Mode）：用于执行命令（查找和替换、保存退出等）

此外还有：
4. 可视模式（Visual Mode）：用于选择文本块（文本选择）

当不知道处于何种模式时，按 ESC 键返回到普通模式。

启动、保存、退出这些动作先练熟¶

启动 Vim¶

文件的打开、新建和保存¶

  • vim 文件名 - 如果文件存在则打开，不存在则创建
  • :w - 保存文件
  • :q - 退出（如有未保存修改则无法退出）
  • :wq 或 :x - 保存并退出
  • :q! - 强制退出，不保存修改
  • ZZ - 保存并退出

模式切换¶

  • 进入插入模式：

    • i - 在光标处插入
    • a - 在光标后插入
    • o - 在当前行后插入新行
    • O - 在当前行前插入新行

  • 返回普通模式：按 Esc 键

  • 进入命令模式：在普通模式下按 :

  • 进入可视模式：

    • v - 字符选择
    • V - 行选择
    • Ctrl+v - 块选择

移动光标是效率的地基，建议先用 h/j/k/l¶

移动光标（普通模式）¶

基本移动

  • h - 左移
  • j - 下移
  • k - 上移
  • l - 右移

单词间移动

  • w - 移至下一个单词词首
  • e - 移至当前单词词尾
  • b - 移至上一个单词词首

行内移动

  • 0 - 移至行首（第一个字符）
  • ^ - 移至该行的第一个非空白字符
  • $ - 移至行尾

文件内移动

  • gg - 移至文件开头
  • G - 移至文件末尾
  • :n 或 nG - 跳转到第 n 行
  • H - 移至屏幕顶部
  • M - 移至屏幕中间
  • L - 移至屏幕底部
  • Ctrl+f - 向下翻页
  • Ctrl+b - 向上翻页
  • Ctrl+d - 向下翻半页
  • Ctrl+u - 向上翻半页

增删改查都有成对的命令，记组合比记单键划算¶

编辑操作¶

插入文本

  • i - 在光标处插入
  • a - 在光标后插入
  • o - 在当前行后插入新行
  • O - 在当前行前插入新行

删除文本

  • x - 删除光标处字符
  • X - 删除光标前字符
  • dd - 删除当前行
  • ndd - 删除当前行及后面的n-1行
  • D - 删除光标到行尾的内容
  • d$ - 删除光标到行尾
  • d0 - 删除光标到行首
  • dw - 删除光标到下一个单词开头
  • db - 删除光标到前一个单词开头
  • diw - 删除整个单词（不含空格）
  • daw - 删除整个单词（含空格）

修改文本

  • r - 替换当前字符
  • R - 进入替换模式
  • s - 删除当前字符并进入插入模式
  • S - 删除当前行并进入插入模式
  • cc - 修改整行（删除当前行并进入插入模式）
  • c$ 或 C - 修改到行尾
  • cw - 修改一个单词

复制粘贴

  • yy - 复制当前行
  • nyy - 复制当前行开始的n行
  • y$ - 复制到行尾
  • yw - 复制一个单词
  • p - 在光标后粘贴
  • P - 在光标前粘贴

撤销与重做

  • u - 撤销上一步操作
  • Ctrl+r - 重做被撤销的操作

文本选择（可视模式）¶

  • v - 进入字符选择模式
  • V - 进入行选择模式
  • Ctrl+v - 进入块选择模式
  • 选择后可以用 d、y、c 等命令操作选中的文本
  • ggVG - 选中整个文件内容

搜索替换用 :%s，批量改前先加 c 确认¶

  • /pattern - 向前搜索指定模式
  • ?pattern - 向后搜索指定模式
  • n - 下一个匹配
  • N - 上一个匹配
  • * - 向前搜索当前光标所在的单词
  • # - 向后搜索当前光标所在的单词
  • :%s/old/new/g - 全文替换所有 old 为 new
  • :%s/old/new/gc - 全文替换所有 old 为 new，但每次替换前询问确认
  • :n1,n2s/old/new/g - 替换从 n1 到 n2 行中所有 old 为 new

多文件和多窗口靠缓冲区、分屏、标签页撑起来¶

多文件操作¶

多文件编辑

  • :e 文件名 - 编辑另一个文件
  • :bn - 切换到下一个缓冲区
  • :bp - 切换到上一个缓冲区
  • :bd - 关闭当前缓冲区
  • :args - 显示当前正在编辑的文件列表
  • :next 或 :n - 切换到下一个文件
  • :prev 或 :N - 切换到上一个文件
  • :first - 切换到第一个文件
  • :last - 切换到最后一个文件
  • Ctrl+^ - 在两个最近使用的文件之间快速切换

窗口操作

  • :split 文件名 或 :sp 文件名 - 水平分割窗口打开文件
  • :vsplit 文件名 或 :vsp 文件名 - 垂直分割窗口打开文件
  • :new - 水平分割出一新窗口
  • :vnew - 垂直分割出一个新窗口
  • Ctrl+w h/j/k/l - 在窗口间移动光标
  • Ctrl+w w - 循环切换窗口
  • Ctrl+w c - 关闭当前窗口
  • :close - 关闭当前窗口
  • :only - 关闭除当前窗口外的所有窗口

标签页

  • :tabnew 文件名 - 在新标签页中打开文件
  • :tabe 文件名 - 在新标签页中编辑文件
  • gt - 移动到下一个标签页
  • gT - 移动到上一个标签页
  • :tabclose - 关闭当前标签页
  • :tabonly - 关闭除当前标签页外的所有标签页

标记、宏、缩进和折叠，是重复劳动的省力开关¶

高级特性¶

标记

  • ma - 在当前位置创建名为a的标记（a可以是任意字母）
  • `a - 跳转到标记a的位置
  • 'a - 跳转到标记a所在行的行首
  • :marks - 列出所有标记
  • :delm a - 删除标记a
  • :delm! - 删除所有标记

宏录制

  • qa - 开始录制宏到寄存器a（a可以是任意字母）
  • q - 结束录制
  • @a - 执行寄存器a中的宏
  • @@ - 重复执行上一次执行的宏
  • 10@a - 执行宏a 10次

代码缩进与格式化

  • >> - 向右缩进当前行
  • << - 向左缩进当前行
  • == - 自动缩进当前行
  • n== - 自动缩进n行
  • gg=G - 自动缩进整个文件

折叠

  • zf - 创建折叠
  • zo - 打开折叠
  • zc - 关闭折叠
  • zR - 打开所有折叠
  • zM - 关闭所有折叠

块编辑和重复操作是真正拉开差距的地方¶

实用技巧¶

  1. 块编辑：

    • 使用 Ctrl+v 进入块选择模式
    • 选择要编辑的列块
    • 按 I 进入插入模式，输入内容
    • 按 Esc 使更改应用到所有选中行

  2. 复制到系统剪贴板：

    • "+y - 复制到系统剪贴板
    • "+p - 从系统剪贴板粘贴

  3. 快速移动：

    • fx - 向后查找并跳转到字符x
    • Fx - 向前查找并跳转到字符x
    • tx - 向后查找并跳转到字符x之前
    • Tx - 向前查找并跳转到字符x之后
    • ; - 重复上一次f/F/t/T命令
    • , - 反方向重复上一次f/F/t/T命令

  4. 快速替换：

    • 把光标置于单词上，按 cw 替换单词
    • 使用 ciw 替换整个单词，不管光标在单词何处

  5. 重复操作：

    • . - 重复上一次编辑操作

  6. 高效行操作：

    • J - 将下一行合并到当前行
    • xp - 交换当前字符与后一个字符的位置

  7. 查看文件状态：

    • Ctrl+g - 显示当前文件信息（文件名、行号、总行数等）

命令组合值得单独记，比逐条敲快得多¶

  1. 删除当前行到文件末尾：dG
  2. 删除当前行到文件开头：dgg
  3. 删除括号内的内容：di( 或 di{ 或 di"
  4. 复制当前段落：yap
  5. 格式化当前段落：gqap
  6. 修改当前单词并继续输入：ciw

卡住时先查这几种情况¶

  • 运行 vimtutor 命令可以开始一个交互式 Vim 教程

  • 使用 :help 命令查看内置帮助文档（例如：:help motion）

  • 官方文档：https://www.vim.org/docs.php

  • 如果不小心按了 Ctrl+s 导致终端冻结，可以按 Ctrl+q 恢复

  • 如果 Vim 崩溃，可以通过 .swp 文件恢复未保存的更改（使用 vim -r 文件名）

  • 使用 :set paste 在粘贴代码时保持原有格式，粘贴后使用 :set nopaste 恢复

  • 如果不知道当前处于什么模式，连按两次 Esc 确保回到普通模式

  • 显示隐藏字符（如制表符、换行符）：:set list

  • 隐藏这些字符：:set nolist

我的判断是：先把移动、删除、撤销这三组练到不用想，再去碰宏和分屏；vimtutor 跑一遍比收藏十篇速查表有用。
