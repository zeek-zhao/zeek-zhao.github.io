仓库类型详解

[!abstract] 三类仓库，一个心智模型
proxy（代理） 缓存外部源；hosted（托管） 存私有制品；group（组） 聚合成统一入口。

1. 三类仓库对比

类型 行为 用途
proxy 按需拉取外部源并缓存 中央仓库、Docker Hub、registry
hosted 只存本地，不可外联 公司私有组件、内部镜像
group 聚合多仓库，对外一个 URL 客户端唯一入口

2. proxy 仓库配置要点

参数 建议
Auto blocking 开启，外部源故障自动标记
Maximum component age 一般不动（除非需要强制刷新）
Negative cache TTL 避免 404 频繁重试

[!note] 强制刷新缓存
proxy 仓库勾选”Expire cache”或调小 Maximum age 可强制重新拉取。

3. hosted 仓库配置要点

参数 建议
Version policy Release / Snapshot（Maven）；其他格式无此项
Deployment policy 默认 Disable redeploy（防覆盖）
写入认证 必须登录，禁止匿名上传

4. group 仓库配置要点

  • 组内顺序 = 查找顺序（先本地后代理）；
  • 客户端只配 group URL，内部路由透明；
  • group 可嵌套（组套组，慎用）。

5. 按格式命名规范

6. 内容选择器与策略

  • Content Selector：按路径正则控制权限（09-权限与匿名访问）；
  • Cleanup Policy：按年龄/大小自动清理（10-Cleanup与任务调度）。

[!warning] 注意

  • proxy 指向外部源必须双向可达（外网或内网源）；
  • group 加新仓库前先验证成员仓库健康；
  • 仓库一旦创建，格式不可改，命名想清楚。
