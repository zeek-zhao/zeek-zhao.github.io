Excalidraw与图表可视化

[!abstract] 一句话
思考需要画图，数据需要画图，结构也需要画图——Excalidraw、Charts 与 Mindmap Nextgen 分别覆盖手绘白板、数据图表和思维导图三类可视化需求，让笔记从线性文本升级为多维表达。

Excalidraw：知识库里的手绘白板

Excalidraw 把风靡设计圈的手绘风格白板搬进了 Obsidian。安装后通过命令面板 “Excalidraw: Create new” 新建画布，即可使用矩形、圆形、箭头、文本等工具自由绘制流程图、示意图和概念草图。

核心操作：

  • 导航：拖动平移画布，滚轮缩放；”Fit to screen” 一键回到全景
  • 编辑：双击元素进入编辑，F2 快速改名，Delete 删除；删除父元素会连带子元素
  • 连接线：用连接工具把元素连起来，拖动元素时连线自动跟随
  • 导出：支持 PNG/SVG/PDF，可设置背景、边框与分辨率

Excalidraw 最大的特点是与笔记双向打通：可以在画布中嵌入 笔记链接 并点击跳转，也可以把画布作为元素嵌入普通笔记；反过来，选中文本右键 “Create Excalidraw from selection” 能把笔记片段直接变成画布素材。编辑画布的所有改动会同步回 Markdown 文件，内容不会丢。

[!tip]
大型画布记得分层管理：把子主题拆成独立画布，用链接元素互相跳转；善用”库（Library）”保存常用图形，头脑风暴时直接拖出复用。

Charts 基于 Chart.js，用 ```chart 代码块即可渲染折线图、柱状图、饼图、雷达图、散点图等。最基础的用法是内联数据：

三种进阶数据源：

  1. CSV 文件：csvFile: data/monthly_sales.csv 直接引用附件
  2. Markdown 表格：在代码块内嵌表格，自动取数绘图
  3. Dataview 查询：dataviewQuery 参数把查询结果变成图表数据——例如把 09-Dataview数据查询 统计的每日任务数画成趋势线

常用配置：width/height 控制尺寸，legendPosition 调图例，xAxis/yAxis 设置轴标题与范围，系列内可写 borderColor、tension（曲线平滑度）等样式。混合图表（柱状+折线双轴）也很简单：给某个系列单独写 type: line 和 yAxisID 即可。

[!warning]
图表不显示时，优先检查三点：代码块语言必须是 chart 或 charts；YAML 缩进是否正确；数据点数量与标签数量是否匹配。一篇笔记放太多图表会明显拖慢渲染。

Mindmap Nextgen：Markdown 即思维导图

Mindmap Nextgen（以及功能相近的 Enhancing Mindmap）把 Markdown 标题和列表渲染成交互式思维导图，而且支持双向编辑——在导图里按 Tab 加子节点、Enter 加兄弟节点，改动会写回 Markdown；反过来改文本，导图即时刷新。

基本用法：打开任意结构化笔记，点编辑器右上角导图图标或执行命令 “Mindmap Nextgen: Open mindmap”。

支持五种布局：Mindmap（发散式）、Standard Tree、Vertical Tree、Fishbone（鱼骨图）、Radial（放射状），快捷键 Ctrl+L 循环切换。常用快捷键：Tab/Enter 增删节点、F2 编辑、Space 聚焦分支、Home 全图视图。节点支持 Markdown 粗体、链接、图片缩略，还能导出为 PNG/SVG/PDF 或兼容 FreeMind/XMind 的文件。

三者如何分工协作

一张表说清选型：

场景 首选 理由
流程图、架构图、手绘草稿 Excalidraw 自由画布、手绘风格、嵌入笔记链接
数值数据展示、趋势对比 Charts YAML 即图表，可与 Dataview 联动
层级结构、头脑风暴 Mindmap Nextgen Markdown 双向同步，编辑即导图
关系网络、知识图谱 Excalibrain / Canvas（见 13-Canvas白板与关系可视化） 见下一篇

实际工作流中的组合拳：先用 Mindmap 在阅读笔记上发散整理（16-阅读与知识内化 的素材），把成型的分支用 Excalidraw 画成概念图并链接到各永久笔记；周记里用 Charts 把本周任务完成数画成趋势图，配合 11-任务与看板管理 的数据闭环。

性能与移动端

  • 三款插件都吃渲染性能：Excalidraw 大画布启用渐进式渲染、限制同时打开数量；导图保持 2-4 层深度、用折叠控制复杂度
  • 移动端建议”桌面创作、移动查看”：Excalidraw 和导图在触屏上可浏览可轻编辑，但复杂操作回到桌面效率更高
  • 样式不满足时可用 CSS 片段微调节点/元素外观，注意选择器与主题的兼容性

可视化的意义不在”好看”，而在强迫你把模糊的想法摆到二维空间里接受检验。手绘让思考放松，图表让数据说话，导图让结构显形——三把刷子各刷一面，你的知识库就有了立体感。
