URDF 与 xacro 建模

[!info] 本节目标
掌握 URDF 机器人模型编写与 xacro 宏建模，能在 rviz2 中加载并检查模型。

1. URDF 基础

URDF（Unified Robot Description Format）用 XML 描述机器人运动学与外观：link（刚体）通过 joint（关节）连接。

标签 说明
link 刚体（质量、惯量、视觉、碰撞）
joint 关节（固定/转动/滑动等）
robot name 根节点

[!warning] 必须写惯量
仿真需要 link 的 inertia（惯量）；简单模型可用近似值，但不可缺失。

2. 关节类型

type 用途
fixed 固定连接
revolute 旋转关节（限位）
continuous 无限旋转（轮子）
prismatic 直线滑动
floating 六自由度浮动

[!tip] axis
revolute/prismatic 关节必须定义 <axis> 与 <limit>，否则 Gazebo/运动学解析报错。

3. xacro 宏

xacro 用宏与变量消除重复，是大型机器人模型的首选。

[!note] 数学表达式
xacro 支持 ${...} 内嵌表达式与变量（如 ${side * 2}），宏复用降低重复代码。

5. 模型检查与可视化

[!warning] 路径
rviz 加载模型需绝对路径或 launch 传入；显示不完整先检查 joint 父子与 origin。

6. 与 tf2 联动

URDF 中的 fixed joint 自动生成静态 TF（如 base_link -> laser），revolute 关节由 controller 发布实际角度。模型加载后可用 ros2 run tf2_tools view_frames 检查。

7. 常见问题

问题 排查
模型不显示 路径错误、visual 缺 geometry
关节不转 未配置 controller / 缺传动
仿真掉地 inertia 缺失或为 0
xacro 解析失败 引号、属性名、宏参数

[!note] 延伸
rviz2 中显示模型见 17-rviz2可视化；仿真加载模型见 18-Gazebo与Ignition仿真；机械臂建模结合 MoveIt2 见 28-MoveIt2机械臂控制。

8. 建模经验与规范

URDF 建模遵循”以坐标系为中心”的思想：每个 link 定义独立坐标系，joint 描述相对位姿，避免在几何内部引入额外坐标偏移。xacro 将重复参数（尺寸、材料、命名前缀）抽成变量，模型更易维护。关节限位、质量与惯量参数影响动力学仿真，真机映射前需标定。建模完成后用 check_urdf 校验结构，并在 rviz2 中加载验证可视化。对于复杂机械臂，推荐使用 MoveIt Setup Assistant 辅助生成配置（见 28-MoveIt2机械臂控制）。

[!note] 建议
好的模型是仿真、导航与机械臂控制的基础，建模后务必结合 rviz2 与 Gazebo 反复验证（见 17-rviz2可视化、18-Gazebo与Ignition仿真）。
