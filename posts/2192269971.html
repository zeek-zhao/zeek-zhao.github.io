02-安装与运行环境

发表于2026-10-25|groovy
|浏览量:

[!info] 本节目标
掌握 Groovy 的安装方式与日常运行工具，建立可用的开发环境。

1. 安装方式

Groovy 的安装方式灵活，最常用的是通过 SDKMAN! 管理版本，也可以直接下载官方发行包并配置 PATH。在 Windows 上可以使用包管理器或免安装 zip 解压使用。安装完成后运行 groovy -version 验证环境。

SDKMAN! 支持多版本共存与切换，适合频繁更新或需要多版本并行的开发者。官方安装包则适合离线环境或自动化部署。

2. groovy 命令

groovy 命令直接执行脚本文件或内联代码，是日常使用频率最高的工具。执行 groovy hello.groovy 运行脚本，groovy -e 运行内联代码。命令支持 -classpath 指定依赖，方便脚本使用第三方库。

groovyc 用于编译 Groovy 源码为 class 文件，groovydoc 生成文档，groovy 命令还支持 shebang 行，让 Groovy 脚本可以像 Unix 脚本一样直接执行。

3. GroovyConsole

GroovyConsole 是 Swing 图形控制台，提供脚本编辑与运行环境，适合实验语法与调试片段。它支持多脚本标签页、结果输出面板与对象浏览器，交互体验友好。

GroovyConsole 还集成了 Swing 对象查看器，可以直观检查返回对象的结构与属性，对学习数据结构与调试非常有用。

4. groovysh 与 REPL

groovysh 是命令行 REPL，逐行输入 Groovy 表达式并立即得到结果，适合快速验证语法。它支持多行输入、命令历史与变量保持，是终端环境下的效率工具。

在 REPL 中可以直接实验闭包、GString、集合操作等特性，无需创建文件，极大降低学习门槛。

5. IDE 集成

IntelliJ IDEA 内置 Groovy 支持，提供语法高亮、自动补全与运行配置。Eclipse 与 VS Code 也提供 Groovy 插件。IDE 的调试器可以逐步执行 Groovy 脚本，查看变量与调用栈。

建议将 IDE 与 groovysh 搭配使用：复杂逻辑在 IDE 中开发调试，简单验证在 REPL 中完成。

6. 环境验证

安装完成后建议运行一组验证：groovy -version 查看版本；执行简单 Hello World 脚本；在 GroovyConsole 中运行表达式；用 groovysh 体验交互。确认这些基础能力正常后，再进入语法学习。

如果遇到命令找不到或依赖缺失，优先检查 PATH 配置与 JAVA_HOME，Groovy 需要 JVM 环境，Java 8 以上均可运行。
