LDAP 是读多写少的目录协议¶

LDAP（Lightweight Directory Access Protocol）
轻量级目录访问协议：

  • 用于访问分布式目录信息服务
  • 数据以树状结构组织（DIT）
  • 读多写少，优化查询
  • 广泛用于统一身份认证

常见实现：

  • OpenLDAP（开源标准）
  • Microsoft AD（企业生态）
  • 云目录（Okta/Azure AD）

先把 DN 这套命名摸清¶

环境用 OpenLDAP 2.5 加 olc¶

本套教程以 OpenLDAP 2.5+ 为例：

  • 操作系统：Ubuntu 22.04 / CentOS 9
  • 服务：slapd + olc 配置
  • 客户端：ldapsearch/ldapadd/ldapmodify
  • 工具：phpLDAPadmin、Apache Directory Studio

开始学习：01-LDAP概述

我一般照着这个版本搭环境，省得在 olc 配置格式上踩兼容性的坑。

⚠️踩坑提示
LDAP 里 DN（辨别名）是条目的唯一标识，写法 uid=zhangsan,ou=people,dc=example,dc=com 是从具体到根、逗号分隔，顺序写反或漏写 dc 都查不到条目。DN 的大小写不敏感但空格敏感，ou=People 和 ou=People （尾部空格）是两个不同条目，配置客户端时尤其容易踩。学习先跑通 ldapsearch -x -b "dc=example,dc=com" 确认能返回数据，再往上加复杂度。
