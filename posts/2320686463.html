搜索与内容管理

接着上一篇 10-页面层级与导航 往下。页面和入口都搭好之后，真正的考验是内容多了还能不能找得到。Confluence 的搜索语法、标签、页面属性加上定期清理归档，是一整套事；下面按这几块讲，末尾还会说几个我踩过的坑。

顶部搜索框做全文检索¶

顶部搜索框：

  • 全文检索（页面标题+正文+附件名）
  • 高级筛选（空间、类型、作者）
  • 最近搜索记录

快捷键：/ 或 Ctrl+K（快速搜索）

用限定词把搜索范围收紧¶

示例：

  • 需求 AND 支付 # 两个词同时
  • “支付回调” # 精确短语
  • space:RD # 限定空间
  • type:page # 类型（页面/评论/附件）
  • creator:张三 # 创建人
  • label:release-notes # 按标签
  • -废弃 # 排除词

组合：space:RD AND label:需求 AND “登录”

标签按类型、状态、主题三个维度打¶

标签分类维度：

  • 类型：需求、设计、规范、会议
  • 状态：草稿、评审、发布
  • 主题：支付、安全、性能

添加：页面底部标签栏 / 编辑器

标签管理：

  • 重命名/合并标签（管理员）
  • 标签云展示
  • 内容动态列表宏聚合（见 05）

页面属性把散落文档变成可统计表¶

页面属性（Page Properties）：

  • 页面结构化字段（负责人、状态、日期）
  • 配合”属性报告”宏生成表格视图

示例：

属性 值
负责人 张三
状态 评审中
优先级 高

价值：将散落文档变成可统计数据库。

季度做一次内容审计和清理¶

定期内容管理：

  1. 搜索过期内容（按修改时间）
  2. 归档旧项目空间
  3. 合并重复页面
  4. 清理大附件
  5. 修复死链

管理员工具：

  • 内容报表（页面数、大小）
  • 回收站（恢复误删）
  • 附件统计

归档留历史，删除要可恢复¶

归档 vs 删除：

  • 归档：保留历史，标记已归档，隐藏
  • 删除：彻底移除（回收站可恢复）

流程：

  1. 确认无引用
  2. 导出备份（HTML/PDF/Word）
  3. 归档空间/页面
  4. 更新入口页与标签

搜不到先查权限和索引¶

我遇到”搜不到”一般先确认自己有没有权限，因为没权限的页面根本不会出现在结果里，白改半天语法。

  1. 搜索不到：检查权限（无权限页面不显示）与索引状态。
  2. 标签混乱：同义标签（需求/requirement），统一维护。
  3. 属性未用：页面属性宏依赖规范填写，模板固化。
  4. 删除不备份：误删重要文档，删除前导出。
  5. 索引损坏：搜索异常时重建索引（管理员）。

标签字典加属性规范，再配季度审计¶

我的做法是把标签字典和属性字段写进模板，大家新建页面时直接填，比事后补省事得多。

  • 统一标签字典 + 属性规范。
  • 季度内容审计：清理 + 归档。
  • 搜索技巧培训：团队常用高级语法。
  • 配合 10-页面层级与导航、12-附件与文件管理。
