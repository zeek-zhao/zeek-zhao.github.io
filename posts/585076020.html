vim 与 nano

[!abstract] 用途
vim 是功能强大的模态编辑器（几乎所有 Linux 预装）；nano 是简单易用的新手编辑器。掌握 vim 基本操作可在无图形界面的服务器上高效编辑配置文件。

7. 注意事项

  • 无图形界面时 vim 是最可靠选择，建议至少掌握：打开、插入、保存、退出；
  • 不要在服务器上把 vim 默认字符集改乱（保持 UTF-8）；
  • sudo vim 编辑系统文件；普通 vim 无写权限时用 :w !sudo tee %（高级技巧）；
  • 大文件（几百 MB）用 vim 会卡，考虑 less / sed 查看。
