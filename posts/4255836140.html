RBAC 权限控制

[!abstract] 是什么
RBAC（基于角色的访问控制）管理”谁（主体）能对哪些资源（对象）做什么操作（动词）”。

核心对象

对象 作用域 作用
ServiceAccount 命名空间 集群内进程的身份
Role / ClusterRole 命名空间 / 集群 定义权限集合
RoleBinding / ClusterRoleBinding 命名空间 / 集群 把角色绑定到主体

第一步：创建 ServiceAccount

第二步：定义权限（Role）

第三步：绑定

ClusterRole 跨命名空间

verbs 速查

动词 含义
get / list / watch 读取
create / update / patch / delete 写入
* 全部

[!tip] 最佳实践

  • 权限最小化：只给需要的资源与动词；
  • 应用 Pod 默认使用 default SA，应显式 serviceAccountName 指定专用 SA；
  • 生产常用 kubectl get clusterrolebinding cluster-admin -o yaml 审查管理员绑定。

[!warning] 注意
RBAC 不替代网络隔离；Pod 间流量控制用 NetworkPolicy。
