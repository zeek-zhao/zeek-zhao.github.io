Bases数据库视图

[!abstract] 一句话
Bases 让你像用 Notion 数据库一样筛选、排序、分组自己的笔记——但底层永远是本地 Markdown 文件，零代码、零锁定。

Bases 是什么

在 Bases 出现之前，想让 Obsidian 的笔记”像数据库一样展示”，只能依赖社区插件 Dataview 写查询语句。2025 年 8 月的 1.9.10 版本，官方正式引入 Bases 核心插件，补上了这块拼图：它把一批笔记的 YAML 属性（见 05-属性元数据与标签）渲染成数据库视图，支持表格、卡片等形态，视图本身保存为 .base 文件。

它最重要的设计承诺是：数据仍然只存在本地 Markdown 里。.base 文件保存的只是”视图定义”（筛选哪些笔记、显示哪些列、怎么排序），并不复制任何笔记内容。关掉 Obsidian，你的笔记依然是带 Frontmatter 的纯文本，可以被任何工具读取。

[!note] 2026 更新
Bases 迭代很快：1.10（2025-10）新增分组、列表视图、官方 Maps 地图插件、表格汇总（Summaries）与 Bases API；1.12 加入 Bases 内搜索；1.14 早期访问版带来看板（Kanban）视图。官方还陆续提供了 Notion（2025-11）、Airtable（2026-07）与 CSV 的导入转换，可以把外部表格数据一键迁移为 Bases。

创建第一个 Base

两种入口：

  1. 命令面板：Ctrl+P → “新建 Base”，得到一个 .base 文件；
  2. 从文件夹创建：右键任意文件夹 → “新建 Base”，它会自动以该文件夹为数据源。

创建后进入视图编辑器，核心配置分三步：

  • 数据源（Filter）：选择笔记范围——按文件夹、按标签，或按属性条件（如 status = "进行中"）；
  • 视图类型：表格（Table）逐行显示笔记与属性，卡片（Cards）以卡片网格展示，适合带封面图的场景（如书影音库）；
  • 列（Properties）：选择要展示的属性列，可拖拽调整顺序、指定列宽。

视图能力详解

  • 排序与筛选：任意属性列可升/降序；筛选条件支持组合（AND/OR），如”状态为进行中 AND 优先级为高”；
  • 分组（Group）：1.10 起支持按属性分组展示，比如按 status 把笔记分成”待办/进行中/完成”三组，每组内独立排序；
  • 汇总（Summaries）：对数字列做求和、平均、计数等汇总，比如项目 Base 底部自动显示任务完成率；日期列也有”最早/最晚”等汇总函数；
  • 列表视图：1.10 新增，以紧凑列表展示，适合轻量索引；
  • 地图视图：配合官方 Maps 插件，笔记若带经纬度属性可在地图上打点；
  • 看板视图：1.14（早期访问）引入 Kanban，按某属性（通常是 status）分列呈现，任务管理场景可直接替代部分看板插件，参见 11-任务与看板管理。

Bases vs Dataview：怎么选

两者是互补关系而非替代关系：

维度 Bases Dataview
出处 官方核心插件 社区插件
上手门槛 零代码，点选配置 需学习类 SQL 查询语言
表达能力 筛选/排序/分组/汇总 任意逻辑查询、跨表聚合、dataviewjs 编程
移动端 完整支持 移动端渲染较慢
维护方 随官方版本演进 依赖社区维护者

经验法则：常规的”按属性看一批笔记”用 Bases（书影音库、项目清单、任务面板）；需要复杂统计、动态计算或嵌入 JS 逻辑时再上 Dataview。两者读的都是同一份 Frontmatter 数据，随时可以互换。

典型应用场景

  • 项目管理：以项目文件夹为源的表格，列含状态、截止日、负责人，按截止日排序；
  • 阅读追踪：卡片视图 + 封面 + 评分汇总，配合豆瓣等导入插件可自动填充元数据；
  • 习惯打卡：日期属性 + 复选框属性，汇总行直接显示打卡天数；
  • 人脉/资源库：联系人笔记按公司分组，地图视图按城市分布。

[!tip] 配合模板食用
Bases 的数据质量取决于属性录入的一致性。先用 07-模板与快捷键 里的模板给每类笔记预置统一字段，Base 视图才不会出现一堆空列。

常见坑

[!warning] 避坑清单

  1. 属性类型不一致：同一列混用文本与数字会导致排序错乱，先在属性面板统一类型；
  2. 把 Base 当数据库改数据：Base 里编辑属性确实会写回 Markdown，但批量结构修改仍建议在源文件层面进行；
  3. **忘记它需要 1.9.10+**：旧版本安装包没有 Bases，升级 Obsidian 后在核心插件列表开启；
  4. 数据源过宽：全库作为数据源会让视图加载变慢，用文件夹或标签收窄范围。
