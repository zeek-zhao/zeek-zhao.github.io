命令替换与算术运算

[!info] 本页概览
本文详解命令替换（$() 与反引号）与算术运算（(( )) 与 $(( ))），覆盖返回值捕获、子 shell 语义、算术比较、自增自减与常见陷阱。

核心概念

  • 命令替换：把命令 stdout 作为值使用；$(cmd) 现代写法（可嵌套），反引号旧写法。
  • 算术展开：$((expr)) 取结果；((expr)) 用于判断/副作用。
  • 算术支持 C 风格运算符：+ - * / % ** ++ -- += 与位运算、逻辑。
  • 整数运算内建，无浮点（浮点用 awk/bc）。

常见坑

  1. 反引号嵌套困难：内部含反引号/转义易错，统一 $()。
  2. 命令替换去尾部换行：echo 输出换行被剥掉；多行输出用数组或 while。
  3. (( )) 无输出：((x=5)) 不输出 5，需要 $((x=5)) 才取值。
  4. 浮点除法：$((5/2)) 得 2（整数）；浮点用 awk/bc。
  5. 除零错误：$((1/0)) 直接报错退出，先判断除数。
  6. 命令替换中的 stderr：只捕获 stdout；需要错误信息用 2>&1 显式合并。
  7. $(...) 中引号：$(echo "$name") 内层引号先解析，注意嵌套转义。

最佳实践

  • 一律 $() 替代反引号；嵌套读代码更清晰。
  • 数值判断用 (( ))，字符串判断用 ``。
  • 大数/浮点/进制转换交给 awk 或 python。
  • 命令替换开销小但非零，循环内避免重复调用 $(date ...)，先缓存。
  • 复杂计算写成函数：calc() { echo "$*" | bc; }。
