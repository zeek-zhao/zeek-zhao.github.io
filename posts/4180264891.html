路由基础

[!info] 本页概览
本文讲解 vue-router 4 基础：路由配置、router-view、声明式与编程式导航、动态路由参数、嵌套路由、重定向与 404，构建单页应用导航体系。

核心概念

  • vue-router：Vue 官方路由库（Vue 3 用 v4），管理 URL 与视图映射。
  • history 模式：createWebHistory（清爽 URL）与 createWebHashHistory（# 号，静态托管友好）。
  • 组件在 router-view 中按路由渲染。

常见坑

  1. history 模式部署 404：Nginx 需 try_files $uri $uri/ /index.html（见 17-部署）。
  2. 路由参数变化不刷新组件：/users/1 → /users/2 复用组件；用 watch(() => route.params.id, ...) 响应。
  3. 动态 import 路径错误：懒加载 () => import(...) 路径写错会在跳转时报错。
  4. 嵌套路由 path 忘记相对：children 的 path 不加 /（绝对路径）会拼接异常。
  5. useRoute 只能用在 setup 内：普通函数/模块中无响应式 route，需传入。
  6. 404 通配路由放最后：:pathMatch(.*)* 必须放在 routes 末尾，否则拦截正常路由。

最佳实践

  • 路由组件懒加载（() => import），配合分包优化首屏。
  • 路由命名（name）而非硬编码 path，便于批量调整。
  • 权限用导航守卫统一控制（见 08-路由进阶与导航守卫）。
  • 路由组件与普通组件分目录（views/ 与 components/）。
  • 参数校验：/users/:id 中 id 是字符串，使用前 Number() 或校验。
