控制流

[!info] 本页概览
控制流决定程序的执行路径：分支（if/switch）与循环（for/while/do-while）。本文讲解语法、适用场景与 break/continue/goto 的正确使用。

核心概念

分支根据条件选择执行哪段代码；循环重复执行某段代码直到条件不满足。它们与函数一起构成结构化编程的基础。

循环语句

C++ 的 range-based for 简化容器遍历：

break / continue / goto

  • break：跳出当前循环或 switch。
  • continue：跳过本次循环剩余语句，进入下一次迭代。
  • goto：C 语言允许，用于跳出多层循环；C++ 中应避免，优先用 std::optional 或重构。

常见坑

  1. for 中声明变量作用域：for (int i = 0; ...) 中 i 在 C99/C++ 中仅循环内可见；旧式 C89 需在外部声明。
  2. switch 忘记 break：会穿透（fallthrough）到下一个 case，常导致逻辑错误。
  3. 浮点数作循环条件：for (double d = 0; d != 1.0; d += 0.1) 可能死循环，浮点累计误差导致永远不等于 1.0。
  4. 空循环体分号：while (i < 10); 末尾分号导致空循环，可能死循环。
  5. **if (a == b) 误写 if (a = b)**：赋值表达式在条件中恒真（非零）。

最佳实践

  • 循环变量用 i++ 而非 ++i 无实际差异，但保持统一风格。
  • 多层嵌套循环超过 3 层时考虑提取函数。
  • 用 for (;;) 表示无限循环时，确保有明确退出条件，或用 while (true) 更可读。
