launch 系统

[!info] 本节目标
掌握 ROS2 Python launch 文件：节点组合、参数、命名空间、条件与事件机制。

1. launch 概念

launch 文件用于一次性启动多个节点、配置参数、设置命名空间并编排启动顺序。ROS2 推荐使用 Python launch（.launch.py）。

[!note] 对比 ROS1
ROS2 弃用 XML launch，全面转向 Python 语法，可编程性更强。

2. 基础 launch

参数 说明
package/executable 运行目标
name 节点名（含命名空间）
parameters 参数列表（dict 或 yaml 路径）
remappings 话题重映射
arguments 命令行参数
output ‘screen’ / ‘log’

3. 参数与重映射

[!tip] 重映射
remappings 把节点内话题名映射到全局名，多机器人场景必备（见 29-多机器人协同）。

4. 命名空间

5. 条件与变量

[!warning] 类型
LaunchConfiguration 默认是字符串；数值参数需转换（如 PythonExpression(['int(', use_x, ')'])）。

6. 事件与生命周期

[!tip] 生命周期联动
Nav2 使用 OnStateTransition 在 configure 成功后自动 activate（见 12-生命周期节点）。

7. IncludeLaunch 复用

[!note] 复用模式
大型系统（导航、机械臂）用 IncludeLaunch 组合子模块，配置通过 launch_arguments 传递。

8. 常见问题

问题 排查
找不到 launch 文件 未 install 到 share 目录
参数不生效 参数 dict 与节点名层级
节点名冲突 命名空间/name 设置
启动顺序乱 用 RegisterEventHandler

[!note] 延伸
launch 与参数联动见 09-参数机制；多机器人 launch 见 29-多机器人协同；产品部署见 38-产品化与部署实践。

8. launch 设计模式

launch 文件应遵循”声明参数-组装节点-组织事件”的结构：所有可变量用 DeclareLaunchArgument 声明并给出默认值，节点参数引用 LaunchConfiguration 传入，事件（on_exit、on_start）控制启动顺序与失败恢复。复杂系统拆分成多个可复用 launch，通过 include 组合，避免单文件膨胀。launch 与参数文件分离，环境差异通过参数注入。调试时用 --show-args 查看可用参数，用 ros2 launch 加日志级别定位启动问题。

[!note] 建议
launch 是 ROS2 系统组织的核心，多机/多模块系统依赖 launch 管理；部署级 launch 见 38-产品化与部署实践。
