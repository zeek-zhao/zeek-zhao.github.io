09-面向对象

发表于2026-10-25|groovy
|浏览量:

[!info] 本节目标
Groovy 面向对象在 Java 基础上增强，学习类定义、属性、继承与多态。

1. 类与对象

Groovy 类定义与 Java 类似，但更简洁：属性声明无需显式 getter/setter，构造器可以省略，默认无参构造器自动提供。类默认 public，字段默认 private 并自动生成访问器。

new 关键字创建实例，也可以省略括号调用构造器。Groovy 支持命名参数构造，让对象初始化更可读。

2. 属性机制

Groovy 属性用字段声明自动生成 getter 与 setter，点号访问属性实际调用访问器。这种机制让封装与访问的代码都更简洁。

只读属性用 final 或仅定义 getter；属性注解如 @PackageScope 可以控制字段可见性。

3. 继承与接口

Groovy 继承语法与 Java 一致，extends 继承类、implements 实现接口。动态语言的多态行为更灵活，方法重写基于运行时类型分发。

接口可以有默认方法，Groovy 3+ 支持 Java 8 风格接口默认方法，也支持 trait 提供更丰富的混入能力。

4. 抽象类与模板方法

抽象类定义骨架，子类实现细节，模板方法模式在 Groovy 中实现简洁。抽象方法用 abstract 声明，具体方法提供公共流程。

Groovy 允许用闭包或元编程在运行时补充抽象方法实现，降低子类数量。

5. 多态与动态分发

Groovy 方法调用基于运行时类型，动态分发让多态表现更充分。鸭子类型让不同类只要方法签名一致即可互换使用。

运行时方法解析顺序：具体方法、属性访问、methodMissing、GroovyObject 钩子，理解解析链有助于调试动态行为。

6. 面向对象实践

设计类时优先组合而非继承，trait 提供安全的混入路径；保持类职责单一；利用属性机制减少样板代码。

大型项目建议结合 @TypeChecked 或 @CompileStatic 保护核心 API，兼顾动态灵活与可维护性。
