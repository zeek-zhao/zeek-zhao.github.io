面试指南与学习路线

[!info] 本页概览
本文整理 Java 学习路线（入门到精通）、核心面试题分类、高频考点速查、简历项目建议与持续成长方法论，帮助读者系统复习并应对 Java 岗位面试。

学习路线总览

高频面试题分类

语言基础

  • String 不可变原理、字符串常量池、== 与 equals 区别
  • 集合：ArrayList vs LinkedList、HashMap 原理（数组+链表+红黑树）、ConcurrentHashMap 分段/CAS
  • 异常体系与受检/非受检区别
  • 泛型擦除与通配符 PECS

并发

  • synchronized 与 ReentrantLock 区别（可中断/公平/条件）
  • volatile 与 synchronized 区别（可见性/原子性）
  • 线程池参数（核心/最大/队列/拒绝策略）与 Executors 陷阱
  • ThreadLocal 原理与内存泄漏
  • AQS 原理、CAS 与 ABA

JVM

  • 内存结构（堆/栈/方法区）与对象创建流程
  • GC 算法与 G1/ZGC 特点
  • 类加载过程与双亲委派
  • JVM 参数与 OOM 排查（jstat/jmap/jstack）

框架

  • Spring IoC/DI 与 AOP 原理（动态代理）
  • Spring Boot 自动配置原理（@EnableAutoConfiguration + SPI）
  • MyBatis 一级/二级缓存、#{} 与 ${} 区别
  • Spring 事务传播行为与失效场景

分布式

  • Redis 数据类型/持久化/过期策略/缓存三大问题
  • Kafka 消息可靠性（生产者 ack、消费者 offset）
  • 分布式锁实现（Redis SETNX vs Zookeeper）
  • 分布式事务（2PC/TCC/本地消息表/事务消息）
  • 微服务注册/配置/网关/熔断

高频考点速查表

考点 一句话答案
HashMap 原理 数组+链表（≥8 转红黑树），加载因子 0.75
ConcurrentHashMap JDK8：CAS+synchronized 锁桶，无分段锁
线程池参数 core、max、queue、keepAlive、拒绝策略
GC 分代 新生代复制、老年代标记整理/清除
Spring 循环依赖 三级缓存解决 setter 注入
AOP 实现 JDK 动态代理（接口）/ CGLIB（子类）
Redis 持久化 RDB 快照 + AOF 日志
消息可靠性 生产 ack + broker 持久化 + 消费 offset 手动提交
分布式事务 最终一致性：本地消息表/事务消息

简历项目建议

项目 技术栈 亮点
秒杀系统 Spring Boot + Redis + MQ 限流、缓存击穿防护、削峰
微服务商城 Spring Cloud + Nacos + Gateway 熔断降级、链路追踪
数据中台 Kafka + ES + Flink 实时/离线数仓、指标看板
开源贡献 JDK/Spring 源码 PR 证明源码阅读深度

[!note] 项目原则
一个”深度”项目优于多个”表面”项目。写清楚：背景问题 → 技术选型 → 架构设计 → 核心难点 → 效果量化。

常见坑与建议

  1. 只背八股不写代码：手写算法 + 项目细节更能体现能力。
  2. 简历夸大：面试官深挖立即露馅；诚实 + 突出真实贡献。
  3. 忽略基础知识：HashMap/线程池/GC 是必考，务必真懂。
  4. 项目无量化：用数据说话（QPS、响应时间、可用性）。
  5. 不准备反问：准备 2-3 个高质量反问（团队技术栈、成长空间）。

最佳实践

  • 用本目录文档系统复习：12-JVM基础、11-多线程与并发、08-集合框架 优先。
  • 刷题：LeetCode Hot 100 + 剑指 Offer；手写 HashMap/线程池。
  • 输出倒逼输入：写技术博客/面经整理，费曼学习法。
  • 参与开源/社区，构建技术影响力。
  • 长期主义：每季度复盘学习路线，按需调整。
