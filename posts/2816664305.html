SQLite3 使用笔记

SQLite 是我做本地原型、嵌入式工具和小型桌面应用时的首选：一个文件就是一个数据库，不用起服务进程。下面这份笔记把命令行操作、SQL 示例、性能优化和完整示例都收在一起，需要时直接翻。

SQLite 以单文件、零服务、自包含见长¶

SQLite 是一款轻量级的关系型数据库管理系统，具有以下特点：

  • 小巧：占用资源极少，可能只需几百KB内存
  • 高速：在许多常见操作上比其他数据库系统快
  • 自包含：几乎不依赖外部库
  • 可靠：完全符合ACID事务特性
  • 功能完备：支持大部分SQL标准

SQLite 由 D. Richard Hipp 于2000年创建，现已发展到第3版。不同于客户端-服务器模式的数据库系统(如MySQL, PostgreSQL)，SQLite 引擎直接集成到应用程序中，整个数据库存储在单个文件中，无需独立的服务进程。

SQLite3 命令行特点¶

  • 以点号(.)开头的是 SQLite 命令
  • SQL 语句必须以分号(;)结尾
  • 命令行按 Enter 键执行当前输入
  • 大小写不敏感（SQL语句和表名）

点命令负责元信息、输出格式和转储¶

.help # 显示帮助信息
.open FILENAME # 打开数据库文件
.databases # 列出附加的数据库
.tables # 显示当前数据库中的所有表
.schema TABLE # 显示表的创建语句
.header on|off # 显示/隐藏列名
.mode column # 设置输出模式为列
.width NUM NUM # 设置列宽
.dump # 以SQL格式转储数据库
.output FILE # 将输出发送到文件
.read FILE # 执行文件中的SQL
.save FILE # 将内存数据库保存到文件
