Windows Terminal

[!abstract] 用途
Windows Terminal 是微软官方推出的现代终端应用，支持多标签、多窗格、自定义主题，统一承载 PowerShell、CMD、WSL、SSH 等多种命令行环境。

1. 安装

Windows 11 默认预装。

2. 核心特性

  • 多标签/多窗格：同时运行多个终端，支持分屏；
  • 多配置文件：PowerShell、CMD、WSL、Ubuntu、SSH 等；
  • GPU 加速渲染：中文/表情渲染流畅；
  • 自定义主题与配色：JSON 配置，可导入配色方案；
  • 快捷键：Ctrl+Shift+T 新标签、Alt+Shift+D 分屏、Ctrl+Shift+W 关闭。

6. 注意事项

  • 默认终端设置：设置 → 默认终端应用程序 选 Windows Terminal，让 Ctrl+Alt+T 等调用它；
  • 升级版本可能重置部分设置，先备份 settings.json；
  • 配色/字体设置是全局默认，可在每个配置文件单独覆盖；
  • 与 WSL 搭配体验最佳（18-WSL）。

[!info] 本节目标对比 DAC、AppArmor 与 SELinux 的差异，理解各自适用场景。 1. DAC 自主访问控制DAC 是 Linux 传统权限模型：文件权限由属主控制，root 拥有完全权限。它灵活易用但粒度粗，进程权限继承用户权限，攻击者拿到普通用户即可能访问其全部文件，无法有效阻止提权与横向渗透。 2. AppArmor 简介AppArmor 是基于路径的 MAC 实现，通过配置文件描述进程可访问的文件路径与能力。它配置简单、易学易用，被 Ubuntu、SUSE 采用。缺点是依赖路径与文件名，攻击者可通过符号链接或硬链接绕过限制，且保护粒度较粗。 3.
