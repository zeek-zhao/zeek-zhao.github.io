运维监控

[!info] 本页概览
本文讲解数据库运维监控体系：慢查询定位、Prometheus 指标采集、Grafana 可视化、日常巡检与容量规划，配可运行示例。

核心概念

  • 慢查询日志：记录执行超过阈值的 SQL，是性能问题第一现场。
  • Prometheus + mysqld_exporter：抓取 MySQL 状态指标（QPS、连接数、Buffer Pool、复制延迟）。
  • Grafana：指标可视化与告警面板。
  • 巡检：定期检查容量、复制、备份、权限与安全配置。

慢查询定位

[!note] 优化闭环
定位慢 SQL -> EXPLAIN 分析 -> 加索引/改写 SQL -> 上线后观察指标回落。

Grafana 告警

日常巡检清单

  1. 磁盘空间与增长速率（binlog、慢日志、数据文件）。
  2. 备份任务是否成功、备份是否可恢复（定期恢复演练）。
  3. 复制状态：IO/SQL 线程、延迟、error log。
  4. 慢查询 TOP SQL 是否在恶化。
  5. 连接数峰值与连接池配置匹配度。
  6. 权限审计：是否存在弱口令、超大权限账号（见 20-数据库安全与权限）。

常见坑与最佳实践

  • 只配告警不接值班：告警要收敛、分级、可行动。
  • 监控账号权限最小化，避免把 exporter 当 DBA 账号。
  • 容量规划：按增长率预留磁盘与内存，结合 08-备份恢复 制定清理策略。
