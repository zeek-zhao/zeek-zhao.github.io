gcc 与 make

[!abstract] 用途
gcc 编译 C/C++ 源码；make 通过 Makefile 自动化管理编译依赖与增量构建；build-essential 集合了编译全套工具，是源码安装与 C 开发的基础。

[!note] make 原理
make 根据文件时间戳判断是否需要重新编译：源文件比目标文件新才重建，节省大量重复编译。

5. 源码安装典型流程

[!warning] 依赖缺失
configure/cmake 报错缺头文件或库时用 apt 安装对应 -dev 包，例如 sudo apt install libssl-dev。

6. 多文件构建与链接

7. 注意事项

  • 编译警告（-Wall）要认真看，多为潜在 bug；
  • 缺 -dev 包是源码编译最常见的坑，先确认依赖；
  • 不要用 root 编译个人项目，源码安装到 /usr/local 需 sudo make install；
  • 大项目优先 CMake / Meson 而非裸 make；
  • 32 位/交叉编译需额外工具链（gcc-multilib 等）。
