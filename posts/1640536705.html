Zsh 使用指南

工欲善其事，必先利其器。ZSH (Z Shell) 是 Bash 的替代品，提供更多自定义选项和增强功能，配合 Oh-My-Zsh 框架能显著降低配置成本。我自己的做法是先装框架和自动提示、语法高亮两个插件，主题最后再挑。

装好框架和插件，命令行手感立刻不一样¶

ZSH 的主要优势：

  • 强大的自动补全功能
  • 拼写修正能力
  • 丰富的主题定制选项
  • 大量实用插件
  • 历史命令搜索优化
  • 目录快速跳转

配置落在 ~/.oh-my-zsh 和 ~/.zshrc，改前先看目录结构¶

Oh-My-Zsh 安装后，会在用户主目录下创建以下目录结构：

  • ~/.oh-my-zsh/lib: 提供了核心功能的脚本库
  • ~/.oh-my-zsh/tools: 提供安装、升级等功能的快捷工具
  • ~/.oh-my-zsh/plugins: 官方自带插件存放位置
  • ~/.oh-my-zsh/templates: 自带模板存放位置
  • ~/.oh-my-zsh/themes: 自带主题文件存放位置
  • ~/.oh-my-zsh/custom: 个性化配置目录，第三方插件和主题存放位置

主要配置文件 ~/.zshrc 可以用文本编辑器打开修改。

自动提示和语法高亮最值得先装¶

1. zsh-autosuggestions - 命令自动提示¶

根据历史记录自动提示可能的命令，按右箭头键接受建议。

2. zsh-syntax-highlighting - 语法高亮¶

为命令提供语法高亮，可以让你在输入时就发现语法错误。

3. z - 快速跳转¶

智能地记住你访问过的目录，可以使用 z 目录关键词 快速跳转。

4. extract - 一键解压¶

支持多种压缩格式，使用 x 文件名 即可解压。

5. git - Git 快捷命令¶

提供大量 Git 操作的别名，例如 gst 代替 git status。

目录跳转、历史搜索和自动补全天天都用¶

1. 目录导航¶

  • cd -: 返回上一个目录
  • cd -<数字>: 返回历史目录列表中的指定目录
  • d: 显示目录堆栈
  • 1 ~ 9: 快速切换到堆栈中的目录

2. 命令历史¶

  • Ctrl+R: 搜索历史命令
  • 输入命令开头几个字母，然后按上下箭头可搜索匹配的历史命令

3. 文件操作¶

  • 使用通配符: cp *.txt target/
  • 递归通配: ls **/*.md 查找所有子目录中的 md 文件

4. 自动补全¶

  • TAB 键补全命令和路径
  • 连按两次 TAB 显示所有可选项
  • 按 TAB 时可选多项时，可以用方向键选择

字体、插件、主题和速度问题按清单排查¶

  1. 字体显示不正确

    • 确保安装了 Powerline 字体
    • 检查终端模拟器设置中的字体设置

  2. 插件不生效

    • 检查 ~/.zshrc 中的 plugins 配置是否正确
    • 确认插件已经下载到正确位置
    • 执行 source ~/.zshrc 重新加载配置

  3. 主题显示问题

    • 对于 agnoster 等主题，确保终端支持 256 色
    • 检查 TERM 环境变量是否设置正确

  4. 速度慢

    • 禁用不常用的插件
    • 使用 zsh-async 插件优化异步加载

我的判断是：插件宁少勿多，自动提示和语法高亮装完先适应一周，再决定要不要换主题；每次改完 .zshrc 都 source 一下，能省掉很多”配置没生效”的误判。
