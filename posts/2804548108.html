数据可视化基础

[!info] 本页概览
本文讲解 matplotlib 绘图基础：折线图、柱状图、散点图、直方图，以及中文显示、子图布局与保存图片，为数据分析输出可视化结果。

核心概念

matplotlib 是 Python 最基础的绘图库：pyplot 提供命令式接口（类似 MATLAB），核心对象是 Figure（画布）与 Axes（坐标系）。数据科学场景常配合 pandas/numpy。

常见坑

  1. 中文乱码：未设置字体 → 方块；设置 rcParams 或使用系统字体名。
  2. show() 后 savefig() 空白：savefig 必须在 show 之前，或两者都用 plt.gcf()。
  3. 多个 figure 状态串扰：用 fig, ax = plt.subplots() 显式管理，避免全局状态。
  4. 图例图名重复：label 与 legend 搭配，否则图例为空。
  5. 坐标轴范围自动缩放异常：用 ax.set_xlim/ylim 控制。
  6. 交互式环境阻塞：Jupyter 用 %matplotlib inline，脚本用 plt.show()。

最佳实践

  • 一图一义：标题、轴标签、图例齐全，读者无需猜测。
  • 数据量变化时选对图表：趋势→折线、对比→柱状、分布→直方图/箱线、关系→散点。
  • 颜色统一、弱化网格线，保证可打印与可访问性。
  • 复杂图表用 seaborn（基于 matplotlib 的高级接口）或 plotly（交互式）。
  • 图表代码封装成绘图函数，参数化复用。
