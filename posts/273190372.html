凭据管理

[!abstract] 核心原则
代码里不写密钥。Jenkins 把密码/Token/SSH 密钥存入加密凭据库，构建时按 ID 安全注入。

凭据类型

类型 用途
Username with password Git/HTTP/平台账号
SSH Username with private key SSH 访问、Git SSH
Secret text API Token、密钥串
Secret file 证书、配置文件（如 kubeconfig）
Certificate 客户端证书

创建凭据

Dashboard → Manage Jenkins → Credentials → Global → Add Credentials

[!note] ID 重要性
Pipeline 按 credentialsId 引用；ID 定了就别改，否则所有引用失效。

Pipeline 注入凭据

[!tip] withCredentials 说明
withCredentials 块内才注入变量，块外不可见；usernamePassword 类型注入 USERNAME/PASSWORD 两个变量。

SSH 私钥凭据

凭据加密与迁移

  • 凭据在磁盘上用Jenkins 主密钥加密（secrets/master.key + hudson.util.Secret）；
  • 备份/迁移时必须同时备份主密钥，否则凭据无法解密（见 15-备份与升级）。

[!warning] 安全红线

  • 严禁在 Jenkinsfile、脚本里硬编码密码/Token；
  • 凭据 ID 权限最小化：不同项目用不同凭据，避免”万能账号”；
  • 定期轮换；离职账号及时禁用并删除其凭据。

重复的 Pipeline 逻辑如何沉淀复用：07-共享库。
