Spring Boot 入门

[!info] 本页概览
本文讲解 Spring Boot 入门：核心思想（约定优于配置）、工程结构、依赖注入、Web 开发（Controller/Service/Repository）、配置与属性、常用 Starter、打包部署，配代码示例与常见坑。

核心概念

  • Spring Boot：简化 Spring 应用开发的框架，自动配置 + 起步依赖（Starter）。
  • 核心注解：
    • @SpringBootApplication：组合 @Configuration + @EnableAutoConfiguration + @ComponentScan。
    • @Controller/@RestController：Web 入口；@Service：业务层；@Repository：数据层。
    • @Autowired/@Resource：依赖注入；@ConfigurationProperties：配置绑定。
  • 约定优于配置：默认端口 8080、默认打包 jar、内嵌 Tomcat。

工程结构

启动类与依赖注入

[!note] 依赖注入方式
推荐构造器注入（final 字段，便于测试与不可变）；@Autowired 字段注入简洁但不利于测试与循环依赖检测；@Resource 按名称注入（Jakarta 标准）。

打包与运行

常见坑

  1. 扫描范围：启动类在包根目录，@ComponentScan 默认扫描其所在包及子包。
  2. 循环依赖：构造器注入可检测；字段注入可能隐藏循环依赖（Spring Boot 2.6+ 默认禁止循环引用）。
  3. 端口占用：改 server.port 或用 --server.port=0 随机端口。
  4. 配置文件编码：中文用 UTF-8；YAML 缩进错误是常见报错源。
  5. RestTemplate 连接泄漏：用 closeable 或换 WebClient。
  6. 实体 JSON 循环引用：双向关联用 @JsonIgnore/DTO。
  7. 热部署：devtools 依赖 + 自动重启，生产不要带。

最佳实践

  • 包结构按分层（controller/service/repository/model），清晰职责。
  • 统一异常处理：@RestControllerAdvice + 错误码对象。
  • 使用 DTO 与实体分离，不直接暴露 JPA 实体。
  • 配置外部化：环境差异用 profile（dev/prod）。
  • 校验入参（spring-boot-starter-validation 的 @Valid + @NotBlank）。
  • 结合 17-Maven与Gradle 管理依赖，19-测试 保证质量。
