常见坑

  1. 提交前未 git status：误提交无用文件，养成先看再提交。
  2. 大文件入仓：超过 100MB 用 Git LFS，勿直接提交。
  3. 敏感信息提交：.env/密钥必须忽略，泄露后立即轮换。
  4. git pull 合并冲突：先 commit 本地再 pull，或 stash。
  5. commit 消息含糊：见 09-提交信息规范。

最佳实践

  • 小步提交：一个逻辑变更一次 commit。
  • 提交前运行 format + lint + test。
  • 远程协作遵循团队工作流（见 03-05）。
  • 深入学习：02-Git分支与合并。
