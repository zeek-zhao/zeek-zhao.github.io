09-自动化规则

When（触发器）→ If（条件）→ Then（动作）
📅 2026-10-24· 更新于 2026-10-24 ✍ zeek.zhao #工具#jira

自动化规则

📑让 Jira 自己干活
自动化规则 = 触发器 + 条件 + 动作。解决重复性操作：自动指派、到期提醒、状态联动。

1. 规则组成¶

组件 例子
触发器 Trigger 问题被创建 / 字段变更 / 评论添加 / 定时
条件 Condition 项目=PAY / 优先级=High / 经办人=空
动作 Action 指派 / 改字段 / 发邮件 / 调 Webhook / 转状态

3. 自动化编辑器（Automation for Jira）¶

⚙ → System → Automation rules → Create rule：

图形化拖拽即可配置；支持模板（”Issue 到期前提醒”等）。

📝规则范围
单项目规则或全局规则；全局规则要有管理员审批，防误伤。

4. 规则编写原则¶

  • 幂等：重复触发结果一致（加条件防重）；
  • 防循环：规则改字段可能再触发规则，用条件终止；
  • 日志审计：启用规则审计日志，出问题可回看；
  • 限量：海量问题触发（批量导入）先测小范围。

5. 高级动作¶

⚠️注意
  • 自动化规则执行有限制（Server 默认全局 N 次/分钟），超限任务会排队/跳过；
  • 定时触发用服务器时区，跨时区团队注意。
