Java 从入门到精通 - 学习路线索引

[!info] 本目录简介
本目录包含 22 篇 Java 教程，覆盖环境搭建、基础语法、面向对象、集合、泛型、异常、IO/NIO、多线程、JVM、注解反射、Lambda/Stream、JDBC、Spring Boot、构建工具、测试、性能调优与工程实践，从入门到精通循序渐进，每篇均含可运行示例与实战要点。

学习路线总览

  1. 入门阶段（01-03）：环境与构建工具、基础语法、运算符与控制流。
  2. 面向对象阶段（04-05）：类与对象、封装继承多态、接口与抽象类。
  3. 核心 API 阶段（06-09）：集合框架、泛型、异常、IO 与 NIO。
  4. 并发与 JVM 阶段（10-12）：多线程基础、JUC 并发工具、JVM 内存与 GC。
  5. 高级特性阶段（13-14）：注解与反射、Lambda 与 Stream。
  6. 数据与框架阶段（15-17）：JDBC、Maven/Gradle、Spring Boot 入门。
  7. 质量与工程阶段（18-22）：测试、网络编程、性能调优、工程实践、综合实战。
