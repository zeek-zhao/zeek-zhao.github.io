集合框架

[!info] 本页概览
本文讲解 Java 集合框架：List/Set/Map 接口、ArrayList/LinkedList/HashSet/TreeSet/HashMap/LinkedHashMap/TreeMap、遍历方式、比较器与并发集合，配可运行示例与选型建议。

核心概念

  • 集合框架：Collection（List/Set/Queue）与 Map 两大体系。
  • List：有序可重复；Set：无序不可重复；Map：键值对。
  • 实现选择取决于：是否有序、是否唯一、是否线程安全、读写比例。
  • 泛型（见 09-泛型）让集合类型安全。

常见坑

  1. 遍历时增删元素：增强 for 删除元素抛 ConcurrentModificationException；用 Iterator.remove 或 Collectors 过滤。
  2. 自定义对象入 Set/Map 不重写 hashCode：去重失效、性能退化。
  3. HashMap 的 key 用可变对象：key 修改后 hashCode 变化，无法再查找到；用不可变 key。
  4. 初始容量不当：频繁扩容影响性能；预估容量用 new HashMap<>(预估大小 / 0.75)。
  5. List.of/Set.of 不可变：添加元素抛异常，不是静默忽略。
  6. ArrayList 与 LinkedList 选错：大量随机访问选 ArrayList；大量头尾插入选 LinkedList。
  7. null 元素：HashSet/HashMap 允许 null，TreeSet/TreeMap 不允许（排序需比较）。

最佳实践

  • 变量类型声明用接口（List/Map/Set），实现按需切换。
  • 大数据量去重排序优先 TreeSet/TreeMap 或 Stream 排序。
  • 多线程共享集合用并发集合（见 11-多线程与并发）：ConcurrentHashMap、CopyOnWriteArrayList。
  • 用 computeIfAbsent/merge 简化分组与计数。
  • 优先不可变集合（List.of、Map.of）防御性返回。
