Freestyle Job

[!abstract] 是什么
Freestyle（自由风格）是 Jenkins 最传统的任务类型：在 Web 界面点选配置源码、构建步骤、构建后动作，适合简单流程。

创建第一个 Job

  1. 首页 → New Item（新建任务）；
  2. 输入名称 demo-build，选择 Freestyle project；
  3. 配置以下区块。

基础配置

General（常规）：填写描述，勾选”丢弃旧的构建”控制磁盘：

Source Code Management（源码管理）：

Build Steps（构建步骤）：

Post-build Actions（构建后操作）：

  • Archive the artifacts：dist/** → 归档制品；
  • Publish JUnit test report：reports/*.xml → 测试报告；
  • Email Notification：失败/不稳定时通知。

构建与查看

查看：构建号、Console Output（控制台输出）、制品、测试趋势。

构建结果状态

状态 含义
SUCCESS 成功
UNSTABLE 不稳定（如测试失败但构建成功）
FAILURE 失败
ABORTED 手动中止/超时

[!tip] 何时用 Freestyle
简单部署脚本、批量任务、测试环境快速任务。**复杂流程建议用 Pipeline**：代码化、可版本控制、可复用。

[!note] Freestyle 的劣势
配置散落在 Jenkins 里、难以审计与迁移；Pipeline 把流程写进 Jenkinsfile，随仓库走。

[!warning] 注意
Shell 步骤失败时脚本默认退出码非 0 才判失败；要用 set -e 确保错误中断。
