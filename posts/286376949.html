函数基础

[!info] 本页概览
函数是程序组织与复用的基本单元。本文讲解函数的声明与定义、参数传递方式（值/指针/引用）、返回值、递归与 C++ 函数重载。

核心概念

函数把一段逻辑封装为可复用单元。声明告诉编译器函数签名，定义提供实现。C 语言中调用前必须有声明，否则编译器报错（C99 起不允许隐式声明）。

[!warning] 递归深度
每次递归占用栈空间，深度过大会栈溢出。阶乘这类问题可改用迭代；深递归考虑尾递归优化或显式栈。

C++ 函数重载与默认参数

常见坑

  1. 数组传参会退化为指针：sizeof(arr) 在函数内得到的是指针大小（8 字节）而非数组大小，必须同时传长度。
  2. 返回局部变量地址：返回栈上局部变量的指针是未定义行为，返回后指针悬空。应返回堆内存（调用方释放）或传输出参数。
  3. 默认参数写在声明处而非定义处：声明与定义分离时，默认值必须出现在声明中。
  4. 递归没有终止条件：无限递归导致栈溢出崩溃。
  5. const char* 与 char* 混用：把字符串字面量赋给 char* 在 C++ 中非法，须用 const char*。

最佳实践

  • 函数职责单一，超过 50 行考虑拆分。
  • 对外接口参数用 const 修饰只读引用（C++），避免意外修改与拷贝开销。
  • 返回错误时不要依赖特殊值（如 -1），C++ 可用异常、std::optional 或错误码明确表达。
