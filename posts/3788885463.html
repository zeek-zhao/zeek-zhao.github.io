什么是 Docker 与核心概念

[!abstract] 一句话
Docker 是容器化平台，将应用及其依赖打包成标准化单元，实现”一次构建，处处运行”。

为什么需要 Docker

传统部署依赖环境一致，应用换个机器就报错。容器把代码 + 运行时 + 依赖打包成镜像，彻底消除环境差异，秒级启动、资源占用远小于虚拟机。

三大核心概念

概念 说明 类比
镜像 Image 只读模板，包含应用与依赖 安装光盘
容器 Container 镜像的运行实例，可启动/停止 光盘运行出的进程
仓库 Registry 存放与分发镜像的服务 应用商店

镜像 vs 容器

  • 镜像是静态文件，容器是动态进程；
  • 一个镜像可启动多个容器；
  • 容器内修改不会影响镜像，除非提交为新镜像。

Docker 与虚拟机

维度 容器 虚拟机
启动速度 秒级 分钟级
资源占用 共享内核，极小 独占系统，较大
隔离级别 进程级 系统级
