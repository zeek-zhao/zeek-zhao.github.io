Web 框架入门

[!info] 本页概览
本文入门两大 Python Web 框架：Flask（轻量灵活）与 FastAPI（现代、类型安全、异步）。覆盖路由、请求/响应、模板、JSON API 与部署要点。

核心概念

  • 路由：URL 到处理函数的映射。
  • 请求对象：携带参数、JSON、表单、头信息。
  • 响应：状态码、JSON、模板渲染。
  • Flask 适合小项目与模板渲染；FastAPI 适合 API 与异步高并发。

常见坑

  1. app.run(debug=True) 上生产：debug 模式有 RCE 风险，生产用 app.run(host="0.0.0.0", port=8000) 且 debug=False，或用 gunicorn/uvicorn 启动。
  2. 同步阻塞异步事件循环：FastAPI 中 def 端点在线程池，async def 端点在事件循环；同步阻塞代码用 def 避免卡死。
  3. CORS 未配置：前后端分离跨域报错，用 CORSMiddleware 允许来源。
  4. JSON 校验缺失：直接读 body 易崩，用 Pydantic 模型（FastAPI）或手动校验（Flask）。
  5. 端口冲突/未绑定 0.0.0.0：容器或局域网访问需监听 0.0.0.0。
  6. 无版本化 API：生产 API 加 /v1/ 前缀以便演进。

最佳实践

  • 新 API 项目优先 FastAPI；需要服务端渲染网页优先 Flask/模板。
  • 路由分组、蓝图/APIRouter 拆分模块（见 07-模块与包）。
  • 日志结构化 + 请求 ID；异常统一返回 JSON 错误格式。
  • 配置走环境变量（pydantic-settings）。
  • 用 httpx 调下游、sqlalchemy 管数据库，形成完整分层。
