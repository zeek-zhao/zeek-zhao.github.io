函数与包

[!info] 本页概览
函数是 Go 的基本组成单元，包（package）是代码组织的边界。本文讲解函数声明、多返回值、命名返回值、可变参数、匿名函数与闭包，以及包的组织与 init 函数。

核心概念

Go 函数支持多返回值（常用于返回结果+错误）、命名返回值、可变参数。包通过 package 声明，小写开头的标识符包内可见，大写开头对外导出。

函数基础

函数是一等公民：匿名函数与闭包

包的组织

init 函数

每个包可以有多个 init 函数，在包初始化时按依赖顺序执行，常用于注册、读取配置。注意它不能被调用，且执行顺序与文件/依赖顺序有关，不要依赖它做复杂业务。

常见坑

  1. 忽略错误返回值：f, _ := os.Open(...) 用 _ 吞掉错误，后续必然空指针崩溃。错误必须处理或显式忽略并注释。
  2. 命名返回值与裸 return：裸 return 降低可读性，短函数可用，长函数显式写。
  3. 包名与导入路径混淆：导入路径最后一段通常是包名，但也可不同（少见），以 package 声明为准。
  4. 循环内闭包捕获变量：见 03-控制流 的坑 3，Go 1.22+ 已修复。
  5. 可变参数传 slice：sum(nums...) 用 ... 展开；直接传 slice 类型不匹配。

最佳实践

  • 错误统一放返回值最后，成功时返回 nil。
  • 函数保持简短（一屏之内），职责单一。
  • 导出标识符写文档注释（// Greet returns...），golint 强制。
  • 包名小写、简短，避免 utils/common 这种无意义包名。
