04-配置文件详解

逐段解析 Hexo 站点配置文件 _config.yml 的全部核心配置项，理解每个字段的作用。
📅 2026-10-25· 更新于 2026-10-25 ✍ zeek.zhao #工具#hexo

配置文件详解

📑一句话
_config.yml 是 Hexo 站点的大脑，理解站点信息、网址、目录、文章、分页、部署六大区块，就能完全掌控站点行为。

配置文件的层次¶

Hexo 的配置分为三层：站点级 _config.yml（根目录）、主题级 _config.butterfly.yml（推荐复制到根目录覆盖）、以及插件自带的配置段（写在站点配置内）。修改任何 YAML 后都需要 hexo clean && hexo generate 才能可靠生效。

⚠️YAML 语法红线
YAML 对缩进敏感（必须用空格、不能用 Tab），冒号后要有空格，值包含特殊字符时建议加引号。配置文件是 Hexo 报错的最常见来源。

网址与永久链接¶

url 与 permalink 是必须认真设置的两项，前者影响绝对链接生成，后者决定每篇文章的 URL 结构：

permalink 支持多种变量组合：:year/:month/:day/:title/ 是默认的日期式，:title/ 简洁但可能重名冲突，:abbrlink/（配合 abbrlink 插件）生成短链接且永不变化。链接结构一旦确定就不要频繁更改，否则已有外链与搜索引擎收录会全部失效。
