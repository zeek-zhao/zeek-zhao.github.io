常见坑

  1. 不设超时：默认永不超时，程序挂死；一律 timeout=...。
  2. r.text 编码错乱：部分站点响应头编码不对，用 r.encoding = "utf-8" 或 r.content 解码。
  3. 忽略状态码：200 不代表成功语义，用 raise_for_status()。
  4. 每次新建 Session：连接无法复用，性能差；长任务复用 Session。
  5. SSL 错误：个别环境证书问题，先更新证书（pip install --upgrade certifi），不要禁用 verify。
  6. 爬取频率过高被封：限速、重试退避、遵守 robots.txt 与 ToS。

最佳实践

  • 请求封装成函数，统一超时、重试（requests + urllib3.Retry 或 tenacity）。
  • 敏感头/令牌放环境变量。
  • 大响应用 stream=True 分块处理。
  • API 调用前后校验 schema（pydantic）。
  • 异步场景用 httpx 或 aiohttp（见 20-并发编程基础）。
