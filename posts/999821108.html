Docker 是什么

先抓住三个对象——镜像、容器、仓库，Docker 就没那么抽象了。镜像是运行环境模板，容器是镜像运行后的实例，仓库是镜像存储与分发的位置。Docker 解决的核心问题是环境不一致：传统部署里应用在不同机器上运行结果不一样，Docker 把应用和依赖打包进容器，让开发、测试、生产环境更一致。我的判断是，初学阶段不必深究底层原理，先把拉取到运行的闭环跑通，概念自然就落地了。

镜像、容器、仓库是三个核心对象¶

  • 镜像（Image）：运行环境模板。
  • 容器（Container）：镜像运行后的实例。
  • 仓库（Repository）：镜像存储与分发位置。

学习前提¶

  • 会使用 Linux 基础命令。
  • 已安装 Docker Engine。

两个验证标准¶

  • 运行 hello-world 镜像输出欢迎信息。
  • 本机访问本机 8080 端口返回 Nginx 页面。

三类常见问题¶

  • 端口冲突：更换映射端口，例如 -p 18080:80。
  • 拉取超时：检查网络或镜像源配置。
  • 权限不足：确认当前用户是否在 docker 用户组。
