模板语法与指令

[!info] 本页概览
本文讲解 Vue 模板语法：插值表达式、指令（v-bind/v-if/v-for/v-on）、条件与列表渲染、样式绑定，掌握声明式渲染的核心写法。

核心概念

  • 插值：{{ }} 双大括号输出响应式值。
  • 指令：v- 前缀的特殊属性（绑定、条件、循环、事件）。
  • 响应式：数据变化自动更新 DOM。
  • 模板内支持简单 JS 表达式（三元、方法调用），不支持语句。

v-html 会渲染原始 HTML，内容来自用户输入时有 XSS 风险，务必消毒或避免使用。

常见坑

  1. v-if 与 v-show 选错：频繁切换用 v-show（保留 DOM），首屏昂贵/条件少用 v-if。
  2. **v-for 不写 :key**：列表更新错乱与警告；用唯一 id 而非 index。
  3. v-for 与 v-if 同元素：Vue 3 中 v-if 优先级更高，同元素两者可能不符合预期，用 template 分离。
  4. 模板内写复杂语句：模板只放简单表达式，复杂逻辑放 computed/方法。
  5. v-html XSS：只渲染可信内容。
  6. 事件修饰符顺序：@click.stop.prevent 与 @click.prevent.stop 都生效，但语义不同（先 stop 再 prevent 或反之）。

最佳实践

  • 统一 :key 使用稳定唯一标识，避免 index。
  • 模板保持可读：逻辑上移（computed/函数），模板只做展示。
  • 列表渲染大数组用 v-memo（性能）或分页。
  • 使用 $event 显式传事件对象，参数顺序清晰。
  • 语义化标签 + 合理使用 template 包裹多元素。
