同步发布与分享

[!abstract] 一句话
Obsidian 的同步管数据流转、发布管知识输出——本文把 Remotely Save、Digital Garden、Webpage HTML Export、Easy Bake、Enhancing Export 五个插件串成一条从”多设备同步”到”对外分享”的完整链路。

同步：Remotely Save 全能方案

Remotely Save 是独立于官方 Sync 的多功能同步插件，支持 S3 兼容存储、Dropbox、OneDrive、WebDAV 和本地文件夹五类目标，具备冲突处理、版本历史和端到端加密，是自建同步方案的首选。

配置 S3 兼容存储（含自托管 MinIO）：

  1. 设置 → Remotely Save → 选择”S3 或兼容 S3 的服务”
  2. 填入端点 URL、区域（如 us-east-1）、存储桶名称、Access Key ID 与 Secret Key
  3. 可选配置自定义路径前缀，点击”验证连接”测试

配置 WebDAV（坚果云等）：

  1. 选择”WebDAV”，输入服务器地址与端口
  2. 指定用户名密码，填写子路径（如 /dav 或 /remote.php/webdav）
  3. 点击”检查连接”验证

基础同步策略：在”同步范围”中决定是否同步插件与主题、是否保留历史版本；用排除规则过滤 .tmp、.DS_Store、.trash 等噪音；开启自动同步后设置间隔（如 30 分钟），并配置应用启动时、文件修改后等触发条件。冲突处理有三种策略：保留较新版本、保留两者（加后缀）、总是询问，多设备用户建议”保留两者”以降低误覆盖风险。

[!tip]
新设备首次接入时选择”拉取”操作获取远程内容，再开始本地编辑；如使用端到端加密，所有设备必须使用相同密码，且密码一旦丢失无法恢复——务必存入密码管理器。

发布：Digital Garden 数字花园

Digital Garden 把库中的部分笔记发布为公开可探索的网站，保留双向链接和图谱，强调”网状互联”而非博客的时间轴结构。

初始设置：

  1. 在 GitHub 新建公共仓库，生成勾选 repo 权限的个人访问令牌（PAT）
  2. 在插件设置中填入 GitHub 用户名、仓库名、令牌
  3. 设置站点名称、标语、作者并选择主题

发布控制靠前置元数据：

dg-publish: true 标记可发布；dg-home: true 设为首页；dg-exclude 可排除特定章节，实现”同一库内混合私人笔记与公开笔记”。发布用命令面板执行”DIGITAL GARDEN: 发布此笔记”或批量发布全部已标记笔记。

发布：Webpage HTML Export 静态导出

需要完全自主掌控时，Webpage HTML Export 可将单篇或整库导出为标准 HTML，保留主题样式、内部链接与图片，支持资源内联（base64）、路径重写和增量导出。

  • 单文件导出：命令面板搜索”Export to HTML”
  • 批量导出：执行”Batch Export to HTML”，选择范围（全部/特定文件夹）与是否只导出已修改文件
  • 自定义模板支持 {{content}}、{{title}}、{{date}}、{{tags}} 变量注入，可加自定义 CSS/JS
  • 可直接部署到 GitHub Pages、Netlify/Vercel 或传统服务器

[!warning]
导出前务必用标签或 YAML 属性设置公开/私密的标记系统，配置敏感信息过滤规则，避免把私人笔记带进公开站点。

效率补强：Easy Bake 与 Enhancing Export

Easy Bake 把模板生成简化为”一键烘焙”：创建”食谱”（Recipe），用 {{date}}、{{title}} 等变量和 {{#if}} 条件逻辑生成标准化内容，支持批量烘焙与嵌套食谱，还可通过 {{templater:COMMAND}} 调用 Templater 的全部函数。它适合会议记录、周报、文献笔记等重复结构，比内置模板灵活得多。

Enhancing Export 扩展导出能力至 PDF、Word、HTML、LaTeX 等格式：支持自定义模板、元素处理器（代码块高亮、数学公式渲染、表格对齐）、预处理/后处理脚本和批量导出。学术论文可配置 APA/MLA 引用格式并自动生成目录；配合 Dataview 可将查询结果转成静态表格再导出。

[!tip]
把两者串起来：Easy Bake 生成规范初稿 → Linter 清洗格式（见 20-维护与清理）→ Enhancing Export 按预设导出成品，形成可复用的发布流水线。

方案选型速查

需求 推荐方案 特点
多设备同步（自建/免费额度） Remotely Save 多后端、可加密、细粒度控制
官方一站式同步 Obsidian Sync 体验最好、付费
免费公开网站 Digital Garden 保留双链与图谱
完全自主托管 Webpage HTML Export 静态 HTML、模板自由
重复内容标准化 Easy Bake 图形化食谱配置
专业文档导出 Enhancing Export PDF/Word/LaTeX 多格式

[!note] 2026 更新
官方 Obsidian Sync 与 Publish 均为付费服务；1.12（2026-02）推出了 Sync Headless Client（无头同步客户端），可在无图形界面的环境中运行同步，适合服务器与自动化场景；官方路线图还包含移动端后台同步。官方 Publish 设置最简单但年费约 $192 且自定义有限——预算敏感的用户，Digital Garden + GitHub Pages 仍是最成熟的免费替代。
