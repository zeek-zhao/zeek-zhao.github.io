安装部署 - Docker

[!info] 本篇目标
使用 Docker Compose 快速部署 GitLab 社区版，理解数据卷、端口与升级注意事项，适合快速验证、临时环境和容器化运维团队。

1. 前置条件

  • Docker Engine 20.10+，Docker Compose v2
  • 磁盘建议 SSD，容器数据目录预留充足空间
  • 内存建议不低于 4 GB

2. 编写 docker-compose.yml

[!warning] 端口冲突
宿主机已占用 80/443 时，可映射为 8080:80、8443:443，同时将 external_url 改为 https://gitlab.example.com:8443，否则 Git 地址会算错端口。

3. 启动

首次启动会执行 reconfigure，通常需要 3~5 分钟，可通过健康检查确认：

4. 数据卷说明

卷 宿主机目录 内容
config ./config gitlab.rb、密钥、证书
data ./data Git 仓库、数据库、上传文件
logs ./logs 各组件日志

[!danger] 备份密钥
config/gitlab-secrets.json 与 config/ssh_host_*_key 一旦丢失，将无法解密既有数据，务必纳入备份体系。完整备份方法见 10-备份恢复。

5. 常见调整

[!tip] 资源限制
生产环境建议显式限制资源，防止容器吃满宿主机：
deploy: resources: limits: memory: 8g, cpus: '4'（Swarm 模式）或运行时 docker update --memory 8g gitlab。

[!note] 数据持久化验证
升级或迁移后应验证：docker exec gitlab gitlab-rake gitlab:check 通过、仓库能 clone、Pipeline 能触发，再清理旧容器。
