FreeFileSync 用户指南

我用 FreeFileSync 做文件夹比较和同步，是因为它免费、跨平台，既能当备份工具也能做实时同步。这篇把 Windows、macOS、Linux 的安装，三种同步模式，以及过滤器、版本控制、RealTimeSync 的配置都收齐了。

免费开源的文件夹比较与同步工具，适合做备份¶

FreeFileSync是一款开源的文件夹比较和同步软件，它帮助您同步文件和同步文件夹，创建和维护备份的理想工具。它设计简单易用，但功能强大，适合个人和专业用户。

三个平台都能从官网下载安装¶

Windows¶

  1. 访问官方网站
  2. 点击”Download”按钮
  3. 下载Windows版安装程序
  4. 运行安装程序并按照向导完成安装

macOS¶

  1. 访问官方网站
  2. 点击”Download”按钮
  3. 下载macOS版安装包
  4. 打开DMG文件并将应用拖到Applications文件夹

Linux¶

  1. 访问官方网站
  2. 点击”Download”按钮
  3. 下载Linux版安装包（通常为AppImage或tar.gz格式）
  4. 根据Linux发行版进行适当安装：

七项主要功能覆盖比较、同步、过滤与冲突处理¶

  • 文件夹比较：快速比较两个文件夹的内容
  • 智能同步：多种同步方式（镜像、双向、更新）
  • 实时同步：使用RealTimeSync组件实现文件变更的自动同步
  • 批处理：保存同步配置并自动执行
  • 过滤器：按名称、大小、日期等过滤文件
  • 版本控制：保留删除和覆盖文件的历史版本
  • 冲突检测：检测并解决同步冲突

界面分为比较区域、菜单栏、工具栏和状态栏¶

FreeFileSync的界面分为几个主要部分：

  1. 比较区域：显示左右两个文件夹的内容比较
  2. 菜单栏：包含所有功能的访问入口
  3. 工具栏：常用功能的快捷按钮
  4. 状态栏：显示比较和同步操作的状态信息

选对同步模式比点同步按钮更关键¶

创建同步任务¶

  1. 启动FreeFileSync
  2. 在左侧面板中，点击”浏览”按钮选择源文件夹
  3. 在右侧面板中，点击”浏览”按钮选择目标文件夹
  4. 点击”比较”按钮分析两个文件夹的差异
  5. 查看比较结果，确认要同步的文件
  6. 选择同步方式（镜像、双向或更新）
  7. 点击”同步”按钮开始同步过程

同步模式说明¶

  • 双向同步：将更改从左到右和从右到左传播，保持两侧更新
  • 镜像：使右侧与左侧完全一致，删除右侧多余的文件
  • 更新：只将新的和修改过的文件从左复制到右

我判断镜像模式风险最高：它会删除右侧多余文件，首次使用前务必用模拟运行确认差异列表。

保存配置¶

  1. 完成设置后，点击菜单中的”文件” > “保存为…”
  2. 为配置文件指定名称和位置
  3. 下次使用时，可以直接打开此配置文件恢复所有设置

过滤器、版本控制和 RealTimeSync 应对进阶场景¶

过滤器设置¶

  1. 点击工具栏中的”过滤器”按钮
  2. 添加要包含或排除的文件模式
  3. 可以按名称、路径、大小、日期等进行过滤
  4. 示例排除模式：*.tmp, *.bak, thumbs.db

版本控制¶

  1. 点击”同步”按钮旁边的齿轮图标
  2. 选择”版本控制”选项
  3. 配置要保留版本的位置和命名模式
  4. 设置版本保留策略（保留数量、时间等）

使用RealTimeSync¶

  1. 启动RealTimeSync组件（随FreeFileSync安装）
  2. 设置要监视的文件夹
  3. 指定FreeFileSync配置文件
  4. 设置触发条件（延迟时间等）
  5. 点击”开始”开始实时监控

冲突、云存储与自动执行是最高频的三类问题¶

Q: 如何处理同步冲突？¶

A: 当双向同步时，如果同一文件在两边都被修改，FreeFileSync会检测到冲突并提示您选择保留哪一边的文件，或保留两者。

Q: FreeFileSync支持云存储同步吗？¶

A: 是的，您可以同步到挂载为本地驱动器的云存储，如OneDrive、Dropbox或Google Drive。

Q: 如何自动执行同步？¶

A: 创建批处理任务并使用操作系统的任务调度器（Windows的任务计划程序、Linux的cron、macOS的launchd）定期运行它。

五条技巧能让同步配置更稳¶

  • 使用变量：在路径中使用环境变量如%USERPROFILE%（Windows）或$HOME（Linux/macOS）使配置更可移植
  • 首次同步测试：首次使用前，可以开启”模拟运行”选项，查看会发生的变化而不实际执行
  • 定期备份：设置重要数据的定期自动同步，确保数据安全
  • 使用排除列表：排除临时文件、缓存和不需要同步的大文件以提高效率
  • 检查日志：执行同步后查看日志文件，确保没有错误发生
