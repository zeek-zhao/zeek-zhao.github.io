Python 资料索引指南

[!important] 使用说明
本指南整理 Python 学习所需官方文档、经典书籍、在线教程、GitHub 仓库与中文资源，按”入门→进阶→精通”组织，配合本目录 22 篇教程使用。

七、学习路线建议

  1. 入门：官方 Tutorial + 廖雪峰教程，做简单脚本（文件处理、爬虫）。
  2. 巩固：《Python 编程：从入门到实践》项目实战；掌握数据结构、异常、模块。
  3. 进阶：《流畅的 Python》深入语言机制；学 asyncio、类型注解、装饰器。
  4. 方向选择：Web 开发（FastAPI/Django）、数据分析（pandas/numpy/matplotlib）、自动化（selenium/requests）。
  5. 工具链：uv + ruff + mypy + pytest + pre-commit 全流程规范。

[!tip] 核心理念
Python 的价值在生态与生产力。掌握核心语法后，按方向深耕（Web/数据/AI），参与开源、写博客输出，是最好的进阶路径。
