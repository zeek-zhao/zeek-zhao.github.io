Docker 安装与初体验

[!note] 选择安装方式
本机为 Windows 时安装 Docker Desktop（WSL2 后端）；Linux 用官方脚本；macOS 同样用 Docker Desktop。

安装步骤（Windows）

  1. 下载 Docker Desktop 并安装，勾选使用 WSL2；
  2. 安装后启动，等待引擎 Running；
  3. 验证：docker --version、docker info。

运行第一个容器

[!tip] 结果
出现 “Hello from Docker!” 即成功。本地无镜像时会自动从 Docker Hub 拉取。

常用命令速览

命令 作用
docker ps 查看运行中容器
docker ps -a 查看全部容器
docker images 查看本地镜像
docker version 查看版本

图形化界面

Docker Desktop 提供镜像、容器、卷的可视化管理，适合观察运行状态；日常操作仍建议命令行。

[!warning] 常见问题

  • 引擎无法启动：确认 WSL2 已开启并更新内核；
  • 拉取超时：配置镜像加速器。
