安装部署 - Omnibus

[!info] 本篇目标
使用官方 Omnibus 软件包在一台 Linux 服务器上完成 GitLab 的安装、基础配置与 HTTPS 启用，适合单机起步场景。

1. 准备工作

Omnibus 安装包自带 Nginx、PostgreSQL、Redis、Gitaly 等全部组件，只需准备一台干净服务器。推荐配置参考：

规模 CPU 内存 磁盘
小型团队（≤100 用户） 2 核 4 GB 100 GB SSD
中型团队（≤500 用户） 4 核 8 GB 500 GB SSD

[!warning] 系统要求
官方仅支持受支持的发行版（如 Ubuntu 20.04/22.04、Rocky 8/9、Debian 11/12）。关闭 SELinux 或按官方文档配置策略，否则 Git 操作可能异常。

2. 安装步骤（以 Ubuntu 为例）

安装完成后 GitLab 会自动 reconfigure 并启动。EXTERNAL_URL 是关键，决定 Web 地址与生成的证书域名。

3. 初始配置

修改 /etc/gitlab/gitlab.rb 后执行 gitlab-ctl reconfigure 生效。常见配置项：

[!tip] 首次登录
首次访问 https://gitlab.example.com 使用 root 用户与 /etc/gitlab/initial_root_password 中的初始密码（或上面设置的自定义密码）登录，登录后务必立即修改。

4. 启用 HTTPS

Omnibus 默认生成自签名证书。生产环境推荐使用 Let’s Encrypt：

[!note] 自定义证书
已有商业证书时：将证书放到 /etc/gitlab/ssl/，命名为 <域名>.crt 与 <域名>.key，并设置 nginx['redirect_http_to_https'] = true 后 reconfigure。

5. 常用运维命令

[!danger] 注意
gitlab-ctl reconfigure 会重写配置并可能重启服务，应在维护窗口执行；修改 gitlab.rb 前先备份该文件。
