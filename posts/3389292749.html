Redis 高级特性

[!info] 本页概览
本文讲解 Redis 高级特性与业务实践：缓存一致性、缓存穿透/击穿/雪崩三大问题、分布式锁（SETNX/Redisson）、Lua 脚本原子性、消息队列（Stream）、布隆过滤器与性能优化，配命令与伪代码。

核心概念

  • 缓存一致性：缓存与数据库数据保持一致的核心问题。
  • 穿透：查不存在的数据，绕过缓存打 DB。
  • 击穿：热点 key 过期瞬间大量请求打 DB。
  • 雪崩：大量 key 同时过期导致 DB 压力爆掉。
  • 分布式锁：多实例下互斥访问共享资源。
  • Lua 脚本：多条 Redis 命令原子执行。

常见坑

  1. 缓存与 DB 不一致：删缓存失败未补偿 → 消息队列重试。
  2. 分布式锁过期：业务未完成锁已释放 → Redisson 续期。
  3. 锁误删他人锁：释放时 Lua 校验持有者。
  4. 布隆过滤器误判：允许”误拦不存在”，业务上可接受才用。
  5. 雪崩未防：缓存 TTL 无随机值，重启后 DB 被打爆。
  6. 热点 key 单点：热 key 加后缀拆分成多个逻辑 key。

最佳实践

  • 缓存尽量”查多写少”且可容忍短暂不一致。
  • 写路径：DB 为主，缓存异步失效。
  • 压测验证缓存策略（命中率、回源 QPS）。
  • 结合 12-Redis 入门与常用命令、13-Redis 持久化与集群 形成完整方案。
