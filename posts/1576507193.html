Hexo 资料索引指南

  • 部署：hexo-deployer-git、hexo-deployer-rsync（见 11-部署方式总览）

部署平台都有现成 Hexo 模板¶

  • GitHub Pages / Actions：docs.github.com（见 12-GitHub Actions自动部署）
  • Vercel、Netlify、Cloudflare Pages：官方文档均有 Hexo 模板

排障先看 Discussions 和 Issues¶

  • GitHub Discussions / Issues：框架与主题排障第一入口
  • 中文社区：各主题官网文档（Butterfly 文档最完善）与开发者博客圈
