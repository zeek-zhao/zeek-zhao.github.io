函数与作用域

[!info] 本页概览
函数是 Python 代码复用的核心。本文讲解函数定义、参数类型（位置/关键字/默认/可变）、返回值、作用域规则（LEGB）、闭包与 lambda 表达式。

核心概念

  • 函数是一等对象：可作为参数、返回值、存入容器。
  • 参数类型丰富：位置参数、关键字参数、默认值、*args/**kwargs。
  • 作用域 LEGB：Local → Enclosing → Global → Builtin，逐层查找。
  • 闭包：内层函数引用外层变量，实现”携带状态”的函数。

常见坑

  1. 可变默认参数：def f(x=[]) 默认列表被所有调用共享，改 def f(x=None): x = [] if x is None else x。
  2. 闭包循环变量：lambda 在循环中捕获的是最终值，需 lambda i=i: i 绑定默认值。
  3. global 乱用：少用全局变量；修改容器元素不需要 global，重新赋值才需要。
  4. *args 与关键字混淆：**kwargs 是字典；注意调用时 f(**d) 展开。
  5. 返回 None 与返回值的混淆：无 return 返回 None，比较时 is None。
  6. 过早抽象：单次使用的代码不要强行抽函数；函数应单一职责、命名表达意图。

最佳实践

  • 函数命名动词开头：get_user、calculate_total。
  • 写文档字符串，复杂参数用类型注解（见 19-类型注解与异步编程）。
  • 默认参数必须是不可变对象（None、数字、字符串、元组）。
  • 参数过多（>5）考虑用数据类打包。
  • 用 functools.partial 固化参数：from functools import partial; twice = partial(int, base=2)。
