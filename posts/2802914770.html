基础语法与数据类型

[!info] 本页概览
本文讲解 Java 基础语法：程序结构、标识符与关键字、基本数据类型、字面量、变量、类型转换、包装类型与自动装箱拆箱。

核心概念

  • Java 是强类型、面向对象语言，代码运行在 JVM 上。
  • 程序入口：public static void main(String[] args)。
  • 基本类型 8 种：byte/short/int/long/float/double/char/boolean。
  • 引用类型：类、接口、数组、枚举。
  • 包装类型：Integer/Double/Boolean 等，支持自动装箱拆箱。

Java 7+ 支持数字下划线分组：1_000_000 便于阅读。

变量与作用域

  • 局部变量无默认值，使用前必须赋值。
  • 成员变量有默认值（int=0、double=0.0、boolean=false、引用=null）。

包装类型与自动装箱

常见坑

  1. 整数字面量溢出：long l = 2147483647 * 10 先按 int 计算再转 long 已溢出；用 2147483647L * 10。
  2. 浮点精度：0.1 + 0.2 != 0.3；金额用 BigDecimal。
  3. 自动拆箱 NPE：Integer n = null; int x = n; 抛 NullPointerException。
  4. **比较用 ==**：包装类型用 equals 比较值。
  5. char 与 String 混淆：char 是基本类型单字符，String 是引用类型。
  6. switch 漏 break：穿透执行；Java 14+ 可用箭头语法避免。

最佳实践

  • 金额计算用 BigDecimal，禁止 double 直接算钱。
  • 常量用 static final + 全大写命名。
  • 优先原始类型避免装箱开销；集合场景必须用包装类型。
  • 数字字面量用下划线分组提升可读性。
  • 变量命名驼峰，类名大写开头。
