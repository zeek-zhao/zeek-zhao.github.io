Resilio Sync 用户指南

Resilio Sync 前身叫 BitTorrent Sync，走的是设备直连的点对点同步路线：数据用 BitTorrent 协议在设备之间直接传，不经过第三方云服务器，私密性和容量都不受云端约束。我判断它最适合”自有设备之间同步、又不想把数据托管给云厂商”的场景，尤其是多台机器、大文件、跨网络的开发资料同步；要共享给外部协作者时，用只读或一次性密钥也更可控。

主要特点：

  • 无云存储：数据直接在设备间传输，不经过第三方服务器
  • 无容量限制：同步的数据量仅受设备存储空间限制
  • 高速传输：使用 BitTorrent 协议，最大化传输速度
  • 端到端加密：保障数据安全
  • 跨平台支持：Windows、macOS、Linux、Android、iOS 等

按平台安装：Linux 和 Docker 最值得脚本化，桌面端按向导走即可¶

Windows¶

  1. 访问 Resilio Sync 官网
  2. 点击”下载免费版”
  3. 运行下载的安装程序，按照向导完成安装

macOS¶

  1. 访问官网下载 macOS 版本
  2. 打开 DMG 文件，将应用拖到应用程序文件夹
  3. 从应用程序文件夹启动 Resilio Sync

参数说明

参数 功能
-p 8888:8888 WebUI 访问端口
-p 55555:55555 默认的数据传输端口
-e PUID=1000 用户ID，可通过 id user 命令查看
-e PGID=1000 组ID，可通过 id user 命令查看
-e TZ=Etc/UTC 时区设置
-v /config 配置文件存储位置
-v /downloads 默认下载位置
-v /sync 同步文件夹位置

首次访问

Docker 部署后，通过浏览器访问 http://your-host-ip:8888 进入 WebUI。首次使用需要设置管理员账户。

卷映射说明

  • /config: 存储 Resilio Sync 的配置文件和数据库
  • /downloads: 默认下载目录，可用于临时下载
  • /sync: 主要同步数据目录，可根据需求映射多个目录

同步文件夹的创建、加入与共享，靠密钥权限划分就够了¶

创建同步文件夹¶

  1. 打开 Resilio Sync
  2. 点击 “+” 按钮，选择 “标准文件夹”
  3. 选择要同步的文件夹
  4. 设置权限（读写或只读）
  5. 点击 “生成密钥” 或 “QR 码”

添加同步文件夹¶

  1. 点击 “+” 按钮，选择 “输入密钥或扫描 QR 码”
  2. 输入共享密钥或扫描 QR 码
  3. 选择本地保存位置
  4. 点击 “连接” 开始同步

共享文件夹¶

  1. 在已创建的同步文件夹上点击 “共享”
  2. 选择共享方式：
    • 读写密钥：允许他人修改文件
    • 只读密钥：只允许他人下载文件
    • 一次性密钥：24小时内一次性使用
  3. 通过电子邮件、消息或二维码共享密钥

选择性同步¶

  1. 在文件夹设置中找到 “选择性同步”
  2. 勾选需要同步的文件或文件夹
  3. 应用更改

性能调整¶

  1. 前往 “首选项” > “高级”
  2. 调整：
    • 下载/上传速率限制
    • 使用的 CPU 百分比
    • 磁盘缓存大小

密钥和版本历史是数据安全的底线¶

密钥安全¶

  • 保存所有生成的密钥，建议使用密码管理器
  • 对重要数据使用加密密钥（在创建文件夹时选择）

备份策略¶

  • 使用 “存档” 功能保留已删除文件的历史版本
  • 配置 “版本历史” 以保存文件的多个版本

连不上、同步慢、冲突文件，按这三步排查¶

同步问题¶

  • 无法连接：检查网络连接和防火墙设置
  • 同步缓慢：验证网络带宽和设备性能
  • 冲突文件：处理 .sync 目录中的冲突文件

常见错误¶

错误 解决方案
权限拒绝 检查文件/文件夹权限
存储空间不足 清理设备存储空间
网络超时 检查网络连接，增加超时时间

与 Obsidian 配合使用¶

  1. 创建 Obsidian 保险库文件夹
  2. 使用 Resilio Sync 同步该文件夹
  3. 注意同步 .obsidian 目录以保持设置一致
  4. 考虑使用 .sync/IgnoreList 排除不需要同步的插件缓存

多设备工作流¶

  • 在家/办公室：使用读写密钥完全同步
  • 移动设备：使用选择性同步节省空间
  • 不常用设备：使用只读密钥作为备份
