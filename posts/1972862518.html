03-语法基础

发表于2026-10-25|groovy
|浏览量:

[!info] 本节目标
快速掌握 Groovy 的语法骨架，为后续特性学习打基础。

1. 变量与类型

Groovy 使用 def 声明变量，类型由赋值推断，也可以显式声明类型。变量分为局部变量、字段与属性，属性通过 getter/setter 自动生成。基本类型在 Groovy 中自动装箱，数值运算与 Java 行为基本一致。

Groovy 是动态语言，变量可以在运行时改变类型，这带来灵活性的同时要求开发者注意运行时类型。

2. 字符串与文本

Groovy 支持多种字符串形式：单引号普通字符串、双引号 GString（可插值）、三引号多行字符串、斜杠字符串用于正则。插值语法让文本拼接简洁直观，是 Groovy 最受欢迎的语法糖之一。

多行字符串常用于模板文本与文档字符串，斜杠字符串让正则表达式不再需要大量转义。

3. 运算符

Groovy 运算符在 Java 基础上扩展：Elvis 运算符提供简洁的空值默认值，安全导航避免空指针，展开运算符批量调用方法，范围运算符生成区间，飞船运算符实现三向比较。

运算符还可以重载，让自定义类型获得自然的运算语义。优先级与 Java 一致，新增运算符均为语法糖，不改变语言心智模型。

4. 流程控制

if/else、switch、for、while 与 Java 语法基本一致，但 switch 支持任意类型与闭包条件，更加灵活。Groovy 的 for 可以直接遍历集合与范围，无需索引变量。

Groovy 3+ 支持 Java 风格 switch 表达式与箭头语法，代码更紧凑。break、continue、return 语义与 Java 相同。

5. 方法定义

方法定义支持 def 关键字、显式返回类型与默认参数。参数可以带默认值，调用时可以省略。方法是值传递语义，对象引用传递。

Groovy 方法支持命名参数调用，配合 Map 参数可以实现可读性极高的调用形式，是构建 DSL 的基础能力。

6. 与 Java 语法差异

Groovy 语句末尾分号可省略，return 可省略，方法调用括号可省略（有歧义时需保留）。默认导入 java.lang、java.util、java.io 等包，import 更少。

这些差异让代码更简洁，但对 Java 开发者来说需要适应省略的边界，建议项目内统一风格。
