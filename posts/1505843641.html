[!info] 本节目标
掌握 FreeRTOS+TCP 协议栈集成方法。

1. FreeRTOS+TCP 概述

FreeRTOS+TCP 是官方 TCP/IP 协议栈，专为嵌入式系统设计，支持 TCP、UDP、IP、ARP、DHCP 与 DNS 等核心协议。栈体积小、可裁剪，与 FreeRTOS 内核深度集成，事件驱动设计高效省内存。

2. 网络接口集成

协议栈通过网络接口驱动接入硬件，需移植 MAC 驱动与 PHY 配置。驱动提供发送与接收函数，栈处理协议逻辑。缓冲区管理与中断接收配合实现高效数据路径。

3. Socket API

提供类似 BSD 的 Socket 接口，支持 Socket 创建、绑定、连接、发送接收与关闭。API 可与任务集成，阻塞调用由内核调度。Socket 操作基于事件通知，非阻塞模式也可用。

4. 协议栈配置

FreeRTOSIPConfig.h 配置 IP 地址、子网、MAC、缓冲区与协议选项。支持 DHCP 自动获取地址或静态配置。内存缓冲池大小影响吞吐，按负载配置。安全选项按需求裁剪。

5. 服务器与客户端

可构建 TCP 服务器监听连接，处理多客户端会话；也可作为客户端连接远程服务。任务模型管理连接生命周期，超时与错误处理完备。UDP 用于轻量数据交换。

6. 与内核集成

协议栈依赖内核调度与定时器，事件由网络任务处理。低功耗模式下网络接口管理需协调，休眠期间断开连接。跟踪工具观察网络事件辅助调试。

7. 实践要点

先跑通回环与 DHCP 再开发应用。缓冲池大小按吞吐与内存平衡，超时配置合理。安全场景考虑 TLS 层。网络调试抓包对比协议行为，结合日志定位问题。

8. 网络调试与性能优化

协议栈调试结合抓包工具观察报文交互，确认 ARP、DHCP 与 TCP 状态机行为符合预期。吞吐瓶颈常见于缓冲池不足与发送阻塞，按负载调整缓冲数量与大小。窗口与重传参数影响弱网表现，按应用场景调优。零拷贝接口减少内存拷贝提升吞吐，需管理生命周期避免悬挂。网络与任务优先级协调，保证协议栈及时处理事件，避免缓冲堆积与连接超时。
