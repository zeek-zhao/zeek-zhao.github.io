表单处理与 v-model

[!info] 本页概览
本文讲解 Vue 表单处理：v-model 各控件用法、修饰符、表单校验、自定义表单组件、受控与非受控，构建可靠表单交互。

核心概念

  • v-model：value 属性 + input 事件的语法糖（Vue 3）。
  • 修饰符：.trim、.number、.lazy。
  • 表单校验：前端校验（必填、格式）+ 后端确认。
  • 复杂表单建议封装字段组件 + 统一校验。

常见坑

  1. checkbox 组必须初始为数组：hobby: []，否则绑定异常。
  2. number 修饰符不生效：v-model.number 只对能 parseFloat 的输入转换；空串返回原串。
  3. trim 后校验：先 trim 再校验，避免空格通过。
  4. 表单 reset 不清理自定义状态：用 form.value = { ...initial } 重建。
  5. 中文输入法 composition 问题：输入拼音时 input 事件触发；需要时用 compositionend 处理。
  6. 受控组件清空：:value 与 @input 同时设置时保持单一数据源，避免 DOM 与 state 不一致。

最佳实践

  • 表单数据集中在一个 reactive/ref 对象，提交/重置/校验统一处理。
  • 校验逻辑抽函数或 composable（useForm），复用于多表单。
  • 生产表单建议用成熟方案：VeeValidate / Element Plus 表单组件。
  • 提交按钮 loading + disabled 防重复提交。
  • 真实项目必做后端二次校验，前端校验只是体验优化。
