环境与虚拟环境

[!info] 本页概览
本文讲解 Python 安装、交互式解释器、pip 包管理，以及虚拟环境（venv）——每个项目独立依赖的关键实践。理解这些是 Python 工程化的第一步。

核心概念

虚拟环境（virtual environment） 是独立的 Python 运行时目录：每个项目有自己的一套包，互不污染系统环境。现代 Python 标准库自带 venv 模块，无需额外安装。

常见坑

  1. pip 装到系统 Python：未激活虚拟环境直接 pip install 污染全局；用 pip -V 确认路径。
  2. PATH 未生效：Windows 安装后重启终端；python 不识别时用 py -3.12。
  3. Python 2/3 共存：老机器可能默认 python2，明确用 python3 或 py -3。
  4. requirements 与平台相关包：pip freeze 会带上平台特定包（如 Windows 的 pywin32），跨平台共享用 pyproject 更稳。
  5. 虚拟环境目录被提交到 git：.venv 必须加入 .gitignore。
  6. 中文乱码：Windows 终端运行 Python 输出 UTF-8 时设置 PYTHONUTF8=1 或 chcp 65001。

最佳实践

  • 每个项目必建虚拟环境，装依赖前先激活。
  • 用 requirements.txt 或 pyproject 锁定依赖，配合 pip-tools/uv 管理。
  • 项目根放 .python-version 与 .gitignore。
  • 升级 pip：python -m pip install --upgrade pip。
  • 国内源加速：pip install -i https://pypi.tuna.tsinghua.edu.cn/simple <pkg>。
