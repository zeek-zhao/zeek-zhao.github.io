动画与过渡

[!info] 本页概览
本文讲解 Vue 动画体系：Transition 单元素过渡、TransitionGroup 列表过渡、CSS 过渡/动画类、JS 钩子与状态过渡，做出流畅界面动效。

核心概念

  • **<Transition>**：包裹单个元素/组件，进入/离开过渡。
  • **<TransitionGroup>**：列表整体增删移动过渡。
  • 过渡类名约定：v-enter-from / v-enter-active / v-enter-to 等。
  • CSS 过渡（transform/opacity）性能优于宽高动画。

JS 钩子

常见坑

  1. Transition 需要单个根元素：多个元素用 <template> + v-if/else 对，或 key 区分。
  2. mode 不设导致重叠：进入/离开同时进行；用 mode="out-in" 或 "in-out"。
  3. 列表动画 position absolute：删除项不设置 absolute 会挤压其他项跳动。
  4. CSS 动画类名拼错：name=”fade” 时类名 fade-enter-from（不是 fade-from）。
  5. 初始渲染动画：appear 属性让首次渲染也走过渡。
  6. display:none 与过渡冲突：v-if 与 v-show 过渡行为不同，v-show 只有 opacity/color 类过渡友好。
  7. GSAP 未卸载动画：组件卸载前用 onBeforeUnmount 清理 gsap 实例/timeline。

最佳实践

  • 优先 CSS 过渡（transform/opacity），避免布局抖动（layout thrash）。
  • 列表移动动画用 FLIP 思路：TransitionGroup 的 move 类实现平滑。
  • 动画时长统一 token（300ms 基准），可关闭（prefers-reduced-motion）。
  • 复杂动效（路径动画、数字滚动）用 gsap/anime.js。
  • 过渡只在需要时加，避免过度动效影响可用性。
