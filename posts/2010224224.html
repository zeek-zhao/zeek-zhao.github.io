环境搭建与第一个程序

[!info] 本页概览
学习 C/C++ 的第一步是搭建可用的编译环境。本文以 Windows（MinGW-w64）与 Linux（gcc/g++）为例讲解环境搭建，并编写、编译、运行第一个程序。

核心概念

C 与 C++ 都是编译型语言：源码先由编译器翻译成机器码，再被操作系统加载执行。编译器是核心工具，常见的有：

  • **gcc / g++**（GNU）：Linux 默认，也通过 MinGW-w64 在 Windows 使用
  • **clang / clang++**（LLVM）：macOS 默认，诊断信息友好
  • MSVC（Visual Studio）：Windows 专属，配合 IDE 使用

环境搭建

Windows（推荐 MinGW-w64）

  1. 到 winlibs.com 下载 MinGW-w64（UCRT 运行时版本），解压到 C:\mingw64。
  2. 将 C:\mingw64\bin 添加到系统 PATH 环境变量。
  3. 命令行验证：gcc --version 应输出版本信息。

常见坑

  1. main 返回值：C 中 return 0 表示正常结束；省略时 C99 起默认返回 0，但显式写出更清晰。
  2. **#include <stdio.h> vs <iostream>**：C 的标准 IO 用 stdio.h，C++ 推荐 <iostream> + std::cout，两者不要混用风格。
  3. **编译 C++ 用 g++ 而非 gcc**：gcc 编译 .cpp 文件时不会自动链接 C++ 标准库，会报链接错误。
  4. Windows 下 ./hello 无效：Windows 可执行文件需加 .exe，直接输入 hello 或 .\hello。

最佳实践

  • 编译时始终开启警告：gcc -Wall -Wextra hello.c -o hello，把警告当错误处理（-Werror）。
  • 使用 -std=c11 或 -std=c++17 等参数锁定语言标准，避免使用编译器扩展。
  • 初次学习推荐配合调试器 gdb（见 19-调试技巧），而非只靠打印输出。
