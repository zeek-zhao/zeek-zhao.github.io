计算属性与侦听器

[!info] 本页概览
本文讲解 Vue 响应式派生数据两大工具：computed 计算属性（缓存、依赖追踪）与 watch 侦听器（副作用、深度监听、异步），并对比选择场景。

核心概念

  • computed：基于响应式依赖计算新值，有缓存，依赖不变不重算。
  • watch：侦听数据变化执行副作用（异步请求、DOM 操作、日志）。
  • watchEffect：自动追踪依赖并立即执行副作用。
  • 选择：派生展示值用 computed，响应变化做动作用 watch。

常见坑

  1. computed 里写副作用：computed 应纯函数（无副作用）；副作用放 watch。
  2. watch 侦听 getter 而非整个对象：watch(state.count) 不响应（被解构失去引用）；写 watch(() => state.count, ...)。
  3. 深度监听性能：deep: true 递归遍历大对象昂贵；尽量侦听具体路径。
  4. 异步 watch 竞态：连续触发请求乱序；用请求序号或 AbortController 保证最新。
  5. watchEffect 异步请求无限循环：副作用内改被侦听的依赖会再触发；注意写回条件。
  6. computed 与 ref 混用：模板自动解包；脚本中 .value 别漏。

最佳实践

  • 优先 computed 派生，少写模板内复杂表达式。
  • watch 用于”变化后做动作”：同步外部状态、触发请求、校验联动。
  • 用 getter 形式精确侦听，避免 deep 整对象。
  • 请求竞态统一处理：记录序号 let seq = 0; const cur = ++seq; if (cur !== seq) return;。
  • 表单联动（如省市选择）用 watch 串起依赖。
