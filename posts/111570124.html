02-安装与west工具

发表于2026-10-24|Zephyr
|浏览量:

[!info] 本节目标
搭建 Zephyr 开发环境并掌握 west 工具工作流。

1. 环境准备

开发 Zephyr 需要 Linux、macOS 或 Windows 环境，安装 Python、CMake、Ninja 与工具链。官方文档提供各平台安装指引，推荐使用虚拟环境管理 Python 依赖。环境版本匹配避免兼容问题。

2. west 工具

west 是 Zephyr 的元工具，管理多仓库源码树、构建与刷写流程。west init 初始化工作区，west update 同步模块版本，west build 构建应用。west 统一工作流简化项目管理。

3. 工作区结构

west 工作区包含 zephyr 主仓库与模块仓库，模块包括 hal、驱动与工具链相关代码。工作区清单 manifest 文件定义仓库与版本，west 按清单同步。结构清晰支撑多仓库协作。

4. 创建第一个工程

使用 west create 或模板创建应用工程，配置 board 与构建参数。west build 生成固件，west flash 下载到目标板。示例工程快速验证环境，qemu 目标无需硬件即可运行。

5. 工具链配置

Zephyr SDK 提供跨平台工具链，west 自动检测。自定义工具链通过环境变量配置，交叉编译参数统一。工具链版本与 Zephyr 版本兼容性检查，升级时验证构建。

6. 常见操作

west list 查看模块，west diff 查看修改，west status 检查状态。west manifest 管理清单，west config 配置选项。命令组合覆盖日常开发，文档查询参数帮助。

7. 实践建议

环境搭建按官方指引逐步验证，记录版本组合。使用虚拟环境隔离依赖，升级谨慎验证回归。熟悉 west 子命令提升效率，脚本化常用流程，团队共享环境配置。

8. 常见问题

环境搭建最常见的坑是依赖版本不匹配：CMake 版本过低、Python 缺少 west、dtc 未安装都会在配置阶段报错。建议按官方文档的版本要求逐项核对，并使用虚拟环境管理 Python 工具链。west init 拉取主仓库后必须执行 west update，否则 zephyr 子目录不会展开，构建时会报找不到 Zephyr 基础目录。SDK 安装路径建议固定在无中文、无空格的目录，避免工具链解析问题。安装完成后，先构建 hello_world 与 blinky 两个官方示例验证环境，再进入自己的应用开发，避免把环境问题与应用问题混在一起排查。
