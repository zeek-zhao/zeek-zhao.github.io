17-semanage管理命令

集中管理策略配置的命令行工具
📅 2026-10-24· 更新于 2026-10-24 ✍ zeek.zhao #技能#selinux
ℹ️本节目标
使用 semanage 管理布尔值、文件上下文、端口与登录映射。

1. 命令概览¶

semanage 是策略管理入口，子命令覆盖 boolean、fcontext、port、login、user、interface、node 等对象，支持 list/add/delete/modify 操作，集中管理运行时配置。

2. 布尔值管理¶

semanage boolean -l 列出全部布尔值及当前状态，semanage boolean -m -1 布尔值 永久开启。与 setsebool 相比，semanage 更利于脚本化管理与审计。

3. 文件上下文管理¶

semanage fcontext -a/-d/-l 添加、删除、列出文件上下文规则。规则以正则路径表达，持久存储于策略库，配合 restorecon 应用，是自定义路径打标的标准方式。

4. 端口管理¶

semanage port -a -t http_port_t -p tcp 8080 将端口关联类型。监听服务需其端口类型与域匹配，网络标签管理详见相关篇章。

5. 用户与登录映射¶

semanage login -a -s user_u 用户名 映射登录用户到 SELinux 用户，semanage user -l 查看用户角色。映射决定用户域与角色集，影响权限边界。

6. 备份与迁移¶

semanage export 导出配置，semanage import 导入，用于备份与多机同步。迁移后执行 restorecon 重新打标，确保标签与规则一致。

7. 综合示例¶

一次典型配置包含：semanage fcontext 定义数据目录标签并 restorecon；semanage port 添加自定义端口；semanage boolean 开启所需布尔值；semanage login 映射运维用户。组合使用各子命令即可覆盖大多数自定义场景。变更前使用 semanage export 备份配置，变更后复核列表确认生效。

8. 批量与脚本应用¶

semanage 命令可嵌入脚本批量管理多主机配置，配合幂等设计避免重复执行报错。使用 export/import 实现配置同步，脚本前校验输入路径合法性。记录变更日志便于回滚与审计。批量操作前先在测试机验证，防止配置漂移。

9. 安全管理规范¶

semanage 操作具备持久影响，生产环境应审批后执行。操作前确认对象与参数，避免误改。关键配置变更备份后操作，必要时演练回滚。规范管理保障配置安全与可追溯。
