运算符与表达式

[!info] 本页概览
运算符是构造表达式的构件。本文覆盖算术、关系、逻辑、位运算与赋值运算符，并重点讲解优先级、短路求值与自增自减陷阱。

核心概念

运算符作用于操作数产生结果，优先级决定结合顺序，结合性决定同优先级运算符从左还是从右求值。

常见坑

  1. == 与 = 混淆：if (a = 5) 会把 5 赋给 a，条件恒真。C++ 中可写 if (5 == a) 规避笔误。
  2. && 与 & 不同：&& 是逻辑短路运算，& 是位运算且不短路。a & b 中若 b 是表达式不会短路。
  3. 自增的副作用：i++ + ++i 属于未定义行为（UB），结果依赖编译器。不要在同一个表达式中多次修改同一变量。
  4. 负数取模：-7 % 3 在 C 中是 -1（向零取整），与 Python 的 2（向负无穷取整）不同。
  5. 移位负数：-1 << 2 是未定义行为；右移有符号负数由实现定义，尽量用无符号数移位。

最佳实践

  • 复杂表达式加括号，宁可多写括号也不依赖记忆优先级。
  • 判断奇偶用 (x & 1)，快速乘除 2 用移位，但可读性优先，非性能瓶颈不必刻意使用。
  • 浮点数不要用 == 比较，改用 fabs(a - b) < 1e-9。
  • 逻辑表达式把易变、副作用小的操作数放左边，利用短路减少无谓计算。
