LDAP 资料索引指南

ℹ️本节目标
汇总 LDAP 学习与运维所需的权威资料、官方文档、书籍与社区资源，形成可持续查阅的索引。

官方文档¶

来源 地址 说明
OpenLDAP 官方文档 https://www.openldap.org/doc/ 安装、配置、schema、复制的权威手册
OpenLDAP Admin Guide https://www.openldap.org/doc/admin24/ 系统管理指南（2.4/2.5/2.6 版本对应）
OpenLDAP Software FAQ https://www.openldap.org/faq/ 常见问题与坑点
IETF RFC 4510 系列 https://www.rfc-editor.org/rfc/rfc4511 LDAP 协议规范（rfc4511 协议、4512 DIT、4513 认证等）
Microsoft AD LDAP 文档 https://learn.microsoft.com/zh-cn/windows/win32/ad/ AD 与 LDAP 集成参考

标准与规范¶

  • RFC 4510-4519：LDAP 核心协议族
  • RFC 4533：syncrepl 同步复制协议
  • RFC 2307：NSS/PAM 网络信息服务 schema
  • RFC 2798：inetOrgPerson 对象类定义
  • RFC 3062：LDAP 密码修改扩展操作

书籍推荐¶

  • 《LDAP System Administration》（O’Reilly，Gerald Carter）
  • 《OpenLDAP 2.x 应用指南》国内社区译本
  • 《Understanding Active Directory》（微软 Press）
  • 《Identity, Authentication, and Access Management in OpenNetworks》

工具资料¶

  • Apache Directory Studio：https://directory.apache.org/studio/
  • ldap-toolkit / ad-ldap-sync：GitHub 开源项目
  • Keycloak LDAP 集成文档：https://www.keycloak.org/docs/latest/server_admin/
  • FreeIPA 文档（RHEL 身份方案）：https://www.freeipa.org/page/Documentation

中文社区与博客¶

  • CSDN / 掘金：搜”OpenLDAP 部署””LDAP 认证对接”
  • 51CTO 博客：Linux 运维视角的 LDAP 实践
  • SegmentFault：SSO 与 LDAP 架构讨论
  • GitHub 搜索 openldap docker：现成镜像与 compose 方案

认证与安全扩展¶

  • ppolicy overlay 文档：OpenLDAP Admin Guide 第 20 章
  • 密码散列算法：SSHA/SSHA512、Argon2 支持
  • TLS/StartTLS 配置：OpenLDAP Admin Guide 第 18 章
  • Kerberos + LDAP：krb5kdc 与 slapd 集成指南
