15-数据库编程

发表于2026-10-24|qt
|浏览量:

[!info] 本节目标
掌握 Qt SQL 模块访问与管理数据库。

1. SQL 模块概述

Qt SQL 模块提供跨平台数据库访问接口，支持 SQLite、MySQL、PostgreSQL 与 ODBC 等驱动。高层模型接口与底层查询接口分层设计，应用既可快速集成数据库，也可精细控制执行细节。

2. 连接与驱动

QSqlDatabase 管理数据库连接，addDatabase 创建连接并指定驱动与参数。SQLite 无需服务端开箱即用，适合本地应用；客户端服务器数据库配置主机、端口、用户与密码。连接复用与关闭需管理生命周期。

3. 查询执行

QSqlQuery 执行 SQL 语句，支持参数绑定避免注入风险。查询结果通过 next 遍历，value 获取字段值。事务通过 QSqlDatabase 的 transaction 与 commit 管理，保证数据一致性。预处理语句提升重复执行效率。

4. 模型与视图集成

QSqlTableModel 与 QSqlQueryModel 将查询结果映射到模型视图架构，直接关联 QTableView 展示。setEditStrategy 控制编辑策略，submit 提交修改。模型封装数据库操作，界面层无需直接写 SQL。

5. 事务与并发

事务保证多个操作的原子性，回滚可恢复一致状态。并发访问需注意连接线程归属，Qt 要求数据库连接仅在创建线程使用。写密集型场景使用事务批量提交，显著提升性能。

6. 数据迁移与维护

schema 变更通过迁移脚本管理，版本化执行保证升级可靠。索引优化查询性能，分析执行计划定位瓶颈。备份恢复策略保护数据，定期验证恢复流程。

7. 错误处理与最佳实践

SQL 错误通过 lastError 获取，统一记录与展示。参数绑定杜绝注入，资源及时释放。复杂查询封装为数据访问层，业务逻辑与数据库细节解耦，详见架构设计篇。

本节小结

Qt SQL 模块在底层驱动与高层模型之间提供了完整分层，SQLite 适合本地轻量存储，客户端服务器数据库满足多用户需求。参数绑定保障安全，事务保证一致性，模型视图集成简化界面绑定。数据访问层与业务逻辑解耦、schema 迁移版本化、索引与事务优化查询，是数据库应用的长期维护之道。
